# 회로 패턴 의도 카탈로그 (연결 서명 기준)

회로 해석(소자가 무슨 역할로 어떤 영역에서 일하도록 설계됐는가)에 쓰는 패턴 지식 모음. 패턴은 **소자·회로 이름이 아니라 연결 서명**으로 찾는다.

## 규칙

- **해석은 연결과 원문만으로 한다.** netlist 연결(`netlist`·`ports`·`supply_nets`)에서 서명을 찾고, 의도와 수치는 원문(`assets/*/sources/`)으로 확인한다. topology 메타데이터(`device_roles`·`symmetry`·`sizing_roles`·`compensation`·`_comment` 류)는 근거로 쓰지 않는다 -- 그 태그가 틀렸는지를 이 카탈로그로 검사하는 쪽이다.
- **analog-grammar skill(`skills/analog-grammar/assets/idioms.py`)은 쓰지 않는다** -- 그 `m_diode_cascode` idiom은 P-1의 source 쪽 소자를 CASCODE로 부르며 승인 해석(triode 레벨 시프터)과 다르다(사용자 결정 user_decisions G-1, 2026-10-16).
- **topology 태그 키(`device_roles`·`symmetry`·`sizing_roles`·`compensation`)를 근거로 쓰지 않는다**(analog-grammar 근거로 만든 태그, 제거 예정 -- 사용자 결정 user_decisions G-1, 2026-10-16). 설계 의도 기록은 topology 최상위 `_design_intent` 주석 키(`_pattern` + 소자별 문자열)에 둔다.
- **엔진이 쓰는 패턴 정의는 해당 계획이 정본이고, 이 카탈로그는 그 정의를 따른다**(P-1 = `docs/01-plan/features/headroom-chain.plan.md` v0.6(승인됨 2026-10-16) N3.2-1 적층 후보 정의, N3.2 포화 불가 판정·보고, N3.3 선언 triode 소자의 검사). 계획 정의가 바뀌면 이 문서를 같이 고친다.
- **새 패턴은 아래와 같은 칸을 같은 순서로 채운다**: 연결 서명 / 변형 / KVL / 의도된 영역 / 목적 / 엔진에 주는 결과 / 사례 / 출처 / 확신도. 칸을 비우지 않는다(모르면 '확인 안 함'으로 적는다).
- **소자·회로 이름은 '사례' 칸에만** 쓴다. 다른 칸은 단자·넷 관계로만 적는다.
- 출처 칸에는 보관 폴더 경로와 쪽(그림·열·행) 번호, 웹 링크를 같이 적는다. 원문 보관 규칙은 `assets/library/sources/README.md`.
- 엔진에 주는 결과가 아직 구현되지 않았으면 그렇다고 적는다(구현된 것처럼 쓰지 않는다).

## P-1. gate 공유 직렬 적층 (stacked diode / Sooch 셀 / self-cascode)

| 칸 | 내용 |
|---|---|
| 연결 서명 | headroom-chain 계획(`docs/01-plan/features/headroom-chain.plan.md`) N3.2-1의 적층 후보 정의와 같다(유도 N3.9 R3-a·R3-b·R3-c. 계획이 바뀌면 이 문서를 같이 고친다): 같은 kind의 MOS X, Y가 (a) gate 넷이 같고(G) (b) Y의 source 넷 = X의 drain 넷(중간 넷 M)이면 X(아래, source 쪽 소자)를 **적층 후보**로 본다. 중간 넷 M의 단자 수(직렬 여부)와 gate 넷 G의 종류(레일 포함)는 제한하지 않는다 -- 판정은 V(M)와 Y 상태만 쓰고 유도에 gate 넷 종류가 들어가지 않으며, 탐지·보고만 하므로 후보가 넓어도 판정이 틀어지지 않는다(R3-b·R3-c, 레일 gate 제외 없음). diode 조건은 서명에 없다. X.source = 기준 넷 R. 두 소자의 bulk·VT0이 같은지는 서명 조건이 아니라 VP 설명의 성립 조건이며 보고 칸에 적는다(R3-a). |
| 변형 | (V1) **위 소자 Y가 diode**(Y.gate = Y.drain = G): stacked diode·Sooch 셀·바이어스 셀. 응용 A(레벨 시프터): cascode 소자 C의 gate = G, 지켜지는 아래 소자 B의 source = R, B.drain = C.source. 응용 B(Sooch 미러 바이어스): C의 gate = M, B의 gate = R. (V2) **위 소자 Y의 drain이 출력**(Y는 diode 아님): self-cascode 합성 트랜지스터(두 소자가 긴 L의 소자 하나처럼 동작). |
| KVL | NMOS 기준(PMOS는 VSG·VSD로 부호 반전). 서명: **VDS(X) = VGS(X) − VGS(Y)** (G−R = VGS(X), G−M = VGS(Y)). V1 응용 A: **VDS(B) = VGS(X) − VGS(C)** (G−R = VGS(X), G−B.drain = VGS(C)). V1 응용 B: VDS(B) = V(M) − VGS(C)(B.source 기준). |
| 의도된 영역 | Y: V1은 포화(diode, VDS = VGS), V2는 포화 또는 선형(Sánchez-Sinencio p.21). **X: 강반전에서 triode가 필연** -- 유도: X 포화 조건 VDS(X) ≥ VGS(X) − Vth(X)에 KVL을 넣으면 VGS(X) − VGS(Y) ≥ VGS(X) − Vth(X) ⇔ VGS(Y) ≤ Vth(X). Y가 강반전으로 도통하면 VGS(Y) > Vth(Y)이다. **전제: 두 소자의 bulk가 같은 넷**(같은 kind·같은 모델 bin). 그러면 Y의 source(M)가 X의 source(R)보다 bulk에서 멀어 VSB(Y) ≥ VSB(X), body 효과로 Vth(Y) ≥ Vth(X)이므로 조건이 깨진다 → X는 triode. bulk가 다른 넷이면 Vth(Y) < Vth(X)가 될 수 있어 유도가 성립하지 않는다 -- LUT로 확인한다(서로 다른 L bin·짧은 채널 효과도 같음). **약반전·moderate에서는 경계 가능**: 약반전 포화 조건은 VDS > 약 3~4 UT로 Vth와 무관하므로 VGS(X) − VGS(Y)가 그보다 크면 X가 포화일 수도 있다 -- LUT로 영역을 확인한다. |
| 목적 | V1 응용 A: 지켜지는 아래 소자 B의 VDS를 X의 VGS로 정하고 기준 넷 R을 따라가게 한다(R이 움직여도 cascode gate G가 R 기준으로 같이 움직임). X의 W/L을 Y보다 작게 해 VDS(X)·VDS(B)를 정한다 -- Sooch: 제곱 법칙에서 X의 Z/L = 1/3이면 VDS(X) = VON(원문 명시). B의 VDS를 '최소 포화 경계'에 둔다는 것은 해석이다(확신도 중간 -- 사례 원문에 명시 없음). V2: 합성 트랜지스터의 출력 컨덕턴스 감소. |
| 엔진에 주는 결과 | R-3(사용자 결정 C-3, H-A의 U-H13·U-H15. headroom-chain 계획 N3.2·N3.3, 유도 N3.9 R3-a·D-1). **엔진은 적층 후보 X를 자동으로 면제하지 않는다** -- 면제 집합은 spec 선언 triode(DEC-88, `DcInputs.linear_devices`)뿐이다(N3.2-3). (1) **포화 불가 판정**(N3.2-1, U-H13 (가)): 그 동작점에서 Y가 전도하고 max_{X의 밀도·L ∈ LUT 범위} [VGS(X) − VDsat(X) − tol_VDsat(X)] < VGS(Y)이면 X를 '이 Y 상태에서 X 크기로는 포화 불가'로 판정한다(VSB(X)는 동작점 값, VDsat는 VDS(X) = VGS(X) − VGS(Y)에서 읽는다, tol = 봉인 7 `tol_VDsat`, 새 문턱 없음). **성립 조건**: Y 상태(VGS(Y))와 X source를 동작점 값에 고정한 판정이다. Y 크기 변화로 VGS(Y)가 달라지는 경우와, X 크기 변화가 V(M)·Y의 VSB를 움직여 VGS(Y)가 다시 바뀌는 결합(VSB 결합)은 포함하지 않는다(N3.9 D-1). 그래서 불가능 증명이 아니고 쓰임은 둘뿐이다 -- (가) **봉인 7 거부 사유 세분**: X가 봉인 7을 어긴 동작점에서 판정식이 성립하면 일반 포화 위반 대신 '이 Y 상태에서 X 크기로는 포화 불가, triode 선언 필요'(X·Y 이름, VGS(Y), 판정식 좌우 값, VP 보고 칸)를 단다. 거부라는 결과는 같다. (나) **출발 단계 기록**: 사다리 칸마다 R-1′ 조정 뒤 동작점에서 같은 판정을 기록만 하고 멈추지 않는다(U-H15 (가)). 선언 triode인 X와 Y가 꺼진 경우는 판정하지 않는다(Y가 꺼지면 일반 포화 판정). 핀치오프 VP 비교는 판정이 아니라 보고 칸이다(X-11). (2) **선언 triode 경로**(N3.3): triode 허용은 사용자가 spec에 선언한다(DEC-88). 선언된 X는 봉인 7·입력 창·스윙의 포화 판정에서 빠지고, 대신 (i) LUT 영역 기록 (ii) **LUT 정의역 게이트**(fail-closed: 동작점 VDS가 [LUT on_mask 유도 VDS 하한, VDS 축 끝] 안이고 그 VDS에서 VGS 역산이 정의되어야 한다. 어기면 소자 이름을 단 모델 정의역 사유로 거부하며, 봉인 7 포화 위반으로 분류하지 않는다) (iii) 지켜지는 소자 검사(X의 VGS가 VDS를 정하는 소자 Z는 일반 포화 판정을 받는다. Z가 없거나 Z도 선언 triode이면 기록만 한다)를 받는다. (3) **R-1′ 사슬 제약**(N3.1, 제약 그래프 + Bellman–Ford 양의 순환 판정): 선언 triode X의 변 항 = LUT on_mask 유도 VDS 하한, 선언되지 않은 적층 후보 X는 일반 전도 소자와 같은 항 VDsat + tol이다(포화 불가 판정이 나와도 항을 바꾸지 않는다). SPICE 오라클도 선언 triode만 포화 판정에서 빼며(N3.6, U-H16), 선언되지 않은 적층 소자가 '포화 아님'이면 일반 FAIL이다. **계획 승인됨(v0.6, 2026-10-16) -- 구현 전.** 지금 엔진은 이 패턴을 알지 못한다. |

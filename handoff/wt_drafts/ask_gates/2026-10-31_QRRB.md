## 질문 문언 (요지)
- **RR-3**: O-206은 ICMR 창 안 점별 기능 기준을 AC `gain_ss_db` 절대값(예)으로 두었습니다. 원칙 3·DEC-67(ICMR = DC 양)과 문언이 충돌하고, 출력 범위에는 같은 꼴의 기준(P:702 (b) 범위 끝 증분 DC 이득, 기준점 대비 선언 허용 저하, 엔진 DE-1 (e))이 이미 있습니다. 실측: oracle `.tf`(DC 증분)와 `.ac` 차는 중앙 0.003 dB, 창 끝 차 ≤ 1.7 mV입니다. 엔진 (d)는 (a)와 같은 계산입니다(반복 0, LUT 30 + LU 1).
  - (d-1) **권고**: 점별 증분 DC 이득 + 출력 범위 (b)와 같은 판정 꼴(기준점·허용 저하 선언), 엔진 = DE-1 (e) 같은 순수 함수, 엔진 창 끝 상시 '추정' + oracle 최종, 끝 찾기 = K_max bisection 또는 격자 사건점 + bisection(계획 개정에서 고름). 조건 여섯: ① 엔진 측정 구성 식 = oracle servo 식 ② 상시 '추정' ③ `graph.ss_nodal` writer 선행 ④ 용량 전용 노드 측정 구성 = 정의 불능 정지(지금 0/13) ⑤ O-206 '(반복 0)' → 근 찾기 K_max 상한(원래 취지와 다름) ⑥ graph 필드 둘(출력 범위 끝·ICMR 점)의 상태 축 기록. 조건 ①~③은 O-205 R0 영역 행 창에도 겁니다. 4/13 회로(nmcnr·ngcc `icmr_v`, current_reuse·sf_pushpull `icm_margin_v`)는 기준점·허용 저하 선언이 필요합니다.
  - (d-2) 증분 DC + 절대 기준 ⚠ 판정 꼴 둘·축 기록.
  - (a) O-206 원안 ⚠ 원칙 3·graph 규칙 3.
  - (b) 영역 행만 ⚠ fail-open.
  - (c) 점별 Newton ⚠ 원칙 1 SPICE식 반복.
  - C4 '점별 KCL 잔차 > tol_I면 추정 불능'은 판별력이 없어 기각합니다.
- **RR-5**: O-207에서 K3 (나) argmax 시도점을 LA-1 9 (c) 측정에서 뺐습니다. 그런데 P:1954 (c)는 'S·F 시도점 규칙(J1)을 사용자가 정한다'고 적습니다. (가) **권고**: O-207 답을 근거로 J1 = (가) 출발 구간 아래 끝으로 닫고, LA-1 9 (c) 두 규칙 문구 삭제, 원래 취지와 다름에 K3·J1·LA-1 9 (c) 추가 / (나) J1 열린 채 (나) 재정의 ⚠ 정의할 정점 없음 / (다) VGS 0 마디 제외 정점 ⚠ 정의 선택 산물.

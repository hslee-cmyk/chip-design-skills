# 점검 파일 -- O-208 재검토 묶음 C: RR-4 off 소자 VGS < 0 처리(O-202 (2)·O-203)와 LUT 단자 전류·VGS < 0 축 확장

## 질문 문언 (요지)
- **RR-4**: O-202 (2)는 VGS < 0 off 소자를 '단조성 구간 [0, I_off]'(I_off = LUT 채널 전류)로 두었습니다. 그런데 실측해 보니 pfet는 끄는 방향으로 단자 누설이 늘어납니다(GIDL -- L 1 µm에서 VSG 0일 때 0.19 pA, −0.6 V일 때 2.5 pA. 접합은 1.1 fA뿐). 그래서 I_off는 물리 상한이 아닙니다. O-203의 'VGS 0 마디 = 누설점 아님'도 채널 기준에서만 맞습니다.
  - (가) **권고**: 구간을 삭제하고, VGS < 0 off 소자가 있는 평가점은 **그 점을 E-0으로 정지**합니다. 판정은 O-h(`judged_by` → oracle)가 맡습니다.
    - **대가**: offset-trim off 스위치는 보통 VGS < 0입니다(연결 구조 추론, 확신 중간 -- 스위치 게이트 전용 넷·싱크 셀 source가 레일 위 내부 노드·모든 코드에 off 스위치). 그렇다면 offset-trim 평가점이 엔진에서 정지합니다.
    - 해소: LUT 단자 전류 열 + VGS < 0 축 확장(아래 (c)와 R7 (다) 순방향 접합)을 **offset-trim TR card 착수 조건**으로 둡니다(원칙 33).
    - 지금 13 spec은 off 선언 0이라 동작 변화는 0/13입니다.
    - O-203은 문언을 '채널 동작점 -- 비채널 누설(GIDL·접합)은 LUT 밖'으로 고치고, 정의역 경계 활성 기록을 둡니다.
  - (b) 그 소자 누설만 빼고 점은 계속 ⚠ O-202가 기각한 O-d′·G2-d(낙관)와 모순 -- 권고 금지.
  - (c) LUT 단자 전류 열 + VGS < 0 축을 지금 당김. 물리 최선이지만 LUT 재생성 비용이 들고, 소비자가 생길 때가 원칙 33에 맞습니다.
  - (나′) 접합만 PDK 접합 파라미터 닫힌 식으로 ⚠ 지배 항 GIDL 누락.
  - (나″) BSIM GIDL 식 엔진 구현 ⚠ 원칙 1 SPICE 모델 복제.
  - (다) 문언 정정만 ⚠ 물리 근거 오류.

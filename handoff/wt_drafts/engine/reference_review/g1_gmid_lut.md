## 1. 발견 목록

### G1-01 VGS 축(과 VDS 축) 보간이 reference 권고(저장 도함수 cubic-Hermite)와 다르다 -- 정확도·tol_V·SLSQP 연속성 동시 손해
- **reference**: LC 7.1(104~110) "이미 있는 gm을 cubic-Hermite 보간의 기울기 입력으로 그대로 재사용 … 50mV처럼 성긴 VGS 격자에서도 오차 <0.01%". LC 7.2(116) "VGS | cubic-Hermite (저장된 gm을 기울기로 사용)". LC 1(14)·3(62~63) "0.025V보다 크게 벌리지 않는다". GM §3.2(209) "interpolation(cubic)으로 소비".
- **새 엔진**: LUTC 4절 표 `op_point`(153) "3축 다중선형 보간 1회: lnID·lnGM·lnGDS 로그공간", `vgs_for_gm_id`(155) "gm/ID 격자 값에서 선형 역보간 … `op_point(vgs).gm_over_id` 와는 칸 안에서 다를 수 있다", LUTC 6절(옛 `_multilinear_interp` AST 해시 복사 고정), M6 3절(99) "다선형 보간은 칸 안에서 선형이므로 …". LUT VGS 간격은 37.5 mV로 LC 권고 25 mV보다 성기고, RG 5절도 49점을 유지한다. 옛 코드 자신도 "VGS 격자를 충분히 촘촘히(예 10~25mV) 스윕하면 선형 보간도 실용적"(legacy/sizing_recipe.py 267~271)이라 조건부였는데 그 조건이 깨져 있다.
- **문제 유형**: 잘못(알고리즘) + reference·LUT 격자 충돌.
- **심각도**: 높음.
- **근거 [실측, VGS 축 LOO, 강반전 분지, 켜진 점]**: ln ID를 VGS로 보간한다. 기울기는 d lnID/dVGS인데, 이 값은 정확히 gm/ID이고 이미 저장돼 있다.

| 지표 | nmos 선형(현행) p50 / p99 / max | nmos Hermite p50 / p99 / max | pmos 선형 p50 / p99 | pmos Hermite p50 / p99 |
|---|---|---|---|---|
| ln ID 오차를 VGS로 환산(= id_equivalent의 VGS 축 성분) | 1.25 / 3.83 / 5.21 mV | 0.0026 / 0.042 / 0.11 mV | 1.49 / 3.44 mV | 0.0068 / 0.037 mV |
| 칸 중앙 gm/ID 상대오차 | 0.22 % / 2.1 % / 4.0 % | 0.0005 % / 0.021 % / 0.056 % | 0.43 % / 2.1 % | 0.0015 % / 0.018 % |

  VDS 축도 GDS/ID(= d lnID/dVDS)를 기울기로 쓰면 nmos p99 69.9 → 6.85 mV, pmos 36.7 → 3.22 mV로 줄어든다. 반면 VS 축은 기울기 열이 없어 선형 그대로 p99 3.3~3.5 mV이고, Hermite를 쓰면 이 축이 오차를 지배하게 된다.
  단조성도 확인했다. Fritsch–Carlson 조건 위반 칸은 nmos 0/126,361, pmos 0/104,125다. 그래서 LC 7.3(127)이 경고한 비단조 출력은 이 LUT에서 생기지 않는다.
- **부수 효과(현행의 결함)**:
  - (a) 같은 칸에서 op_point의 gm/ID와 역산의 gm/ID가 다른 곡면에서 나온다(LUTC 155가 스스로 인정함). 이 차이가 봉인 2의 잔차와 gm_id_inverse tol(셀 p50 222 mV, LUTC 5절)에 섞여 들어간다.
  - (b) gm = ID·gm_id에서 ID와 GM을 따로 보간하므로 gm ≠ d(보간 ID)/dVGS다. 값과 미분이 서로 다른 모델이 된다.
  - (c) 격자선에서 C0 꺾임이 생긴다. SLSQP(기울기 기반)와 격자 간격 FD 스텝이 이 꺾임을 할선으로 가로지른다(M6 99).
- **보강안**(MOD1):
  - (1) `_helpers_interp`에 축별 방법 표를 둔다. 기울기 열이 있는 축은 2점 cubic-Hermite, 없는 축은 선형이다.
    - VGS: y = lnID, 기울기 = GM/ID. gm/ID는 그 다항식의 미분 p′(VGS)로 **정의**한다. 그러면 op_point·gm_id_curve·역산·gm이 모두 한 곡면이 된다.
    - VDS: 기울기 = GDS/ID.
    - VS: 선형(G1-05의 GMBS 열이 생기면 기울기 = −GMBS/ID).
    - lnGDS의 VGS 방향은 기울기 열이 없어 선형으로 둔다.
  - (2) LUTC 6절의 `multilinear_interp` AST 해시 복사 고정을 '옛 함수 = 기대값 비교 참조'로 바꾼다. 이렇게 하면 옛 엔진과 비트 동치가 아니게 되므로 동치 test는 격자점에서만 한다.
  - (3) 역산(`vgs_for_gm_id`, D-1 (라)의 `vgs_for_current_density`)은 같은 Hermite 칸 안에서 근을 찾는다. 3차식의 단조 구간에서 bisection을 쓰고, 상한은 K_max다.
  - (4) tol_V 표는 운영 보간과 같은 방법으로 다시 계산한다(G1-06).
  - (5) 로드 시 칸마다 Fritsch–Carlson 검사를 하고, 위반 칸은 실패로 기록한다(비단조 곡선 → 격자 전수, P 476과 같은 처리).
- **누가 정하나**: 엔진 내부(MOD1 알고리즘). 다만 LUTC r2가 확정 계약이므로 계약 개정 사실은 보고한다. VGS 간격을 25 mV로 재생성하는 대안도 있지만, Hermite만으로 재생성 비용 0에 100배 이상 줄어들어 필요 없다.
- 대원칙 충돌: 없음. 기울기는 LUT 열이고 새 상수는 0이다.

### G1-02 접합 용량(CJD·CJS)이 엔진 MNA·기생 루프에 없다 -- reference 기생 반복의 핵심 항 누락, SPICE와 불일치
- **reference**: GM §4.2(274~284) "폭 W가 커지면 드레인 접합 커패시턴스 CJD가 출력부하에 병렬로 … Weak inversion 깊숙이 가면 W가 너무 커져 CJD가 Co를 압도 → ID가 다시 증가로 반전. 최적점은 moderate inversion 중앙". GM §4.2(286) transistor partitioning으로 접합 용량 약 30 % 감소. GM §12.1(771) extrinsic 성분(접합 Cbse/Cbde)은 레이아웃 의존. 부록(989) "기생 CJD를 C에 더해 3~4 반복 수렴".
- **새 엔진**: M15 2.8(110) "접합 용량(cdb·csb)은 LUT에 없어 MOD5가 별도 열로 보고한다"(MNA 스탬프 3.3에 cdb·csb 없음). P N3.8(516) "LUT에 없는 접합용량 때문에 못 세는 노드는 … 별도 열로 보고". RG 5절(230)은 CDD·CSS를 '(선택) D6'으로 둔다. 반면 ORC C3(99)은 `diffusion`이 선언되면 SPICE 넷리스트에 `ad=as=ad_per_w_m*finger_w`, `pd=ps=finger_w+pd_extra_m`을 `m=n_fingers`로 넣는다. 이 방식은 finger마다 확산을 따로 두므로 공유 확산이 없다.
- **문제 유형**: 빠짐.
- **심각도**: 높음.
  - `diffusion`을 선언한 합격 실행이면 SPICE 쪽만 접합 용량을 가진다. 그래서 엔진이 PM·UGF·GBW를 낙관적으로 예측하고, free 모드 스펙 판정(UD 129, 합격 조건 (i))에서 떨어질 수 있다.
  - 선언하지 않으면 양쪽 다 빠져 합격하지만 실리콘과는 어긋난다.
  - 게다가 전력 최소화 목적은 gm/ID를 키우는 쪽(약반전, 큰 W)으로 밀어붙인다. 그런데 이를 되돌리는 항(CJD)이 없어서 GM §4.2가 말하는 moderate 최적점이 front에서 나타나지 않는다. [추측: library 회로에서 얼마나 크게 나타나는지는 미측정]
- **보강안**:
  - (1) MOD5 `ss_linearize`에 `cdb`(d–b)·`csb`(s–b)를 스탬프한다. 값의 출처는 둘 중 하나다.
    - (a) RG D6의 CDD·CSS 열(드레인·소스 AC 여기 Y22·Y33 허수부, 부호 보존. LC 7.3 156~162의 op-info 금지 원칙을 그대로 따름)에서 CGD·CGS를 뺀 값.
    - (b) PDK 모델카드의 접합 파라미터(CJ·CJSW·MJ·MJSW·PB 계열)를 `core.pdk_decl`에서 읽고, 역바이어스(봉인점 VDB·VSB)와 확산 기하로 계산.
  - (2) 확산 기하는 **ORC와 같은 규칙 한 곳**에서 읽는다(지금은 ORC `diffusion` 입력뿐이다). MOD7이 nf·행 구성을 정한 뒤 공유 확산(GM §4.2 partitioning)을 반영할지는 그 규칙의 선택지로 둔다.
  - (3) DEC-71 (4)(d) 층 0 고정점과 GB5 `C_out,total`(P 498), 슬루 `C_k,total`(P 500)이 이 필드를 읽게 한다.
  - (4) MOD8 W_request 루프에서 nf가 바뀌면 이 필드가 무효화되는 입력 버전에 nf를 넣는다.
- **누가 정하나**: 사용자 결정이 필요하다. 합격 실행에서 접합 용량을 넣을지, 기하 규칙(finger마다 따로 / 공유 확산)과 값 출처((a) LUT 열 / (b) PDK 식)를 무엇으로 할지는 방법론 선택이다. 스탬프·필드 배선은 엔진 내부다.
- 대원칙 충돌: 없음. 단 (b)는 확산 연장 길이를 PDK 규칙에서 읽어야 하고, 지금 ORC의 `ad_per_w_m`도 근거 선언이 필요하다(LCS 25행 "0.5·W 관례"는 근거가 아니다).

### G1-03 VDsat 정의가 세 곳에서 갈린다(합격 판정 = BSIM VDSAT, 엔진 봉인 7 = 미정, MOD1 계약 = 만들지 않음)
- **reference**:
  - GM §2.7(167~171) "VDsat ≈ 2/(gm/ID) … short-channel에서 과대추정 … 최종은 반드시 LUT/시뮬레이션".
  - GM §9.3(620~622) "2/(gm/ID)와 EKV 둘 다 short-channel에서 과대추정 — BSIM 추출값이나 LUT 직접 조회를 우선".
- **새 엔진**:
  - ORC 49·109: 합격 = `VDS − VDSAT ≥ sat_margin_V`, VDSAT = BSIM op `@m[vdsat]`.
  - P N3.6 봉인 7(450) "VDS − VDsat(DF-25 유도 규칙)"이고, P DF-25(969)는 "교체 식은 6b design이 LUT의 (ID, gds, VDS) 곡선에서 정한다".
  - G7 117·142는 `lut.vdsat`을 창 계산과 봉인 7에서 소비한다.
  - 그런데 LUTC 8절(246)은 "`vdsat`: 규칙 미확정·**소비자 없음** → 만들지 않음"이다.
  - RG 5절(225)은 VDSAT 열을 '권고(D6)'로 둔다.
- **문제 유형**: 충돌(설계 문서 사이, 판정 장치와 엔진 사이). reference에도 빠진 것이 있다. GM §2.7은 short-channel 과대추정만 적었는데, 약반전에서는 2/(gm/ID) ≈ 2nUT ≈ 60~80 mV라 포화에 필요한 수 UT(약 100 mV)보다 작아 **과소추정**한다. P DF-25도 "약반전 VDsat와 다르다"고 적어 두었다.
- **심각도**: 높음. 합격 조건 (ii) '전 MOS 포화'는 BSIM VDSAT으로 판정한다. 엔진 봉인 7이 다른 정의를 쓰면 엔진이 통과시킨 점이 SPICE에서 '포화 아님'으로 떨어지거나, 반대로 엔진이 너무 보수적이 되어 헤드룸을 낭비한다.
- **보강안**:
  - (1) RG D6의 VDSAT 열(op 값이라 추가 비용 거의 0, RG 1.4 실측 0.040~0.63 V)을 채택한다.
  - (2) MOD1 `vdsat.py` = VDSAT 열을 L 앵커 한 장에서 (VGS, VDS, VS) 보간한 값으로 정의해, 판정 장치와 같은 정의를 쓴다.
  - (3) LUTC 8절의 '소비자 없음'을 G7 소비로 정정한다.
  - (4) 열이 생기기 전까지는 봉인 7을 '정의 미확정'으로 표시하고, 2/(gm/ID)를 대체 정의로 몰래 쓰지 않는다.
  - (5) GM §2.7에 약반전 과소추정을 덧붙이도록 reference를 정정한다.
- **누가 정하나**: VDSAT 열 채택은 사용자(RG D6, 생성기 수정 D7). 봉인 7 정의를 판정과 같게 맞추는 것은 엔진 내부(UD 129의 합격 정의에서 유도).

### G1-04 GB4 '블록 gain 상한'을 소자별 gm/gds 최대로 넣으면 상한이 아니다(거짓 INFEASIBLE 위험)
- **reference**:
  - GM §13.7(946~957) "`"gain"`은 `gm/gds`(intrinsic gain)를 최대화할 뿐 `ro` 자체를 최대화하지 않는다 … M202 실측: `"gain"`의 `ro=129938Ω`이 진짜 최댓값 `ro=250266Ω`의 절반 … `gm/gds` 최대화와 `gds` 최소화는 서로 다른 축".
  - GM §2.5(150~157) intrinsic gain과 Early 전압은 상충한다.
- **새 엔진**:
  - M15 3.5(213) "블록 국소 모델에 격자 전 범위(L 앵커, VDS, 레일 안 VS, 폭 슬라이스)의 **gm/gds 최대**를 넣은 상한".
  - P N3.7(477)은 "max(블록 i의 국소 소신호 모델 gain) over gm_id 격자 × L 앵커 × W4 창의 VDS × y 가능역"(결합 최댓값)이다.
- **문제 유형**: 잘못(M15 문구 기준). 충돌(M15 대 P).
- **심각도**: 높음(조건부 -- M15 문구대로 구현될 때). 블록 gain = Σ gm 기여 / Σ gds 부하에서 부하 소자의 기여는 gds/ID(같은 ID에서 ro)다. 소자마다 'gm/gds가 최대인 점'을 꽂으면 부하의 gds/ID가 최소가 되지 않는다. 그러면 계산값이 실제 달성 가능한 gain보다 작아져 상한이 아니게 되고, 탐색 전 INFEASIBLE_TARGET 거짓 정지가 생긴다. 이 정지는 합격 시험에서 그 회로를 통째로 실패시킨다.
- **보강안**(MOD5 `achievability.py`): 상한을 **완화 문제의 최댓값**으로 정의한다. gm이 이득 분자에 들어가는 소자는 그 소자의 격자 가능역 최대 gm/ID를, gds가 분모에 들어가는 소자는 최소 gds/ID를 **독립으로** 고른다. 그 블록 국소 모델 값은 결합 최댓값 이상이므로 진짜 상계다. 같은 소자가 분자와 분모에 함께 들어가면 각 항에 그 소자의 극값을 따로 넣는다(완화라 상계가 유지됨). 행 표에는 극값을 낸 격자 조건을 소자마다 따로 기록한다. M15 3.5 문구를 이렇게 정정하고, test는 '임의 격자 표본의 실제 국소 gain ≤ 상한'(표본 수 = `dof_rank_sample_count`)으로 한다.
- **누가 정하나**: 엔진 내부. reference의 role 라벨("gain"/"load")은 쓰지 않는다. 기여 위치(분자·분모)는 국소 모델 스탬프에서 유도하므로 topology에 종속되지 않는다.

### G1-06 tol_V(LOO)는 '격자 간격 2배 LUT'의 오차라 실제 칸 오차보다 크게 나오고, 보간 방법이 바뀌면 다시 재야 한다 -- [결정 재검토 제안]

- **새 엔진**:

  - (4) 환산을 채택하지 않으면 지금 정의를 유지하되, '보수 배수 약 2^p'를 결과 JSON에 표시한다.

### G1-10 reference 오류: Miller Cm 재계산 식(식 8.15)에 1/2이 빠졌다
- **reference**: GM §6.4(436~439) `Cm = (NDP/Z) · [ C1+C2 + sqrt((C1+C2)² + 4·C1·C2·Z/NDP) ]`.
- **근거(유도)**:
  - GM 416행 ωNDP = gm2·Cm/[Cm(C1+C2)+C1C2]와 gm2 = Z·ωT·Cm(=Z·gm1)에서 NDP = ωNDP/ωT = Z·Cm²/[Cm(C1+C2)+C1C2]이다.
  - 이를 정리한 2차식 Z·Cm² − NDP(C1+C2)·Cm − NDP·C1C2 = 0의 양의 근은 **Cm = (NDP/(2Z))·[C1+C2 + √((C1+C2)² + 4·C1·C2·Z/NDP)]**다.
  - 같은 절의 예제(441, C = 3 pF, Cm ≈ 1.41 pF)도 그렇다. C1 → 0이면 1/2이 있는 식은 0.4/2·2·3 pF = 1.2 pF(+C1 기여)로 1.41 pF와 맞고, 없는 식은 2.4 pF 이상이 되어 자기 예제와 모순된다.
- **새 엔진**: Z·NDP 키는 회로 전용 키로 금지됐고(design_spec_format 145, 대원칙), GB5는 MNA 극점·영점 일반 규칙이다(P 496). 그래서 직접 사용처는 없다.
- **문제 유형**: reference 오류.
- **심각도**: 중간(엔진 직접 영향은 낮다. 하지만 GB5 일반 규칙 test의 손계산 oracle이나 층 0 초기 Cm 추정에 이 식을 옮기면 Cm이 2배가 된다).
- **보강안**: GM §6.4 식 정정(1/2 추가)과 유도 한 줄을 덧붙인다. GB5 test의 손계산 oracle은 이 유도로 만든다.
- **누가 정하나**: reference 정정은 문서 소유자(사용자 승인). 엔진 내부 영향은 없다.

## 3. 상위 5개 권고

1. **G1-01**: MOD1 VGS 축(과 VDS 축)을 저장 도함수 cubic-Hermite로 바꾼다. y = lnID, 기울기 = GM/ID(VDS는 GDS/ID)이고, gm/ID는 그 다항식의 미분으로 정의해 op_point·역산·gm을 한 곡면으로 만든다. 실측으로 VGS 축 오차가 100~500배 줄고(ln ID→VGS p50 1.25 mV → 2.6 µV, gm/ID p99 2.1 % → 0.02 %), 단조성 위반은 0이며, 재생성 비용도 0이다. LUTC 6절 AST 복사 고정은 '참조 비교'로 바꾼다.
2. **G1-02**: 접합 용량 cdb·csb를 MOD5 `ss`·MNA·층 0 기생 고정점·GB5 C_total·슬루 C_k에 넣는다. 확산 기하 규칙은 SPICE 오라클 `diffusion`과 한 곳에서 같게 둔다. 합격 실행에서 접합 용량을 넣을지와 출처(LUT CDD·CSS 열 / PDK 접합 식)는 사용자가 정한다.
3. **G1-03**: VDsat을 판정 장치와 같은 정의(BSIM VDSAT LUT 열, RG D6)로 통일한다. LUTC 8절 '소비자 없음'은 G7(봉인 7·창)과 충돌하므로 정정한다. 열이 생기기 전에는 봉인 7을 '정의 미확정'으로 표시한다.
4. **G1-04**: GB4 블록 gain 상한을 '소자별 gm/gds 최대'가 아니라 완화 극값(분자 소자 최대 gm/ID, 분모 소자 최소 gds/ID를 독립으로)으로 정의한다. M15 3.5 문구를 정정하고 '표본 국소 gain ≤ 상한' test를 둔다. 함께 G1-08의 '격자 끝 극값 → LUT 범위 한계' 분류를 넣는다.
5. **G1-06·G1-07**(결정 재검토 제안): tol_V를 운영 보간 방법과 같은 방법·차수 환산(2^p)으로 다시 정의하고 SPICE 칸 중앙 표본으로 검증한다. W 허용오차 창은 '실효 = max(tol_V·gm/ID, 격자/(2·finger_w))'로 보완한다. G1-01을 채택하면 지금 창이 거의 모든 폭에서 비게 된다(gm/ID 20에서 finger_w_crit 약 48 µm).

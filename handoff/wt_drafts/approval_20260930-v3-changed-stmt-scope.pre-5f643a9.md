## 범위 설명

**판정 기준 적용 범위 축소(약화) 승인.** design 05 §10 V3 ①·계획 N4.2 V3의 대상 단위 'AST 해시가 바뀐 def(본문 전체)'를, 해시가 바뀐 기존 def에서는 아래 '덮는 대상'으로 좁힌다(DEC-40 -- 약화는 매 건
사용자 승인). 정의의 정본은 spec card `20260930-v3-changed-stmt-scope` 계약 1이다.

덮는 대상(해시가 바뀐 기존 def -- base와 문장 단위로 맞춘 결과): 바뀐 문장(새·옮긴·들여쓰기만 바뀐 문장 포함), 머리가 바뀐 복합문의 자기 필드, 이 영역과 삭제 지점을 감싸는 제어문, 바꾸거나 지운
문장 자리 바로 뒤 문장, 바뀌거나 지운 문장이 바꾸는 이름(대입·삭제 대상 이름, 속성·첨자 대입과 메서드 호출의 맨 앞 이름)을 **같은 블록 뒤쪽**에서 읽는 문장 -- 반복문 본문이면 그 본문의 모든 문장 --,
def 머리가 바뀌면 그 자기 필드(기본값·데코레이터 인자·주석)와 바뀐 매개변수를 읽는 문장, 그리고 항상 `early_return`(그래서 바뀐 def에 닿는 test가 없으면 항상 FAIL). 새 def는 본문 전체(지금 그대로).

**놓치는 것(이 승인이 받아들인 약화)**: 해시가 바뀐 기존 def에서 ① 바뀌지 않은 문장의 기존 test 강도(대상 밖 변이는 실행하지 않는다), ② 바뀌거나 지운 문장이 바꾼 값이 **다른 블록**(바깥 블록,
다른 절, 뒤 복합문의 안쪽 블록)에 있는 바뀌지 않은 문장으로 흐르는 경우 -- 블록 끝에서 지운 절의 뒤 영향 포함, ③ 값이 이름을 **두 단계 이상** 거쳐 흐르는 경우 -- 매개변수 값이 다른 이름을 거쳐 흐르는
문장, 호출한 함수 안의 부작용 포함. 같은 블록 안에서 이름 한 단계로 흐르는 문장은 위치와 무관하게 대상이다.

재측정 수치(card '작성 전 실측', 넓힌 규칙, gate `master` `0f23786`에서 독립 프로토타입으로 다시 잼): B26-1 card v4 모의 head 대상 변이 2,442 → **301**(승인 당시 정의 235), 시간 25.1분 ~ 16.0 h,
현실 하한 **0.89 h**, 미실행 줄 대상 변이 **9**. 승인 질문의 228은 옛 시뮬레이션 head(2,472 → 228, 넓힌 규칙 294, 현실 하한 약 19 h → 0.9 h, 미실행 줄 대상 변이 306 → 9)의 값이다 --
그 뒤 B26-1 card가 v4(사이트 10·14를 B35로)로 바뀌어 301이 정본이다(넘기기 전 review2 head면 330).
P9 실제 28 → 12, B34 좁힌 초안 55 → 10(둘 다 승인 당시와 같음). 적대 사례 재측정에서 사례 11·14는 대상에 든다(덮임). 지금 규칙보다 더 놓치는 사례는 ②·③ 안의 것뿐이다(사례 1c·4b = ③, 15 = ②).

덮는 것(그 밖):

* 데코레이터 변이가 소스에 반영되지 않던 `_replace_def` 결함 수정(첫 데코레이터 줄부터 치환) -- 강화(거짓 생존 제거, 진짜로 사는 데코레이터 변이는 드러난다).
* 새 redteam 케이스 `attacks/35-v3-changed-scope/`(D-18 배정 번호, rt.py 동작 추가 없음 -- `20260930-v3-exempt-binding`의 `out_jsonl` 관찰 사용). 다른 블록 사용이 대상 밖임을 고정하는 control 단계 포함
  (규칙을 다른 블록까지 넓히는 것은 별도 card·별도 승인).
* 문서: design 05 §10 V3 행 ①, 계획 N4.2 V3 행 대상 문구, `mutate_changed.py` 모듈 docstring ①.

덮지 않는 것:
* V3 연산자 집합·인벤토리·면제 규칙(면제는 `20260930-v3-exempt-binding`). 두 규칙 공통의 기존 한계(bool·문자열·이름·예외 종류 변이 없음, 모듈·클래스 수준 변경은 변이 0개)는 이 승인의 약화가 아니다(백로그 B46).
* Phase 3 이동 card G1의 옮긴 def 처리 -- G1 card 몫(G1 계약 4에 이 card 계약 1을 잇는 문장, 백로그 B45 -- G1 초안 v7에 반영됨).
* 대상 밖 변이를 판정 없이 실행하는 모드(`--report-untargeted`) -- 별도 card 후보.
* 판정 표(`plan_tables_hash` 입력) -- N4.2 V3 칸은 입력이 아니다. 바뀌면 이 승인이 아니라 `plan_tables` 승인이 필요하다.

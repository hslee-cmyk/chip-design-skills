### Q2. `balance_solve` 삭제(O-53 A3, OT N7.5 §10.5) 대 (3) 코드 상태별 DC 풀이
- 삭제 대상(실측 OTD:602-615): 코드 상태마다 '고정 기하 DC', 미지수 = 넷 전압 + V_id, 방정식 = KCL(LUT 순방향 전류) + 출력 균형, `newton_solve`. OT:873이 이것을 삭제 대상으로 고정했다.
- (3)의 '합성 회로의 코드 상태별 DC 풀이(… W·바이어스 고정 KCL …)'는 같은 대상(코드 상태, 고정 W, KCL)이다. 글자대로 읽으면 **모순**이다.
- O-176 Ⅳ(UD:1157)와 대조하면, 허용 예외는 'W′ 재봉인(E-0)'뿐이다. 금지 대상은 '대신호 양을 SPICE 대신 정확히 내려는 순풀이'이고, OT:663 완료 9의 grep 정의가 바로 '보정 구간 끝·끝 코드 포화'를 금지 대상으로 적었다. 코드 상태 풀이는 허용 예외에 들지 않는다.
- 해소: O-53 A3의 '−G⁻¹·ΔI'를 방식 무관으로 일반화한다. 코드 상태 c에서 trim 소자 스탬프 차를 봉인점 전압에서 계산하고(Δf_c = f_c(V_seal) − f_seal(V_seal), 전류원·컨덕턴스 모두 포함), 그 상태의 선형 G_c(= 봉인 `graph.ss_nodal` + 그 상태 trim 스탬프, off 소자 기여 0)로 ΔV_c = −G_c⁻¹·Δf_c를 1차로 전파한다. 이것은 선형 풀이 한 번이고, LUT 재조회·Newton은 없다. 정확값은 oracle `.dc` 코드 스윕이다. 이렇게 하면 O-53 A3·완료 9·DEC-103·O-202 (2) 꼴과 모두 맞는다.

## 2. 수학·물리 직접 검토

### 2.1 실현 정수화 -- 멤버별 계산 꼴(1-5): 맞음
독립 멤버 i의 선택은 다른 멤버의 e_j·m_j에 영향이 없다. 최적 max 값 M* = max_i (min e_i)이고, 멤버별 최소 e_i를 고른 벡터는 max를 M*로, 합을 Σ_i min e_i로 동시에 최소화한다. 어느 멤버라도 최소가 아닌 후보로 바꾸면 합이 엄격히 커지므로(동률은 x_i 반정수일 때뿐) 둘째 키까지 최소인 벡터 = 멤버별 최소 벡터이고, 반정수 동률은 셋째 키 Σm이 작은 m 하나로 정한다. 묶음 밖 소자(n = 1)에서 상대 오차 최소 = 절대 오차 최소 = round이므로 (a)·(b)가 한 규칙이라는 주장도 맞다. x < 1이면 후보 {1} 하나 -- max(round, 1)과 같다.

### 2.2 동률 끝 키 증명(1-6): 문언 거짓 -- M-1
문언 «서로 다른 두 후보 벡터는 Σm이 다르다(멤버별 후보 둘은 m이 다르고 …)»(40 :1363, history 기록 '서로 다른 후보 벡터는 Σm이 달라 언제나 하나로 정해짐', 42 D-FS1d '증명')은 거짓이다.
- 반례: 독립 멤버 A·B의 x_A = 2.5, x_B = 3.5 → 후보 벡터 (⌊x_A⌋, ⌈x_B⌉) = (2, 4)와 (⌈x_A⌉, ⌊x_B⌋) = (3, 3)은 서로 다르고 Σm = 6으로 같다(max·합도 같음).
- 결론(사전식 최소 벡터가 하나)은 참이지만 근거는 다른 논증이다: M* 고정 뒤 제약 'max ≤ M*'는 곱집합 제약이고 둘째·셋째 키(Σe, Σm)는 멤버(또는 파생 묶음)별 합으로 분리된다 → 단위마다 독립으로 (Σe, Σm) 사전식 최소를 고르면 되고, 한 단위 안 서로 다른 선택은 m(또는 m_d·(1 + Σk_j))이 달라 Σm이 다르므로 단위마다 하나 -- 따라서 전체가 하나. 위 반례의 두 벡터는 둘 다 (2, 3)에 셋째 키로 지므로 최소 집합에 들지 않는다.
- 같은 문단의 계산 꼴 «후보 ≤ 2 + 2·출력 수»(:1362)는 칸 안 선언 묶음이 **하나**라고 전제한다. 정합 칸 폐포(:1331)는 선언 미러 묶음 둘 이상(기준이 다른)을 한 칸에 모을 수 있고 그때 계산 꼴·후보 수·'도달 0' 단언이 정의되지 않는다. 위 분리 논증을 쓰면 묶음 여럿도 O(Σ 후보)로 같은 값이 나오므로, 수정은 문언 교체 + 다중 묶음 계산 꼴 한 줄이다(규칙·목적식 변경 0).
- 판정: Major(브리핑 기준 '동률 증명 포함 수학 오류'; 구현 결과는 바뀌지 않으나 design의 증명·단언 근거가 거짓 문장).

### 2.3 gate R 분포 환산(1-11): 맞음
한 끝 구동·먼 끝 개방 균일 RC 선 Z(s) = √(R/(sC))·coth(√(sRC)) = 1/(sC) + R/3 + O(s) -- 저주파 직렬 등가 R/3 맞음. 두 끝 접속 = 길이 반(총 R/2)인 선 둘의 병렬 → (R/6)/2 = R/12 = R/(3·2²) 맞음. 손가락 R = R_□·w_f/L, m 손가락 병렬 /m 맞음. 열잡음 4kT·R/3도 같은 등가(분포 gate 잡음의 표준 결과)라 '기존 저항 열잡음 규칙'과 정합. 1/3은 급수 계수라 상수 발명 아님. n_c = 1은 행 기하(gate 연결 단을 행 한 변 -- h_r 식)에서 정해진 값.

### 남은 문제 (원 파일 확인)

**① 구현 꼴 그대로면 가드가 master와 모든 bin에서 발동한다 -- 모순 있음(Major 꼴: fail-closed 과잉, 거짓 거부, master 회귀).**
- v2 V2-1.1 1의 구현 꼴: "`with_external`의 'ext None이면 셀 값 그대로' 갈래 삭제".
- 원 파일 `lut/tolerance.py:154-158`: 행마다 `ext = ext_rows.get(i, {})`, `with_external(opt(eq[i, k]), ext["id_equivalent_v"][k] if ext else None)`.
- `ext_rows`는 `l_loo_report`(`_helpers_loo.py:57-84`)가 상태 "external"인 bin의 앵커에만 채운다. 상태 "computed"(앵커 3개 이상, 외부 값이 필요 없음)와 "single_point"(앵커 1개) bin의 행도 ext가 없어 None이 넘어간다.
- 그래서 None 갈래를 지우면 앵커 3개 이상 bin(L 0.18~0.5 µm)과 앵커 1개 bin의 셀까지 모두 None이 된다. 기준 폭 키만 쓰는 master에서도 가드가 발동한다. 이것은 v2의 "LM-1e를 master에 먼저 넣어도 가드 발동 0 기대"와 모순이다. `vdsat_tolerance.py:117`도 같은 꼴이다.
- **고칠 방법**:
  - `with_external`은 그대로 둔다.
  - 표 구성(`tolerance.py`·`vdsat_tolerance.py`)에서 bin 상태가 **"missing_external"인 앵커 행만** None으로 만든다. 상태는 `_helpers_loo.py:82`가 이미 낸다.
  - 중점 파일이 없는 toy LUT(`_checks_of`가 `l_bin_checks = ()`를 낸다, `tolerance.py:121-123`)는 앵커 2개 bin 셀이 모두 None이 된다. 이 test 영향을 LM-1e card에 적는다. 정의대로의 변화라 기준 약화가 아니다.

**② 가드의 판정 자리가 둘이다 -- P:663 '판정 자리 = 이 행 하나'와 긴장.**
- 원 파일 `sizing/block_dc.py:497-509`: SCC 수렴 허용오차 `tolerance`는 SCC 소자의 tol 셀이 모두 None이면 봉인 전에 `SealViolationError`를 던진다(reason `tol_v_undefined`, `s2_values.py:101`). 수렴 전이면 `:571-572`에서 그대로 올린다.
- 따라서 같은 원인(셀 정의 불능)이 두 분류로 갈린다:
  - SCC 소자에 걸리면 DC 블록 실패 레코드.
  - 봉인 항목에 걸리면 봉인 10행 정의 불능(`seal_undefined`).

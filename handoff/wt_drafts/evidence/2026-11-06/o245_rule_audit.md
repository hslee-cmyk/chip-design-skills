## 0. O-245 원문 요지와 감사 축

O-245: LUT DC 열(ID·GM·GDS·GMBS·VTH·VDSAT 등, 지금 `@m[...]`)을 SPICE 단자량(단자 전류·단자 소신호 어드미턴스 등)으로 정의해 컴팩트 모델과 무관하게(O-197 확장). 시점 문언 없음. '단자량으로 정의되지 않는 양(VDSAT·VTH)의 새 정의는 원 결정 근거 대조 뒤 질문'.

분류 축: **모순**(O-245를 적용하면 그 결정 문언이 뒤집힘 -- 원칙 20 재질문 대상) / **낡음**(문언이 `@m`·BSIM 정의를 전제로 적혀 O-245 적용 때 정정 대상, 결정 취지는 남음) / **되살림**(O-245가 앞서 미뤄지거나 철회된 안을 다시 살림·흡수) / **무관**(O-245와 독립, 또는 이미 단자 정의라 정합 -- '정합'으로 따로 표기).

물리 결정자(감사자 확인, 원칙 21 재료 -- 판정 아님):
- (K1) **단자 전류는 4단자 보존량이다.** I_D + I_S + I_G + I_B = 0. 채널 전류는 d–s 사이에서만 흐르므로 지금 엔진 KCL(봉인 3)은 드레인 넷에 +ID, 소스 넷에 −ID를 넣는 2단자 모형이다. LUT ID를 드레인 단자 전류로 바꾸면 소스 단자 전류 ≠ −ID(접합 누설·GIDL이 벌크로 감)라 **드레인 열 하나만 바꾸면 KCL 자기 정합(E-0)이 깨진다** -- 단자 정의를 쓰면 소스(또는 벌크) 단자 전류 열도 있어야 KCL이 닫힌다. 크기: 켜진 소자에선 누설 ≪ tol_I(무시 가능), 꺼진·VDS = 0 소자에선 누설이 전부.
- (K2) **VDS = 0 단면의 ID ≡ 0**(DEC-88 'VDS = 0 단면은 ID ≡ 0', P:2581 채널 대칭 I = f(VG,VS) − f(VG,VD) → I = 0이면 VD = VS, DR-1·Q-S9 KCL 항등 0 집합)은 **채널 전류의 성질**이다. 드레인 단자 전류는 VDS = 0에서도 D–B 역바이어스 접합 누설만큼 0이 아니다(VSB > 0 점). 이 규칙들은 단자 정의에서 성립하지 않는다.
- (K3) **VGS ≈ 0 부근 단조성**: O-212 실측(`o208_gidl/gidl3.log`, pfet L 1 µm: 단자 전류 VSG 0 → −0.6 V에서 0.19 → 2.5 pA, LUT 채널 1.9e-18 A)으로 긴 L pfet VGS 0 근처는 단자 전류를 GIDL이 지배한다. GIDL은 |VGS|가 커지는(채널이 켜지는) 쪽으로 줄어 단자 ID(VGS)가 VGS 0 근처에서 평탄·비단조일 수 있다(물리 추론, **미측정**). DEC-87 Fritsch–Carlson 단조 검사·DEC-88 `vgs_for_current_density` 유일 역산의 전제(VDS > 0에서 ID(VGS) 엄격 단조)가 그 구간에서 깨질 수 있다.
- (K4) **단자 소신호 어드미턴스**: 저주파 Re(Y_dd) = gds + g_jd(드레인 접합 컨덕턴스), Re(Y_dg) = gm, Re(Y_db) = gmb + … -- 켜진 소자에선 접합 항 ≪, 정의는 다름(원칙 2 정의 동일성 확인 대상, `cap_questions_contradiction_check.md:294`와 같은 지적). 소스 행 Re(Y_s·)는 드레인 행의 부호 반대가 아니다(QC1 C 행렬 비상호와 같은 꼴) -- 대칭 VCCS 스탬프로는 드레인·소스 행을 동시에 맞추지 못할 수 있다(QC1 (라)와 같은 구조 문제, 크기 미측정).
- (K5) **VDSAT·VTH는 단자량이 아니다.** 단자량에서 유도하는 정의(외삽 VTH, gds/ID 꺾임 VDSAT 등)는 모두 **다른 정의**이고 대개 문턱 상수를 요구한다(원칙 11·O-200 '물리 경계를 수치 분해능으로 정하지 않는다'와 충돌 위험). 그리고 oracle 포화 판정(spec `vds_ge_vdsat`, `@m[vdsat]`)이 같은 정의로 바뀌지 않으면 O-178 (4) 정의 동일성 관문이 깨진다.
- (K6) **O-245를 LUT 쪽에만 적용하면 정의 동일성 위반을 새로 만든다.** 엔진 = 단자 ID, oracle = `@m[id]` 채널이면 O-205 (2)·O-210 RR-2의 '엔진 P5와 한 정의'가 깨진다. 적용은 LUT 생성기 + oracle 측정량 + spec 포화 정의를 한 변경으로 묶어야 정의 동일성이 유지된다(적용 순서 조건).

## 2. 진행 중 card 판정 (원칙 19)

판정 기준: 원칙 19 '낡은 card' = 그 card의 규칙·완료 조건이 번복된 결정 문언을 읽는 card. O-245는 **방향 결정**이고 구체 정의(ID를 드레인 단자 전류로 둘지·4단자 열·VDSAT/VTH 새 정의)는 O-245 원문대로 '원 결정 근거 대조 뒤 질문' 단계라 아직 계획에 규칙으로 들어가지 않았다.

**결론(오케스트레이터 결정 재료)**: O-245 적용을 **별도 card(계획 개정 먼저)** 로 두고 WB-1·LM-1e를 계속하는 것이 원칙 19와 모순되지 않는다. 근거:
1. 진행 중 card 셋의 규칙·완료 조건 가운데 `@m` 정의나 O-245가 뒤집는 문언(O-210 RR-2 '단자 전류 아님', O-204 '`@m[vdsat]` 정의 동일')을 읽는 것이 0이다(1.6절 71~74).
2. O-245를 WB-1 안에서 일부(예: LUT DC 열만) 적용하면 K6(엔진·oracle 정의 동일성 위반)·K1(4단자 KCL 불닫힘)을 새로 만든다 -- 부분 적용이 오히려 물리 정합·원칙 2 위반이다. 한 변경 = LUT 생성기 + LUT 재생성(32 슬라이스·기준 표·중점) + oracle 판정량 + spec 포화 정의 + 엔진 소비자(봉인 7·9·DR-1·DEC-88 역산).
3. 그 card는 착수 전에 사용자 질문이 필요하다(위임 밖, O-229 5 '근본원칙 변경' + O-238 절차): (Q-a) O-210 RR-2·O-205 (2) 번복(채널 대 단자, 4단자 열 여부) (Q-b) VDS = 0 ID ≡ 0·0 전류 MOS 규칙의 채널 성분 정의 존치(DEC-88·P:2581·O-182) (Q-c) VDSAT 새 정의 또는 유지(O-204, U-122/B88 흡수, O-200·원칙 11 ⚠) (Q-d) VTH 열(소비자 0 -- 삭제 대안) (Q-e) mismatch·`noise_ef` 확장 범위(DEC-96 (2)·2026-10-08 Q2·Q3·P:1089) (Q-f) 적용 시점(O-229 (4)·O-232 -- sky130 켜진 영역 값은 같아 LA-1 비차단이라는 측정 인용, 재생성 ngspice 허용).
4. 같은 축의 QC1(C 9원소 행렬)과 단자 어드미턴스 실수부(K4)는 같은 여기(단자 AC 전류)에서 나오는 양이라, 데이터 생성을 한 card로 묶을지는 질문 재료(감사자 권고 아님).

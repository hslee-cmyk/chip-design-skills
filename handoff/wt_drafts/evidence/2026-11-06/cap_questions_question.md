# 용량·원 넷·적재 질문 문서 -- QC1~QC4 (+ QC5 표지)

작성: 오케스트레이터(2026-11-06). 재료 = 실측 `junction_c_column_contrast.md`(측정 agent, 정정 표지 포함), 권고 `cap_and_set_questions_recommendation.md`(v1 대체됨 + '## 개정 v2', 권고 agent), 결정 간 모순 점검 `cap_questions_contradiction_check.md`(§1~§6 + '## v2 차분', 점검자 ≠ 권고 작성자), 단순화 점검 `new_sets_branches_simplicity_check.md`. 사용자 지시: "왜 C열을 사용하지 않아?", "C열과 4열은 PDK와 무관해야 PDK가 바뀔때,즉, 공정을 바꿀때 영향이 없잖아. 그게 이전에 얘기했던 원칙이고 이게 준수된 권고인지 확인해"(O-197), "새로운 집합을 만들거나 가지를 새로 만들때는 … 불필요하게 복잡해지지 않는지 점검해".

## 1. 사실 (원 파일·실측)

- 엔진 MOS 소신호 스탬프는 대칭 2단자 용량 5개다(`metrics/stamp_mos.py:28-35`). 고유 용량 cgg·cgd·cgs·cgb는 LUT C 열, 접합 cdb·csb는 엔진이 BSIM4 4.5 접합 식을 재구현해 계산한다(`metrics/junction_cap.py:1-20`, 오케스트레이터 직접 확인; PDK 선언 `junction_<kind>_<BSIM4 이름>` 54키, `assets/sky130_pdk_decl.json:133~`). LUT CDD·CSS 열은 '대조 test 전용'(DEC-91 (3), U-27 (d))인데 그 대조 test는 없었다.
- 실측(기준 폭 표, kind당 1008점): 접합 항은 정의 동일(깊은 off에서 (CDD−CGD)/cdb = 1.000). 채널이 켜지면 소스 자기 용량이 다르다 -- Rs/(cgs+csb) sat p50 −26 %(드레인 쪽 +1 % 안팎). 물리 결정자 = BSIM 진성 전하의 비상호 분배(모델 xpart 0, 40/60). 대칭 스탬프로는 게이트 행과 자기 용량 행을 동시에 맞출 수 없다.
- 4단자 비상호 C 행렬의 독립 원소 9, LUT가 재는 양 5(게이트 행 3 + CDD + CSS) -- 4개(C_dg·C_sg·C_ds·C_sd)가 모자란다(권고 v2 자유도 표).
- 생성기 원문: C 6열은 단자 AC 전류 Im(i)/ω로 정의 -- 모델 무관(`sky130_lut_sweep.py:240-243·311-312`, 권고 agent 확인). 새 4열도 같은 여기에서 print 4줄. 반면 엔진 BSIM4 접합 식·54키는 공정이 다른 컴팩트 모델을 쓰면 선언만 바꿔 동작하지 않는다(O-197 취지 위반, O-233 금지 꼴).
- 영향(연결만): 소스가 신호 마디인 회로 10/13(캐스코드·공통 게이트 7, 추종기 꼴 5). 극점·PM 이동은 추정(PM −2~−6°)이고 미측정.
- 바이어스 전압 넷 20개(8/13 회로)는 레일 밖·입력 포트 밖·gate 전용이라 봉인 3 행 0·재풀이 미지수 0(동작 영향 0)이나, SPICE 측정 구성은 이 넷을 전압원으로 구동한다(`authoring/CONTRACT.md:271` `bias_voltages`). 봉인 9행 다리 규칙(A-22)은 이미 '레일·바이어스 전압·입력 포트'를 들고 있어 원 넷 정의가 두 자리.
- 중점 결측 적재 거부: 범위 = `widths()` 슬라이스 30장이면 거부 0, `slice_map` 전체면 키 72·78(W_min 아래) 때문에 LUT 전체 거부. 다른 None 원인(켜진 격자점 없는 셀, `lut/_helpers_loo.py:132`)이 있어 봉인 10행·A-139 집계 규칙은 남는다.

## 3. 함께 알리는 것(질문 아님) -- QC5 모델 의존 표지

LUT DC 열(ID·GM·GDS·GMBS·VTH·VDSAT)은 ngspice 소자 내부 변수 `@m[...]`, mismatch는 sky130 카드 꼴 정규식, 잡음 `noise_ef`는 BSIM `ef` 분해식에 묶인다 -- sky130 수치에는 영향 0, 이식성 문제. VDSAT는 봉인 7 정의(O-204 'LUT VDSAT = SPICE `@m[vdsat]`')와, ID는 oracle 꺼짐 판정 정의(O-205 (2)·O-210 RR-2 '`@m[id]` 채널 전류, 단자 전류 아님')와 묶여 있어 단자 정의로 바꾸면 그 결정들을 번복한다 -- LA-1 재점검 입력 + 표지로 두고, LA-1 뒤 원칙 질문으로 올린다(후보: O-204, O-205 (2), O-210 RR-2, U-27 (c), DEC-96 (2), U-36, 2026-10-08 Q2, U-122/B88).

## 4. 원래 취지와 다름
- QC1 (가): DEC-91 (3)(접합 정본 PDK 파라미터 → LUT C 행렬), U-27 (d)(h) 번복, BSIM 식·54키 삭제, LUT 열 4개 추가, 데이터 card(ngspice 허용 필요).
- QC2 (가): DEC-105 (2) '읽는 열'(용량 = 기준 폭 표) 번복, 레이아웃 뒤 접합 보정 = SPICE 단위 표(LA-1 뒤), 그 사이 레이아웃 뒤 평가 fail-closed.
- QC3 (가): O-244 집합 문언에 바이어스 입력 추가.
- QC4 (가): O-242 문언 '`missing_external` 앵커 행만 None' → '적재 거부, 범위 = widths()'.

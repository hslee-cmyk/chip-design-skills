## 2. 물리 정합·fail-closed

- 레이아웃 뒤 재풀이 + 재봉인: P:2482 'W′ = 배치 nf·finger_w(W_request = 요청 W), 재풀이 비수렴·봉인 실패 = 그 재평가 위반(기존 거부·키 제외 경로)'. IF:152 대기 소자 행 없음 = `realized_finger_missing`. 원칙 4(정해진 회로를 흔드는 분석 = W·바이어스 고정 KCL)와 맞음.
- 입력 고정 갈래: P:305 '재풀이 비수렴 또는 봉인 실패면 그 점은 front에서 빠진다(fail-closed, 사유 기록)', IF:249 R-6c '마지막 값으로 봉인하지 않음'. 맞음.
- 전력 축: P:305 'MOS 채널 = `DeviceOp.current`, `device.dc_current`는 이상 전류원에만'. 대조: as-built `metrics/dc_metrics.py` `_operating_point`는 저항을 노드 전압·값으로 넣고(`Resistor(index[a], index[b], values[name])`) MOS만 `dc_current`를 읽는다. 그래서 저항 쪽에는 같은 구멍이 없다. `off` MOS는 `dc_current_basis`의 `ends`에서 빠진다(`sizing/current_basis.py:81·88`). 그래서 `dc_op` 없는 off 소자를 읽는 경로도 없다. `metrics_dc` READS에 `device.dc_op`가 이미 있다(`dc_metrics.py:40`). 맞음.
- tol을 넓히는 문언: 0. tol은 P history·D40:1230에서 '넓히는 근거가 아니다(O-200·O-240)'로만 나온다.
- fail-open 점검 -- 재평가 스냅샷을 다음 레이아웃 입력으로 읽지 않는 규칙:
  - 기준점이 고정되면 같은 키 제외 상태에서 레이아웃 결과는 기준점의 함수다. 재평가가 통과하면 다음 레이아웃은 같은 기하 → 고정점(수렴). 실패하면 키 제외 → 후보 0이면 `infeasible_after_layout`. 실측 CG −70 % 표류 경로(`wb1_resolve_check.md:41`)가 닫힌다. 구멍 없음.
  - W_request 경로: LY3(P:1098)은 'MOD8은 그 소자 W를 고정 입력으로 평가 커널을 다시 돌리고 새 계약으로 MOD7을 다시 돈다'라고 적는다. 그 '새 계약'의 스냅샷이 새 LY1 규칙(P:1096)의 예외인지 문언이 없다. P:2482·D40:1230이 '미측정(LA-1 재점검 입력)'으로 표지했다. 재평가는 W′ = 요청값으로 봉인하므로 fail-open은 아니다. 최악은 K_max NONCONVERGENT(fail-closed)다 → mi-2.
  - 피벗 갈래 불일치: 실현 평가는 실현 스냅샷의 IT-2c 판정이 다르면 `realized_servo_branch_mismatch`로 막는다(D40:1196). 레이아웃 뒤는 '피벗 갈래 = 기준 스냅샷 기록 참조'(D40:1230, P:2482 '실현 평가와 같은 규칙, 새 판정 자리 0')만 적는다. 불일치 검사를 포함하는지 IF §3(IF:152)·R-13에 명시가 없다. '같은 규칙' 참조로 덮이는 것으로 읽어 Major로 두지 않는다 → mi-3.

## 4. 새 test 기대값 손 유도

- **R-6**: 회로 M1 (out, in, gnd), R vdd → out(IF:261). 탐색 KCL(out): (V_dd − V_out,s)/R = I. 입력 고정이라 VGS가 같고, IDu가 같으면 I′ = IDu·W′/L = (1 + r)·I, V_out = V_dd − R(1 + r)I이다. 그래서 ΔV(out) = −R·r·I = −r·(V_dd − V(out)_탐색). **식은 맞다(전제 성립 시)**.
- **MJ-1**: 전제 'VDS 무관 LUT라 IDu 같음'(IF:248)이 IF가 지정한 LUT(§4, IF:261 '슬라이스·LUT = §4')에서 거짓이다. WB-1 합성 LUT `write_r4_bins_lut` → `r4_arrays`(`tests/sizing/wb1_toy.py:15·18`, `tests/sizing/conftest.py:163`)의 식은 `ID = (W/L)·I0·exp(B·G − C·G²/2 + LAM·D − A·S²)`, `GDS = ID·LAM`(`:165`), `LAM = 0.1`(`:52`)이다. 그래서 ΔV(out) = ΔVDS(M1)이 IDu를 e^{LAM·ΔV}만큼 바꾼다.
  - 바른 손 값: ΔV = −a·[(1 + r)·e^{LAM·ΔV} − 1], a = V_dd − V_out,s(한 변수 고정점, 손으로 풀 수 있음).
  - 예: r = 0.1, a = 0.9 V → 바른 ΔV ≈ −81.9 mV, IF 식 −90 mV. 차 ≈ 8 mV ≫ 봉인 tol_V(µV~mV, `wb1_resolve_check.md:10`). 바른 엔진이 R-6 단언 '손 값과의 차 ≤ tol_V'에서 red가 된다.
  - R-13 (b)(IF:256)와 R-6c 근 조건 'R·(1 + r)·I > V_dd − V_gnd'(IF:249)도 같은 결함이다. LAM이 있으면 V_out = 0에서 M1 전류 = (1 + r)·I·e^{−LAM·V_out,s}이므로, 레일 밖 근 조건 = R(1 + r)I·e^{−LAM·V_out,s} > V_dd이다.
  - IF:261 '아니면 멈추고 보고'가 있어 fail-open은 아니다. 다만 지금 잴 수 있는 거짓 전제라 test 작성이 반드시 멈춘다. 고칠 안(둘 중 하나, 상수 발명 없음): (가) R-6 계열 회로에 LAM = 0 r4 변형 LUT를 지정(합성 LUT 인자 -- 새 인프라 아님) (나) 손 값을 위 고정점 식으로, R-6c 조건을 e^{−LAM·V_out,s} 항으로 바꿈.
- **R-6c**: 위 정정 뒤에는 손 유도 가능. 실제 소자라면 triode 해가 있고 봉인 7이 거부한다는 점은 `wb1_resolve_check.md:9`와 같은 성격이다(어느 쪽이든 탈락). 맞음.

- **R-14**: spy가 둘째 `place_layout`의 설계점 스냅샷 `is` front 점 스냅샷인지 본다. 숫자 없음. 맞음.

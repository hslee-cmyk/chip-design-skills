# 봉인 3 질문 문서 -- 입력 포트 넷의 KCL 행 (E-30 '모든 넷' 재검토)

작성: 오케스트레이터(2026-11-06). 재료 = 재측정 `seal3_input_net_cg_recheck.md`(독립 측정 agent), 결정 간 모순 점검 `seal3_contradiction_check.md`(점검자 ≠ 권고 작성자), 앞선 점검 `wb1_questions_check.md` 질문 2 절·`wb1_resolve_check.md`, 사용자 원칙 진술 O-243.

## 1. 사실

- 봉인 3 = 레일이 아닌 넷마다 소자 전류를 노드전압에서 다시 계산해 |Σ| ≤ tol_I(`skills/analog-gmid-design/gmid_engine/sizing/seal_kcl.py`; 레일 제외는 31·47~48행, 오케스트레이터 직접 확인). 계획 N3.6 표 3행(P:656)·E-30(P:2556) = '제외 넷 없음, 모든 넷 검사'. E-30 원 근거 = 쓰이지 않던 `exclude_nets` 선언 칸 삭제, 문언에 '수요가 생기면 계획 개정으로 만든다'(점검자 확인).
- 입력 포트는 엔진 모형에서 원이 정한다: 입력 고정 재풀이는 입력을 미지수에서 뺀다(`block_dc.py:779-792`, 같은 `node.port_direction` 필드), oracle도 입력을 이상 전압원으로 구동(`tools/spice_oracle/oracle_netlist.py`). 봉인 3만 그 넷 행을 판정한다(정의 불일치).
- 사용자 원칙 진술(O-243): DC sizing에서는 입력을 target 바이어스에 고정된 것으로, AC(gain·PM)에서는 그 바이어스 위 신호 주입 포트로 본다 -- DC/AC 분리 원칙(DEC-67)의 의도. AC 해석이 spec을 만족하는지가 DC sizing의 충분함을 확인한다.
- 재측정(WB-1 3397b834 사본, 4/13 회로, 레이아웃 루프까지 2/13): 앞선 'LI-1 이후' 조건의 근거였던 CG 전류 −40 %·−70 % 표류는 레이아웃 기준점 되먹임 때문이었고 A-124(기준점 = front 점)로 사라졌다 -- 안 A에서도 1회 이동 뒤 고정점. 재평가는 `spec:`·`ss:` 행을 매번 다시 판정했고 안 A로 통과한 CG 점의 AC 행은 모두 c ≥ 0(fail-open 아님). 판정이 바뀐 회로 = 입력이 채널 끝점에 닿는 CG 1회로(2점); 입력이 gate에만 닿는 회로(two_stage_ota·folded·pushpull)는 봉인 3에 입력 넷 행이 없어 비트 동일.
- 지금 판정은 tol이 물리 경계를 정한다(O-200 위반): 같은 입력원 전류(I_D의 약 6 %)가 기준 폭 셀에서는 통과(비 0.35), 다른 폭 셀에서는 거부(비 849).

## 2. 질문 S3 -- 입력 포트 넷의 KCL 행

| 안 | 내용 | 물리 정합 | ⚠ |
|---|---|---|---|
| **A (권고)** | 봉인 3 제외 넷 = 레일 ∪ 측정 구성 입력 포트(`node.port_direction` = input, 기존 필드, 재풀이와 같은 판별 상수 하나). 입력원 DC 전류는 같은 `graph.dc_seal_3` 레코드 detail에 기록만(거부 문턱 없음 -- 상수 발명 금지; spec이 선언한 경우만 판정). WB-1 안에서 계획 → design → card 순으로 개정해 적용 | 맞음(이상 전압원 넷의 KCL은 원 전류가 닫으므로 방정식이 아님; 레일과 같은 이유; 내부 넷·servo 출력·목표 넷 행은 그대로) | E-30·P:656 '모든 넷' 번복(원래 취지와 다름); 판정 바뀐 표본 CG 1회로 |
| B | 지금처럼 모든 넷 판정 | 틀림(원이 닫는 넷을 방정식처럼 판정, tol이 경계를 정함 -- O-200) | 입력이 채널에 닿는 회로는 실현 뒤 계속 거부 |

A에 붙이는 조건(점검자 조건 a~d 반영):
1. servo 출력 넷 행은 판정 유지(입력 차를 정하는 방정식).
2. spec 노드 목표 넷 판정 유지 -- 목표 넷에는 원이 없으므로 뺄 수 없다(이유를 문언에 적음).
3. N3.8 측정 구성에 '입력 포트 = 측정 구성의 이상 전압원(servo는 값이 미지수, 입력 고정은 상수)' 전제를 한 문장으로 두고, 이것은 측정 구성의 경계 조건이지 topology 원소가 아님을 명시(P:301·P:2333·E-27 'topology 원소 이상 전압원 미지원'과 구별). ⚠ 전류 구동 입력 회로(TIA 등)가 들어오면 측정 구성 정의부터 바꾼다.
4. detail `input_source_current`는 출력 전용 선언(L-4, WB-1 spec J-5 선례).
5. 판정이 바뀐 회로를 변화표에 남김(U-74 선례): 4/13 측정, 바뀐 것 CG 1회로 2점, 목표 넷 회로 사례 0.
6. 철회되는 조건: A-124의 'LI-1과 같은 병합 또는 그 뒤', `wb1_questions_check.md` 2-3 (iii) '단독 채택 금지'(근거였던 표류가 A-124로 사라짐).

적용 card: WB-1 안((i), 점검자 대조 모순 0 -- 어긋남이 WB-1의 재풀이(A-123 (3))에서 생겼으므로 O-229 3의 '필수'; 별도 card·LA-1 안은 CG 거부를 안은 채 LA-0 기준선이 서서 P:2486과 긴장). 위임 판단 아님: 결과가 '거부 → 통과'로 바뀌어 외형상 기준 약화와 구별이 어렵고(O-226·O-229 7) E-30 문언 번복(O-238)이라 사용자 질문.

부수(질문 아님, LA-1 재점검 입력): 실현 재풀이는 spec 목표 넷(REL_TARGET)도 고정해 행에서 뺀다(`block_dc.py:791` `held`) -- 목표 넷에는 원이 없으므로 정의 밖인 쪽은 풀이(지금은 거부 방향이라 fail-open 아님).

## 3. 질문 문언

**S3**: "봉인 3(노드 KCL 검사)에서 입력 포트 넷을 레일처럼 판정에서 빼고 입력원 전류는 기록만 할까요? DC sizing에서 입력은 target 바이어스에 고정된 이상 전압원이라 그 넷의 KCL은 원 전류가 닫고 방정식이 아닙니다(O-243). 재측정에서 표류는 A-124로 사라졌고, 재평가가 AC 제약을 다시 판정해 통과 점은 spec을 만족했습니다." -- 선택지 A(권고: 조건 6개, WB-1 안에서 계획부터 개정), B(지금처럼 모든 넷 ⚠ tol이 물리 경계를 정함).

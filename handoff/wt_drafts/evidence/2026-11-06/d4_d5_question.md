# D4·D5 질문 문서 -- MOS 용량 스탬프와 C 열 폭 (개정 3: 조합 (5) 추가, 재검증 minor 3 반영)

작성: 오케스트레이터(2026-11-06). 앞 질문 문서 `cap_questions_question.md`(QC1·QC2)를 대체한다. 재료: 원본 판독 `gmid_book_lut_definitions.md`, 실측 `d4_d5_measure.md`·`combo5_offregion_junction.md`(측정 agent), `junction_c_column_contrast.md`(정정 표지 포함), 권고 `cap_and_set_questions_recommendation.md` v2, 결정 간 모순 점검 `cap_questions_contradiction_check.md`(v1·v2 차분), 검증 `d4_d5_question_validation.md`(개정 1 Major 1)·`d4_d5_question_validation_v2.md`(개정 2 Major 0, minor 3). 개정 3: 사용자 관점("gmid 방법론 자체는 손계산은 오차가 있다는 전제이고 spice로 최종 판단해서 그 결과를 기반으로 sizing을 수정하는거야. 이 관점으로 봐도 현재의 C열만으로는 불가능한건가?")에 따른 조합 (5) 추가와 실측, 재검증 minor m-a·m-b·m-c 반영.

## 1. 사실

- 엔진 MOS 스탬프는 대칭 2단자 용량 5개(`metrics/stamp_mos.py:29-37`), 접합 cdb·csb는 엔진이 BSIM4 4.5 식으로 재구현(`metrics/junction_cap.py`, PDK 선언 BSIM4 이름 54키 -- 소비자·운반 자리는 card 완료 조건 'junction grep 전수 + 삭제/유지 분류', 봉인 6 `junction_forward`는 유지) -- 공정을 바꾸면 선언만 바꿔 동작하지 않는다(O-197 취지).
- 고유 용량은 `lut/cap_query.py:24-52`(:30·:44-45)가 기준 폭 표(5 µm, finger 1개)를 W/w_ref로 비례 -- 근사 표지 없음.
- gm/ID 원본(Jespers & Murmann 2017): LUT 저장 열에 CDG·CSG 포함(304~305쪽), 접합은 LUT CDD 안 -- `Cdb = Cdd − Cgd`(112쪽), 방법론은 준정적 상호 용량만·transcapacitance 다루지 않음(56쪽), 기준 배치 하나·W > 2 µm 'within about 1.5 %'(315~319쪽), 손계산 뒤 SPICE로 확인.
- 실측 원본 방식(대칭 5칸에 Cdb = CDD − CGD, Csb = CSS − CGS를 켜진 점에서): 강반전 포화 칸 Csb < 0이 약 58 %, 준정부호 위반 약 49 %(λmin/CGG p50 −0.090·−0.120), 회로 손 봉인 점 Csb < 0 10/10 -- 수동성 위반(거짓 극점 위험, O-200).
- **실측 조합 (5)**(접합을 LUT의 off 점 -- 그 L·VDS·VSB 단면의 VGS 축 최소 격자점, 상수 0 -- 에서 CDD − CGD·CSS − CGS로 뽑아 대칭 5칸의 Cdb·Csb에): off 점 드레인 비 (CDD−CGD)/PDK = 1.000~1.034(VDS ≥ 한 격자), 회로 점 rd 1.000~1.003·rs 0.983~1.017; 긴 L·영바이어스 일부에서 오염(nmos L 20 µm VDS 0 열 0.38, 소스 긴 L·VSB ≈ 0 최대 6.6배 -- 게이트 밑 공핍 전하) -- 경계를 두면 상수가 되므로 손계산 오차로 둠. **수동성: Cdb·Csb 음수 0(전 격자·회로 70소자).** 켜진 영역 노드 자기 용량 오차: 드레인 강반전 포화 p50 0.8~1.4 %, **소스 +36 %(p50, 최대 +58 %, 과대)** -- 이 소스 오차는 지금 PDK 식 엔진과 같은 크기(차 ≤ 0.007)로 대칭 5칸 스탬프 구조의 오차. 좁은 finger 폭 오차(접합을 기준 폭에서 비례): finger 0.42 µm에서 접합 nmos −24 %·pmos −45 %, 회로 드레인 노드 p50 −10 %·최대 −38 %(과소 = 극·GBW·PM 낙관 쪽) -- 기준 폭 표 한 장으로는 면적·둘레를 나눌 수 없어 데이터 생성 0으로는 못 고침.
- 4단자 비상호 C 행렬 독립 원소 9, LUT가 재는 양 5 -- 4열(CDG·CSG·CSD·CDS)이 모자란다(생성기의 기존 단자 AC 여기에서 print로 얻음).
- 레이아웃 뒤 실현 확산 경로(`JUNCTION_LAYOUT_DIFFUSION`, `convergence/junction_change.py`·`realized_geometry.py`, LY8)는 지금 PDK 식을 쓴다 -- 어느 조합도 데이터 0으로는 대체 못 함(면적·둘레 분리 필요).

## 3. 원래 취지와 다름 (권고 (5) + LAJ (가))
- DEC-91 (3)(접합 정본 PDK 파라미터 → LUT C 열의 off 점 값), U-27 (d)(CDD·CSS '대조 test 전용' → 스탬프 입력), BSIM4 식·54키 삭제.
- O-179: C 열은 다 쓰지만 CSS 행을 정확히 맞추지 않는 근사(비상호 성분 버림, 원본 56쪽과 같음).
- 레이아웃 뒤 평가 fail-closed(단위 표 card 전까지) -- A-124 효과 일시 정지.
- 조합 (1)(9원소 + 슬라이스별 C)은 LA-1 재점검 입력(정확도 개선 후보)으로.

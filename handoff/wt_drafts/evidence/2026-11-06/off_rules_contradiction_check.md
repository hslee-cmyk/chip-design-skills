### (d) (다) 부호 판정 유지 근거 개정이 O-205 (2)·O-210 RR-2와 맞는가

O-205 (2) 원문은 "F-b: oracle ID 부호가 잡음 수준이면 **기록만**"이었다. O-210 RR-2가 이를 고쳤다: "ID ≤ 0 = 크기 무관 FAIL, … '잡음 수준이면' 문구·ε 식 삭제". 현행 정본은 RR-2다.

OA §3.2가 고친 근거는 셋이다.

| 근거 | 판정 |
|---|---|
| 엔진 = 정의역 조건 | O-203·DEC-87과 맞다 |
| oracle = 선언 없는 소자에서 포화 FAIL이 이미 함의하므로 부호는 사유 표지 | **조건부 정합** |
| triode 선언에서만 판정을 바꿈 | 표 9행 (ii)(O-53 B1)와 맞다 |

oracle 근거가 조건부인 이유는 둘이다.

- 판정 결과(FAIL)를 유지하므로 RR-2와 결과는 같다. OA도 'oracle 쪽 부호 판정은 지우지 않고 유지(fail-closed)'라고 적었다.
- 그러나 '사유 표지만 더한다'를 근거 문장으로 계획에 넣으면 RR-2가 지운 '기록만'(O-205 (2) F-b)으로 읽힐 위험이 있다. 또 그 함의는 LUT 순방향(VDS ≥ 0) 범위의 사실이다. 역방향 소자에서 ngspice `@m[vds]`·`@m[vdsat]` 부호 관례는 OA도 재지 않았다.

**고칠 방법**: 근거 문언을 이렇게 적는다. "oracle 부호 판정 = 크기 무관 FAIL(O-210 RR-2 그대로). 선언 없는 소자에서는 LUT 순방향 범위에서 포화 FAIL과 함께 나며(사유 구분), 역방향·VDSAT 열 없는 소자에서는 이 판정이 유일하다." '사유 표지만'이라는 말은 쓰지 않는다.

### (e) KCL 항등 0 전류 MOS 예외

- 표 9행(:662)이 이미 '**KCL 항등 0 전류 MOS 예외**(정의 자리 = 이 행 하나, 다른 자리는 인용)'로 정의한다. 내용은 다리 규칙(A-22), 원 넷 = O-246 D6, `off` 선언 소자 엣지 제외, O-182 Q-S9 (A′)다. O-210 RR-2도 '선언 없는 MOS(KCL 항등 0 집합 제외)'다.
- 원리 문장 '선언 없는 소자는 선언 방향으로 전도한다'는 이 예외 없이는 표 9행과 모순이다. OA 4.1이 예외를 넣었으므로 **정합**이다.
- **조건 두 가지**
  - (1) 원리는 예외를 다시 정의하지 않고 표 9행을 **인용**한다(정의 자리 하나 -- 규칙 3). OA 4.1 '표 9행 다리 규칙'은 인용 꼴이라 맞다.
  - (2) 다리 밖의 구조적 0 전류(`current_basis` `mos_zero_current_structural` 정지, DR-1 대기)는 예외가 아니라 정지(fail-closed)다. 원리 문장에 '그 밖의 구조적 0 전류 = 정지'를 한 줄 넣어야 '전도 아님인데 거부도 아님'으로 읽히지 않는다.

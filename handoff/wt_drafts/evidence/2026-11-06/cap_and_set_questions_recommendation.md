## QC1 진성 전하 분배 -- 비상호 용량(transcapacitance)

### 물리 검증(원칙 21)

- **물리 결정자**: BSIM4 진성 전하 분배(PDK 모델 카드 capmod 2, xpart 0 = 40/60, acnqsmod 0 = 준정적)가 결정자다. 용량은 단자 전하의 편미분 C_ij = ∂Q_i/∂V_j로 정의되고(대각 +, 비대각 −), 일반적으로 C_ij ≠ C_ji이다.
- **식(손계산, 강반전 sat, 긴 채널, 진성만)**: Q_g = (2/3)C·V_ov, Q_d = −(4/15)C·V_ov, Q_s = −(2/5)C·V_ov (V_ov = V_gs − V_t, V_d와 무관). 여기서 다음이 나온다.
  - C_gs = 2/3·C, C_gd = 0
  - C_sg = 2/5·C, C_ss = 2/5·C
  - C_dg = 4/15·C, C_ds = −4/15·C, C_dd = 0
  - 열합 검사: ∂/∂V_g의 열합 2/3 − 4/15 − 2/5 = 0으로 전하 보존이 맞는다.
  - 상호 스탬프(cgs 하나)는 C_sg = C_gs = 2/3·C로 둔다. 그래서 소스 행이 0.267·C만큼 크다(= Rs).
- **실측**: 측정 문서 jc1의 값이다. Rs/(cgs + csb)는 sat p50 −26 %, p05 −34~−36 %이고, 깊은 off에서 ≈ 0이다. 드레인 Rd는 sat p50 +1 %이고 triode에서는 −10~+17 %다. 채널이 켜질 때만 차가 생긴다는 점이 결정자가 진성 분배라는 증거다.
- **판정**: 엔진 소스 행은 **틀림(정의 다름)**, 드레인 행은 **조건부**다. 게이트 행(CGG·CGD·CGS·CGB)은 LUT 열 그대로라 **맞음**이다.

## QC2 접합 용량 정본(DEC-91 (2)(3))

### 물리 검증

- **물리 결정자**: 확산 기하(ad·as·pd·ps, 손가락 수)와 역바이어스다. 둘레 항이 손가락 폭·수에 따라 달라서 W에 비례하지 않는다.

  - 손가락 폭과 m(= n_fingers, DEC-91 (2))은 슬라이스·A-139 (가)의 '입력 기하 그대로'로 유지된다. 그래서 gate 쪽 변의 길이는 바뀌지 않는다(조건: 레이아웃 손가락 폭 = 슬라이스 폭).
  - 바뀌는 것은 공유 확산으로 달라지는 AD·AS·PD·PS뿐이다.
- **식(보정)**: ΔC_db(V_db) = c_A,d(V_db)·ΔAD + c_P,d(V_db)·ΔPD, 소스 쪽도 같다. 2단자 d–b·s–b 원소로 스탬프한다(접합은 상호 2단자 -- 물리).
  - Δ = (그 평가의 기하) − (그 C 행렬을 잰 생성 기하)
  - 레이아웃 전 기하 = 생성 기하이면 Δ = 0

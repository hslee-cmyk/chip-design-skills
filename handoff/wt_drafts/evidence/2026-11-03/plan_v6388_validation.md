### M4. OP-7 선언 조각의 측정 근거

- 사실: P:1393 '(다) 선언 칸만', 사유 칸은 '오라클 실행 거부'뿐이다. A-13 뒤로 WB-1 범위 0이 이 선언을 **코드에서 읽는다**. OP-7 행 정본은 '검증자가 지금 LUT의 경계 앵커 점 전부에서 그 시뮬레이터 판으로 다시 잰다'이고 경계 소속은 호환 모드로 뒤집힌다(oracle plan OP-7 행). A-13 스스로 '조각 측정 방법 미확인'이다.
- 결과: '선언 칸만'을 측정 없는 기입으로 읽으면 bin 규칙이 근거 없는 값이 되고(원칙 11), SPICE 다리가 A-5로 미뤄져 있어 LA-1 측정 시점까지 잡히지 않는다.
- 측정 경로: 어댑터가 없어도 된다. 옆 선언은 원래 검증자 스크립트 측정 + 검증자 작성(NFR-P5 예외)이고, OP-3 선행 사유는 '새 LUT 측정 경로'다. 실현 가능성 자체는 미측정이다.
- P:1393 고칠 문언: 사유 칸에 'WB-1 범위 0이 읽음(bin 규칙 근거)'을 더하고, 처리 칸을 다음으로 바꾼다.

  > (다) 경계 앵커 점 재측정과 선언 칸 + 근거 칸(모델 sha256·시뮬레이터 판·호환 모드) -- 엔진 평가 0, 어댑터 없이 검증자 스크립트, 작성 = 검증자; 재측정이 안 되면 선언을 쓰지 않고 멈추고 보고(WB-1 범위 0은 선언 없음 fail-closed). library 13회로 비트 동일·거부 test는 어댑터 조각 몫

- oracle plan OP-7 행 '선행' 칸에도 '조각 = 경계 앵커 재측정 포함'을 적는다.

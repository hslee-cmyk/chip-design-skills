## 판정 요지

- **낡음 표지 처리 자체는 구현을 틀리게 하지 않는다.** 표지 범위가 주제로 한정되고 '정본 절이 이긴다'는 규칙이 분명하다.
- 결함은 표지가 없는 쪽에 있다. 정본 절에 남은 옛 문장, 그리고 정본 절 바깥에서 고치지 않아 새 절차와 어긋나는 규칙(M2)이다.
- Major 13 = oracle 9 + EO-1 4.
- **A-8 + R1 미채택 조합의 모순 = 있다**: E2·E3·E4. R1 표만 고쳐서는 닫히지 않는다.

## Major -- oracle design

### M1. 단일 입력 회로에 servo를 걸면 ICMR이 물리적으로 틀린다 (§21.2 2·3단계, §18.1)
- 원 문언: 훑는 포트 = `input_p`·`input_n` 쌍 또는 `input` 하나, 포트마다 `Vcvs tb:servo:<n>`, 이득 −sgn(A)·K·e(n).
- 정의 정본 gain-budget N3.8: "**단일 입력 회로**는 회로 그대로다(입력 자체를 훑고 출력은 회로대로 -- 보정할 입력 자유도가 없음)", "단일 입력 회로의 ICMR = 출력이 회로대로 따라가는 상태에서 입력 포트를 DC로 훑을 때".
- 물리: e와 x의 방향이 같아 servo가 x를 그대로 지운다. 포트 전압은 v0에 머물고, 모든 점이 통과해 끝이 `rail`, `icmr_v` ≈ 0이 된다. 값이 나오므로 정의 불능으로 걸리지도 않는다.
- 영향: library 2/13(common_gate, pushpull_follower). 추가로 s0 미선언·A 판정 불능이면 정의되는 측정을 거부하게 된다.
- 고칠 문언(§21.2 2단계 맨 앞에 추가): "**입력 포트 하나인 회로 = servo 없음**(gain-budget N3.8 '단일 입력 회로는 회로 그대로'): `tb:icm:<n>` = v0(n) + x만 걸고 `tb:servo`를 넣지 않으며 출력은 회로가 정한다. s0·`sim.a_dc`·K·점별 고정 확인(`icmr_sense_target_undeclared`·`icmr_servo_sign_undefined`·`icmr_output_lock_violated`)은 이 갈래에 없다. 아래 servo 항목은 입력 포트 둘일 때만이다." §18.1 v0.4.0 servo ICMR 행에 "단일 입력: 벤치에 Vcvs 0, V_cm 폭 = 손 해, servo를 건 변형 = 폭 0으로 실패" 추가.

### M2. ICMR만 요청하면 `sim.a_dc`가 없어 servo 부호를 못 읽는다 (§21.5 3단계)
- 원 문언: `sim.a_dc` 있는 조건 = "`offset_mc`·`offset_sys_mv`·PC-10 가운데 하나라도 요청됐을 때만", "셋 다 요청 없음 ... 칸이 없다". §21.2는 status `undefined`만 다룬다. 칸 없음은 갈래가 없어 KeyError가 나거나 임의 처리된다. §21.5는 v0.4.0 정본 절 목록에도 없다.
- 고칠 문언: "free bias 실행이고 `offset_mc`·`offset_sys_mv`·PC-10·**입력 포트 둘인 회로의 ICMR(servo 부호, §21.2)** 가운데 하나라도 요청됐을 때만 한 번". 소비자 목록에 §21.2 servo 부호 추가, 정본 절 목록에 §21.5 3단계 추가.

### M3. noise 꼬리 검사 부등식이 반대다 (§18.3 끝)
- 원 문언: "바로 앞 구간 기울기 ≥ n̂(꼬리에서 완만해지지 않음)". 괄호 뜻과 식이 반대다. 식대로면 n_prev = 2, n̂ = 1.5(완만해짐, 상계 S ≤ S0·(f0/f)^n̂ 근거 없음)가 통과하고(fail-open), n_prev = 1, n̂ = 1.5(극으로 가파라지는 정상 꼴)는 거부된다.
- 상계 식 T = S·f0/(n̂ − 1)과 닫힌 식 f_hi는 재유도해 맞음을 확인했다.
- 또 확장이 필요 없는 입력의 처리가 없다. 닫힌 식을 늘 적용하면 격자 위끝이 바뀌어 N4 'noise 칸 동일성'과 §18.1 '상한에 닿지 않은 입력 비트 동일'이 깨진다.
- 고칠 문언: "n̂ ≥ n̂_앞(꼬리에서 완만해지지 않음)이고 n̂ > 1. 어기면 `noise_tail_bound_undefined`. **T(f0) ≤ ε·I(f0)이면 확장하지 않고 f_hi = f0(격자 불변, N4 비트 동일 대상)**. 넘을 때만 닫힌 식으로 f_hi를 정한다." `core/test_bounds_derived.py` 행에 "완만해지는 꼬리 → 거부, 한 극 꼬리 → 통과" 추가.

### M4. `.tran` 끝 시각이 절차에 없고 SR_req 입력 출처가 없다 (§21.6 3단계)
- 정의(N3.8, §21.6 머리 인용): 끝 시각 = t_step + |Δx|/SR_req, SR_req = 그 방향 spec 값.
- 3단계는 `tran_plan` 수학·교차 주파수만 적어 끝 시각이 그쪽으로 구현된다. `SR_req`는 머리 한 곳에만 있고 `/slew` 칸에 없다. 추종 판정 (다) '끝에서 x_to 띠'의 판정 시각이 달라져 정의 불능 경계가 틀린다.
- 고칠 문언: "3단계 `tran_plan`은 걸음·t_step만 정한다. **끝 시각 = t_step + |Δx|/SR_req**, SR_req = 입력 `acceptance.constraints[]`의 그 방향 measure(`slew_rise_v_per_s`·`slew_fall_v_per_s`) 값(참조, 사본 칸 없음). 제약이 없으면 그 방향 `slew_required_undeclared`(정의 불능, 시뮬레이터 호출 0)." §7에 코드 추가, §18.1 OP-10 행에 "끝 시각 식, 제약 없음 거부" 추가.

### M5. 추종 판정의 β 출처가 없다 (§21.6 4단계, §11.6 `/measure_feedback`)
- 정의: 목표 = 계단 × 1/β, β = 선언 되먹임, 선언 없으면 1. `/measure_feedback`는 `{kind, inverting_input?}`뿐이고 spec `feedback`도 원소 목록만 있다(`spec_elements.py:19-20`, 수치 β 없음). `declared` 구성에서 구현 불가다.
- 원칙 판단: 수동소자 망에서 β를 유도하는 규칙은 계획에 없고, 지어내면 안 된다. library 비지 않은 선언은 current_reuse 하나뿐이고 이미 `input_network_step_deferred`라 OP-10에서 잃는 회로가 없다.
- 고칠 문언(1단계 구성 검사에 추가): "`declared`이고 지금까지 사유에 걸리지 않은 구성 = `feedback_config_undeclared`(`why = beta_undefined`, 정의 불능, 시뮬레이터 호출 0) -- 선언 망의 β 유도 규칙은 계획에 없다(AP-1과 함께 계획 개정). OP-10의 추종 판정 β = 1은 `unity_follower`와 단일 입력만." `la1_auto_decisions`에 기록, 원래 취지와 다름 표지(발동 0/13, 위 근거의 읽기).

### M6. 정본 절에 지운 사유가 남아 DC 되먹임 없는 단일 출력의 갈래가 없다 (§21.6 1단계 끝)
- 원 문언: "같은 입력의 ICMR이 `icmr_feedback_dc_absent`(§21.6 0단계 (e))라 확정 끝이 없어 2단계 `slew_step_end_undefined`로 끝난다". 두 코드 다 v0.4.0 삭제이고, DR-27로 슬루가 ICMR 끝을 읽지 않는다.
- 그대로 지우면 용량만 선언한 단일 출력에서 1a가 DC 되먹임 없는 `.dc`를 돌린다. 우연히 공칭 통과하면 무의미한 범위로 계단을 잰다(fail-open 위험).
- 고칠 문언: "**단일 출력 + DC 되먹임 없는 선언**(0단계 판정): `feedback_config_undeclared`(`why = start_op_deferred`, 시뮬레이터 호출 0) -- 1a `.dc`를 돌리지 않는다." §7 해당 행 (c)를 '차동 출력'에서 '출력 꼴 무관'으로 넓힌다.

### M7. offset 기준 도달 판정이 swing 측정 없는 실행을 다루지 않는다 (§21.4 DR-28)
- `swing_icmr` 블록 없음 = "그 측정 안 함(결과에 키 없음)"(§11.4). EO-1 생산자는 해당 판정 제약이 있을 때만 그 블록을 낸다(§4.9-2). offset 제약만 있으면 `sim.swing_icmr.swing`이 없고, "정의 불능이면 `output_range_undefined`"는 이 경우가 아니다. PC-10 온도 실행도 같다.
- 고칠 문언: "`offset_sys_mv`·PC-10 요청이면 같은 실행·같은 온도에서 swing 훑기를 **요청 여부와 무관하게** 돌려 `sim.swing_icmr.swing`을 쓴다(둘째 측정 아님, 그 기록 하나를 읽음). 블록이 있으면 그 설정, 없으면 `dc_sweep`만으로. 순서 swing → offset." §21.5 '소비자 없는 측정 없음' 조건과 §18.1 DR-28 행에 "swing 블록 없는 입력" 추가.

### M8. KCL 항등 0 집합의 유도 규칙이 없다 (§21.1 2단계)
- 원 문언: "회로 IR 연결에서 집합을 독립 유도". 규칙이 없어 구현자가 정의를 짓게 되고, 판정자 독립(O-182)의 뜻이 사라진다. 다르면 전체 거부이므로 규칙 차이가 곧 전 입력 거부다.
- **실측**: 아래 규칙을 library 13 topology(`netlist`, `passive_elements`, `ideal_sources`; 용량 제외)에 적용한 결과 = erfc_ota {M19, M20, M21}, 나머지 12회로 빈 집합. 계획 Q-S9의 '13회로 해당 = erfc_ota M19~M21 셋'과 일치한다. 인라인 스크립트, 파일 없음, 엔진 코드 안 읽음.
- 고칠 문언: "규칙: `role == 'circuit'` 원소로 그래프를 만든다. 마디 = 넷, `/rails`·`/bias_voltages`·입력 포트 넷은 고정 마디 하나로 합친다. 엣지 = MOS drain–source, 저항, 인덕터, 이상원. 용량·gate·bulk는 엣지가 아니고, `off` 선언 소자는 엣지에서 뺀다(엔진 0 모형 전류 기저와 같은 뜻). **어떤 MOS의 엣지가 다리(bridge)이면 KCL 항등 0**이다(그 엣지 하나만 지나는 절단이라 KCL로 전류가 0)." `off` 처리는 작성자 몫 문언으로 표지하고 toy 하나를 §18.1에 추가.

### M9. 호환 모드가 어댑터 계약과 캐시 키에 없다 (§16, §8.1, §9, §11.7)
- `RunConfig`는 §16 한 줄에만 있고 §8.1 `run(...)`에 그 인자가 없다. §9 키 = 지문 ∥ 방언 텍스트 ∥ 모델 ∥ 실행 인자이고 `.spiceinit`은 넷리스트 텍스트 밖이다. §9는 "키에 없는 입력이 결과를 바꾸면 결함"이라 적고, §16은 호환 모드가 bin 소속을 뒤집는다고 적는다. 그대로면 다른 모드의 캐시 결과를 조용히 재사용한다(fail-open). `fingerprints.compat_sha256`도 §11.7 칸 목록에 없다.
- 고칠 문언: §8.1 `run(..., compat: CompatDecl|None)`(이름은 작성자 몫). §9 키에 "∥ `spiceinit_sha256`(없으면 빈 값)" 추가. §11.7 `fingerprints = {adapter_fp, descriptor_fp, capability_record_id, compat_sha256}`. §16 완료 측정에 "모드만 다른 두 실행의 캐시 키가 다름" 추가.

## Major -- EO-1 design

### E1. A-12: `device.off_op`에 값 사본 (§4.8-5 1, 4.8-11)
- `OffOp(kind, W, L, vgs, vds, vsb, w_key)` 가운데 W·L은 `device.region_decl`의 `w_m`·`l_m`, kind는 `device.kind`와 같은 값이고 같은 블록이 READS한다. graph 규칙 1·3 위반이고 승인 예외(N3.3·N3.5) 목록에 없다. A-12 채택 문언도 'VGS·VDS·VSB'뿐이다.
- 계획 (5)(라)가 'kind·선언 W·L'까지 적었으니 **계획 문언도 함께 고친다**. 승인 사실은 근거가 아니다(O-208).
- 고칠 문언: "`device.off_op` = `OffOp(vgs, vds, vsb, w_key)`. W·L은 `device.region_decl`, kind는 `device.kind`를 소비자가 READS." §4.9-2 `devices[]` 행 "off 소자 W·L = `device.region_decl`". `ss_off_op` 필드 자리와 VGS < 0 정지 순서는 맞다(A-12 본안 채택 가능).

### E2. A-8 모순: 판정 실행 시점을 코드가 막지 않는다 (§4.9-3, §4.9-5 R1·R2, T-B1)
- 계획 N6.20: "EO-1 판정은 OP-5 뒤에만 실행한다 ... 옛 식 판정 기록을 두지 않음". design: `run_decl`이 있으면 `judge_point`가 돌고 `threshold_eps1` 기록을 만든 뒤 `bridge_status`가 보류로 읽는다. T-B1은 "실제 oracle 1회(OP-3 뒤)". 통과로 세지 않아 fail-open은 아니지만, 계획이 없애려 한 기록이 생긴다. R1 표는 채택되지 않은 (a)를 '권고'로 적고 있다. R2는 A-11 채택 사실과 다르다.
- A-11 판정: 파일 하나·`find_front` 호출자가 경로 전달은 원칙에 맞다. 시점만 빠졌다.
- 고칠 문언:

### 작성자가 달리 쓴 곳

- **M8 IR 용어**: `tb:` 제외는 §4.1 이름 규약과 같아 수용한다. 다만 `measurement_load` 제외는 뜻이 다르다(R1).

- **M5 범위 좁힘**: 수용(Minor 하나).
- **A-24**: 수용. 격자가 달라지는 입력은 비트 동일일 수 없고, `noise_tail_bound_undefined`는 fail-closed다. 발동 수는 F-24 미측정으로 표지되어 있다. O-225 범위다.

### R1. KCL 항등 0 규칙의 `measurement_load` 제외 -- 새 물리 오류 (§21.1 2단계)

- 원 문언: "입력 회로 원소(`tb:` 테스트벤치 원소와 `measurement_load` 제외)로 그래프를 만든다".
- 물리: 측정 부하 저항은 판정 넷리스트의 `.op`에 실재하는 DC 전류 경로다(§10.6 '측정 부하 = 이상 R'). DC 경로가 그 부하뿐인 MOS(출력에서 레일로 가는 경로가 부하 하나인 follower·개방 드레인 꼴)는 실제로 전류가 흐르는데 다리로 판정되어 'KCL 항등 0'이 된다.
- 결과: 엔진 집합이 같으면 그 소자는 판정 대상에서 빠진다. 꺼져 있어도 FAIL이 나지 않으므로 fail-open이다. 엔진 집합이 다르면 전체 거부다.
- 발동: **13회로 0**(이번 실측: 제외·포함 두 경우 모두 erfc_ota {M19, M20, M21}, 나머지 빈 집합). 다만 topology 파일에 `measurement_load` 표지 원소가 없어 **이 실측과 `oracle_m8_bridge.jsonl`은 그 제외 조건을 가르지 못한다**. 측정 부하는 spec 쪽 선언이다. 그래서 §21.1의 '재측정' 문장은 이 조건의 근거가 아니다. 인라인 측정, 파일 없음.
- 고칠 문언: "입력 회로 원소(`tb:` 테스트벤치 원소 제외, `measurement_load` 저항은 DC 전류 경로이므로 엣지에 넣음)로 그래프를 만든다." §18.1 다리 규칙 toy에 "DC 경로가 측정 부하 저항뿐인 MOS → 집합에 안 듦" 추가.

### R2. 격자 밀도 판정까지 ε = r²가 적용됨 -- 새 결함 (§18.3 끝)

- 원 문언: "ε = r²" 뒤에 "**격자 밀도**: 연속 두 적분 차 ≤ ε까지 격자를 2배".
- 옛 판정은 `abs(integ - prev_int) <= reltol * integ`(`O/oracle_noise.py:305`)이고, 계획 OP-B1은 '연속 두 적분 차 ≤ 분해능'이다. r²는 꼬리 V² 눈금에서 나온 값이지 적분 수렴 눈금이 아니다.
- 그대로 구현하면 문턱이 약 1/r배 좁아져(r = 1e-3이면 1000배) 격자가 더 늘고, `top_extensions = 0` 입력까지 N4 비트 동일이 깨지며 `noise_grid_unresolved` 거짓 거부가 늘어난다. 문언도 `·I`가 없어 V²와 무차원을 비교하게 된다.
- 고칠 문언: "**격자 밀도**: |I_k − I_(k−1)| ≤ reltol·I_k까지 격자를 2배(옛 판정과 같은 눈금 -- ε = r²는 꼬리 판정 전용). 상한 = ⌈log_2(최대 점 수 / 시작 점 수)⌉". §18.1 OP-B1 행에 "격자 판정 눈금 = reltol, 옛 입력 격자 점 수 불변" 추가.

**가장 큰 발견 넷**:

1. **KVL 정합은 θ 전류 값과 무관하다.** θ 좌표가 (ln IDu, L)이라 전류는 W만 바꾼다. 대안별 정확 풀이 최소 여유가 5자리까지 같다(§1.3). 그래서 R6에 필요한 것은 '정의된 값'이고, 어떤 값인가는 소신호 행에만 영향을 준다.
2. **LA-1a로 대상 회로에 front가 생기지 않는다.** 조립 출발점에서 as-built 외층을 돌린 결과 ngcc·nmcnr·sf 모두 front 0이고 current_reuse는 출발점이 없다(§12). O-214의 '엔진 front 점이 생긴 뒤 다시 묻는다'는 LA-1a 뒤에 성립하지 않는다.
3. **W_min 하한은 KCL로 '순수 바이어스'로 보이는 가지 가운데 신호 경로가 있는 것을 굶긴다.** sf `R1c` 가지가 그 예다. GBW c −8.12이고 전류만 올리면 −0.42까지 회복한다(§1.4).
4. **HiGHS 허용오차 함정**: 측정 도구 첫 판에서 A 단위 LP가 nA·pA 하한을 삼켰다(§14). 구현이 LP를 쓰면 단위를 스케일해야 한다.

## 1. PG-1 θ 전류 writer

### 1.1 물리 결정자

- 같은 ln IDu·L에서 VGS·VDS 동작점은 전류와 무관하고, gm ∝ I, W ∝ I다. 따라서 **DC KVL 행은 전류를 저항 강하로만 읽고, AC 행은 전류를 직접 읽는다.**
- 하한 행 W ≥ W_min ⇔ I ≥ W_min·IDu(ln IDu, L)/L. 소자 밀도가 있어야 값이 정해진다.

### 1.2 식·원문

- P:304 DEC-104 R3: 필요 gm과 θ 전류는 같은 매크로 풀이가 KCL 기저 행으로 함께 정하고, 미지 둘 이상은 '전원 전류 최소' 변수, 교류 요구가 닿지 않으면 하한 행 최대, 망에 없는 극점이면 하한 행 최대 + '극점 미포함'.
- P:1974 N6.14 범위 13: `iv_currents.py` 건너뜀 삭제, 이 card 시점의 하한 행 = W_min뿐, 기하 평균 자리값 삭제, DK1.
- P:2514: 칸 0 밖 θ 전류 writer = R3, writer 없으면 정의 불능.
- **검증자 지적 재확인(범위 재평가): 맞음.** P:304 R5′ (1) '정해지는 순서 = spec → S·θ 전류 → 쓰기 계획 등식 → …', (4) I_R = `dc_current_basis`, D41:1897 READS `dc_current_basis`. θ 전류가 없으면 R6의 J_point와 R = V_R/I_R이 정의되지 않는다. **단 필요한 것은 값의 존재다**(§1.3).

## 12. two_stage_ota_sf GBW 19 → 1

**판정: LA-1a 결함 아님, L 물리 결과 아님, as-built 외층 궤적 + 측정 지표 산물.** 근거는 측정이고, 외층 보폭 차의 원인만 추측이다.

1. **'19'는 점 19개가 아니라 외층 반복 하나의 FD 스텐실이다.** `m3_twostage_sf.jsonl`: base 궤적 뒤쪽 19점이 모두 Cc 153 fF·I_M6 267.9 µA 한 점 주변이고(c +0.66~+0.76), 그 앞은 전부 음수다. d1은 같은 자리가 Cc 156 fF·I_M6 26.9 µA에서 c −0.19~−0.47이고 그 스텐실 한 점만 +0.65다. 재현: 스캔 6점을 빼면 19와 1이 정확히 나온다.
2. **L만 바꾸면 GBW가 오히려 좋아진다**(`m3b_factor.jsonl`, 칸 0, 같은 나머지 θ):

| 점 | GBW c | PM c | gain c |
|---|---|---|---|
| base | −0.592 | +0.941 | −2.742 |
| base + L만 d1 | **−0.242** | +0.278 | −2.306 |
| base + ln IDu만 d1 | −0.862 | +0.852 | −2.784 |
| base + θ 전류만 d1 | −0.787 | +2.416 | −2.742 |
| base + L + ln IDu | −1.023 | −0.281 | −2.404 |
| d1 전부 | −1.502 | +1.855 | −2.404 |

   물리: L 상승은 PM을 깎는다(기생 C). GBW를 깎는 것은 매크로가 고른 전류·밀도 변화다(g_i → A_i → 매크로 해, M8 전류 27 → 68 µA, gm_O1 5.17 → 4.84 µS). design 문장 '이득 블록 L을 늘린 대가'는 **틀림**(m2 지적 맞음, 측정으로 확인).
3. **같은 L·규칙에서 GBW·PM을 함께 만족하는 점이 있다**: d1 칸 0에 Cc ×0.7 → +0.17 / +0.34, 전류 ×1.5 → +0.36 / +0.70. 물리적 불가가 아니다. 다만 gain −2.40이라 front는 없다.
4. **외층 첫 보폭**: base는 I_M6 ×46으로 뛰고(PM −1.65), d1은 ×5다. **그 차이의 원인은 추측이다**(SLSQP 척도, 시작 활성 집합). 측정하지 않았다.

A0 + 같은 모드 대조(`A0d1none`, 812 s, 보고 전달 뒤 완료): 받아들인 칸 없음, 정확 풀이 위반 5행(`M4a −0.0887·M4b −0.1008·M5 −0.0576·root:M3b −0.0068·root:M4a −1.8`)이 ND와 값까지 같다. 이 회로에서도 θ 전류 값이 출발점 유무를 가르지 않는다(시제품 기준).

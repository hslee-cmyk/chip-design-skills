## 2. PG-1 θ 전류: 닫힌 식

### 2.1 물리·식

- θ 전류는 KCL 행으로 묶인 선형식이고, 소신호 요구가 닿는 행은 I = gm/g 등식이다(P:304 R3·R4). 나머지는 W_min 하한 행이다.
- 양의 미지가 하나인 행 x ≥ (f − rest)/c는 최소 원소가 하나이므로 어떤 양의 목적에서도 해가 같다.
- 차동 입력쌍은 같은 gate DC·공통 source라 VGS가 같고, 정합 소자면 전류가 같다. 대칭은 물리이므로 깨는 안은 권고하지 않는다.

### 2.2 실측 n/N (`n3_closed.jsonl`, integ-it12, D1 L)

| 회로 | 미지 행 N | 양의 미지 1 | 양의 미지 2 | 묶이는가 | 음의 항만(상한 행) |
|---|---|---|---|---|---|
| common_gate | 3 | 3 | 0 | -- | 0 |
| current_reuse | 27 | 24 | 1(M38) | 아니오 | 2(M18b·M9b) |
| folded | 13 | 12 | 1(M11) | **예** | 0 |
| ngcc | 3 | 3 | 0 | -- | 0 |
| nmcnr | 8 | 8 | 0 | -- | 0 |
| pushpull | 6 | 6 | 0 | -- | 0 |
| sf | 8 | 8 | 0 | -- | 0 |
| two_stage, two_stage_sf | 0 | 0 | 0 | -- | 0 |
| **합** | **68** | **64** | **2** | **1** | **2** |

- 닫힌 식과 LP의 값 차이: 묶이는 행이 없는 회로 상대 오차 ≤ 1.2e-16. **LP가 필요한 행 = 1/68(folded M11), 입력쌍 등식을 넣으면 0/68.**
- **LP를 뺀다.** 단위 스케일 상수와 꼭짓점 의존 문제도 함께 사라진다.

### 2.3 차동 비대칭과 입력쌍 pA의 원인

- **비대칭(239 pA / 75 pA)**: folded M11 행 M3 + M4 − M5 − M6 ≥ f_M11이 묶이는데, 입력쌍 M1 = M3 − M6, M2 = M4 − M5의 분배를 LP 꼭짓점이 임의로 정했다. 이번 정식화의 같은 LP는 157/157을 냈다(`n3_closed.jsonl` `pair_I.lp`). 물리 틀림, 결정성도 약함.
- **닫힌 식 + 쌍 등식**: M1 = M2 = max(f_M1, f_M2, f_M11/2) = 157 pA로 대칭.
- **pA 수준의 원인**(folded, data 커밋 전): (a) GBW 미선언이라 매크로 비활성, 입력 소자에 gm 요구가 없다 (b) 그래서 전류가 W_min·IDu/L로 정해지고 (c) IDu가 칸 0의 약반전 밀도다. 값이 틀린 계산이 아니라 **요구가 없는 데서 나온 하한이다.** 결과: noise_excess 9849, offset_excess 8569.
- **판정**: R1이 잡음을 소신호 요구로 적으나 R3에 잡음 → gm 행은 없다. 범위 14 data 뒤에는 GBW 등식이 풀어 준다. LA-1a 변화표에 원인 표지로 적고 새 규칙은 두지 않는다(질문을 넓히지 않음).

### 2.4 권고 규칙(회로 이름 없음)

1. 입력 소자 전류 = gm_b/g(매크로 READS -- rout follower gm 포함, 블록 gm 칸 그대로). 등식.
2. 같은 블록 입력 소자이고 kind·source 넷이 같은 쌍은 전류 등식.
3. 미지 하나 행을 KCL로 차례로 전파(단조 반복, 상한 = 행 수).
4. W_min 행 값의 출처 = §3.
5. 음의 항만 있는 행은 상한이다. 전류가 KCL로 이미 정해진 행의 W_min은 전류 하한이 될 수 없고 그 소자 밀도 상한이다(D:1753 'S_m, 최소 폭 하한 포함'). 실례: current_reuse GBW 추정 모드 LP 해 없음의 원인 = M18b 행 하한 6.84 µA > KCL 고정 M17 1.2 µA(`m4_proto_hook.jsonl`).

**⑩ 문언 반영**:
- S8 변수 조건: 자유도 남는 전류는 하한 행 최대에 놓고 등식이 나머지를 정한다(least solution). '전원 전류 최소 변수'는 망 안 극점일 때만이고 LA-1 몫이다. 해가 min Σ와 같음은 toy로 확인.
- R4: 입력 소자의 W_min은 S 좌표 범위(정의역 ∩ 최소 폭)가 맡는다. 전류 행 충돌로 세지 않는다.
- 해 없음 어휘: 등식 값과 행이 충돌하면 R3 '목표 미달 = 정의된 출발값'대로 등식을 쓰고 `StartConflict`를 기록하며 커널로 넘긴다(R-1′ 행이 아니므로 정의 불능 아님, P:304 (4)).
- 기록 '극점 미포함': 값을 쓰는 자리는 LA-1a. 망 판정이 LA-1까지 '출력 노드'이므로 전부 표지된다.
- E-31 기간: `macro_root_missing`이 PM 미달과 근 없음을 섞는 동안(4/9) 매크로 gm을 그대로 READS하고 변화표 원인 항목으로 적는다. 근 없음 분리는 LA-1 (g).
- 배정 변경: O-140 D8 '이 card가 고친다', 완료 9 (a)·1 (i) toy, P:1973 범위 13.

## 3. PG-1b·PG-4 공통: 쓰기 순서 재유도

### 3.1 물리 결정자

θ 좌표가 (ln IDu, L)이면 **DC KVL 행은 전류를 저항 강하로만 읽는다.** 실측: 전류 대안이 달라도 J_point 최소 여유가 같다(ngcc 0.31812, nmcnr 0.02778, sf 0.0449, folded 0.10122). current_reuse도 spec 모드 A0·ND 위반 5행 값이 같다.

- **표지(m1 수용)**: pre-layout LUT 접근이 한 폭 슬라이스라 이 무관성은 손계산 모형 안 사실이고 물리 측정이 아니다. W 범위 0.42 µm~8.3 mm의 좁은 폭 효과는 SPICE 다리(완료 4)에서 처음 드러난다. 예외: 값 선언 R은 전류가 강하를 정한다.

### 3.2 M2 재현과 원인

sf R1c = W_min·e^(−13.05)/L = 6.03 µA, M9 = 5.98 µA. 묶는 소자 M13·M15는 시제품 분류 B이고 밀도는 R6·R7이 아니라 as-built 칸 값이다. 지우기로 한 B 값이 블록 안 값으로 남아 θ 전류를 정하면 PG-3·P2·원칙 11과 충돌한다. **옛 판의 '블록 안 값으로 풀림'은 철회한다.**

### 3.3 원칙에서 유도

W ≥ W_min은 (I, IDu) 행이다. **밀도가 먼저 정해지면 전류 하한이고, 전류가 먼저 정해지면 밀도 상한이다.** B만 있는 가지는 그 가지 전류를 정하는 다른 요구가 없다. O-127 θ 기저로 읽으면 그 전류는 **B 밀도에 종속**이다. 값 선언 R 가지 전류 I_R = V_R/R도 V_R에 종속이다. 그래서 순서는:

| 단계 | 정하는 것 | 근거 |
|---|---|---|
| (1) S·F | S·F 밀도·L, 입력 소자 등식 전류, 그것으로 KCL이 닫는 θ 전류, S·F 행 W_min 하한 | R3·R4 |
| (2) R6 | B ln IDu, 종속 W4, V_R. J_point는 (1)과 V_R로 정의됨(전류 무관) | R5′, O-127 |
| (3) 종속 전류 | B 행 W_min 하한 = W_min·IDu(B)/L, 값 선언 R의 I_R = V_R/R, 값 미선언 R의 R = V_R/I_R, 나머지 θ 전류를 KCL 전파 | 위 유도 |

- **생산자 하나**: (3)의 값은 R6 블록 출력 `LoopDep`의 성분으로 쓴다(새 필드 0, 성분 '종속 θ 전류' 추가). 출발점 조립이 (1)의 칸과 이 성분을 참조로 읽는다. 같은 원소의 writer는 하나다(원소마다 (1) 또는 (3), 구조로 결정).
- **R 상자**: '상자 × I_R로 V_R 구간'(P:304 (4))이 '상자로 I_R 구간'으로 뒤집힌다: V_R/R_hi ≤ I_R ≤ V_R/R_lo. 전류 상한을 어기면 `StartConflict`.
- **순환 0**: R6는 (3)을 읽지 않는다. 가드 입력 '매크로·KCL 전류만'(DEC-105 (5)(b))은 (1) 전류만 쓰고, (3) 전류 소자는 R6 시점에 가드 계산에서 빼며 (3) 뒤 기록한다. **가드 약화 크기는 미측정**(code 전 재측정).
- **문언 개정 필요**: P:304 R5′ (1) 순서, R6 '독립 성분 writer 아님'(종속으로 재분류되므로 어기지 않음), (4) V_R 구간, DEC-105 (5)(b).

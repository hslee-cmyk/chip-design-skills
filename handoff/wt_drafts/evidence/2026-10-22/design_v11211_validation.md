### S-2 G7은 출력 구조 분류 규칙을 as-built로 새로 정했다
- 위치: 41:721 '**출력 넷 자신이 F′ 안이면 걷기 전에 `"kvl_fixed"`**(`writer_plan.py:134` …; 아래 G_vgs 밖 갈래보다 먼저; 13회로 발동 수 = 감사 측정 대기)'.
- 근거
  - code `c4506f47` `writer_plan.py:122-142` `_output_structure`는 `reached = output in fixed`(:134)로 시작한다. 출력이 F′면 엣지 유무와 상관없이 `kvl_fixed`이다.
  - 계획 O-64 (1)(계획 v6.33 O-64 행)은 '출력이 속한 G_vgs 성분에서 출력 자신의 W3 목표 핀을 뺀 뒤 다른 F(레일·입력 DC)가 있으면 KVL 고정, **없거나 출력이 G_vgs 밖이면 고임피던스**'이다.
  - 41:721(v1.12.10)도 '출력 넷이 G_vgs 엣지의 끝점이 아니면(G_vgs 밖) `"high_impedance"`'이다.
- 판정
  - (1) **충돌 사례가 있다.** 출력 넷이 F′(레일 또는 선언 입력 넷)이면서 G_vgs 엣지에 닿지 않으면, 계획 문언으로는 `high_impedance`이고 G7로는 `kvl_fixed`이다. G7은 '아래 G_vgs 밖 갈래보다 먼저'라고 우선순위를 명시해 계획과 반대 결론을 정한다.
  - (2) 출력이 F′이면서 G_vgs 안이면, 계획의 '다른 F'가 출력 자신을 포함하는지가 계획에 정해져 있지 않다. 이것은 문언의 공백이다.
  - (3) 따라서 G7은 '사실 정정·빈칸 채움'이 아니다. **계획 공백(·일부 충돌)을 as-built code 동작으로 메운 분류 규칙 결정이다.**
    - 회로 해석 규칙은 사용자와 함께 분석해야 하는 대상이다(메모리 '회로위상 해석은 항상 공동분석').
    - S-7 '계획 먼저'와 'as-built 결정 금지'에 어긋난다.
    - 오케스트레이터 지시('문구 자리만, 수치는 감사 측정 대기')도 넘었다.
- 물리 판단(공동분석 입력용, 결정 아님)
  - 출력 넷 = 레일: DC가 이상 전원으로 고정되어 x에 따라 움직이지 않는다(감도 0). follower 행 V_out = x(고임피던스 갈래)는 물리적으로 불가능하다. 그래서 `high_impedance`는 틀리고 `kvl_fixed`(감도 연립에서 s_out = 0)가 물리와 맞는다. 다만 출력 포트가 레일인 회로는 선언 오류일 가능성이 커서, 분류보다 **fail-closed(정의 불능·사유)**가 더 맞을 수 있다.
  - 출력 넷 = 선언 입력 넷: 측정 구성에서 선언 포트 묶음은 같은 Δ로 움직이므로(P3), 출력 = 입력이면 s_out = 1이다. 이 값은 `kvl_fixed` 감도 연립이 구동(Δ)으로 정확히 낸다. `high_impedance` follower 행도 V_out = x라 값은 같다. 다만 F′ 고정 넷에 follower 행을 다시 세우면 같은 넷에 식이 둘이 되어(고정 + V_out = x) 연립이 과결정될 위험이 있다. 그래서 `kvl_fixed`가 물리·수치로 더 일관된다.
  - 결론: 방향(출력 ∈ F′ → KVL 고정)은 물리적으로 그럴듯하다. 그러나 레일 출력은 fail-closed가 더 맞을 수 있다. 이 차이를 계획·사용자 결정 없이 design에서 정하면 안 된다.
- 수정 제안
  - **권고**: 721의 G7 구절을 '출력 넷 자신이 F′ 안인 경우 = 계획 O-64 (1) 문언 공백(G_vgs 밖이면 계획은 `high_impedance`) -- as-built `writer_plan.py:134`는 `kvl_fixed`, 분류 규칙은 계획·사용자 공동분석 대기; 13회로 발동 = 감사 측정 대기(발동 0이면 해당 없음, 1 이상이면 41:724대로 멈춤)'로 바꾼다. 계획 O-64 (1)에 '출력 ∈ F′' 갈래(선택지: KVL 고정 / 레일 출력은 fail-closed / 둘의 조합)를 사용자 결정 항목으로 올린다.
    - 원칙 적합: 적합. 계획 먼저, as-built 결정 금지, 회로 해석 공동분석, fail-closed 선택지를 보존한다.
  - 기각할 안: G7 문언 그대로 병합. as-built 규칙 결정이고 계획 문언과 충돌하는 사례가 있다. 원칙 위반이다.

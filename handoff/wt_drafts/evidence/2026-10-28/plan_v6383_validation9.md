### V9-M3 (중간) 'E-31 대상 = 근 없음만'이 DEC-105 (3)의 P = 0 요건과 맞물리지 않는다 -- 모든 칸이 '근 있음·P ≠ 0'일 때 규칙이 없다

- **자리**
  - GB:304 DEC-105 (3): '매크로 출발점은 \|H(jω)\| = 1 근에 더해 개방 루프 RHP 극점 수 P = 0을 요구하고, 아니면 뒤 블록 gm을 같은 2배 사다리 … 다음 칸으로 올리고, 사다리 끝 처리는 N6.35 E-31'.
  - GB:2368 E-31: '**대상 = \|H(jω)\| = 1 근이 상자 안에 없음 … 만**'.
  - GB:2334 공통 규칙: '정의 불능 = … 식·근·전달이 없다는 사실(예: \|H\| = 1 근이 상자 안에 없음, MNA 특이). 근은 있으나 목표 … 못 맞춤 … 은 정의 불능이 아니다'.
  - GB:1930 LA-1 완료 (b): 'RHP 극점이 있는 출발점을 버림'.
- **사실**: 모든 gm 사다리 칸에서 \|H\| = 1 근은 있으나 P ≠ 0인 후보를 보자.
  - DEC-105 (3)대로면 칸마다 버리고 사다리 끝 → E-31이다.
  - E-31은 '근 없음만'이라 이 경우를 대상에서 뺀다.
  - 공통 규칙의 정의로는 근이 있으니 정의 불능이 아니다. 그러면 '정의된 값으로 출발'이 되는데, 어느 칸 값인지 정해지지 않는다.
  - as-built는 P를 계산하지 않는다(`macro_poles.py` 출발점 탐색에 P 검사 없음). 그래서 library 발동은 지금 측정할 수 없다.
- **막는 경로**: LA-1 범위 15 (b)·(g)의 design이 이 경우의 처리를 정해야 한다. 계획 세 자리의 결과가 서로 다르다(후보 불능 / 대상 아님 / 출발). design 착수 브리핑의 'as-built 결정 금지, 멈추고 보고'에 걸려 착수가 멈춘다. 완료 toy (b)도 '모든 칸 P ≠ 0' 경우의 기대값을 정할 수 없다.
- **대안**
  - (가) **권고.** E-31 대상을 'DEC-105 (3) 출발점(\|H\| = 1 근이면서 개방 RHP 극점 수 P = 0)이 상자 안에 없음'으로 적는다.
    - 물리 결정자: P ≠ 0이면 \|H\| = 1 교차에서 읽은 PM은 안정 여유가 아니다(Nyquist 판정은 P를 세야 함). 그래서 매크로가 내도록 정의된 출발점(안정 루프의 UGF 점)이 없다. 이것은 근 없음과 같은 '정의 불능'이다.
    - 공통 규칙 정의의 예시에 'P = 0 근 없음'을 더한다.
    - LA-1 (g) toy에 '모든 칸 P ≠ 0 → 후보 매크로 출발 불능'을 더한다.
    - library 발동은 LA-1 착수 측정(P 계산이 생긴 뒤)에서 잰다.
  - (나) P ≠ 0 칸을 '정의된 값 + StartConflict'로 출발한다. ⚠ DEC-105 (3)(사용자 결정 Q2-2 B 'RHP 출발점은 다음 칸으로 올린다')과 완료 (b) '버림'에 반대된다.
  - (다) 그대로 둔다. ⚠ 세 자리가 서로 다른 결과다.

## 6. 상정 판단

중간 3건이 남아 **상정 불가**다.

- **V9-M1**: E-31 실측 문장·승인 #27·GC history를 후보 단위로 다시 적는다. 근 없음은 최상 칸 t = 1에서 3회로, PM 미달은 4회로(아래 칸 `refine=False` 포함), 최종 선택점 근 없음은 0이다. 아래 칸(정제 생략) PM 미달의 기록 여부와 '후보'의 범위(사다리 칸·격자 점 / 탐색 점 제외)를 한 구절씩 정한다.
- **V9-M2**: GC:445·692(604·779 표지)와 GB E-31 비대상 칸에 한 구절을 넣는다. '해제는 PM 미달·미수렴 실패만 푼다. 근 없음 원인 후보는 해제 뒤에도 매크로 출발 불능이다.' 혼합 원인 픽스처를 더한다.
- **V9-M3**: E-31 대상과 공통 규칙 정의에 'P = 0인 \|H\| = 1 근 없음'을 넣는다(DEC-105 (3)과 한 정의). LA-1 (g) toy에 '모든 칸 P ≠ 0 → 후보 출발 불능'을 더한다.
- 경미 L-1~L-5를 함께 처리하면 다음 검증의 종료 기준을 충족할 것으로 본다.

## Q1. ICMR 기능 기준의 꼴 일반형 (O-211 재검토, 원칙 20)

### 원결정
- O-206(UD:1187): ICMR 판정 제약(`icmr_v`·`icm_margin_v`)마다 창 안 점별 기능 기준 spec 칸, 미선언 = 정의 불능. 예 문언은 **절대**('gain_ss_db ≥ 사용자 선언값 또는 value_from_constraint').
- O-211 RR-3(UD:1192, P:729 'ICMR 기능 기준'): 기능 기준 = 점별 **증분 DC 이득**, 판정 꼴 = 출력 범위 (b)와 같은 **기준점 대비 선언 허용 저하**, 엔진 함수 = DE-1 (e), 창 끝 = [봉인점, 영역 행 창 끝] 첫 교차(K_max), ICMR 끝 = 영역 행 끝 ∧ 기능 기준 끝. 근거 문서 `evidence/2026-10-31/o208_rereview_candidates.md`:125가 (d-2) 절대 꼴을 '판정 꼴 칸이 둘, 공칭 미달 점에서 창이 비어 이득 제약과 중복 판정'으로 기각. [Q1 해석 반영] 정정: 이 중 '이득 제약과 중복 판정'은 성립하지 않는다 -- gain 제약은 공칭점 하나, ICMR 절대 항은 선언 폭 전체를 판정해 대상이 다르다(Q1 권고 '대가와 중복 판정 정정').
- O-157 S2: current_reuse 출력 범위 (b) = Vod = 0 기준 −3 dB(원문 정의).

### 문제
분석가 넷이 두 꼴로 갈렸다(nmcnr·ngcc·sf = 절대 하한, current_reuse = 상대 3 dB). 원칙 12로 회로 무관 일반형 하나가 필요하다. 새 사실 둘: (1) O-133으로 current_reuse에는 SF-1 뒤 gain 하한이 없다(D2) → 절대 꼴 단독은 4/4가 안 된다 (2) 상대 꼴의 X를 원문이 정의한 회로는 1/4(current_reuse Fig. 11)뿐이고 3/4는 근거 없는 숫자를 사용자가 골라야 한다.

읽는 법과 사실:
1. **절대 항이 스스로 끝을 정한 x0 = 0/4 회로**(주사 전체). 절대 항은 'x0에서 이미 미달'(= gain 제약 실패, nmcnr R3·ngcc L 0.5 µm)이거나 영역 행 뒤에 숨는다. 이유: 측정 설계점의 gain 여유 δ = A(x0) − 하한이 10~28 dB로 커서다.
2. **항등식**: 절대 항은 상대 항 X = δ와 같은 창을 낸다(T = A(x0) − δ = 하한). front 점에서는 gain 제약이 활성이라 δ → 분해능 수준이 되고, 그때 절대 항은 위 표의 '상대 1 dB' 열처럼 거의 모든 x0에서 끝을 정한다. 즉 측정점의 '절대 항 무력'은 큰 여유 때문이고, front에서는 **ICMR이 gain 여유와 결합**한다(물리 뜻: 선언 ICMR 폭 안 모든 CM에서 gain spec을 지켜야 함).
3. 상대 항이 끝을 정하는 쪽은 **점진적 이득 저하가 영역 이탈보다 먼저 오는 쪽**뿐이다: current_reuse 위(캐스코드 M3a ro 감소, 영역 끝보다 30 mV 앞), sf_pushpull 위(입력쌍 VDS 감소, 40 mV 앞). 아래 끝은 4/4 영역 행(또는 레일).
4. **ngcc 관찰의 뜻**(분석가 §3.4 재확인): 영역 창 밖(위)에서도 A가 ≤ 1.6 dB만 변한다(tail 전류 1/1800). 약반전 gm ∝ I, ro ∝ 1/I라 gm·ro가 전류와 무관 → **증분 DC 이득은 전류 고갈을 보지 못한다**. 4/4에서 전류 고갈은 꼬리 소자 영역 이탈(ngcc M0, nmcnr M101, current_reuse M5, sf M3)과 함께 오므로 영역 행이 잡는다. 결론: (a) 어느 꼴이든 영역 행을 빼면 안 된다(ngcc 반례 -- O-205 (3) 유지와 정합) (b) 기능 기준의 실제 역할 = 영역 이탈 전 점진 ro 저하 포착 (c) 이 판별 한계는 (가)(나)(다)에 똑같이 걸려 꼴 선택을 가르지 않는다 (d) 고갈의 AC 결과(GBW ∝ I)는 DC 양이 아니라 ICMR(DC 양, 원칙 3) 밖이다 -- 기록.

- **[Q1 해석 반영] 기준의 뜻과 해석 선택(사용자 몫)**: (다)의 절대 항이 말하는 것은 'spec `icmr_v`는 이 폭 안에서 이득 spec이 유지되는 공통모드 폭'이다(데이터시트의 'spec 보장 범위' 꼴). 사용자 spec 해석이 이것이면 합리적이다 -- 새 상수 0, 요구 이득 = 사용자 선언값(`gain_ss_db`), 그리고 공통모드에 따라 gm·ro가 변해 창 안 실제 이득이 2.0~3.8 dB 떨어진다는 실측(nmcnr R2b 2.5·R4 2.9·R6 3.8, ngcc L 1 µm 2.0 dB, `q1_unified_windows.jsonl`)이 이 판정이 실제로 일을 한다는 근거다. 교과서 정의('소자가 동작 영역에 머무는 폭')로 읽으면 영역 행만으로 충분하다((마) 꼴, O-54). 다만 O-205 P5가 약반전 전 구간을 전도로 받고 반전 수준 하한 행이 철회돼(O-207) 영역 행만으로는 전류가 거의 없는 약반전 점도 통과하는 과대 통과가 남는다(O-205·O-206이 (마)를 fail-open으로 기각한 이유). 이 해석을 고르면 그 과대 통과를 막을 판정을 따로 정해야 한다(지금 계획에 그 자리 없음 -- 고르면 계획부터). 어느 해석이 spec `icmr_v`의 뜻인지는 사용자 몫이다.
- **[Q1 해석 반영] 대가와 '중복 판정' 정정**: 공칭점 이득이 spec을 겨우 넘는 front 점(gain 제약 활성, 여유 δ → 분해능)에서는 ICMR 폭이 0에 가까워진다 -- 선언 ICMR 폭을 살리려면 x0에 창 안 이득 저하(2.0~3.8 dB)만큼 설계 여유가 필요하다. '범위 전체에서 이득 유지' 의도에서는 이것이 정당한 판정이고 중복 판정이 아니다: gain 제약은 공칭점 하나를, ICMR 절대 항은 선언 폭 전체를 판정해 대상이 다르다. x0 미달 점에서는 같은 원인이 두 판정에 함께 기록될 뿐이다(조건 (3) 원인 표지). 따라서 O-211 RR-3 근거 문서(`evidence/2026-10-31/o208_rereview_candidates.md`:125)의 (d-2) 기각 사유 중 '이득 제약과 중복 판정'은 이 사실로 정정한다('판정 꼴 칸이 둘' 사유는 (다)가 한 꼴로 해소).
- **[Q1 해석 반영] 원문 정의와 다름(표지)**: ngcc 원문 ICMR = 식 (9) 입력단 전부 포화 폭(영역 행만)인데 (다) 권고는 절대 이득 항을 더한다 → 원문 정의와 다름. current_reuse 원문 = 이득 정점 −3 dB, 계획 꼴 기준 = 봉인점 → 원문 정의와 다름. nmcnr·sf는 원문 정의 없음. ngcc는 증분 DC 이득이 tail 고갈을 보지 못하므로(위 사실 4) 영역 행 병용이 필요하다(어느 안에서도 영역 행 유지).
- **[검증 A-2] Q1·Q3 결합 결과(질문 문언)**: Q3 (가′)(권고)이면 current_reuse·sf의 ICMR 보고 값이 보고용 선언으로 정의된다. Q3 (가)(보고 유지·선언 없음)을 고르면 두 회로의 ICMR 보고 값은 **영구히 정의 불능**이다.

### 직접 재확인(유도)
P:729 정의: `icm_margin_v` = min(V_cm0 − V_cm(아래 끝), V_cm(위 끝) − V_cm0), V_cm0 = 봉인점 입력 평균; ICMR = 출력을 봉인점 동작점에 묶은 servo(O-115); 창 끝 근 찾기 구간 = [봉인점, 영역 행 창 끝]. x = V_cm0에서 servo 상태 = 봉인 상태 그 자체(같은 θ, 같은 입력 차, 같은 출력). 따라서
- 영역 행: 봉인 7이 전 소자 VDS ≥ VDSAT(경계 고정, 판정 여유 0 -- O-204) → x0에서 만족.
- 레일: 봉인점 입력은 레일 안.
- 상대 기능 항: x0에서 저하 0 ≤ X → 만족.
- ⇒ 봉인된 모든 점에서 icm_margin_v ≥ 0 **항등 참**. 절대 항을 선언하면 x0에서 A(x0) ≥ 하한 ⇔ gain 제약(같은 뷰일 때) → 둘째 판정일 뿐 새 정보 0. oracle 쪽도 x0의 비포화는 T4 포화 대조가 먼저 FAIL.
- 과거에 의미가 있었던 이유: 'LUT tol 여유 포함 창'(판정 여유 +tol)이면 x0가 창 안쪽으로 tol 이상 들어가야 해서 참이 아닐 수 있었다. O-204(여유 0)·O-205 (3)(R0 삭제)·O-115(servo)가 겹쳐 항등 참이 됐다.
- 실측: 9사례 모두 영역 창 ∋ x0(`q1_unified_windows.jsonl` -- 봉인점이 아닌 nmcnr R1 제외), 분석가 margin 0.044~0.11 V.
- 판정: sf 분석가 지적 **맞음**, current_reuse에도 같음.

## [Q8] G2-a의 `triode` 선언 소자 비대칭 (계획 확인 항목 (3) -- 작성자 유도, 확인 질문)

## 2. 결론

이름은 **물리적으로 무해한 tie-break가 아니다**. 또 **DEC-64 metamorphic test로 충분하지 않다.** 근거는 셋이다.

1. **해 집합은 두 선택이 같다.** 정의역, E-0, 가능 점 수가 같고 왕복 오차는 ≤ 4e-8이다. 그래서 '어느 다이오드를 종속으로 하느냐'는 물리 정합(E-0)을 바꾸지 않는다.
2. **그러나 θ → 물리점 사상, 풀이 형태, 손계산 오차가 놓이는 자리는 바뀐다.**
   - 같은 θ에서 oracle I_Q가 0.3~13 %p 다르다.
   - 레일 종속은 반복 풀이이고, 쌓인 종속은 닫힌 꼴이다.
   - 그러므로 이름 전단사(예: M11a↔M11b 맞바꿈)를 하면 종속 소자가 물리적으로 바뀐다. front 정규화 해시가 **비트 동일하지 않게 된다**. metamorphic test는 이름 규칙을 '고정'하는 것이 아니라 **실패로 드러낸다**. 오히려 이름이 결과에 영향을 준다는 증거가 된다.
3. 이름은 고리마다 다른 물리 부류를 고른다(레일 2/4, 쌓인 2/4. r2r도 1/2씩).

## 5. §추가 (2026-10-30 2차): 규칙 (가)의 n/N -- 13회로 전체 kvl_branch 고리, 연결만

스크립트 `loops13.py`(엔진 import 없음), 결과 `loops13.jsonl`.

**고리를 찾은 방법**
- G_vgs: MOS 하나가 gate 넷–source 넷 무향 엣지 하나다. supply_nets는 고정 노드 하나로 병합했다(계획 92행 정의).
- 평행 엣지(같은 {gate, source})는 equal_vgs 부류 하나로 접었다.
- 고리 = 접은 그래프의 **단순 사이클 전수**다. 입력 포트 넷을 지나는 고리는 port_diff로 빼냈다.
- 엔진은 사이클 기저를 쓴다(current_reuse 4, r2r 4 -- 앞 기록 `classab_battery.md`). 단순 사이클 전수는 기저 4개를 포함하고, 그 조합 고리가 더 나온다(r2r 6).

**B를 판정한 방법**: 계획 91행 DC 역할 절차를 연결만으로 근사했다.
- diode = gate == drain이다.
- bias = diode와 {gate, source}를 공유하거나, gate가 bias_inputs 또는 레일인 소자다.
- 이것은 엔진 S1v 셀 분류(loop_pick가 쓴 stage_a)와 다를 수 있다. 다를 수 있는 자리는 아래에 따로 표지한다.

**규칙 (가)의 판정식**
- 고리에서 소자 Y의 엣지를 빼면 경로 하나가 남는다. 그 경로에서 레일부터 source_Y까지 놓인 멤버 집합을 P(Y)라 한다.
- P(Y)는 source가 비레일이고 결합이 있는 Y에만 둔다. 결합 = VSB가 있거나, diode가 아니라서 VDS가 source 전압을 읽는 경우다.
- 후보 D가 어떤 P(Y)에도 없으면 '하류'다. 하류 D를 종속으로 두면 닫힌 꼴로 풀린다.

- 다이오드 B 고리: **8/8 유일**(엔진 기저 기준 4/4: current_reuse 4, r2r 2 + 조합 2).
- 다이오드 없는 r2r 고리 2개: 읽기에 따라 (i) 2/2 유일, (ii) 0/2 유일(tie).
- sf_pushpull 1개: 적용 불가.
- 단순 사이클 전수로 보면 11고리 중 유일 8~10, tie 0~2, 해당 없음 1이다.

**r2r 다이오드 없는 고리의 두 읽기**: 연결은 F–M26–n_gn–M19–n_abn–M27–n_mn–M17/18–F이다.
- 읽기 (i): current_reuse loop_pick이 M9a(같은 꼴의 부유 class-AB 소자)를 S/F 'pass'로 분류했다. 그 유비를 따르면 M19·M27은 pass, M17/M18(합산 부하)은 B다.
  - 그러면 B = {M17/18} 하나라서 tie-break가 필요 없다.
  - **그러나 강제된 종속 M17/18이 M27의 상류다**(P(M27) = {M17/18}). M27의 VSB와 VDS가 M17의 VGS를 읽으므로 이 고리는 **암묵 풀이(1차 근)**가 된다.
  - 이것은 DEC-104 'B만 종속'과 (가)의 닫힌 꼴 선호가 부딪치는 꼴이다. (가)는 순위 키일 뿐 B 제한을 넘지 않으므로 결과는 '유일하지만 반복 풀이'다.
- 읽기 (ii): gate가 다이오드 생성 바이어스 n_abn인 M19·M27을 B로 본다. 그러면 하류는 {M19, M27}이다.
  - P(M19) = {M26}, P(M27) = {M17/18}이고, 서로의 P에 없다.
  - **두 후보 모두 닫힌 꼴이고 구조 동치가 아니다**(M19 → 출력 M25/M26 gate, M27 → M11/M12/M17/M18 gate). 그래서 tie다.
- 어느 읽기가 맞는지는 엔진 S1v 셀 판정(엔진 밖에서 확인 불가)이나 사용자 회로 해석이 정해야 한다. 원칙 14·15의 사용자 몫이다.

**tie가 나면 다음 키 DEC-97 정준 라벨이 물리적으로 무해한가**
- 판정: **해 집합·E-0·풀이 형태는 무해하다. 같은 θ → 같은 물리점은 아니다.**
- 근거:
  - 두 후보가 모두 하류(닫힌 꼴)이면 KVL 1식의 해 곡선은 같다. 어느 쪽을 종속으로 해도 해 집합과 풀이 비용이 같다. current_reuse에서 잰 왕복 오차 ≤ 4e-8, 가능 점 수 일치가 같은 수학이다.
  - 그러나 독립 좌표 집합이 다르다(IDu_M19 대 IDu_M27). 그래서 같은 θ 벡터는 다른 물리점으로 간다. 자기동형(궤도)이 아닌 한 **어떤 tie-break 키로도 피할 수 없는 성질**이다. current_reuse 실측: 같은 θ에서 W 16.2/15.0 대 15.0/16.4, oracle I_Q 차 0.3~13 %p.
  - 정준 라벨의 장점은 이름 전단사 불변이다. 그래서 DEC-95 metamorphic test(비트 동일)를 구성상 통과한다. 이름은 이 test에서 실패한다.
- 결론: tie에서는 (라) 정준 라벨이 (마) 이름보다 낫다. 다만 '물리적으로 고른다'는 아니다. 남는 점별 사상 차는 탐색 상자가 두 좌표 모두에서 정의역 전체일 때 결과(front)에 영향이 없다. 상자가 출발 구간 축소 등으로 좁혀지면 front가 달라질 수 있다(미측정).

**갱신된 권고**
- 순위는 diode → 대칭 궤도 대표 → **(가) 소스 사슬 하류** → **DEC-97 정준 라벨**(이름 대체)이다.
- 열린 물음 둘:
  - (a) r2r 다이오드 없는 고리의 B 판정(읽기 i/ii) -- 사용자 회로 해석.
  - (b) 레일 없는 follower 고리(sf_pushpull)의 종속 선택 -- B = ∅이라 DEC-104 R6 밖. 이 고리가 엔진 기저에서 kvl_branch로 잡히는지부터 확인해야 한다(이번에 재지 않음).
- graph 정본: 새 필드 0이다. (가)는 G_vgs의 source 넷을 읽고, 정준 라벨은 DEC-97의 기존 산출을 READS로 읽는다.

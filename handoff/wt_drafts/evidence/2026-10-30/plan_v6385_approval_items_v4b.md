## 1. Q-TH1 -- θ 좌표 통일 (GB 1185)

### 1.1 결정할 것

- 본 질문 (A): θ 독립 좌표와 모든 역산 키를 ln IDu로 통일할지 정한다.
  - 통일하면 gm/ID는 순방향 조회 필드만 남고, '가장 큰 VGS 해' 분지 규칙은 사라진다.
- 하위 질문 (L): 레이아웃 보존량 (§1.9).

### 1.2 사실 (O-171)

- **물리 결정자 1 -- ID(VGS) 단조**(오케스트레이터 실측, LUT r2 전수, 2026-10-30)
  - 범위: VDS > 0 전체, nfet·pfet 각 414,720 인접 VGS 쌍.
  - ID가 감소하거나 같은 쌍은 **0**이다.
  - 인접 비 ID(k+1)/ID(k)의 최소는 **1.021(n)·1.027(p)**이다.
  - gm ≤ 0인 점은 **0**이다.
  - 그러므로 ln ID(= ln IDu + ln W_ref)는 VDS > 0에서 VGS에 **엄격 단조**이고, 역산 VGS = f⁻¹(ln IDu)는 유일하다.
  - VDS = 0 단면에서는 ID ≡ 0이라 전류 밀도로 VGS를 정할 수 없다. 이것은 구조적 0 전류 소자의 정의 그대로다. 그 소자는 Q-S9(봉인·oracle 판정 제외)·Q-ZG1(기하 = W_min·L_min)·DR-1(VDS = 0 묶음)이 따로 다루므로 정합한다.
- **물리 결정자 2 -- gm/ID는 단조가 보장되지 않음**
  - gm/ID = ∂ln ID/∂VGS는 기울기다. ln ID가 단조여도 기울기가 단조라는 보장은 없다(ln ID의 오목성이 필요).
  - LUT r2 전수(MR §2): nfet 비단조 0/8640, pfet 6265/8640(72.5 %).
  - pfet의 비단조는 중간 반전 혹이다(VGS 약 0.6~1.05 V, gm/ID 약 14~18 S/A, 진폭 중앙 0.88 %·최대 8.2 %, L ≤ 0.2에서 최대).
  - 가려진 점에서 LUT 대 ngspice 차가 ≤ 1.1 %다. 즉 LUT 인공물이 아니라 sky130 pfet 모델 곡면의 성질이다.
- **as-built '가장 큰 VGS 해' 규칙**(재작성 범위 `lut/vgs_root.py`)
  - kv1 대표점(sky130에 맞춘 치수, M9a L 0.15) 근처 current_reuse class-AB 반쪽에서 pfet 49/81(전체 49/161)에 다른 동작점을 고른다(VGS +0.09~+0.30 V, 헤드룸이 없는 쪽).
  - 이 결과는 원문 설계점 결과가 아니다. 원문 치수로 옮기면 M9a는 혹 밖이다(MR §5.1).
  - 판정: 틀림.
- **원문 설계점(IDu·L 보존 이식)**(MR §5.1)
  - 판정 가능 6/13 가운데 확정 1: current_reuse 다이오드 M11a·M20a·M11b·M20b(VGS +0.074~0.078 V, Xie 2019 Fig.7(b)).
  - 조건부 1: erfc 8소자.
  - 0인 회로 4, 판정 불능 7/13.
  - 사용자 spec이 gm/ID를 직접 주는 곳: 0/13.
- **계획 안 충돌**(graph 규칙 3)
  - DEC-70(269)·DEC-88(287): 'S·F 셀 = ln IDu'.
  - DEC-104 R4(303)·LR7(729)·DEC-73(272)·DEC-105(304): 'S 소자 gm/ID·L 독립 좌표'.
- **엔진 역산 경로**(재작성 범위, MR §5.2)
  - 다른 점을 조용히 고르는 곳: `vgs_for_gm_id`·`strong_inversion_root`(실행 소비자 `layout/slice_density.py`), `_at_gm_id` → `curve_value`(출발 구간 8곳).
  - `gm_id_for_target`은 비단조면 fail-closed다.

### 1.3 gm/ID 방법론 정합 (원칙 1)

- **원문**: Jespers & Murmann 2017 §3.1.6(pp.83-84).
  - "gm/ID no longer uniquely defines the drain current density once the transistor enters weak inversion … Since there is a one-to-one mapping between JD and gm/ID, we can always begin by selecting JD, then look up gm/ID and complete the design as usual."
  - Fig. 3.17: "Current density-based sizing, appropriate for all inversion levels."
- **ln IDu와의 관계**
  - ln IDu = ln(ID/W_ref)는 전류 밀도 JD = ID/W(같은 L, VDS, VSB)의 로그다. **같은 정보를 다른 좌표로 쓴 것**이다.
  - gm/ID·ft·intrinsic gain은 JD 축 위에서 순방향으로 읽는다. 같은 차트 집합이다.
- **sky130 pfet에서 무엇이 달라지는가**
  - 원문은 'JD ↔ gm/ID 일대일'을 가정한다. sky130 pfet 혹에서는 gm/ID → JD가 일대일이 아니다.
  - JD → gm/ID(순방향)는 여전히 함수다(§1.2 결정자 1).
  - 그래서 원문의 'JD를 먼저 고르는 흐름'은 sky130 pfet에서도 그대로 성립한다.
- **판정**: 맞음(상). (A)는 gm/ID 방법론을 벗어나는 것이 아니라, 원문이 '모든 반전 영역에 적합'이라고 한 일반형이다.

### 1.5 권고와 원칙 근거

**권고: (A).** 근거는 넷이다.
1. **물리**: VDS > 0에서 엄격 단조인 좌표는 ln ID뿐이다. gm/ID는 기울기라 단조가 보장되지 않고, sky130 pfet에서 실제로 깨진다.
2. **원칙 1**: Jespers의 전류 밀도 흐름과 같다. 역산이 사라져 가볍다.
3. **graph 규칙 3**: 계획 안의 좌표 정의 둘이 하나로 준다. 새 필드·cache는 0이다.
4. **원칙 6**: (B)는 결국 (A)로 수렴한다.

남는 일: LR6 하한 같은 gm/ID 부등식은 순방향 제약 행 g(ln IDu) ≥ 하한으로 둔다. 출발 구간이 이 행의 해 집합(hull)을 쓰면 구간이 여럿일 수 있다(M-TH1a).

- **옛 OrderHints**: (다) 승인 시 삭제한다. 미배선 as-built라 (가)를 골라도 ② 재작성과 함께 지운다.

### 2.5 r2r 다이오드 없는 고리 해석 -- 사용자 승인 대상 (원칙 14)

|---|---|---|---|
| M19/M20 | **(i) pass(F)** | DC 절차: diode 아님, source 비레일 → 신호 소자. AC: 채널이 신호 넷 사이, gate n_abn은 바이어스 넷 → pass. 원문 "current … M19 decreases"(Hogervorst 1994 PDF p.3 / 저널 p.1507, Fig. 5) | 상(M9a형 '종단 임피던스' 성분 기준이면 중상) |

| M17/M18(M11/M12) | B(미러) | 원문 "current mirror M15 – M18"(p.1509) | 중상 |

- **(i)의 귀결**
  - 종속은 M17/18이다. M27이 그 하류에 있어 고리 N은 1차 암묵 풀이가 된다(유일하지만 반복).
- **발동 여부**
  - DEC-64 기저가 {A, N}이면 이 고리가 생기고, {A, B}면 사라진다(M-KV1c).
  - 원문의 물리 결정자 고리는 다이오드 고리 B {M17, M23, M24, M27}이다(p.1509).
- **벌크 미선언**: topology 정정 대기열(사용자 몫)로 넘긴다.
- **원래 취지와 다름 후보**: M27/M28의 원문 기능(바이어스)과 계획 정의(F)가 다르다. B로 바꾸려면 R13 정의를 개정해야 하고 사용자 승인이 필요하다(지금 권고 아님).

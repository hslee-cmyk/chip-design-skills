## 0. 결론

1. **분류**: P(물리·정의) 30, M(방법·구조) 23, A(승인·병합) 7. 합계 60(§2).
2. **P 판정**: 적합 13, 의심 13, 위반 4(§3·§5 표).
   - 위반 넷 가운데 셋은 ICMR follower 줄기(O-25 (2), O-33 (5), O-50 G4)다. 이미 O-115가 대체했다.
   - 나머지 하나 O-49 P5는 대상이 소멸했다(O-109 C1).
3. **새로 찾은 가장 큰 문제 -- 계통 offset**
   - O-43 D1 (c)·O-46·O-47·O-59 (4)의 전제는 '계통 offset은 θ 프레임 봉인점에서 구조적으로 0'이다. 실측 5/5 회로가 이 전제의 반례다(§4.1).
   - 봉인점의 입력 차 Vid0 = x0 − V_inv0는 −0.76 ~ −28.9 mV다. 엔진이 반전 입력을 `vgs_gate` writer로 쓰기 때문이다.
   - SPICE도 그 입력 차에서 출력이 V_out0(±0.16 mV, nmcnr 제외)임을 확인한다.
   - 원천은 입력쌍 VDS 차(채널 길이 변조)다. M1·M2는 같은 ln_idu·같은 전류·같은 W라 ΔW = 0이다. 그래서 지금 정의(ΔW 성분만)가 이 성분을 빼먹는다.
   - 지금은 모든 library spec의 `input_dc`가 `pending SP-2`라 offset이 정의 불능으로 가려져 있다. SP-2가 선언되면 드러난다(**추정**).
4. **슬루 계단 끝**(O-28·O-34 (2)·O-50 G2·O-51 → 지금 U-102)
   - 근거는 관례 전이다.
   - 실측(손계산 추정): class-A 입력쌍 4회로에서 계단 폭이 완전 전환 전압의 2.3~5.4배다. 그래서 계단 끝을 어디로 잡든 슬루율(I/C)은 같다.
   - nmcnr 위 방향은 0.7배라 계단 끝까지 밀어도 슬루 조건이 성립하지 않는다(§4.2).
   - 끝 정의가 값을 바꾸는 곳은 class-AB와 nmcnr뿐이다. 그런데 class-AB 엔진 전류(θ 전류 합)가 정의(입력 끝 DC 해 전류)와 같은 양인지는 **실측 필요**다.
5. **사용자 질문 '왜 비교가 빠졌나'에 대한 기록상 답**: 같은 꼴이 네 번 반복됐다.
   - (a) 관례·선례를 정의로 옮김: O-25 (2) Allen 관례, O-50 G4가 슬루 규칙 O-34 (2)를 ICMR에 전이, O-51이 슬루 계단을 ICMR 창에 묶음.
   - (b) 사실 주장을 실측 없이 전제로 씀: O-43 D1 (c) '구조적 0'.
   - (c) 계산 틀 원칙(DEC-103)이 없던 동안 항목마다 계산법을 정하다가 번복이 이어짐: O-19 → O-21 → O-109, O-26 (1) → O-30 → O-31 → O-32 → O-33 (3) → O-108·O-109.
   - (d) 정의를 고치는 대신 측정 구성 갈래를 더함: ICMR 줄기를 다룬 뒤 결정 43건, 정의 불능 갈래를 다룬 결정 25건(§3.0 신호표).

- UD 601~680행의 O-1~O-60 원문을 모두 읽었다. 대상이 겹치는 뒤 결정(O-61~O-117, UD 681~816)도 읽어 대체 여부를 확인했다.

  - 주제 키워드가 나오는 결정 수(UD, 느슨한 키워드라 상한값)

### 3.1 ICMR 줄기 (O-25 (2), O-33 (5), O-50 G4, O-52 G4-D, O-53 A-1·A-2, O-58 S-3, O-49 P3)

EV가 이미 깊게 다뤘다(EV:21-50, 54-73). 여기서는 판정만 정리한다.

**O-25 (2)** -- UD:644 "ICMR = 차동 입력 0 … 출력은 회로가 정하는 대로 따라가는 상태에서 전 소자 포화 유지 범위(출력 고정 안 함, Allen 관례)"
- 그때 근거: **관례만**(Allen 측정 관례). 실측과 대안 비교가 없었다(EV:58, 72).
- 대안 비교

  | 후보 | 물리 정합 | 교과서 손계산 | 단순성 | 속도 | 실측 |
  |---|---|---|---|---|---|
  | (A) follower(채택) | 출력 스윙이 섞임(EV:105-106) | 시뮬 관례(Matibag p.46, EV:86). 손계산 식과는 다른 양 | 차동 특례·선언 되먹임·P3 갈래 필요 | 같음 | 없음(그때) |
  | (B) 출력 동작점 servo | 입력단 고유 범위 = 손계산 식과 같은 양 | Razavi 1판 §4.2 p.105-106 식 (4.1)(EV:81), Lee 2007 식 (9)(EV:84) | 정의 하나(EV:265) | 같음 | EV 5회로, A 대 T 최대 0.9 V(EV:181-187) |

**O-33 (5)** -- UD:653 "ICMR 정의 O-25 하나로, oracle servo 출력 고정 방식 변경". 이미 있던 oracle servo(B)를 follower로 바꾸기로 했다. 비교는 없었다. **위반, 대체됨(O-115 '계획 1720/1723 oracle servo 대체 취소', UD:805).**

**O-50 G4** -- UD:670 "ICMR 측정 구성 = spec 선언 되먹임 구성, 없으면 단위 이득 follower(β = 1, O-34 (2) 슬루와 같은 규칙)"

- **위반, 대체됨(O-115).**

**O-52 G4-D**(UD:672)
- G4-D: follower 위에 KVL 고정 출력 갈래를 더했다. **대체됨**.
- 확인 1(차동 미선언 = 정의 불능): O-67에서 대체, O-115에서 본문으로 들어갔다.

**실측(§4.1)이 전제를 깬다**
- 5회로 봉인점에서 반전 입력은 writer `vgs_gate`다.
  - 예: two_stage_ota `vin_n ← (vgs_gate, M1, CS)`, 근거 SRC `two_stage_ota.engine.json` writers

- 그래서 '구조적 0'은 θ 봉인점이 **자기 입력(이미 Vid0를 품은)**에서 잰 출력 오차가 0이라는 뜻일 뿐이다(**추정**: 옛 `offset_systematic` 분자 '봉인 해의 입력 0 출력 오차', PL:1613 F-DE4). offset 자체가 0이라는 뜻이 아니다.

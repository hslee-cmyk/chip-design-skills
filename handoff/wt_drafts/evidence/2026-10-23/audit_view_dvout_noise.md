## 1. 6번 -- 판정 gain 전달 뷰 선택 규칙 (O-117 (i)~(vii))

### 1.1 지금 규칙 (P:603, 원문 요약)

- **정본 자리**: S1v writer `s1v_fields`가 '판정 gain 전달 뷰'를 graph 값 하나로 쓴다.
- **소비자**
  - `icm_config`: servo의 감지 s와 여기 e를 정한다.
  - DE-1 (c): A_dc의 여기 방향(DEC-23).
  - GV-1: 뒤에 GB4 achievability와 block_residual을 소비자로 더한다.
- **선택 규칙**
  - (i) 판정 gain 제약의 뷰가 결정 대기이면 정의 불능
  - (ii) (ac_excite, sense)가 하나면 그 뷰
  - (iii) 판정 gain 제약이 없으면 기본 포트 뷰
  - (iv) 서로 다른 뷰가 둘 이상이면 정의 불능
  - (v) 입력 포트가 셋 이상이면 정의 불능
  - (vi) 여기 넷이 입력 포트 밖이면 정의 불능
  - (vii) 뷰를 만들 수 없으면 정의 불능
- 갈래는 7개이고, 그중 정의 불능이 5개((i)(iv)(v)(vi)(vii))다.
- 기본 포트 뷰는 `E/graph/views.py:66-74` `_default`가 만든다.
  - 감지 = 출력 포트 전부
  - 입력이 차동 role 쌍이면 여기 = ±1/2 가중 하나
  - 그 밖이면 입력 포트마다 하나씩 만든다

### 1.2 대안

- **(가) 지금 규칙**: (i)~(vii).
- **(나) '감지 = 출력 포트(기본 포트 뷰)'로 단순화하고, 선언 뷰는 덮어쓰기만 허용**
  - 결정된 gain 뷰 선언이 있으면 그 뷰로 덮어쓰고, 없으면 기본 포트 뷰를 쓴다.
  - 덮어쓰기를 허용하면 다음 세 갈래가 다시 필요하다.
    - (i): 결정 대기 뷰는 덮어쓸 수도 있는 값이다. 그래서 기본 뷰로 대신하면 fail-open이다. 계획 P:603 '(a) 판정 입력 선택이 갈리는 사례'의 논리가 그대로 적용된다.
    - (iv): 덮어쓸 뷰가 둘이다.
    - (vi): 선언 뷰의 여기 넷이 입력 밖이다.
  - 따라서 (나)는 갈래 수가 (가)와 같다(아래 1.4). 결정 대기를 무시하고 기본 뷰를 쓰는 변형 (나′)도 있다. 그러나 (나′)는 덮어쓰기가 가능한 정의에서 결정 대기를 가정하는 것이라 ⚠ fail-open이다.
- **(다) ICMR 감지·여기 = topology 포트 모양의 기본 포트 뷰만 쓴다**
  - ICMR은 gain 뷰 선언을 읽지 않는다.
  - 판정 gain 뷰는 GB4·block_residual(GV-1)처럼 gain 제약 자체를 판정하는 소비자만 읽는다. 이 소비자들에게는 그 제약에 붙은 자기 view가 정본이다.
  - DE-1 (c) A_dc는 DEC-23 원문대로 포트 모양에서 정한 여기 방향을 쓴다. 그래서 a_e와 같은 뷰가 되고, 합치기는 무조건 성립한다.
  - 정의 불능은 (v) 입력 셋 이상과 (vii) 기본 뷰를 만들 수 없음, 두 개만 남는다.
  - (iv)는 사라진다. `_default`는 차동 role 쌍이면 뷰 하나를 만들기 때문이다. 단, 2입력이면서 role이 차동 쌍이 아닌 회로는 뷰가 둘 나와 (v)와 같은 성격의 정의 불능이 된다. 13회로에는 그런 회로가 없다(1.3).
  - (vi)도 사라진다. 기본 뷰의 여기는 정의상 입력 포트이기 때문이다.

## 2. 8a번 -- 판정 분해능 δV_out (O-67 (3)·O-68 (1)·O-70 (1)·O-71·O-107)

### 2.1 대안 정의 (측정 구현 = `meas_dvout_alt.py`)

- **(가) 지금 식**
  - δV_A = |z_u|ᵀ(|r| + E|v|)
  - E = γ_{k−1}S + Σγ_{c_s}|ĝ_s| + γ_{n+1}|Ĝ|
  - 계획 P:603 식 그대로다. k·c_s·n은 실제 스탬프에서 센다.
- **(나) 구조적 0 판정**
  - 경계 행렬 [[G_uu, b],[s_uᵀ, 0]]의 구조 rank(`scipy.sparse.csgraph.structural_rank`)를 본다. 패턴은 스탬프가 닿은 자리(S > 0)다.
  - 이 rank가 n_u+1보다 작으면 A ≡ 0(정의 불능)이고, 그 밖이면 판정 가능이다.
  - 부동소수 값을 보지 않는다.
- **(다) LU 상대(노름) 상한**: δV_C = n_u·u·κ_∞(G_uu)·‖x‖_∞. 표준 순방향 오차 꼴이다.
- **(라) 그 밖 -- 엔진도 oracle 문턱(vntol + reltol·|V|) 사용**: ⚠ 엔진에 시뮬레이터 상수를 들여오는 것이다(상수 발명, 도구 축 혼합). 측정하지 않고 비교표에서만 다룬다.
- 판정 공통: |A|·레일 폭 ≤ δ이면 판정 불능이다.
- oracle 문턱: δ_or = reltol·|V_op| + vntol. 값은 ngspice 기본 1e-3과 1e-6이다(`tools/spice_oracle/oracle_simulate.py:402`).
- 참값: 같은 float64 파라미터를 mpmath 60자리로 조립·풀이한 값이다.
- 여기 방향 네 가지
  - 입력 포트 단독 T_p: oracle 슬루 반전 입력 식별
  - DM(±span/2): a_e와 A_dc의 기본 뷰
  - CM(둘 다 +span): 상쇄 시험용

### 3.5 권고 (8c)

**(가)를 유지한다. NB-1은 '`()` 회로에 `noise_out_int_vrms` 제약이 생기거나 SD-1로 current_reuse가 `()`이 될 때' 착수한다.**
- 근거 1: 교과서의 구성 무관 잡음 양은 입력 환산 잡음이다(Razavi §7.3 pp. 218-220, §9.10 p. 336). 엔진은 이 양을 이미 `noise_th_in_v2hz`·`noise_fc_in_hz`·`noise_excess_th`로 낸다. 8회로의 잡음 제약도 이 축(`noise_excess_th`)이다.
- 근거 2: 적분 잡음은 대역, 곧 구성이 있어야 정의된다(§7.6 p. 239). 그래서 구성이 없는 `()`에서 정의 불능은 물리·교과서와 맞는다.
- 근거 3: β = 1을 기본 정의로 삼는 근거는 관례뿐이다(교과서 근거 미확인). 감사가 지적한 ICMR과 같은 유형이다.
- 결론: 수요가 없는 지금 β = 1 기본을 정의로 확정하지 않는 것이 '구성 관례를 정의로 쓰지 않는다'는 원칙과 맞는다.

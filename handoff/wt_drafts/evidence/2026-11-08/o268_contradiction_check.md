## 0. 결정 요지 (원문 대조)

- **O-268**(:1249)
  - (1) 출발 단계는 입력 고정점에서 시작한다. 입력 공통모드가 KVL 트리의 뿌리(W4)이기 때문이다.
  - (2) 피드백 증폭기(입력 DC = 출력 DC로 바이어스를 맞추는 측정 구성)에서는 입력 고정점 = 출력 스윙이 최대가 되는 출력 바이어스(출력 스윙 창의 중심, DC 양)다.
  - (3) spec에 입력 DC가 선언돼 있으면 그 선언값을 쓴다.
- **O-269**(:1250): 피드백 구성이 아니고 입력 DC가 미선언이면 기본값은 레일 대칭점 (V⁺+V⁻)/2다. 물리적으로 불가능할 때(입력 공통모드 창 밖 등)만 정의 불능으로 정지한다. 조용히 옮기지 않는다.
  - 우선순위: ① spec 선언 > ② 피드백이면 출력 스윙 최대 바이어스 > ③ 레일 중앙 > ④ 불가능하면 정지.

## 2. 질문 1~5 답

### 질문 1. v_cm 탐색 변수와의 관계 — '고정 동작 조건'인가 '출발값'인가

- **사실 1**: DEC-106 (6)(plan:306)은 v_cm 값을 '탐색 변수 y 성분 하나(F에 닿지 않을 때)'로 둔다.
- **사실 2**: 그 y가 실제로 움직이는 곳은 두 곳뿐이다.
  - R5′ (2): 출발 단계와 층 0에서 R-1′ 창 안 max-min으로 고른다. DEC-64 "출발 단계와 층 0은 같은 R-1′ 그래프로 W4 구간을 계산해 그 안에서 고른다"(plan:264).
  - R5′ (4)(i): 행이 깨지면 다시 연다.
- **사실 3**: y를 탐색하는 중층 y 좌표강하는 '정밀 경로 구현하지 않음'이다(plan:273). 그러므로 v_cm은 지금도 사실상 '출발 단계에서 정하고, 깨질 때만 다시 여는 동작 조건'이다. R5′ (2) 원문도 "W4 … 동작 조건"이다.
- **판단**: O-268·O-269는 **고정한 동작 조건**으로 읽는 것이 맞다.
  - O-269 원문 "조용히 옮기지 않음"과 "불가능할 때만 정지"는 '출발값만 정하고 이후 움직임'과 양립하지 않는다.
  - O-168은 '두 포트 DC 차는 설계 자유도가 아님, v_cm은 DC 동작 조건'(DEC-106 (2))이다. v_cm을 탐색해 최적화할 설계 자유도로 두라는 문언은 없다. 그래서 고정 동작 조건 해석이 O-168과 같은 방향이다.
  - DEC-103으로 보면, 동작점을 정하는 일은 θ 틀의 질문이다. 값을 규칙으로 고정하는 것은 그 틀 안의 선택이라 위반이 아니다.
- **그래서 바뀌어야 할 문언**(= 모순 C1, 계획 개정은 사용자 승인 대상, O-267):
  - DEC-106 (6) '탐색 변수 y'
  - R5′ (2): 입력 W4 뿌리에 대한 max-min 선택
  - R5′ (4)(i): 입력 W4 뿌리 재개방
  - LA-1a 범위 2: R6 max-min 대상
- 입력 W4 뿌리가 아닌 다른 W4·V_R에는 R5′ (2)·(4)(i)가 그대로 남는다. 그래서 '입력 W4 뿌리는 R5′ (2)·(4)(i)에서 뺀다'는 한정 문언이면 충분하다. 범위 = 부분 개정이다.
- **⚠ 대가**: 지금 R5′ (4)(i)가 W4를 옮겨 살리던 후보가 O-268·O-269에서는 정지(또는 E-0 거부)가 된다. 영향 n/N은 엔진 실측이 필요하다(불확실, 이 점검에서는 재지 않음).

### 질문 2. 출력 스윙 창의 정본, 그리고 층 순서와 순환

- **정본**: 출력 스윙은 N3.8(plan:764)이 정의한다('입력 공통모드를 동작점에 고정하고 차동 입력을 DC로 훑을 때 …').
  - 엔진 필드는 card DE-1 (b)(plan:1940) '출력 창 별도 필드'다. 봉인점 KCL 선형 감도 끝이고 '추정' 표지가 붙는다.
  - writer는 DEC-104 R2 (c) DE-1 DC 동작 범위 블록이다.
  - 계획상 '보고 양'이고 metric `swing_out_v`는 삭제됐다(O-154 Q3).
  - DE-1은 미구현이다. code 존재 여부는 이 점검 범위 밖이다.
- **순환**: 생긴다(모순 C3).
  - (i) 정의 자체가 v_cm을 입력으로 받는다.
  - (ii) 값은 봉인 뒤 `graph.ss_nodal`에서 나오는데, 출발 단계는 그보다 앞이다(층 역전).
  - (iii) 스윙 끝은 VDSAT(층 0의 S·L에 좌우)에 의존한다.
- **순환 없는 해소 후보**(계획 개정안 재료이고, 권고는 아니다):
  - 출발 단계에 이미 있는 θ 틀 R-1′ 그래프(DEC-64)의 **출력 마디 W4 구간**을 쓴다. VGS를 θ로 고정했을 때 포화 행이 허용하는 출력 마디 범위다.
  - 이것은 N3.8 출력 스윙(KCL 틀, 차동 훑기)과 **정의 축이 다르다**. 축은 '틀: θ 고정 대 W·바이어스 고정 KCL'이다. 그래서 graph 규칙 3에 따라 축을 문서에 적고, 이름을 '출력 스윙'과 나눠야 한다. 새 필드가 필요한지, R-1′ 블록 중간값으로 READS할 수 있는지는 design의 몫이다. 정본 자리가 없으면 멈추고 보고한다(규칙 6).
  - 남는 순환: 출력 마디와 입력 W4 뿌리가 같은 G_vgs 성분에 있으면(예: 텔레스코픽형은 출력 아래 끝이 입력쌍 VDS를 거쳐 v_cm에 묶임) 그 구간도 v_cm의 함수다. 그러면 v_cm = 중심(I_out(v_cm)) 고정점 식이 된다. 해당 회로 n/13은 엔진 실측 전이라 **불확실**이다(topology 판독 추정만 있음: current_reuse가 후보).
  - 반복이 필요하면 DEC-70 반복 자리 목록에 없는 새 반복이다. 계획 개정 대상이다.

### 질문 4. 창 밖일 때의 처리

- O-269 ④ '정지(조용히 옮기지 않음)'는 원칙 10 fail-closed와 정합이다. 물리 경계를 VDS = VDSAT(O-204)로 긋고 허용오차를 쓰지 않으면 O-200과도 정합이다.
- 원칙 6 관점: 다른 가능한 점이 있는데 정지하는 것은 과보수다(K5 follower형). fail-open이 아니므로 위반은 아니고, 사용자에게 알릴 대가다.
- 기존 R5′ (4)(i)는 같은 상황에서 W4를 다시 열어 옮긴다. 그래서 정지 규칙과 정면으로 반대다(모순 C1에 포함).
- 정해야 할 것(K6):
  - (a) 판정 창 = 출발 시점에 있는 θ 틀 R-1′ 입력 W4 구간 ∩ 레일(DEC-106 (5) 문언 재사용, 새 범위 0)로 두는 것이 층 순서와 맞는다. 봉인 뒤 ICMR(`node.dc_window_cfg`)은 이미 커널 판정 `icm_margin_v`의 몫이다.
  - (b) 정지 단위: 출발 단계에서 구간이 비면 회로 정지인지, 층 0 후보마다 바뀌는 구간 밖이면 그 후보만 E-0 거부인지 정해야 한다.

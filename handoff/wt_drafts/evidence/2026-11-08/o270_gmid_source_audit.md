### 0.1 오케스트레이터 전제의 정정 (원본 판독)

브리핑의 "원본은 출력 정지점에서 시작하고 입력 바이어스는 그에 맞춘다(Ex.3.11 p.105)"는 **반만 맞다.**

- **맞는 부분** -- 단일 소자 CS·IGS: 입력 VBIAS를 원하는 출력 정지점(예 VOUT = VDD/2)에 맞춘다(JM p.63 3.1절 둘째 문단, Fig.3.5 p.68 보조 되먹임이 VDS = 0.6 V가 되게 VGS를 계산, Ex.3.8 p.95 "quiescent output voltage is VOUT = VDD/2").
- **다른 부분** -- 차동쌍: "transconductance is set by the tail current source, rather than a voltage applied at the gate"(JM p.102). 그래서 Ex.3.11(p.105)은 VIC = 0.7 V와 VOC = 1 V(CMFB가 강제)를 **둘 다 주어진 값**으로 둔다. Ex.3.12(p.108)도 VIC = 0.7 V가 주어지고 출력 DC(0.6142 V)는 KVL로 따라 나온다(p.109~110). Ex.3.13(p.111)도 VSC = 0.7 V를 준다. Fig.6.2(p.227)는 CMFB가 출력 CM을 "typically near mid-supply"로 둔다는 것이고 입력 CM 규칙은 아니다. Ex.6.2(p.239)의 출력 정지점은 0.8 V(VDD/2 아님)다.
- **입력 = 출력 정지점** 근거는 다른 곳에 있다: J10 §8.3 p.129 "output voltage … supposed to be equal to VDD/2 while the input terminals … centered half the power supply"(단위 이득 사용, Fig.8.10 p.138), Rz Ex.9.6 p.305(출력 범위 0.6~2.1 V → "optimum output common-mode level is 1.35 V", 입출력을 묶으면 VGS1 + VOD = 1.35 V로 입력쌍 크기를 정함).
- 결론: O-268 (2)는 원본(J10 p.129, Rz p.305)과 같다. 다만 JM 본문의 차동 예제는 VIC를 spec으로 받는다(O-268 (3) '선언값 우선'과 같은 꼴).

**원본의 ICMR 접근**

- JM 2017: ICMR을 구하는 절차는 **원본에 없음**(찾은 범위: 2~6장·부록 전문 검색 "common-mode range|input common|VIC|ICMR"). 유일한 언급은 "folded-cascode design offers a wider input common-mode range [4]"(p.281). 입력 CM이 정해진 뒤 꼬리 노드는 VS = VIC − VGS1(LUT `lookupVGS`, VSB 반영 -- Ex.3.11 p.106, Ex.3.12 p.108)이고 포화는 VDS를 VDsat와 비교해 확인한다(p.109 "VDS1 = 0.3812 V, which indicates that M1b is saturated"; VDsat ≈ 2/(gm/ID), 식 (2.34) p.45). 곧 **θ 틀의 KVL 손계산**이다.
- J10: ICMR 절차 원본에 없음(8장 검색). 입력 CM은 VDD/2로 둔다(p.129).
- Rz(회로 일반, 원칙 1a의 보조 원본): 식 (4.1) p.105~106 -- VGS1 + (VGS3 − VTH3) ≤ Vin,CM ≤ min(VDD − RD·ISS/2 + VTH, VDD). 꼬리 전류가 포화로 일정하다는 전제의 **동작점 VGS로 쓴 KVL 경계**다. Ex.9.6 p.305의 "minimum input common-mode level, VGS1 + VOD11"도 같은 꼴이다.
- 물리 판정: 꼬리 전류원이 포화이고 그 출력 컨덕턴스를 무시하면 W·바이어스 고정 KCL에서 CM을 훑어도 각 소자 전류(곧 전류 밀도 = θ)는 그대로다. 그래서 Rz (4.1) 꼴(θ 틀 창, 끝점 VSB를 LUT로 다시 조회)은 servo ICMR의 **0차 KCL 해**와 같다. 차이는 꼬리 CLM·출력 노드 이동(1차 항)뿐이고, 이것을 (나)의 선형 감도가 넣는다. 반대로 (나)는 봉인점에서 경계까지 선형 외삽이라 체적 효과(VSB 비선형)를 1차로만 넣는다. 두 근사의 정밀도 차이는 **미측정(불확실)**이다. 어느 쪽이든 최종 확정은 oracle servo(E-1)다.

### 3.2 O-272 창의 정본과 층 순서

- 창 = §3.1 (A)의 통일 창(입력쌍·꼬리 등 모든 R-1′ 포화 행·writer_root 행의 입력 W4 뿌리 구간, 다른 W4는 그 스냅샷 값). 출발 단계에서 계산 가능하다(봉인 전 θ, LUT VGS·VDsat만 필요). **층 역전·순환 없음**.
- 남는 결합: 입력 뿌리와 같은 G_vgs 성분에 다른 자유 W4가 있으면(예 텔레스코픽의 캐스코드 바이어스 -- Rz p.305 "three voltages must be defined carefully") 창이 그 W4 값에 의존한다. 권고: v_cm과 그 성분의 자유 W4를 **함께** 차분 제약 다면체의 체비쇼프 중심(행 여유 max-min)으로 정한다. 원본의 '헤드룸 등분'(JM p.255, Rz p.299)과 같은 취지다. 반복이 아니라 한 번의 max-min이다.
- 중심 = max-min: 차분 제약 행은 v_cm 계수가 ±1이라 v_cm만의 max-min 해는 [lo, hi]의 중점이다. 그래서 O-272 '물리 정합 중앙값'은 지금 R5′ (2) 계산과 **값이 같다**. 다른 점은 (i) 깨질 때 옮기지 않고 정지 (ii) 피드백 갈래는 O-268. 그러므로 R5′ (2)를 지우고 같은 값을 새 규칙으로 다시 만드는 것은 둘째 생산자를 만들 위험이 있다 -- **규칙 하나**('입력 뿌리 값 = 통일 창의 중심, 피드백이면 §3.3 결합 중심, 비면 정지')로 쓰고 R5′ (2)에서는 참조만 남기는 문언을 권고한다.
- 정지 단위(K6 (b)): 창은 층 0 후보(S·L)마다 다르다. 권고: 출발 θ에서 창이 비면 회로 정지(`StartConflict` 사유 = 비어 있는 행 쌍), 층 0 후보에서 비면 그 후보만 E-0 거부. 원칙 10 fail-closed와 정합.

## 1. O-171 물리·회로이론 독립 재판정

### 1.1 P2 -- DEC-92 (3) '조건과 물리 결정자'·결합 꼴·P2-b

**물리 결정자**
- 영점 해석에서는 B를 AC 접지한다. s → ∞에서 보상 가지 전류는 v_n/R이고, 능동 전류는 G_m(∞)·v_n이다.
- 여기서 n은 R의 커패시터 쪽 노드다. 단일 직렬 가지에서는 n이 A와 같아지고, T 망에서는 n = CM이다.
- 일반식은 G_m(∞) = Σ_c gm_c·(h_gate,c − h_source,c)이고, 이때 R_null = 1/G_m(∞)이다.

**식·원문**
- Leung 1999 Structure 4 원문: "the s2 term can be adjusted to zero by setting Rm1 = 1/gm3"(PDF p.2 = 저널 p.600, 로컬 `skills/analog-gmid-design/assets/library/sources/nmcnr_amplifier__leung_1999/source.pdf`, 본문 추출 `leung_text.txt:148-151`). 인용은 **맞다**.
- Table 1 "400 µW, ±1 V, 100 pF ∥ 25 kΩ"(PDF p.4 = 저널 p.602)도 **맞다**.

**실측 -- 계획 식의 맞는 부분** (`p2_indep/out.jsonl`)
- 게이트 결합 꼴: R_null = (C_AG + C_G)/(C_AG(gm + gm_c) + C_G·gm). 계획 식과 같다.

**실측 -- 계획 일반 명제의 반례**

'0 ≤ h ≤ 1이므로 R_S ≥ R_null, 남는 영점은 좌반면'이라는 일반 명제에는 반례가 넷 있다.

1. **SPICE, 영점 해석 정의** (`p2_spice/p2_hB0_ac.txt`)
   - 조건: B(Vom)를 1 F로 AC 접지하고, A(Vop1)를 1 F 결합으로 강제했다.
   - 결과: Re h가 20~100 GHz 구간에서 **−0.02688로 수렴**했다(위상 ≈ −178°).
   - R_null = 1850 Ω이고 **R_S/R_null = 0.982**다. R_S가 아래 경계라는 뜻이다.
   - 작성자 값(0.228, 1.15)은 B를 풀어 두고 입력을 구동한 벤치의 값이다(`p2_h_rerun_ac.txt`로 재현). Vom → M15 Cgd → Vg15 경로가 섞였고, 100 GHz에서도 위상이 0.16 rad로 아직 돌고 있다.
2. **source 결합 꼴** (SRC)
   - 조건: S 셀의 source X가 Cgs로 A와 결합한 경우다.
   - R_null/R_S = (C_X + Cgs)/C_X > 1이다.
   - R = R_S에서 **우반면 영점 1개**가 나온다(1.1e9 rad/s). R_null에서는 우반면 영점 0이다.
   - library 해당 수: 0/9(S 셀 source = 레일).
3. **T 망 -- nmcnr, library 1/9**
   - R_null = (1 + C_G/C_m2)/gm3다. 보상 망 밖 결합이 없어도 S 정확형이 **아니다**.
   - 파일럿 설계점에서 1.124·R_S다(C_G ≈ M301 Cgg 70 fF, Cm2 568 fF).
   - 안정 쪽이 거꾸로다. R ≤ R_null이면 유한 우반면 0이고, R > R_null이면 우반면 1이다(128점 sweep 전부. Cn 0~30 fF, C2 0~1 pF).
   - R_S는 아래 경계이면서 안정 쪽이다.
4. **S 셀 자신의 Cgd** (C_AB, CGD)
   - 분자는 C_AB·Cc·R·s² + (C_AB + Cc − Cc·R·gm)s − gm이다. 근의 곱 < 0이므로 **어떤 R에서도 우반면 영점 1개**가 남는다(R = 0.5~5/gm, 5/5).
   - 20 fF·450 fF에서는 0.33~3.5 GHz다.
   - current_reuse M16 cgdo는 5.8 fF이므로 추정 ≈ 1.7 GHz다.
   - 따라서 '우반면 영점을 남기지 않는다'는 손계산 모델(C_AB = 0) 안에서만 맞다.
- UGF 30.3 MHz는 맞다(`wt/_pilot_current_reuse/cr_a2_0.5e-6_0.45e-12_lg.summary.json`). 영점들은 모두 UGF보다 50배 이상 높아 실제 해는 작다.

**판정**
- 게이트 결합 식: **맞음**.
- '결합 0이면 S 정확형', 'h ∈ [0,1] ⇒ 위 경계 ⇒ 우반면 없음', 'h∞ 0.228·R_S/R_null 1.15·좌반면 영점 ≈ 1.5 GHz': **틀림**.
- P2-b 기본안 자체(R_S로 출발하고 결합을 기록, 판정은 MNA): **조건부 맞음**. 단 근거를 바꿔야 한다(C-1).

## 3. 지적

### Critical

**C-1 P2-b 근거 정리와 SPICE 측정 조건이 틀림** (plan 291, 636, 11)
- 근거: 1.1의 반례 넷.
  - SPICE를 영점 해석 정의(B 접지)로 재면 h∞는 −0.027이고 R_S/R_null은 0.98이다.
  - source 결합 꼴에서 R_S < R_null이고 우반면 영점이 생긴다.
  - T 망(nmcnr)은 결합이 0이어도 R_null = (1 + C_G/C_m2)/gm3이고, 안정 쪽이 거꾸로다.
  - Cgd가 있으면 어떤 R에서도 우반면 영점이 남는다.
- 사용자가 '0.228·1.15·위 경계'를 근거로 P2-b를 승인하면, 틀린 물리를 근거로 한 결정이 된다(O-171 위반).
- 수정안
  1. 결정자를 'R의 커패시터 쪽 노드 n(단일 가지 = A, T 망 = CM)에서, B를 AC 접지한 전체 용량망(보상 C 포함)의 s → ∞ 전압비 h_gate·h_source'로, G_m(∞) = Σ gm_c(h_g − h_s)로 고친다.

**M-4 P7 '오라클 OP-11과 같은 식'이 거짓** (2225, DEC-78 277)
- 근거: 1.3. 오라클 레일 전류에는 측정 부하가 레일로 돌아오는 전류가 들어간다. nmcnr에서 엔진은 213.8 µW, 오라클은 228.0 µW다.

  - oracle-portability 교차 행도 갱신한다.
  - 또는 엔진 정의를 공급원 전력으로 바꾸는 안을 대안으로 사용자 질문에 더한다.

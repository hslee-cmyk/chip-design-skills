  - (2) 재작성 범위: 바꾸거나 지울 코드, 소비자 목록.
  - 불변식·자리·writer·입력 필드는 원칙에서 유도한다. 원칙 = graph 단일 정본, 양의 정의, 층 순서, 물리 결정자.
- 분류
  - (가) 허용 -- 엔진 밖 사실
  - (나) 허용 -- 재작성 범위·상태 기록
  - (다) 위반 -- as-built로 규칙·자리·writer·입력·순서·판정을 정함
  - (라) 위반 -- as-built와 비교해 대안을 기각하거나 채택함
  - (마) 위반 -- as-built 동작으로 design·계획 문언이 옳은지 그른지 판정함
  - '경미'는 결론이 바뀌지 않고 문언만 바꾸면 되는 경우다.

## 0. 요약

1. 이 판이 넣은 엔진 인용은 GB 36자리, AP 9자리, DI·DI2 8자리, 검증 보고 5자리다. 이 가운데 **위반 (다)(라)(마)는 19건**이다(§2 표 V-1~V-19). 나머지는 (가)·(나) 허용이다(§1).
2. **결론이 바뀌는 위반 2건**
   - **V-1 (가장 큼)**: DR-1이 '영역 선언 없이 구조 규칙 하나'를 정당화하면서 근거로 엔진 동작을 썼다. 근거는 '0 전류 소자는 봉인 7·9 대상 밖 -- 판정은 `op.current > 0` 소자만'이고, 출처는 `seal_saturation.py:56`·`seal_conduction.py:41`이다.
     - 그런데 이 동작은 계획 자신이 **결함**으로 적은 as-built 동작이다. GB 613 봉인 9행은 이렇게 적는다: '지금 구현은 ID ≤ 0 MOS를 판정에서 말없이 뺀다 … 같은 정의로 맞추는 일은 card EO-1 범위 4'.
     - 계획 규칙에서 다시 유도하면 결과가 반대다. 봉인 9 (i)(O-50 G3·O-52·O-53 B1)는 '선언 없는 MOS의 선언 방향 ID ≤ 0은 거부'다. oracle 합격 판정도 같은 정의(꺼짐 = FAIL)를 쓴다.
     - 그래서 EO-1이 결함을 고친 뒤에는 erfc M19~M21(선언 없음, ID = 0)이 **봉인 9와 oracle 2단계 판정 둘 다에서 거부된다**.
     - O-174가 지속되려면 계획 규칙이 하나 더 필요하다: 공용 전도 판정 함수가 '구조적 0 전류(KCL 항등 0)' 소자 집합을 graph에서 읽어 꺼짐·전도 판정에서 빼는 규칙이다. 집합은 `graph.dc_current_basis` 빈 항 행이다.
     - 이 개정은 봉인 9 (i)를 바꾸므로 **원래 취지와 다름** 표지가 필요하다(N3.6 9행·EO-1 범위 4·DEC-90 (1)·DR-1).
   - **V-14**: DI2 C4·C11·X1은 design의 '(d) 거부 = 단계 A'를 'as-built `search_domain`은 단계 B(`stage_b.py:158`)'라는 이유로 틀렸다고 판정했고, design을 '단계 B'로 고치자고 제안했다.
     - G6(파이프라인 접착 코드는 정본 자리가 아님)과 G1(그 값의 writer 블록, 가장 이른 자리)로 다시 유도하면 거부 자리는 '적용 상자 블록, 탐색 전'이다. 단계 이름은 입력 층이 정한다. 그래서 이 수정 제안은 근거가 없고, design 반영 목록에서 빼야 한다.
3. **결론은 같고 근거만 바꿔야 하는 위반 17건**: Q-CB1 적용 상자 writer 자리·층(V-2), '새 블록 = 둘째 생산자 남음' 기각(V-3), Q-KV1 '쓰기 계획 종속 = θ 기저 종속'(V-4), 'S1v가 쓰기 계획 앞 -- 순환 0'(V-5), M9a·M9b R13 손 판정의 S1v 증거(V-6), OrderHints (B)·(C) 대안과 'Kruskal 키'(V-7·V-15), mismatch slope bin(V-8), DR-1 대상 정의(V-9), Q-CF1 틀(V-10) 등이다. 원칙에서 다시 유도해도 결론은 같았다. 다만 그 결론이 지금은 as-built 사실 위에 서 있다. **다음 재작성에서 엔진 구조가 바뀌면 근거가 사라지는 문언**이므로 근거를 바꿔야 한다.
4. **질문별 영향**
   - Q-CB1: 결론 유지. writer 자리 문언(V-2·V-3)과 design 반영 목록(V-14)을 정정한다.
   - Q-KV1: 권고 (다) 유지. 근거 문언 넷(V-4~V-7)을 정정하고, (B)·(C)를 대안 표에서 뺀다.
   - Q-CF1: 결론 유지. 다만 '이름 보존 대 새 타입'은 계획 수준의 사용자 결정이 아니다(이름 = design, O-153). 규칙 문언 하나로 바꿀 수 있다(V-10).
   - Q-W1: 아직 결정하지 않았으므로 결론 영향은 없다. 착수 실측의 판정 기준 'front 소속 변화 수'는 as-built 탐색 출력에 기대고 있다. 판정 기준을 점별 물리량으로 바꿔야 한다(V-13).
   - Q-ZG1: 영향 없음. 다만 V-1이 같은 소자(erfc M19~M21)의 판정 통과를 막는다. DR-1 완료 조건에 봉인 9·oracle 판정 toy가 빠져 있다.
   - Q-CA1: 위반 없음.
5. **재발 원인**: 브리핑·재판정에서 쓴 문구 일곱 꼴이 as-built를 기준으로 만들었다(§3). 대표는 셋이다.
   - '정본 자리를 찾아라'를 '엔진의 기존 자리'로 읽게 둔 것
   - '실현 가능성 = 코드로 끝까지 확인'을 층 순서·writer 근거로 쓰게 둔 것
   - '재작성 범위로만 인용' 표지만 붙이면 O-165를 통과한 것으로 받아들인 것(V12)

   재발 방지 문구 10개를 §3.2에 적었다.

### 3.2 재발 방지 문구(모든 작성·검증·재판정 브리핑에 넣을 문안)

1. **인용 용도 표지 필수**: 엔진(as-built) 파일·줄·함수·필드·동작을 인용할 때는 `[외부 사실]` 또는 `[재작성 범위]` 표지를 붙인다. 규칙·자리·writer·입력·층 순서·판정·대안 기각의 **근거 문장**에 엔진 인용이 있으면 표지와 상관없이 위반이다.
2. **자리·층은 계획 정의로**: 'writer 자리'·'층 순서'·'순환 없음'은 계획의 필드 정의 행·READS·G1·G6·층 규칙으로 증명한다. 엔진 호출 순서·READS는 '구현이 정의를 따르는가' 대조 칸에만 적는다.
3. **'기존 자리'의 뜻**: '기존 필드·기존 writer 재사용'은 **계획에 정의된** 필드·블록만 가리킨다. 엔진 함수 이름은 자리 이름이 아니다. 계획에 정의가 없으면 정의를 먼저 쓴다(S-7).
4. **옛 코드 잔존은 기각 사유가 아니다**: 대안 비교에서 '옛 코드가 남는다'·'as-built와 다르다'를 ⚠로 쓰지 않는다. 모든 대안은 '같은 변경에서 옛 코드 삭제'를 전제로 비교한다(O-153).
5. **'만들면 배선'의 범위**: 이 원칙은 이번 작업이 만든 것에만 적용한다. as-built 미배선 코드는 재작성 범위 목록에 넣고, 계획 대안을 만들지 않는다.
6. **회로 해석 증거**: R13 분류 같은 회로 해석은 연결과 원문만으로 판정한다. 엔진 S1v·쓰기 계획 출력은 '구현 대조 기대값'으로만 기록한다.
7. **소비자 전수**: 소비자 목록 = 계획·design READS 전수와 엔진 grep(재작성 범위) **둘 다**다. 엔진 grep만으로 '전수'라고 쓰지 않는다.
8. **결함 동작 인용 금지**: 계획이 결함·불일치로 적은 엔진 동작(예: 봉인 9의 ID ≤ 0 생략)을 다른 규칙의 근거로 쓰지 않는다. 인용하려는 엔진 동작이 계획 본문 규칙과 같은지 먼저 대조한다.
9. **검증자 재유도 의무**: 검증·재판정 항목에 'as-built 근거 문장 수'를 따로 둔다. '재작성 범위로만 인용' 표지가 붙은 문장도, 그 결론이 엔진 사실 없이 성립하는지 원칙(정의·층·graph 규칙·물리 결정자)으로 따로 재유도해 기록한다.
10. **승인 문서 확인표**: '승인 결정이므로 0'·'SPICE 수치 일치 0' 행 옆에 **'as-built를 근거로 쓴 칸 0(외부 사실·재작성 범위만)'** 행을 둔다.

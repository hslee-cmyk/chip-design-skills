DEC-104 (4) 'R 자체를 θ 독립 성분' 재검토 = **맞음**(θ점에서 R을 정하는 KVL·KCL 고리 없음), 단 **R은 범위 끝 상태에서 DC 부하**다(I_R = V_od/(R1+R2), 10 kΩ에서 60 µA) -- 범위 끝 KCL(R8·R9·R10)과 DE-1 (e) 노달 망에 R이 들어가야 한다는 문언 확인 필요(§3.2).

## 1. 회로 연결 직접 판독 (태그·주석 미사용)

`skills/analog-gmid-design/assets/library/current_reuse_telescopic_ota.topology.json` `netlist`·`passive_elements`:

- R1: Vom–Voc, R2: Voc–Vop. Voc의 다른 연결 = M37a gate 하나(M37a: D=Vcmfb, S=Ncmfb_tail). → 저항 분압 CM 감지 + 차동쌍 M37a/M37b(gate Voc / Voc_des, 꼬리 M38) + 다이오드 부하 M36a(Vcmfb) → M7 gate(꼬리 Vx 보조 전류원).
- 출력 Vom 구동 = M15(P, gate Vg15) ∥ M16(N, gate Vop1) class-AB. Vom의 다른 연결 = Cc1, CL2, Cf1(→Vip), R1. Vop 대칭.
- 그래서 차동 신호에서 Voc는 AC 가상 접지(R1 = R2일 때)이고 R은 출력 노드에서 접지로 가는 부하다. 공통모드에서는 R에 전류가 없다(Voc가 따라감).

9회로 전수(`p4r_cm_sense/scan_cm_sense.py` → `scan_cm_sense.out.jsonl`, 판정 = '두 저항이 한 넷을 공유하고 그 넷의 다른 연결이 MOS gate뿐, 먼 끝이 서로 다름'): **저항 CM 감지 꼴 1/9(current_reuse)**. 저항이 있는 다른 회로: nmcnr Rm·RL, sf_pushpull R1a·R1b·R1c, two_stage Rz -- CM 감지 꼴 0. θ점 전류 0 저항 중 CM 감지가 아닌 것(Rz1·Rz2·Rz·Rm)은 DEC-92 (3) 출발식 writer가 있다.

## 2. 물리 결정자 유도

R1 = R2 = R, 출력 노드 자기 컨덕턴스 G_o = gds15 + gds16 (r_o = 1/G_o), C_voc = Voc 노드 용량(M37a cgg + 저항 기생).

| 역할 | 식 | 방향 | 출발값을 정하나 |
|---|---|---|---|
| (i) 차동 DC 이득 | A(R) = A∞ · R/(R + r_o) (출력 노드에 1/R 병렬) | R↑ → A↑ (단조) | **하한**: 이득 요구 A_req가 있으면 R_min = r_o·A_req/(A∞ − A_req) (A∞ > A_req일 때). 상수 없음 -- A_req는 선언 행, A∞·r_o는 출발 동작점 LUT |
| (ii) DC 전류 | θ점(균형): I_R = 0. 범위 끝: I_R = V_od/(2R) | R↓ → 범위 끝 출력단 공급 요구↑ | **하한**(R8·R10 공급 요구 행이 R 가지 전류를 요구 쪽에 넣을 때) |
| (iii) CMFB 루프 | T_cm(DC)는 R과 무관(DC 전류 0); Voc 극점 f_p = 1/(2π·(R/2)·C_voc) | R↑ → PM_cm↓ | **상한**(pm_cm_ss_deg 행, MNA 판정) -- 출발값을 정하지 않음 |
| (iv) 면적 | 엔진 area_decl: 2R · W_min²/R□ (+머리) | R↑ → 면적↑ | **상한**(area_search_m2 행)·목적 축 |
| (v) 잡음·차동 PM | 출력 컨덕턴스(kL)로 보상과 결합 | 비단조·설계 의존 | 정하지 않음 |

→ R을 아래에서 묶는 것은 이득 행·범위 끝 공급 행, 위에서 묶는 것은 면적·CMFB PM이다. R은 전력 중립(θ점 전류 0)이고 위 비용(면적)이 단조 증가이므로, 교과서 손계산 순서(R5′ (1)·R7 (가)와 같은 꼴)는 "아래 행이 묶이는 최소 R"이다. 이것은 spec에 적힌 사용자 기록과 같은 규칙이다: `current_reuse_telescopic_ota.sizing_spec.json` `element_values.R1.source.record`(2026-10-07) "감지 저항은 출력 노드를 부하하지 않아야 한다(출력 임피던스 대비 gain 손실이 허용 여유 안인 최소 저항, 면적·잡음 대가와 함께 sizing 변수)".

계획에 이미 있는 양만으로 식이 닫히는가:
- r_o: 출발 동작점에서 출력 노드 소자 gds LUT 조회 -- 있음.
- A∞(또는 A(R) 자체): 출발 블록이 이미 부르는 DE-1 (e) 순수 함수(LUT gm·gds → ω → 0 노달 전달, **노달 망은 DC 경로 저항 포함** -- 계획 R5′ (1))를 R에 대해 1-D 단조 근 찾기로 쓰면 새 식 없이 된다. 닫힌 식 R_min = r_o·A_req/(A∞ − A_req)는 손계산 확인용.
- A_req: **current_reuse에는 엔진 쪽 이득 행이 없다** -- `gain_ss_db ≥ 54`는 SF-1 범위 5에서 삭제(O-133 '같은 물리량의 둘째 원천'), 정적 정착 오차 ≤ 0.1 %는 oracle `.tran`만 판정(DEC-58·289행 "엔진은 정착을 판정하지 않고 대역폭 출발 목표 '추정'만"), 출력 범위 판정 꼴은 포화 기준이라 범위 끝 이득 저하 행 없음, g_i^(1)·found_db는 current_reuse 출발 단계에서 정의 불능(DEC-105 (1)(c)). 그래서 (나)는 current_reuse에서 '행 없음 → 상자 아래 끝'으로 떨어진다.
- CMFB 극점 조건은 출발값에 필요 없다: T_cm(DC)가 R과 무관하고(§3.1) PM_cm은 상자 위 끝 가까이에서만 R에 걸리며 판정은 커널 MNA 몫이다.

### 사용자 결정이 필요한 것 (원래 취지와 다름 표지)

- **U-a(권고와 함께 올림, ⚠ 원칙 경고)**: current_reuse는 엔진 안에 R(그리고 이득 전반)을 키울 행이 없다. 정적 오차 0.1 %는 DC에서 정확한 등식 ε_s = 1/(1 + β·A)(범위 끝은 A_sec)로 이득 요구가 되지만 계획은 이것을 oracle 판정만으로 두었다. 대안: (a) 현행 유지 -- R은 출발 10 kΩ, 외층도 R을 키울 이유 없음, 정적 오차는 oracle에서 FAIL로만 드러남(파일럿 점 ε_end 0.24 %) (b) 대역폭 출발 목표 '추정'(O-139·O-157 S3)과 같은 지위의 '정적 오차 → 루프 이득 출발 목표 추정'(A_req = (1/ε − 1)/β, 새 상수 0, 판정 아님) -- **원래 취지와 다름**(O-133이 gain_ss_db를 '같은 물리량 둘째 원천'으로 지운 취지와 부딪칠 수 있음; 추정은 원천이 아니라 파생 필드라는 논리로 정합 가능하나 사용자 판단 몫). (나)는 (b)가 들어오면 자동으로 그 행을 쓴다(규칙 변경 없음).
- **U-b(재검토 -- 사용자 결정 2026-10-08 '8번' R 상자 [10 kΩ, 10 MΩ])**: 상자 위 끝은 엔진 면적 선언으로 면적 예산 하나만으로도 못 들어가고(113 %), 실제 poly 기생으로는 0.5 MΩ 위에서 PM_cm < 60°. 지금 바꿀 필요는 없음(외층이 면적·PM 행으로 걸러냄) -- 기록만 권고.
- **U-c(작은 것)**: 출발 단계에서 R을 포함하는 행이 선언됐지만 정의 불능(예: found_db 없음)일 때 (나)는 그 행을 출발값에서 빼고 사유를 기록한다(P2-b 'R_S는 출발값일 뿐·기록'과 같은 지위, 거부는 커널 뒤 행) -- 이것이 skip인지 사용자 확인. current_reuse(SF-1 뒤)에는 해당 없음.

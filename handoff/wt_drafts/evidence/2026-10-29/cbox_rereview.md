## 결론 (요약)

1. **'10번'의 원래 근거는 관례였다. 그리고 결합 C에는 성립하지 않는다**(확신도 상).
   - 당시 기록(이 세션 대화 기록, 2026-10-08)은 이렇다: "보상 커패시터는 통상 이 범위 안에 있습니다. 파일럿 논문값 500 fF와 부하 1~100 pF 대비 비율을 봐도 들어갑니다."
   - 근거는 '통상'이라는 관례와 파일럿 값 하나뿐이고, 물리 유도가 없다. 대상도 **보상 커패시터**뿐이었다. erfc는 2026-10-13에야 들어왔다.
   - N13(2026-10-14)이 CBAT에 "같은 규칙"을 적용했다. 그런데 결합 C의 물리 결정자는 확인하지 않았다.
2. **결합(부유 전지) C의 하한은 결합비 α와 SR spec이 정한다.** sky130 bench에서 그 값은 상자 하한 0.1 pF보다 **약 10~15배 위**다(확신도 중상).
   - 실측 경계(O-122 정의 20-80 %, 방향별 min ≥ 19.32 V/µs):
     - 세 C를 같게 두면 1.0 pF FAIL, 1.5 pF PASS.
     - CBAT2만 바꾸면 1.0 pF FAIL, 1.5 pF PASS.
     - CBAT1만 바꾸면 0.1 pF FAIL, 0.2 pF PASS.
   - 0.1 pF에서 상승 SR은 9.4 V/µs(20-80 %)다. 면적 최소화가 C를 상자 하한으로 밀면 erfc 점은 **모두 oracle FAIL**이다.
3. **SR에서 C 하한을 상수 없이 엔진 손계산으로 유도하는 길은 성립하지 않는다**(확신도 중상).
   - 꼴은 C_min = α_req/(1−α_req)·C_g,eff다.
     - 상승 SR ≈ SR_∞·α₂ 모형은 실측 오차 −2~+7.5 %로 맞는다.
     - CBAT2에서 C_min 0.87 pF가 나온다. 실측 경계는 (0.7, 1.5] pF다.
   - 그런데 두 입력이 모두 대신호 양이다.
     - SR_∞는 oracle `.tran`만 잴 수 있다.
     - C_g,eff는 대신호 영역 용량이다. 정지 cgg로 쓰면 n_m8g는 1.45배, n_m5g는 2.9배 과소다. C_min도 그만큼 낙관 쪽으로 틀린다.
   - DC 문턱식 손계산도 실측과 2~4배 어긋난다(c2).
   - 그래서 O-122(엔진 슬루 값·행 0)와 충돌하지 않게 하한을 두는 자리는 **spec 선언**(data 커밋 + 사용자 승인)뿐이다.
4. **일반성**: 13회로에서 θ 커패시터는 15개다.
   - library 9: 보상 Miller 8, 보상 shunt 1.
   - heldout 3: erfc 결합 3(CBAT1_L, CBAT1_R, CBAT2).
   - 결합 역할 θ는 erfc 셋뿐이다. 다른 결합·감지 C(cnr C1·C2 53.8 fF)는 선언값이다.
   - **cnr_ota는 실제 sky130 설계인데 53.8 fF MIM을 쓴다.** 그러니 0.1 pF는 PDK 최소값도 아니다.
5. **권고: 역할별 분리 (나)**(확신도 중).
   - 보상 C는 '10번'의 공통 상자를 유지한다. 단 ⚠ 하한이 맞닿는 경우는 따로 적는다(아래 4절).
   - 결합 C(부유 전지)는 회로별 spec 선언 상자로 둔다('8번' 저항과 같은 형식). 하한 값은 oracle SR sweep 증거와 손계산 검산식을 붙인 data 커밋이 제안하고, 사용자가 승인한다.
   - **원래 취지와 다름 -- 재질문**: DEC-105 (10)(a)의 '보상·결합 공통 규칙'과 N13 "회로별 상자 값 선언 안 함"을 바꾼다.

## 2. C 상자 하한의 물리 결정자 (역할별)

### 2.1 연결로 본 erfc 결합 경로 (topology.json, c0)

- 상승 edge(out ↑): X ↑ → CBAT1_L → n_m5g(M5 게이트) ↑ → M5가 n_m7d를 끌어내린다. n_m7d ↓ → CBAT2 → n_m8g(M7·M8 게이트) ↓. 이어서 M9 → M10 미러, M8 → out.
- 하강 edge(out ↓): Y ↑ → CBAT1_R → n_m6g ↑ → M6 → out.
- M19~M21(pseudo-R)은 DC에서 게이트를 VCN·VCP에 묶는다.

### 2.2 메커니즘 분리 (c3)

M19~M21을 이상 R 1e15 Ω(누설 0)으로 바꿔도 SR이 같다.

| C | mos 상승 SR | 이상 R 상승 SR |
|---|---|---|
| 0.1 pF | 8.18 | 8.36 |
| 0.3 pF | 16.07 | 15.82 |
| 1 pF | 18.89 | 19.05 V/µs |

- 그래서 첫 주기 하한은 **pseudo-R의 역방향 전도(처짐)가 아니라 전하 분배 α가 정한다**.
- 10 %·90 % 시점의 결합 효율이 거의 같다. 0.3 pF에서 0.567 대 0.564다.
- 다만 0.1 pF 이하에서는 처짐이 보인다. 0.1 pF에서 a(t90) = 0.10이다.

### 2.4 결합 C 하한을 SR spec에서 유도할 수 있나

**(i) DC 문턱식 손계산(c2)**: 필요 전류 I_req = CL·SR_spec = 70 pF × 19.32 V/µs = 1.352 mA다. 실측 피크는 1.45~1.55 mA로 맞는다. 이 전류에서 M5·M7이 전류를 흘릴 게이트 전압 조건을 세웠다.

| 결합 | 손계산 α_req | 실측 경계 α(10-90 % 변형별) | 판정 |
|---|---|---|---|
| CBAT1 (M5) | 0.21 | 0.41(FAIL) ~ 0.60(PASS), 20-80 %로는 0.31 ~ 0.49 | 손계산이 낙관적이다. 1.5~3배 어긋남 |
| CBAT2 (M7·M8) | 0.95 (Δn7d 손계산 0.64 V) | 0.89(FAIL) ~ 0.92(PASS) | Δn7d 손계산이 실측 0.94 V와 다르다(n_m7d는 M9 diode 전압이 아니라 0.07 V까지 내려간다). 실측 Δn7d를 넣으면 0.66으로 낙관적이다 |

→ E-0 범위 안에 들지 않는다. 피크 전압 하나로 정의되는 문턱이 없기 때문이다. SR은 edge 전체의 시간 평균이고 SR_∞ 근처에서 완만하게 포화한다.

**(ii) 비례 모형(c4)**: SR_rise ≈ SR_∞·α₂/α₂(10 pF)다. CBAT2 변형 10점의 오차는 −2.0~+7.5 %다. 그러면 α_req = SR_spec/SR_∞ = 19.32/21.07 → 0.910이 된다.

- C_g,eff(n_m8g) 실측 역산값은 0.087 pF이고, C_min = 0.910/0.090 × 0.087 = **0.87 pF**다.
- 실측 경계는 10-90 %로 (0.7, 1] pF, 20-80 %로 (1, 1.5] pF다. 크기가 맞다.
- 그러나 입력 둘이 손계산 양이 아니다.

| 입력 | 손계산 가능? | 실측 |
|---|---|---|
| SR_∞ | 아니다. 대신호 `.tran` 양이고 θ 전체에 의존한다 | 20.4~21.3 V/µs(측정 잡음 ±0.7). **spec 대비 여유가 5~9 %뿐**이라 α_req가 0.91~0.95로 민감하다 |
| C_g,eff(n_m8g) | 정지 cgg 합 0.060 pF → C_min 0.61 pF(FAIL 쪽). 강반전 선형 cgg 0.121 pF → 1.22 pF(보수 쪽) | 0.086~0.097 pF |
| C_g,eff(n_m5g) | 정지 0.069 pF, 강반전 선형 0.138 pF → **둘 다 과소** | 0.20~0.23 pF. M5 drain(n_m7d)이 반대로 움직여서 Cgd Miller가 붙는다 |

→ C_g,eff는 θ(W·L)에도 의존한다. 그래서 고정 숫자 하나가 모든 θ에서 정확할 수는 없다.

**(iii) O-122와의 관계**:

- O-122는 엔진 슬루 값·슬루 제약 행 0이다(근거: 손계산 추정 0.28~28×). 이번 측정도 같은 결론이다. 대신호 α·SR은 손계산 범위 밖이다.
- '엔진 C_BAT 하한 행'(Q-ZG1 대안 (ii))은 두 결함을 가진다.
  - SR에서 유도한 제약 행이라 O-122와 충돌한다.
  - 정지 cgg를 쓰면 낙관 쪽으로 틀린다(n_m5g 2.9배).
- '상자 하한(spec 선언 값)'은 엔진 슬루 행이 **아니다**. 엔진은 θ 상자를 읽기만 한다. 그 값은 다음과 같이 정한다.
  - **누가**: 사용자 spec 영역의 data 커밋. card SF-1의 held-out data 커밋 계열이며, 상자 선언은 '8번' 저항과 같은 자리(`search.theta_bounds`)다. 값 확정은 사용자 승인이다.
  - **근거**: oracle `.tran` SR sweep(그 spec의 SR 정의·계단 크기·측정 구성, O-122 20-80 %) + 기준 θ + 손계산 검산 C_min = α_req/(1−α_req)·C_g,eff. 그 결과를 출처 기록(source.record)에 남긴다.
  - **남는 위험**: θ가 기준점에서 멀어지면 C_g·SR_∞가 바뀐다. 이것은 oracle이 점별로 판정한다(fail-closed). 선언 하한은 'front 공백 방지용 탐색 범위'이지 PASS 보장이 아니다.
- **상수 발명 여부**: 여유 계수를 따로 붙이면 상수 발명이다. 실측 경계값(가장 작은 PASS 격자점)을 그대로 쓰고 측정 조건을 같이 기록하는 것은 실측 출처다. 격자 간격은 기록 대상이다.

### 2.5 상충: 하한을 올리면 반복 대신호 정류 위험이 커진다 (s6, flow_derivation 4절)

- MOS pseudo-R 정류 표류: C 1 pF, 60주기에서 g5가 0.700 → 0.540 V로 내려갔고 계속 진행 중이었다. C 10 pF는 20주기에 −0.08 V였다. C 0.1 pF는 표류 0이다(α가 낮아 게이트 상승이 작기 때문).
- 하한을 1~1.5 pF로 올리면 첫 주기 SR은 PASS 영역에 들지만, 반복 계단 oracle에서는 정류 표류 영역에 든다.
- 이것은 O-174 'VDS = 0 묶음'의 별건 위험이고 oracle 반복 계단 측정 몫이다. 하한 선언 근거와 함께 기록해야 한다.

- **결합 C**는 erfc 셋뿐이다. 판별 구조는 "C 한 끝 넷의 DC 원소 = MOS 게이트 + 구조적 0 전류 MOS(DR-1)뿐"이다. 회로 이름이 없는 구조 규칙으로 판별할 수 있다. flow_derivation S5와 같은 결과다.
  - 다른 '게이트에 닿는 C'는 결합 C가 아니다.
    - sf_pushpull Cc(Y–agnd), ngcc Cm1(V1에 M8·M14 게이트), two_stage_sf Cc는 그 넷이 이득단 출력(드레인 있음)이라 보상이다.
    - cnr C1·C2(LPCO = x42 게이트 + 저항 x37·x38)는 선언값이다.
- **PDK 대비 0.1 pF**:
  - sky130 MIM 2.00 fF/µm², 둘레 0.19 fF/µm(`models/r+c/res_typical__cap_typical__lin.spice` 7-8행). 0.1 pF는 약 7.1 µm 정사각형(50 µm²)이다.
  - capm 최소 폭 규칙은 로컬 `skywater-pdk/docs/rules/periphery/periphery.csv` 745행에서 값이 'N/A'라 확인하지 못했다.
  - 실제 sky130 설계(cnr_ota, wulffern, `CNR_OTA.sch` L632-633)가 5×5 µm = 53.8 fF를 쓴다. 그러니 **0.1 pF는 PDK 최소값이 아니고 관례값**이다.
  - 하판 기생은 로컬 cap_mim_m3 셀 모델이 없어 재지 못했다.
- 상한 10 pF: 결합 C는 α 0.99에서 포화한다. 보상 C는 nmcnr CL 100 pF·erfc CL 70 pF 회로에서 상한이 맞닿는지 측정하지 않았다(이번 범위 밖).

**판정**:

- '10번'은 보상 C에 대해 **유지**한다. 하한이 맞닿는 경우(PM 목표 빈칸 3회로, ngcc Cm2)는 spec 빈칸의 문제다. 보상 C 하한의 물리 결정자(PM)는 MNA가 본다.
  - ⚠ 그래도 그 근거는 '통상' 관례다. PM 목표가 없는 회로에서는 이 관례값이 설계값이 된다. 이 경고를 함께 기록하는 것을 권고한다.
- 결합 C에 대해서는 '10번' 적용을 **철회**하고 **역할별 분리 (나)**를 권고한다. 확신도는 중이다.
  - 근거: 물리 결정자 실측(2·c1·c3·c5), 손계산 비성립(c2·c4), O-122 정합.
  - 불확실성: sky130 대용 공정. SR_∞ 여유 5~9 %라 경계가 민감하다. 측정 잡음은 ±0.7 V/µs다.
- **원래 취지와 다름 -- 재질문**:
  - DEC-105 (10)(a)의 "보상·결합 커패시터 -- 값을 정하는 법칙이 없는 AC 설계 변수, 출처 = '10번' 하나"를 바꾼다.
  - N13(2026-10-14) "같은 규칙, 회로별 상자 값 선언 안 함"도 바꾼다.
  - 결합 C 판별 규칙(구조적 0 전류 MOS에 닿는 게이트 넷의 C)은 design 몫이다. 계획을 먼저 고친다(S-7).
- 착수 조건: SF-1의 `.tran` SR 항목(자극 크기 포함, O-122 20-80 %). 상자 값은 그 정의로 다시 잰다. 이번 수치는 원문 600 mV 크기를 쓴 대리 측정이다.

## 6. 원칙 점검

- graph 정본: 결합 C 상자는 spec 선언 자리 하나(`search.theta_bounds`, writer = spec 로더)다. 새 cache·memo·사본은 0이다. 엔진은 READS만 한다.
  - 공통 상자와 회로별 선언이 같은 원소를 두고 겹치면 둘째 생산자가 된다. 그래서 design은 '역할별 출처 하나'를 정해야 한다(공통 규칙은 보상 C만, 결합 C는 선언만).
- 상수 발명: 여유 계수는 넣지 않는다. 격자 경계값과 측정 조건만 쓴다.
- O-122: 엔진 슬루 값·행 0을 유지한다.
- DC/AC 분리: SR은 대신호 과도라 oracle 몫이다. 소신호 α 효과는 MNA가 본다.
- 회로 이름: 판별은 구조 술어(DR-1 0 전류 MOS 게이트 넷)로 한다. 값 선언만 회로별 data다.
- 이번 측정은 bench 대용 공정이다. 계단 크기는 원문 600 mV이고 oracle '전 폭 계단'과 다를 수 있다 → 값 확정 전에 SF-1 정의로 다시 잰다.

## 1. 물리 결정자 -- 연결에서 유도한 정의

- DC 전도 그래프의 간선은 MOS 채널(d–s), 저항, 이상 전류원이다(전압원이 있으면 그것도 간선).
  - 게이트와 커패시터는 DC 전류가 0이다.
  - bulk 접합은 이상 KCL에서 0으로 둔다. 누설은 3절 SPICE에서 따로 본다.
- 고정 넷(supply ∪ bias_inputs ∪ input 포트)은 노드 하나로 합친다.
- MOS 간선 e = (d, s)가 KCL 항등 0인 경우는 두 가지다.
  - **Z1**: d = s. 이때 VDS = 0이므로 ID = 0이다.
  - **Z2**: G − e에서 d 쪽이나 s 쪽 성분이 고정 넷에 닿지 않는다(섬). 섬의 경계를 지나는 DC 간선이 e 하나뿐이다. 그래서 KCL에 따라 I_e = Σ(섬 안 다른 간선 순전류) = 0이다. 소자 크기·바이어스·섬 안 원소 값과 무관하다.
- 0 전류 MOS가 직렬로 이어진 사슬도 Z2로 잡힌다.
- 값에 따라 생기는 0(대칭점 등)은 포함하지 않는다.
- self-test: 합성 toy에서 기대대로 나왔다(MP → Z2, MC(d = s) → Z1, MN1·MN2·MQ(드레인–R–gnd) → 제외). 정의가 실제로 고르고 실제로 거른다는 뜻이다.

## 3. SPICE (sky130 tt, ngspice-46, `seal9_spice.txt`)

판정식(계획 613행 문언): (i) 선언 방향 ID ≤ 0이면 거부. (iv) ID > 0이고 I_off > ε·ID(= gm·tol_V)이면 거부. I_off는 같은 VD·VS·VB에서 VG = VS인 복제 소자로 SPICE가 직접 쟀다. tol_V는 1e-4, 1e-3, 1e-2 V 세 값으로 봤다.

**(a) 합성 toy**
- 구성: 전류원 1 µA → NMOS 다이오드(n1). PMOS pseudo-resistor는 s = b = n1, d = nfl. nfl에는 게이트와 1 pF만 붙는다.
- bulk = source, VSG 0.1~0.9 V, gmin 1e-12와 1e-18.
  - V(d) − V(s)는 0 ~ 6e-7 V이다.
  - signed ID는 −5.5e-19 ~ +5.7e-25 A이고, 부호는 수치 잡음이다.
  - **봉인 9 판정: 12점 가운데 9점이 (i)로 거부되고 3점이 (iv)를 통과한다.** VSG = 0.6(두 gmin 모두)과 0.9(gmin 1e-18)가 통과한 점이다.
  - 같은 소자·같은 물리인데 판정이 잡음 부호로 갈린다. 재현이 안 되는 판정이다.
- bulk = vdd(대조):
  - VDS = −0.49 ~ −7e-5 V, signed ID ≈ −1e-12 A(접합 누설)이고 6/6이 (i)로 거부된다.
  - DR-1 '조건: bulk ≠ 고정 쪽이면 정지'와 같은 물리다.
- 정상 소자 MN1(1 µA)은 모든 경우 통과한다. 예외가 정상 소자를 건드리지 않는다.

**(b) erfc_ota 전체 .op**
- 조건: 현재 topology(bulk = source, O-174), Table 1 치수를 sky130으로 대신함, 단위이득.

| 소자 | gmin | @vds V | signed ID A | I_off A | 봉인 9 (결함 고친 판) |
|---|---|---|---|---|---|
| M19 / M20 | 1e-12 | −1.1e-16 | −2.6e-30 | 1.0e-28 | 거부 (i) |
| M21 | 1e-12 | −2.2e-16 | −2.6e-27 | 2.0e-28 | 거부 (i) |
| M19 / M20 | 1e-18 | −3.8e-9 | −8.6e-23 | 2.3e-24 | 거부 (i) |
| M21 | 1e-18 | −1.2e-13 | −1.4e-24 | 1.5e-28 | 거부 (i) |

- 대조 소자 M5·M7(ID = 2.9e-7 A)은 통과한다.
- gmin 1e-12에서는 'Dynamic gmin stepping failed' 경고가 났지만 해는 나왔다(`erfc_full_g1e-12.cir.log:63`).

**결론**
- 예외가 없으면 erfc M19~M21이 결함 고친 봉인 9에서 거부된다.
  - 엔진: ID = 0 정확이므로 (i)로 **항상 거부**된다.
  - oracle: 잡음 부호에 따라 거부되거나 통과한다(이 점에서는 6/6 거부).
- 그래서 DR-1 완료 조건 (8) 'erfc 단계 A 진행'과 함께 성립할 수 없다(R-06 확인).
- 이 소자에서는 ε·ID와 I_off가 둘 다 0 근방(1e-30 ~ 1e-19 A)이다. 전도 여유라는 양 자체가 정의되지 않는다(0/0). 임계 전류로 거르는 안은 상수를 발명하는 것이라 원칙 11에 맞지 않는다.

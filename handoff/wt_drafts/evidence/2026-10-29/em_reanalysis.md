## 1. e_m의 정의 -- 원칙에서 다시 유도

### 1.1 무엇과 무엇의 차인가

점 p(실현 평가 W′·바이어스), 회로 c, metric m에서 d_m(p) = 엔진 손계산 값 − oracle SPICE 값이다. 측정 구성(부하·되먹임·자극·측정 정의)은 같아야 한다. DEC-72는 이것을 (회로, metric)마다 선언값 하나 e_m = |d|로 기록한다(GB 271). 측정점은 시작점과 front 점이다(GB 2017~ ME-1).

### 1.3 축

d_m은 (회로, metric, 동작점 p, PDK 모서리·온도)의 함수다. DEC-72는 이것을 (회로, metric) 값 하나로 줄인다.

- 위 (ii) 실측대로 근사 오차는 동작점(예: VS)에 따라 1.6배쯤 변한다.
- 측정점은 회로당 시작점 + front 점 몇 개뿐이다(지금 front가 있는 회로는 1/9, GB 1315).
- 따라서 e_m = max |d|를 **새 점(LA-1 새 front)에 그대로 쓰는 것은 근거 없는 외삽**이다. 표본 밖 점에서 상한이라는 보장이 없다. 원칙 11에 가깝게 걸린다: 측정값이기는 하지만, 측정하지 않은 점에서는 상한 역할을 근거 없이 맡는다.
- 분위수(p95 등)를 쓰면 분위 수준이라는 새 상수가 생긴다(원칙 11 ⚠). 최대값은 n이 작아서 덮지 못한다.

**자기 순환(tautology)**: ME-1이 front 점에서 재고 e_m = max로 두면, 그 front 점에서 E-1 (a)('|s| > e_m인데 판정이 갈림')는 정의상 일어날 수 없다. E-1 (a)는 표본 밖 점에서만 의미가 있다. 그 점에서는 어차피 oracle을 돌린다(DEC-98 (나)).

### 2.2 Z1이 바꾸는 판정 문언

- **DEC-98 (나)·A' 완료**: 문언 그대로 둔다('front 점 모두 oracle 통과'). 닫힌 점에 적용한다. 엔진 실패 = 점을 내지 못함, E-0·정의 위반, 닫기 비수렴. 약화가 아니다.
- **NFR-5**: '활성 제약의 **oracle 여유** ∈ [0, 해당 metric 분해능]'(닫힌 점). 엔진 쪽 여유 상한 max(분해능, e_m)은 삭제한다. 띠 폭 0 모순이 사라진다. 미측정 metric은 보류.
- **SB-1 (4)**: R10이 거부한 점의 표본을 oracle로 잰다. 거짓 거부는 기록하고 원인을 나눈다. R10 가정(창·C_lower·포락)의 정의가 원인이면 정의 결함 card, 손계산 수치(I_cell)가 원인이면 뒤집힘 기록으로 E-2에 넘긴다. '1이라도 엔진 결함'은 '정의 원인이면 결함'으로 바뀐다 → ⚠ 18 판정 대상. e_m 대상 metric이 없어 영구 보류되는 문제(q456 Ⅴ-6 5)가 사라진다.
- **σ_in(R-15)**: 정의 동일성 관문(PDK 선언에서 읽은 면적 지수·bin 환산 대 엔진 식 = 거부 관문, q456 조건 유지) + 최종 offset 합격은 oracle MC다. 수치 차는 판정 기준이 아니고 기록만 한다.
- **U-46**: '예측-SPICE 차만큼 조여 1회 다시 푼다'는 뜻이 Z1 닫기로 정해진다(1회 → 진전 없음 정지). 닫힘 문언을 갱신한다.
- **E-2 착수 조건**: (1) E-0 위반 (2) 뒤집힘 기록에서 같은 손계산 꼴 원천이 닫기 비수렴을 일으키거나, 닫기가 front 순위를 목적 축 bin(분해능)보다 크게 바꾼 경우. 전·후 완료 조건 = 그 원천이 낸 뒤집힘 수·닫기 반복 수 실측. 새 상수 0.

### 2.3 O-173 E-1 문언 개정안 (Z1)

> **E-1 결정 확정 = oracle**: 엔진 판정은 손계산 값으로 한다(가드 없음). front·선택 점의 합격은 oracle이 정한다(실현 평가 W′, 같은 정의의 측정). 엔진·oracle 판정이 갈린 점은 결함이 아니다. 뒤집힘 기록(회로, metric, 점, 엔진 여유, oracle 여유, oracle 기록 id)으로 남긴다. 활성 제약의 oracle 여유가 [0, 분해능] 밖인 점은 그 제약 문턱을 oracle 여유만큼 옮겨 다시 풀고(닫기), 진전이 없으면 정지·보고한다. 엔진 결함 = E-0 위반 ∪ 정의 동일성 위반 ∪ 닫기 비수렴. (c) 목적 축 순위 bin = 분해능(예산 게이트로 넓힘).

- Z1: c = 여유/분해능(분해능 단위, 무차원), 엔진 합격 c ≥ 0(spec 경계 포함, '≥'). oracle 여유는 원 단위로 기록하고 닫기 목표 0 ≤ s° ≤ 분해능. e_m 단위 맞춤 문제(q456 Ⅴ-6 2의 '가드 c ≥ e_m' 단위 불일치, 등호 '>' 대 '≥')가 **사라진다**.
- (c)를 고르면: 가드 = 원 단위 여유 **>** e_m(E-1 (a)의 '>'와 맞춤), c 정규화를 다시 정의하고 NFR-5 상한을 e_m + 분해능으로 바꾼다.

## 4. 대상 metric 정의 규칙 (항목 5, 일반형)

판정 행마다 'oracle 대응 측정(같은 정의)'이 있는지 없는지를 선언한다. 회로·metric 이름 목록은 쓰지 않는다.
- 대응이 있는 행(엔진 값과 oracle 값이 모두 있음): 뒤집힘 기록·닫기 대상.
- oracle 전용 행(엔진 값 없음, 예: 슬루 O-122): 뒤집힘이 정의되지 않는다. oracle 판정만.
- 필요조건 행(가정 붙은 엔진 하한, 예: R10 → 보호하는 spec의 oracle 측정): 거짓 거부 기록(§2.2 SB-1).
- 대응 측정이 없는 행: 보류(U-76 (4) 보류화).
Z1에서는 '어떤 metric에 e_m을 재나' 목록이 필요 없다. (c)·M을 고르면 위 규칙으로 ME-1 대상을 정해야 하고 R10 문제가 남는다.

## 6. 권고

**Z1(e_m 폐지 + oracle 닫기)**. 근거:
- 원칙 1: SPICE로 최종 확정한다.
- 원칙 2: 수치 동일성은 기준이 아니다. e_m 판정은 수치 차 판정이다.
- 원칙 11: 표본 밖 외삽 상수를 없앤다.
- 원칙 7·25·O-169: 필드·card·소비자가 줄고, T-30과 통일된다.
- 실측: 지배 오차는 동작점마다 달라지는 손계산 꼴 근사다(gmbs/gm 0.14~0.33). 보간은 1 % 미만이다. 그래서 (회로, metric) 값 하나보다 점별 oracle이 물리에 맞다.

조건:
- (1) O-173 E-1·DEC-72 변경은 근본원칙 변경이므로 사용자 승인을 받는다.
- (2) SB-1 (4) 기준 변경은 ⚠ 18로 따로 묻는다.
- (3) σ_in 대체 관문(정의 대조)을 같은 변경에 넣는다.
- (4) 착수 전 실측: 9회로(library, held-out 금지)에서 닫기 반복 수와 oracle 비용, 특히 MC metric. 무거우면 MC metric만 M꼴 초기 Δ를 쓰는 예외를 다시 묻는다.
- (5) Q-W1(실현 평가)이 정해진 뒤 적용한다.

원래 취지와 다름: **예** -- O-173 E-1(e_m 기반 결정 불변) → oracle 확정 + 닫기; DEC-72(선언값·소비자 8곳) 삭제; ME-1 card 삭제; NFR-5 문언; SB-1 (4); U-46 닫힘 문언; T-30의 model_error 용도.

### 2.2 MJ-3 LA-0 (5) 판정 정의 (GB 1877)

**맞는 부분**
- 문턱 ε/(1−ε)는 e^(−x)/(1−e^(−x)) ≤ ε/(1−ε) ⇔ e^(−x) ≤ ε ⇔ 1−e^(−x) ≥ 1−ε이다. 계획의 괄호 '(ID/I∞ 확산 분율 ≥ 1 − ε와 같음)'과 동치다.
- ε = (gm/ID)·tol_V는 VGS 오차 tol_V가 만드는 상대 전류 오차 δID/ID = (gm/ID)·δVGS다. 차원이 맞고, VGS 감도로 명시했다. 새 상수도 0이다.
- **U_T에 n이 없는 것이 물리적으로 맞다**: EKV 약반전 ID = I_S·e^((V_P−V_S)/U_T)·(1 − e^(−V_DS/U_T))에서 VDS 항의 척도는 n이 아니라 U_T다. 실측도 같다. 자유 맞춤 U_fit/U_T0 = 0.86~1.00이다(gm/ID ≥ 18 /V, `fit.txt`). n ≈ 1.3이었다면 1.3 근처가 나와야 한다.

**표본 재측정**(`fit.txt`, U_T0 = kT/q @ 27 °C = 25.865 mV, ε = gm/ID × 1 mV)

**결함**(NJ-2)
1. **판정이 SPICE 자료를 쓰지 않는다.**
   - 계획은 '두 매개변수 I∞·V_E를 스윕에서 맞춘다'고 하므로 U_T는 고정이다. 그런데 판정식 e^(−VDS/U_T)/(1−e^(−VDS/U_T)) ≤ ε/(1−ε)에는 I∞·V_E가 들어가지 않는다.
   - 그래서 'SPICE 쪽 포화 판정'은 VDS ≥ U_T·ln(1/ε)라는 닫힌 식이 되고, 스윕을 돌리지 않아도 같은 답이 나온다. 맞춤은 판정에 쓰이지 않는다.
2. **전 소자에 적용하지만 식은 약반전 전용이다.**
   - gm/ID ≲ 17 /V(pfet)에서 U_T 고정 꼴은 잔차가 14~91 %로 성립하지 않는다. 자유 맞춤의 전이 척도는 1.2~4.5 U_T로 커진다.
   - 강반전 소자는 VDS ≈ 0.1 V에서 '포화'로 판정되지만, 실제 전이는 0.36~0.7 V다. 엔진 `vds_ge_vdsat`이 맞게 '비포화'라고 해도 대조표에는 불일치로 잡힌다.
   - LA-0 (5)의 '불일치 1건 이상이면 규칙 정정 = HC-S'가 거짓 불일치로 발동한다.
   - '식 세부(강반전 쪽 항)는 design 질문'으로 미뤘지만, 판정 규칙 자체는 이미 계획 문언으로 정해져 있다.
3. **약반전에서도 맞춤 꼴의 오차(3.4~7.4 %)가 ε(1.6~2.9 %)보다 크다.** 그래서 자료 기반으로 바꿔도 이 꼴로는 ε 수준을 가를 수 없다. 자료로 잰 교차와 식의 교차가 12~105 mV 어긋난다.

- 잔여(n-2): '고유 키 수 = 색인 항목 수'와 '고유 키 수 = 평가 수'의 정의
  - as-built `perf.unique_keys = len(computed_keys)`는 `outside_domain` 결과를 세지 않는다(`kernel.py:107-111`은 `cache`에만 넣고 `computed_keys`·`seq`는 건드리지 않는다. seq = −1).
  - 색인이 정의역 밖 결과도 항목으로 담으면 항목 수 = kernel_calls + outside_domain이 된다. 그러면 '9회로 `perf.unique_keys` 같음(순수 리팩터링)'이 깨지거나 정의를 바꿔야 한다.
  - `seq` 순 열거에서 seq = −1인 항목들의 순서(결정성 NFR-4)도 정해야 한다.

## 4. 지적

### Critical

### Major

**NJ-1 오라클 DUT 저항 = PDK 셀 X 인스턴스이면 R이 엔진 θ R과 다른 양이 된다**(GB 2190 (d)(e)·후보 선언, OP 506)
- 근거
  - `cell_r.txt`: l = R/rsheet일 때 셀 R은 10 kΩ에서 +7.3 %, 100 kΩ에서 +0.6 %이고, 0.5 V 차 전압에서 −0.3~−1.1 %가 더해진다. 원인은 셀 `:48·:50` rend(rcon 589.99 Ω × 전압 다항식)와 `:51` 본체 전압 계수다.
  - 계획의 R→기하 규칙은 본체 시트 저항뿐이다. 그래서 '엔진 소신호 = PDK 셀 X 인스턴스'·'엔진·오라클 PM 같음' 완료 조건이 nulling R 규모에서 성립하지 않는다.
  - (c)가 가리키는 일반 셀(`…res_high_po.model.spice`, sha `5d5f46…`)과 물리 결정자·OP-3의 `_0p35` 셀(sha `b734c53d…`)은 R 모델이 다르다. '같은 셀·같은 sha256'이 한 파일을 가리키지 않는다.
- 수정안(권고 (가))
  - (가) 기하 필드 writer가 l을 **고른 셀의 R 식 전체(머리 저항 포함, 전압 계수는 ΔV = 0 값)를 역산**해 정한다. 그러면 셀 R(l) = θ R이 된다.
    - 전압 계수에 의한 DC 차는 오라클 쪽 model_error(DEC-72) 기록 항목으로 둔다.
    - 셀 파일 하나를 명시한다(고정 폭 `_0p35`인지 일반 셀인지, sha 하나). 그 C 출처 행(셀 :55-56 또는 parasitics :26-27)도 함께 적는다.
    - 실측 근거: 실제 레이아웃 저항은 머리를 포함하므로 물리 정합 우선이다.
  - (나) 대안: 오라클 DUT 저항 = θ R 값의 이상 R + 같은 식·같은 출처의 C/2 쌍으로 둔다. 엔진과는 같지만 PDK 머리·비선형은 오라클에서도 빠진다. ⚠ 'PDK 셀 동일성' 기준을 약화하는 쪽이다.
  - 4축 비교 -- 물리 정합: (가) 높음 / (나) 머리 저항 누락. 손계산 속도: 둘 다 같다(역산은 닫힌 식). design 단순성: (나)가 더 단순하다. 실측: (가) 머리 7 % 반영 / (나) 0.

**NJ-2 LA-0 (5) SPICE 판정이 SPICE 자료를 쓰지 않고, 강반전 소자에서 거짓 '포화'를 낸다**(GB 1877)
- 근거: §2.2.
  - U_T를 고정하면 판정식에 맞춤 매개변수가 들어가지 않는다. 그래서 판정은 VDS ≥ U_T·ln(1/ε)라는 닫힌 식이 된다.
  - 전 소자에 적용하지만 꼴은 약반전 전용이다. gm/ID ≲ 17 /V에서 잔차는 14~91 %, 전이 척도는 1.2~4.5 U_T다.
  - 약반전에서도 맞춤 오차(3.4~7.4 %)가 ε(1.6~2.9 %)보다 크다.
  - 결과적으로 거짓 불일치가 '불일치 1건 이상이면 HC-S 규칙 정정'을 촉발한다.
- 수정안(권고 (가))
  - (가) **모형 없는 판정**: 같은 (VGS, VSB, L, W)에서 SPICE ID(VDS_op)와 엔진이 가정한 포화 ID(LUT 같은 점) 사이의 상대 차가 ≤ ε이면 '포화 가정 성립', 아니면 불일치로 판정한다.
    - 반전 정도와 무관하고 맞춤 꼴 오차가 없다. ε = (gm/ID)·tol_V 정의는 그대로 둔다.
    - 엔진에 실제로 필요한 사실, 곧 '가정한 전류가 맞는가'를 직접 잰다(물리 정합 우선, 가장 일반적 형태).
  - (나) 대안: 전이 척도 U_eff를 세 번째 맞춤 매개변수로 두고 e^(−VDS/U_eff) ≤ ε로 판정한다. 맞춤 잔차가 ε보다 크면 '해상도 밖 = 판정 불능'으로 기록하고 불일치로 세지 않는다(fail-closed가 규칙 정정 쪽으로 새지 않게). ⚠ 실측상 21/21점 모두 자유 맞춤 잔차(4.8~13 %)가 ε(0.8~2.9 %)보다 커서 전부 판정 불능이 된다.
  - 어느 쪽이든 'U_T 고정 꼴 = 판정'은 지운다. U_T는 kT/q(LUT 측정 온도)이고 n은 넣지 않는다(실측 U_fit/U_T0 0.86~1.00) -- 이것은 맞춤의 참고 기록으로만 둔다.
- 원칙 점검: 상수 0, 물리 정합 우선(가장 일반적 형태), 회로 이름 0, DC/AC 분리(DC 양을 DC 풀이로), 새 card 0.

### Minor

- **n-1 PS-7 열거 생산자 문언 2곳이 낡았다**
  - OS 443 머리 '열거 API는 OS-2가 만든다'와 같은 문단 끝 '그 열거 API는 OS-2가 소비자(하네스)와 같은 변경에서 만든다'가 남아 있다. GB 1229도 'PS-7 S3 색인 열거 API = OS-2가 만듦(… LA-1이 먼저면 읽기만)'이다.
  - 이 문언들은 같은 문단 본문·GB 1852·OS 463·615의 '먼저 병합되는 card가 만든다(조건부 제작 단위)'와 어긋난다. 생산자 하나의 문언을 맞춘다.
- **n-2 계수 정의**: '고유 키 수 = 색인 항목 수'가 정의역 밖(`outside_domain`, seq −1, `computed_keys` 밖) 항목을 세는지 정한다. as-built `unique_keys`는 세지 않는다. '평가 수'는 kernel_calls인지도 정한다. `seq` 열거에서 seq −1 항목의 순서(결정성)도 정한다.
- **n-3 저항 b 단자 기본 레일**: DEC-61은 nmos·pmos만 정의하므로 'DEC-61 bulk 기본 규칙의 레일'로는 저항의 레일이 정해지지 않는다. '최저 전위 레일(p 기판 -- poly는 field oxide 위)'로 적고, 소신호에서 모든 레일이 교류접지라 MNA가 같다는 근거를 붙인다.
- **n-4 직렬 세그먼트 저항**: 값 선언 저항이 셀 여러 개의 직렬이면(heldout cnr_ota 16 × res_high_po) PDK 위상은 세그먼트마다 π다. 단일 π(C_total/2)와는 다르다. 기하 필드에 세그먼트 수를 둘지, 또는 적용 범위를 적는다.
- **n-5 오라클 쪽 변화 표지**: OP-3 DUT 저항이 이상 R에서 PDK 셀로 바뀌면 저항 있는 회로의 오라클 판정값(PM·극점)이 기존 기준선과 달라진다. 엔진 쪽 변화표(GB 2190 (d))와 짝을 이루는 오라클 쪽 변화표, 그리고 OP-3 card 성격 확장 '원래 취지와 다름' 표지와 Status 등재가 필요하다. 아니라면 아닌 근거를 적는다.
- **n-6 U-75 기한**: GB 2475 U-75 행은 아직 'U17 단계 ② 완료 판정 전'이고, Q-C4(GB 1163)는 'card DR-1 착수 전'이다. 둘 다 성립할 수는 있지만 더 이른 쪽 하나로 맞추거나 두 기한을 같이 적는다.
- **n-7 U_T 정의 자리**: GB 1877의 U_T가 kT/q(LUT 측정 온도, PDK 선언)인지 맞춤 매개변수인지 적혀 있지 않다(NJ-2 수정 때 함께).

## 5. 승인 가능 판정

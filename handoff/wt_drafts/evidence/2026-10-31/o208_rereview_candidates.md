## R1. O-205 (3) 'SR 하한 정의 삭제'

**원결정 원문**(UD:1186 (3)): "R0(O-118 2번) 창 끝 = 포화·triode 영역 행만, SR 하한(O-119 정정 4·U-110) 정의 삭제."

**문제**
- 삭제 근거는 감사 V20이다(`o200_audit_k10_physical_v3.md:65`). V20은 "SR 하한 계단 = 입력쌍 소수 가지 전류가 `device.dc_conduction_floor`에 닿는 차동 입력 -- P:703, P:2581 U-110"이라 보고, (b)꼴(tol_V가 경계를 정함) 틀림으로 분류했다. 검증 43(`o200_validation43.md:83`)도 이 전제를 받아들였다.
- 실측(계획 원문): P:703의 현행 SR 하한 계단은 **점근선 교점 A_lo = SR_fw/(2π·UGF_β)**다. 이 정의는 v6.37 둘째 커밋이 정했고, floor 기준 (a)는 같은 행 '기각'에 있다. 판정에 쓰지 않는 보고 전용 양이고 엔진 칸은 0이다(O-120). 이 정의에는 tol_V·floor·분해능이 하나도 없다. 두 양 SR_fw와 UGF_β는 모두 oracle 측정값이다.
- floor 문언은 두 자리에만 낡게 남아 있다. 하나는 P:2581 U-110 **제목 칸**('하한 = 입력쌍 소수 가지 전류가 `device.dc_conduction_floor`에 닿는 차동 입력')이고, 다른 하나는 같은 행 원칙 칸 '상수 0(전도 하한·범위 정의 재사용)'이다. 같은 행 본문은 이미 'A_lo -- (a) floor 기준 기각'으로 적혀 있다.
- 따라서 V20의 전제가 틀렸다. O-205 (3)의 SR 부분은 O-200 위반이 없는 정의를 지운다.

## R2. O-205 (2) F-b -- C1(T4 꺼짐·포화 대조), C2(T5)

**원결정 원문**(UD:1186 (2)): "F-b: oracle ID 부호가 잡음 수준이면 기록만, 합격 = 기능 spec(판정 제약 전부 verified_by·통과) + 포화 대조 -- DEC-90 (1) 꺼짐 FAIL 조항·O-45 U2 삭제, oracle 전류 분해능 양은 정본 자리 없어 만들지 않음."

**문제**
- C1(모순 조건부): T4(P:1343)의 포화 대조 대상은 '선언 없는 **ID > 0** MOS'다. 꺼짐 FAIL을 지우면, 선언 없는 MOS가 SPICE에서 ID ≤ 0일 때 FAIL도 포화 대조도 걸리지 않는다(fail-open). 반면 엔진 P5(봉인 9 (i), P:635)는 같은 소자를 거부한다. 그래서 정의 동일성(O-178 (4), DEC-90 (1) '봉인 7·9와 같은 판정 함수', P:289)이 깨진다.
  - '잡음 수준이면'은 문턱 양을 전제한다. 그런데 F-b가 그 양을 만들지 않기로 해서 조건문 자체가 정의 불능이다.
- 이 문서 실측 RR-1: oracle options gmin 1e-15는 pushpull 깊은 약반전 점(채널 5e-14 A)에서 비채널 겉보기 몫을 2.3e-2에서 5.8e-2로 키운다. 시뮬레이터 바닥(gmin·V ≈ 1.8 fA)이 설계 전류와 같은 자릿수에 가까워지는 곳은, 설계점 자체가 oracle 측정 분해능에 닿은 곳이다.
- C2(누락 + 사실 오기): '판정 제약 전부 verified_by'는 T5(P:1344, '측정할 수 없는 제약은 `spice_unverifiable[]`로 실행 전 보고')보다 강화다. 그런데 후보 문서는 이를 '기존 T5 규칙'이라 적었다.

## R4. O-202 (2)·O-203 -- C3 GIDL·단자 누설

**원결정 원문**
- O-202 (2)(UD:1183): "봉인 KCL은 off 전류 0 모형(기존 DC writer), 효과는 전 노드 1차 ΔV = −G⁻¹·ΔI_off(… 정의역 안 점값, VGS < 0은 단조성 구간 [0, I_off] -- E-0 예외 명시) …"
- O-203(UD:1184): "VGS = 0 마디는 깊은 약반전 채널 동작점(누설점 아님)."

**문제**
- M1(`o208_gidl/`)과 RR-2를 보면, pfet는 끄는 방향으로 단자 누설이 **늘어난다**. L 1 µm에서 VSG 0일 때 1.87e-13 A, −0.6 V일 때 2.52e-12 A다. 그래서 [0, I_off](I_off = LUT 채널)는 물리 상한이 아니다.
- RR-2 새 사실: pfet L 1 µm의 비채널 지배 몫은 **GIDL**(agidl ≠ 0)이고, 접합은 1.15 fA뿐이다. C3·M1의 'VSG 0에서 접합이 10⁵배'라는 해석은 'GIDL이 10⁵배'로 정정해야 한다.
- pfet L 0.15 µm bin은 `agidl` < 0(피팅값)이고 비단조라 GIDL 몫을 분리할 수 없다.
- 설계 전류 대비 비채널(RR-1, 켜진 소자):
  - 6/6 표본 회로에서 비채널/채널 ≤ 2.3e-2다(gmin 1e-18). 5/6은 ≤ 7.6e-4이고, 모두 그 점의 ε = (gm/ID)·tol_V(수 %~수십 %)보다 작다.
  - 지금 `off` 선언 소자는 0/13이다(13 spec `intended_region` pending, CI-18). 그래서 VGS < 0 구간 규칙의 현재 대상도 0이다.
  - 표본 L은 0.15~0.18 µm뿐이다. 긴 L pfet의 VGS ≈ 0 근처 점은 표본에 없다.

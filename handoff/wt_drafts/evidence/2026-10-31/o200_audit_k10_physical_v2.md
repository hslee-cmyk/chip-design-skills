## 2부 -- 전도 정의와 K10 (대칭 비교)

### 2.1 물리 사실 (판별력 있는 것만)
1. VGS = 0 마디의 I_off는 게이트가 제어하는 약반전 채널 전류다. R1(ID 열 n 1.12~1.91)·R2(g1/g0 ≤ 1, 0/7380)로 판별했다.
   - VGS = 0 ~ 수백 mV 구간은 물리적으로 정상인 깊은 약반전 동작점이다. gm/ID = 곡선 최댓값, VGS − |VTH| = −0.5 ~ −1.4 V.
   - 약반전에는 '켜짐/꺼짐'의 물리적 날 경계가 없다. 전류는 VGS에 대해 지수로 매끄럽게 변한다.
2. 전도에 대해 상수 없이 서는 물리 사실은 둘뿐이다.
   - **전류 방향**: 선언 방향 ID > 0(topology d/s 표기 = 물리 방향, DEC-97 (4)).
   - **엔진이 값을 정의할 수 있는 범위**: E-0 LUT 정의역. 이것은 LUT 생성 선언의 표본 범위라는 정의 사실이지 판정 문턱이 아니다. PDK 이식성 면에서 소자형마다 LUT 선언이 범위를 정한다.
3. VGS = 0(I_off 기준점)은 업계 I_off 정의의 관례 기준점이다. enhancement 소자에서는 '구동 없음'과 겹치지만, native·zero-VT·depletion 소자에서는 VGS = 0이 중간~강반전이다. 지금 LUT는 `nfet_01v8`·`pfet_01v8`뿐이라 현재 영향은 0이지만, 규칙 일반성(O-197)에서는 소자형에 기대는 꼴이다.

## 5부 -- 사용자 질문 초안 (권고 확인표 9항목 칸마다)

### Q-O200-1 전도 정의 (선언 없는 MOS -- 봉인 9·DEC-90 (1)·범위 끝 한 묶음)

**질문**: 지금 '전도'는 I_off ≤ (gm/ID)·tol_V·ID입니다(U-69, O-45 U2). 이 식은 'I_off가 ln ID 분해능 안에서 무시 가능'이라는 분해능 꼴이지만, 두 가지 때문에 O-200에 어긋납니다. 첫째, 분해능 판정을 거부·FAIL·범위 끝에 씁니다. 둘째, I_off는 별도 누설이 아니라 같은 채널의 VGS = 0 전류라서, 실제로는 tol_V가 정하는 VGS 문턱이 됩니다(LOO 셀로 0~0.41 V, tol 1십진에 약 75 mV). 어떻게 할까요?

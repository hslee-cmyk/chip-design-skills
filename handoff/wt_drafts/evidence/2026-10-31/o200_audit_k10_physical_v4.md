### 2.4 `dc_conduction_floor` 소비자 R0·SR 하한 -- 묶음 결정 (Major E -- v3 §2.4 대체)

#### 2.4.1 실측: 후보 (가) '선형 예측 영 교차'의 물리 뜻 (`o200_v4/m_linear_zero_cross.txt`)
- 소자 전류를 봉인점에서 VGS 1차로 늘이면 영 교차는 ΔVGS = −1/(gm/ID)다.
- 그 VGS에서 실제 LUT 전류 / 봉인점 전류를 반전 수준별로 쟀다(VDS ≥ 0.3 V, 격자 마디 전부, ln ID는 마디 사이 선형 보간). 반전 구간 이름은 보고용 표지이고 판정 문턱이 아니다.

- 해석: 약반전 봉인점에서 (가)의 '전류 0' 점은 실제로 전류가 e^{−1} ≈ 0.37배로 줄었을 뿐인 점이다. 지수 전류를 직선으로 늘인 산물이고, 위치는 봉인점에 묶여 있다(봉인점에서 ΔVGS ≈ −32~−50 mV). 강반전에서도 실제 전류는 중앙 0.2~0.24배가 남는다.
- 그래서 (가)는 물리적 차단점이 아니다. R0 행의 k(회로 감도)는 소자 자기 VGS 감도와 다를 수 있지만, '선형 예측 0'이 지수·제곱 전류에서 0이 아닌 점이라는 귀결은 같다.

## 3부 -- `off` 선언 판정 (Major D -- v3 §3 대체)

### 3.1 사실 (원칙 22 ①)
- **KCL 처리**: 계획은 off 소자 DC 전류를 KCL 합에 넣는지 정하지 않는다.
  - 봉인 3 '제외 넷 없음'(P:629), O-55 V5 '사이징·역산 경로 제외'(P:635, ot N3.5), O-53 A3 'off 소자 G 기여 없음'(ot X-29, 소신호)뿐이다.
  - 그래서 사실상 0 전류 모형이다(v3 §3.1과 같음).
- **기능 spec 연결**: offset-trim metric(보정 구간·잔여 Δ_max/2·DNL σ, ot:285~289)은 '`verified_by`(SPICE 오라클)가 생긴 뒤에만 제약'이다(ot:291). 지금은 판정에 이어져 있지 않다. 이어지는 것은 TR card 완료 조건 2(ot:555 '선언 회로에서 trim 제약·metric이 `verified_by`를 가진다')다.
- **toy**: offset-trim toy·`augment_trim`·`trim_decl`은 `skills/analog-gmid-design` 아래 0건이다(실측 `o200_v43/v43_toy_grep.txt`, v3 grep과 같음). 엔진에 `off` 영역 처리가 없다. oracle에는 as-built `off` 처리가 있다(m-n2, §4).
- **원문 물리**(Bertotti 2012, *An 8 bit current steering DAC for offset compensation purposes in sensor arrays*, Adv. Radio Sci. 10:201-206, **p.3**. 로컬 PDF `skills/analog-gmid-design/assets/technique/sources/offset_trim__bertotti_2012/source.pdf`, 텍스트 `paper.md` 300~308행)
  - "the LSB current cell in this work is based on an NMOS transistor operated in subthreshold region" -- 켜진 LSB 전류부터 약반전이다. 그러니 켜짐/꺼짐을 소자 전류 문턱으로 가를 물리 근거가 없다.
  - "Two output nodes are used to ensure an optimum transient response by never switching off the current sources" -- 전류원은 끄지 않고 출력만 조향한다. 그래서 꺼진 쪽 스위치 전류가 남기는 결과는 출력 오차(잔여·DNL)로 나타난다.
- **단조성**: ID(VGS) 엄격 단조 위반 0이다(agent 인용 `o200_v41/v41_p4_vs_p2_meta.json`). 그래서 VGS < 0(LUT 정의역 밖)인 소자의 전류는 0 < ID < I_off(VGS = 0, 같은 VDS·VSB)다. 물리로 정해지는 구간이다.

## 5부 -- 질문 초안 (변경분)

### Q-O200-1 전도 정의 + R0·SR 하한 (한 묶음, Major E·F 반영)

**질문**: 지금 '전도'는 I_off ≤ (gm/ID)·tol_V·ID입니다(U-69, O-45 U2). 같은 바닥(`dc_conduction_floor`)을 R0 측정 구성 창 전도 행(O-118 2번)과 SR 하한(U-110)이 씁니다. 이 식은 분해능 꼴이지만, 분해능 판정을 거부·FAIL·창 끝에 쓰고, I_off가 같은 채널 전류라 tol_V가 정하는 VGS 문턱이 되어 O-200에 어긋납니다. 셋을 한 묶음으로 어떻게 할까요?
- (가) **권고**: 한 묶음으로 바꿉니다.
  - 엔진 전도 = 선언 방향 ID > 0. 엔진 끝 = LUT 정의역(밖은 정의 불능 기록).
  - oracle 합격의 '꺼짐 FAIL' 조항은 지우고 SPICE ID 부호는 기록만 합니다. 합격은 기능 spec + 포화 대조입니다.
  - R0는 삭제합니다. ICMR 창 끝은 포화·triode 행이고, 차단의 기능 결과는 기능 spec이 판정합니다.
  - SR 하한 계단 정의는 삭제합니다.
  - 이 결정 전까지 계획 문언은 그대로 두고 O-200 위반 표지만 답니다.
  - ⚠ O-45 U2·U-69·O-118 2번·O-119 정정 4·O-50 G5·DEC-90 (1) 꺼짐 조항과 원래 취지가 다릅니다. ICMR 창이 차단점 너머로 넓어지는 회로(nmcnr·ngcc)는 기능 spec이 있어야 합니다.
- (나) 같은 묶음이되 R0·SR 하한을 선형 영 교차로 바꿈. ⚠ 실측상 그 점의 실제 전류는 봉인점의 0.37배(약반전)라 물리적 차단점이 아닙니다.
- (다) P4(VGS > 0). ⚠ 관례 기준점.

- (다) O-f(사용자 선언 꺼짐 전류 상한). ⚠ 선언값과 기능 spec의 연결 근거가 필요합니다.

### Q-O200-5 포화 판정 여유 +tol_VDsat (실측 완료 -- 질문으로 복귀)

**질문**: 물리 포화 경계는 VDS = VDSAT입니다. LUT VDSAT와 SPICE `@m[vdsat]`은 같은 양이고, 같은 op 점의 차는 ≤ 0.97 mV입니다. 그런데 봉인 7·triode 여유·측정 구성 판정 창·S_d 헤드룸 행·출발 단계·diode 창은 이 경계를 tol_VDsat(LUT LOO 보간 분해능, 소자당 중앙 1.1 mV, 셀 구성값 최대 32.5 mV)만큼 옮겨 거부하거나 정의역을 자릅니다. 실측으로는 띠 안 1/2413(nmcnr M109)이 SPICE에서는 포화(+3.567 mV)인데 봉인 7만 거부하고, 엔진 출발점이 iv_domain 격자 올림으로 최대 |Δln IDu| 0.391(sf_pushpull, 전류 −9.7 %) 움직입니다. 어떻게 할까요?
- (가) **권고 (ii)**
  - 정의역 행(S_d 헤드룸·출발 단계·diode 창)과 판정(봉인 7·triode·측정 구성 판정 창)을 모두 VDS ⋚ VDSAT로 바꿉니다.
  - 엔진 값으로 VDS ≥ VDSAT면 통과합니다. 0 ≤ VDS − VDSAT < tol_VDsat인 띠 안은 '구별 불가' 기록만 하고, 최종 판정은 oracle입니다.
  - 엔진 값으로 VDS < VDSAT면 E-0 fail-closed 거부를 그대로 둡니다(크기와 무관).
  - 측정 구성 판정 창과 정의 창은 같은 정의가 되면 필드 하나로 합칩니다.
  - ⚠ DEC-88 Q3 (ii)(C)·Q4 (4)·O-58 T-1·S-1·O-109 C1·hc O-15 (C)·DEC-12와 원래 취지가 다릅니다.
- (나) (i) 현행 +tol 절단·거부 유지. ⚠ O-200(물리 경계를 분해능으로 옮김), ⚠ 원칙 2 E-1(가드).
- (다) (iii) 띠 안 거부 대신 E-1 닫기에 맡김. ⚠ 범주가 맞지 않습니다. E-1 닫기는 활성 metric 제약의 oracle 여유에 쓰는 문턱 이동이고, 포화는 E-0 영역 관문이라 닫기 대상이 아닙니다. 띠 안 처리 결과는 (가)와 같아지고, 위반 쪽까지 닫기에 맡기면 E-0 fail-closed를 잃습니다.
- (라) (ii′) 양쪽 띠(|VDS − VDSAT| < tol 모두 기록). ⚠ 원칙 2 E-0. 엔진 값이 위반인 점을 통과시킵니다(fail-open). 실측상 위반 4점은 SPICE에서도 비포화(부호 같음)였습니다.

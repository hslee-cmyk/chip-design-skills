**물리 해석(판정 근거)**
1. VGS = 0 마디의 I_off는 별도 누설 기구가 아니다. 게이트가 제어하는 약반전 채널 지수 전류다. 근거 셋: gm/ID가 곡선 최댓값(약반전 plateau)이다. n_eff가 1.1~1.8의 물리 범위다. ln ID 기울기가 gm/ID와 같다. 그래서 VGS = 0 ~ 수백 mV 구간은 물리적으로 정상인 깊은 약반전 동작점이다. 이 구간은 '누설 지배 영역'이 아니다.
2. 봉인 9 식 I_off ≤ (gm/ID)·tol_V·ID는 ID/I_off ≥ 1/((gm/ID)·tol_V)와 같다. 이 식은 켜짐/꺼짐 비 문턱이고, 문턱 크기를 tol_V가 정한다(1 mV면 약 35~40배). 경계는 tol_V 십진 한 칸마다 ln 2.30(VGS 약 n·U_T·ln10 ≈ 70~80 mV)씩 옮겨 간다. 측정한 경계는 닫힌 꼴보다 격자 한 칸 이내 위다. 경계 마디의 gm/ID는 곡선 최댓값과 같다(plateau 안). 즉 물리량(gm/ID·n·채널 전류)이 같은 점들 사이를 tol_V가 가른다. 이것이 O-200 '물리 경계를 판정 허용오차로 정한다'의 정확한 사례다.
3. 식 꼴 결함도 있다. ε = (gm/ID)·tol_V는 ln ID의 분해능 δ(무차원)다. 분해능 판정의 바른 꼴은 'ln(ID/I_off) ≤ δ이면 I_off와 구별 불가'이고, 이는 ID ≤ I_off·(1+δ)에 해당한다. 그런데 지금 식은 I_off/ID ≤ δ, 곧 ID ≥ I_off/δ를 요구한다. 분해능 δ를 그 역수의 비 문턱으로 쓴 것이다. 그래서 이 식은 판정 분해능 규칙도 아니다((a) 꼴 아님).
4. gm/ID 정점(DEC-88 반전 수준 하한)은 LUT 정의역 안에 물리 위치가 없다. nfet에서는 plateau가 LUT VGS 훑기 시작점(정의역 끝)까지 이어진다(7380/7380). pfet에서는 정점 이웃이 소수 넷째 자리까지 같다(M-J1 §4.6: 상대차 ≤ 1.3e-6). 즉 정점 위치를 반올림이 정한다. 상수 없이 정의를 고칠 길도 없다.
   - plateau 시작·약반전 끝을 정하려면 비율 문턱(예: gm/ID ≥ x·max), IC 기준값(IC = 0.1 등), 과구동 문턱 중 하나를 골라야 한다. 셋 다 상수 발명이다(원칙 11).
   - EKV IC는 n을 plateau에서 뽑으면 VGS = 0에서 ≈ 0이다(M4). 그러니 IC 하한은 상수 선택 없이는 정의되지 않는다.
   - 물리적으로도 약반전 쪽(낮은 ln IDu)은 지배되지 않는다. gm/ID 이득은 없지만 면적이 커서 matching(Pelgrom)·1/f 잡음이 좋아지고 VDSAT도 낮다. 그래서 일반형(원칙 6)에서는 정점 하한이 물리 근거를 갖지 못한다.

### 1.3 조건부 -- 포화 판정 여유 +tol_VDsat (경계는 물리, 여유가 수치)

물리 경계 VDS = VDSAT(LUT VDSAT 열 = oracle `@m[vdsat]`, 같은 정의)는 정의 창에서 tol 없이 지켜진다(P:1758 (i)). 문제는 판정·탐색에서 경계를 +tol_VDsat만큼 옮기는 쓰임이다. tol_VDsat는 VDSAT 열 보간 분해능이다. ## 2부 -- K10 재분석 (O-200 기준)

### 2.1 질문 다시 세움
K10이 묻는 것은 'S·F 출발 구간 S_d의 약반전 쪽 끝'이다. 측정(§0)으로 보면 이 끝을 정할 수 있는 물리 사실은 셋뿐이다.
1. **LUT 정의역 끝** -- VGS 훑기 시작점. E-0 'SPICE 표본 정의역' 정의 경계이고, 수치 분해능이 아니다.
2. **게이트 구동 부호** -- ID > I_off ⇔ VGS > 0. 엄격 단조라 상수가 0이다.
3. **실현 가능** -- 최소 폭(PDK), 면적 예산·W 상한(spec), 속도·헤드룸 순방향 행.

전도 여유 행(tol_V)과 정점 행(잡음)은 물리 결정자가 아니다(V7·V8).

또 하나의 사실이 있다. S_d 전도 행은 봉인 9의 탐색 투영이다(d40:1362). 그래서 봉인 9(V1)를 그대로 둔 채 S_d에서만 행을 빼면, S_d가 봉인이 거부할 점을 품는다. **K10은 봉인 9·DEC-90 (1) '꺼짐' 정의 재결정과 한 묶음이다.**

후보 문서의 'D2 누설 영역 출발(F 25/63)'에서 '누설'은 봉인 9 식(tol_V)으로 정의된 말이다. 물리로 다시 판정하면 그 점들은 gm/ID가 최댓값이고 n_eff가 1.1~1.8인 깊은 약반전 채널 동작점이다(M1). 그래서 '물리적으로 무의미한 점(원칙 1 ⚠)'이라는 D2 판정은 근거를 잃는다. 그 점들이 극단(큰 W)인 것은 실현 가능 행(면적 예산)이 다룬다. M-J1b §2.2·§2.4를 보면 예산을 적용한 뒤 t* 차는 0.0~0.8 %이고, 다수 누설 출발은 ID 1e-7 full F 2개뿐이다.

## 3. 사용자 질문 초안

**Q-O200-1 (전도/꺼짐 정의 -- 봉인 9·DEC-90 (1)·S_d 전도 행 한 묶음)**
지금 '전도'는 I_off ≤ (gm/ID)·tol_V·ID입니다(U-69, O-45 U2 엄격화). LUT 실측을 보면 이 경계는 tol_V 십진 한 칸마다 VGS 약 70~80 mV씩 움직이고, gm/ID·n이 같은 깊은 약반전 점들(VGS 0~0.26 V, gm/ID = 최댓값)을 가릅니다. 식 꼴도 분해능 δ를 비 문턱 1/δ로 쓴 것입니다. O-200에 따라 어떻게 할까요?
- (가) **권고**: 전도 = 선언 방향 ID > 0 ∧ ID > I_off(VGS > 0 구동 부호, 상수 0). tol_V는 0 < ln(ID/I_off) ≤ (gm/ID)·tol_V를 '구별 불가'로 기록할 때만 씁니다(합격 최종은 oracle). ⚠ O-45 U2 '엄격화' 취지와 다름 -- 옛 Q5 ε = 1 꼴로 돌아갑니다.
- (나) 지금 식 유지. ⚠ O-200 위반(물리 경계를 판정 허용오차로 정함).
- (다) 다른 물리 결정자 지정(예: 회로 기여 기준). ⚠ 정의하려면 새 문턱 = 상수 발명(원칙 11). 회로 기여는 SPICE 성능 spec이 이미 판정합니다.

**Q-O200-2 (K10 -- S_d 약반전 끝, Q1의 답에 따름)**
- (가) **권고**: S_d = LUT 정의역 ∩ 구동 부호(Q1 (가)) ∩ 실현 가능(최소 폭·면적 예산·W 상한) ∩ 속도·헤드룸 순방향 행. 전도 여유 행·정점 행은 두지 않습니다. 이전 조건부 권고(D2+ → 정정 뒤 D1)는 철회합니다.
- (나) 옛 D2+(tol_V 경계). ⚠ O-200.
- (다) 반전 계수 하한(IC_min). ⚠ 상수 발명. 실측상 IC(VGS = 0) ≈ 0이라 값을 고르지 않으면 경계가 없습니다.
- 착수 뒤 실측: (가)와 옛 D2의 t* 차(VGS 0 마디 하나, ln IDu ≤ 1.3), 13회로 봉인 거부 변화.

**Q-O200-3 (DEC-88 반전 수준 하한(정점) 행, P-7 재검토 -- 원칙 20)**
정점은 nfet에서 LUT 정의역 끝(7380/7380), pfet에서 반올림 위치(이웃 상대차 0.0000)입니다. 상수 없이 고칠 정의가 없고, 약반전 쪽은 matching·잡음·VDSAT에서 이득이 있어 일반형에서 지배되지 않습니다.
- (가) **권고**: SLSQP 행·S_d 행에서 철회하고, gm/ID를 보고값으로만 둡니다. K3 (나) 'argmax' 정의도 함께 다시 씁니다.
- (나) 유지. ⚠ 수치 잡음이 경계를 정합니다.

**Q-O200-4 (포화 판정 여유 +tol_VDsat -- V10~V15)**
물리 경계 VDS = VDSAT는 정의 창에서 지켜집니다. 그러나 봉인 7·triode 여유·측정 구성 판정 창은 tol_VDsat 띠를 거부·창 좁힘에 쓰고, S_d 헤드룸 행·출발 단계·diode 창은 탐색 정의역을 tol_VDsat 합만큼 자릅니다.
- (가) **권고**: 탐색 정의역(V13~V15)에서는 tol을 뺍니다(물리 꼴 VDSAT 합). 판정(V10~V12)은 띠 안을 '구별 불가' 기록 + oracle 판정으로 바꿀지 따로 정합니다(원칙 2 E-1 '가드 없이'와 같은 방향).

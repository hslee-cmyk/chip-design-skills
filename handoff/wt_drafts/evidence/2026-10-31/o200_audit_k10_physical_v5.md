## 3부 -- `off` 선언 (Major G -- v4 §3에 고침·추가)

### 3.3 O-d″ 정본 문언과 다른 소자 판정 전파

**(1) 정본 문언(원칙 7 -- 하나로)**
- 봉인점 노드 전압 필드(writer = 기존 DC 블록)는 **off 소자 전류 0 모형의 해**다. off 전류를 봉인 KCL에 넣지 않는다. 넣으면 off 소자 전류가 노드 전압에 따라 바뀌는 비선형 풀이를 반복해야 하므로, 원칙 1 (2) SPICE식 정풀이 ⚠가 된다.
- off 전류의 효과는 **전 노드 1차 ΔV 벡터** = −G⁻¹·ΔI_off다(봉인점 G, O-53 A3과 같은 1차 기계, 반복 0).
  - **[v5.1] m-p2**: G는 기존 정본 필드 `graph.ss_nodal`(`NodalSystem(nodes, fixed, g, g_bound, factor)` -- 봉인점 컨덕턴스 계·인수분해, 계획 P:557 B1 행, design 40:469)을 READS로 읽는다. 새 행렬·사본은 만들지 않는다.
  - ΔV 기록은 새 필드 하나(writer 하나 = DC 블록 또는 봉인 뒤 블록 -- 자리는 계획 개정에서 정함)이고, 소비자 = G2-a 포화 여유 판정(봉인 7·E-0)이다. 소비자 점검(≥ 1)은 계획 개정 착수 조건이다.
  - VGS ≥ 0(정의역 안): ΔI_off = 봉인점 LUT 점값 → ΔV 점값.
  - VGS < 0(정의역 밖): ΔI_off ∈ [0, I_off] → ΔV 구간(구간 끝 두 번 계산).
- ΔV 벡터의 자리는 DC 블록의 기록 필드다. 새 필드이므로 계획 개정 때 원칙 7(writer 하나·소비자 ≥ 1) 점검 대상이다.
- v4의 'off 소자 DC 전류를 KCL에 넣는다' 문언은 지운다.

**(2) 다른 소자 판정 전파 -- 대칭 비교**

ΔV 벡터를 각 선언 없는 소자의 VDS와 VDSAT(VGS 변화의 1차 -- ∂VDSAT/∂VGS·ΔVGS, LUT 순방향 조회)에 전파해 포화 여유 s = VDS − VDSAT의 보정값(점값 또는 구간)을 낸다.

| G2-d (v4 암묵) | 다른 소자 판정은 0 모형 봉인점 값으로만, 보정은 출력에만 | 정의역 안 점값 주입도 판정에 들어가지 않아 낙관적이다(O-d와 같은 결함) | 없음 | -- | **틀림**(낙관) |

### 3.4 '담는가'의 기계적 정의 (원칙 14·15 -- 회로 해석은 사용자)

- **선언 칸(spec 쪽, 상수 0)**: `off` 선언 소자마다 그 꺼짐의 결과를 판정하는 spec metric 목록을 사용자가 선언한다(이름 예: `intended_region.off[<소자>].judged_by = [<metric>, ...]` -- 칸 이름·꼴은 계획 개정·design 몫). 새 spec 칸이므로 계획 개정(S-7)·원칙 7 점검 뒤에 둔다.
- **O-h 기계 정의**: `off` 선언 소자에 대해 (a) `judged_by` 칸이 없거나 비어 있으면, 또는 (b) 그 목록의 metric 중 하나라도 판정 제약이 아니거나 `verified_by`가 없으면 → 선언 검증 불능 → E-0 정지(사유 기록).
  - offset-trim은 TR card가 metric에 verified_by를 붙일 때까지(ot:291·555 2) 정지한다.
- **F-b 기계 정의**(선언 없는 소자 -- 소자별 선언을 요구하지 않음): oracle 합격 = 그 회로 spec의 판정 제약 전부가 `verified_by`를 갖고 모두 통과 + 선언 없는 MOS 포화 대조(VDS ≥ VDSAT). SPICE ID 부호는 기록만 한다. '담는가'는 회로 단위로 '판정 제약 전부 verified_by'(기존 T5 규칙)로 정의한다.
  - 대가: 소자별 대응이 없어, 역방향 전도처럼 어느 판정 제약에도 결과가 드러나지 않는 변화는 잡히지 않을 수 있다. 소자별 `judged_by`를 선언 없는 소자 전부에 요구하는 안은 모든 MOS에 선언을 요구하는 꼴이라 원칙 6(가장 일반형)·사용자 부담 면에서 대안으로만 적는다.
- **(4) 영향 표지 정정**: 13 library spec은 모두 `intended_region` = `{"pending": "CI-18"}`이고 heldout spec은 0이다(agent 인용 `o200_v44/v44_checks.txt`, 실측 재확인: nmcnr spec 199~200행, ngcc spec 164~165행). **선언 전이라 0**이다. CI-18로 선언이 생긴 뒤의 영향은 그때 잰다.

## 5부 -- 질문 초안 (변경분 전문)

### Q-O200-1 전도 정의 + R0·SR 하한 (한 묶음, 하위 결정 Q-1b 포함)

**질문**: 지금 '전도'는 I_off ≤ (gm/ID)·tol_V·ID입니다. 같은 바닥을 R0 측정 구성 창 전도 행과 SR 하한이 씁니다. 분해능 판정을 거부·FAIL·창 끝에 쓰고, I_off가 같은 채널 전류라 tol_V가 정하는 VGS 문턱이 되어 O-200에 어긋납니다. 셋을 한 묶음으로 어떻게 할까요?
- (가) **권고**: 한 묶음으로 바꿉니다.
  - 엔진 전도 = 선언 방향 ID > 0. 엔진 끝 = LUT 정의역(밖은 정의 불능 기록).
  - oracle 합격의 '꺼짐 FAIL' 조항은 지웁니다. 합격 = 판정 제약 전부 verified_by·통과 + 포화 대조이고, ID 부호는 기록만 합니다(F-b).

### Q-O200-2 `off` 선언 소자 판정 (Major G 반영)

**질문**: `off` 선언 소자가 '충분히 꺼졌는가'의 결정자는 소자 전류 문턱이 아니라 그 꺼짐의 결과를 판정하는 기능 spec입니다(Bertotti 2012 p.3: LSB 셀부터 약반전이고, 전류원은 끄지 않고 조향함). 어떻게 할까요?

  - 그 ΔV를 다른 소자 VDS·VDSAT에 1차로 전파합니다. 보정 여유가 점값 < 0이면 E-0 거부, 구간이 0을 가로지르면 E-0 정지입니다.
  - '그 꺼짐을 담는 metric'은 사용자가 소자별로 선언합니다(`judged_by` 칸). 칸이 없거나 그 metric이 verified_by를 갖지 않으면 선언 검증 불능으로 E-0 정지합니다.

### Q-O200-5 포화 판정 여유 +tol_VDsat (Major I·m-o2 반영)

  - 경계 = VDS = VDSAT로 고정합니다. **분해능은 양쪽 판정 모두에 쓰지 않습니다.**
  - 엔진 값이 VDS ≥ VDSAT면 통과, VDS < VDSAT면 크기와 무관하게 E-0 거부입니다.
  - 양쪽 띠(|VDS − VDSAT| < tol_VDsat)는 '구별 불가' 기록만 합니다. 음쪽 띠의 기록은 [v5.1] 엔진·oracle 대조 기록용(m-p4)이고 거부를 바꾸지 않습니다.
  - 이 비대칭(음쪽 거부)은 경계를 옮기지 않습니다. 엔진 자기 손계산 해가 선언 영역(포화)과 어긋나면 E-0 fail-closed라는 원칙 2 정의 그대로의 귀결이라 정당합니다. 분해능이 판정을 정하는 곳은 없습니다.
  - 측정 구성 판정 창과 정의 창은 같은 정의가 되면 필드 하나로 합칩니다.

- (나) (i) 현행 +tol 절단·거부. ⚠ O-200, ⚠ E-1(가드).
- (다) (iii) E-1 닫기에 맡김. ⚠ 범주 불일치(포화는 E-0 영역 관문).

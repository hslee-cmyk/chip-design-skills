3. **'D2여도 VGS = 0 누설점 출발을 피함'은 nfet에서 틀림**: nfet gm/ID는 VGS에 단조 감소라 최대점이 늘 VGS = 0(7380/7380 -- M-J1 §1 '정점 = VGS 0 격자점 = 아래 끝 0/59'와 같음). 속도 행이 없는 소자(gbw 미선언 4회로)에서는 (라)·(가)·D1·D2 모두 nfet 출발이 VGS = 0(작은 동률 폭) 근처 약반전 누설 영역이다. pfet도 동률 이동 뒤 ID가 1e-18~1e-12 A(5 µm)로 누설 영역이다. 그래서 (라)의 장점 칸 '누설점 출발 회피'는 사실 오류 -- '속도 행·전도 여유 행이 없으면 (라)도 누설 영역 출발'로 고쳐야 한다. (참고: 이 점의 전류 밀도로 1 µA를 흘리려면 W ≈ 5 µm × 1e-6/ID(5 µm) -- nfet 2.6e-15 A면 ~2 km급; 실제 출발은 design 41 §6.1-9 출발 사다리의 면적 실행 가능 탐색(칸 0 = 면적 ≤ 예산인 최대 t*)이 옮긴다 -- 이 사실도 (가)·(라) 공통 대가로 적을 것.)
4. **물리 결정자 범위 누락**: '전력 ∝ ID = gm/(gm/ID)이므로 gm/ID 최대 = 전력 최소'는 gm 요구가 정해진 **S**(M-J1 52/115)에만 성립한다. **F**(캐스코드·pass·follower, 63/115)는 전류가 가지(다른 소자)로 정해지므로 gm/ID 최대 = 같은 ID에서 gm 최대·VDSAT 최소·W 최대이고, 전력 논거가 아니다. F에 대한 물리 근거(또는 F는 다른 규칙)를 따로 적어야 한다(O-171).
5. **바뀌는 문언 누락**: design 41 §6.1-9 출발 사다리는 't = 1 = 7의 선택 끝(아래 끝), t = 0 = 반대 끝'의 누적 길이 매개화이고 칸 0은 '실행 가능한 최대 t*'를 `bracket_root`로 찾는다. (라)는 선택점을 S_d **안쪽**(argmax)으로 옮기므로 사다리 매개화(어느 끝 쪽으로 물러나는지, 면적 실행 가능 방향 = ln IDu 큰 쪽)가 함께 바뀐다 -- '바뀌는 결정·문언'에 §6.1-9를 넣어야 한다(design 몫이라도 영향 범위로).
6. **대칭(편향)**: (가)에는 '⚠ 원칙 23·24(열린 U-124 한쪽 선확정)'를 붙였는데, (라)의 동률 방향 'ln IDu 큰 쪽 = 면적 최소'는 U-124의 한 선택지(면적 최소)와 같은 방향이다. U-124는 B 소자 결정이라 직접 선확정은 아니나, U-124가 '위치 최대'로 정해지면 같은 ln IDu 좌표에서 S·F 동률 방향과 B 방향이 반대가 된다 -- (라)에도 같은 무게로 적을 것('U-124 결과와 방향이 갈릴 수 있음').
- O-186 (A) 정합 자체는 맞다: (라)는 ln IDu 격자 위 순방향 조회 argmax라 역산·gm/ID 분지 규칙이 아니다(DEC-88 금지 대상 '가장 큰 VGS 해'와 다름). ln ID는 ID > 0 전 마디에서 VGS에 엄격 증가(아래 B36-M2 1, 위반 0)라 argmax 좌표는 하나로 정해진다.
- 정정 방향: (라)의 동률 정의를 '정의가 다른 둘째 양 -- 축·출처'로 명시하거나 동률 규칙 없이 '최대점 = 가장 왼쪽 argmax(수치 반올림이 정함)'의 대가를 그대로 적어 (나)와 합치고; 2·3·4·5·6을 표와 질문에 넣은 뒤 판정('조건부'의 조건에 '동률 폭 정의 결정' 추가) 재기재.

### B36-M2 (Major) -- K10 D1/D2: 기존 DEC-88 '반전 수준 하한(정점)' 제약 행 누락, 오케스트레이터 의견의 선택적 행 포함

1. **사실 누락 -- 이미 있는 규칙**: 계획 DEC-88(plan:287)은 같은 문단에 두 연속 부등식 행을 둔다 -- '**반전 수준 하한(정점)은 상태 의존이라 bounds가 아니라 연속 부등식 제약이다**'와 '봉인 9 전도 여유 … 탐색에서는 같은 조건을 동작점별 연속 부등식 제약 행으로 둔다'. design 40 §3.10.4(d40:1357, 사용자 승인 2026-10-12 P-7·U-69)가 그 행을 'c_m = (ln IDu_m − floor_m)/b_m ≥ 0, floor_m = 그 (L, VDS, VSB) 곡선의 gm/ID 정점의 ln IDu'로 정의한다. 즉 '정점 이상'(= D1의 아래 경계)은 승인된 기존 행이다. 후보의 '계획 원문은 '그 L bin LUT 정의역'뿐, D1·D2 어느 쪽도 정의하지 않는다'는 이 행을 빠뜨렸다.
2. **D1 = D2 ∩ (반전 수준 하한 행)**: LUT 실측(`v36/d2mono_out.txt`) -- nfet·pfet 모두 ID > 0인 마디(VDS > 0 전부; ID ≤ 0 마디 8820 = VDS = 0 단면)에서 GM ≤ 0 마디 0, ln ID 비증가 VGS 걸음 0. M-J1 D1 정의의 'ln ID 엄격 증가 첫 구간' 조건은 공허하고, D1 = {VGS ≥ 정점} = D2 ∩ 반전 수준 하한 행이다. 그러므로 질문의 실체는 '정의역 D1/D2'가 아니라 **'기존 DEC-88 반전 수준 하한 행을 S·F(θ = ln IDu, O-186 이후 쓰기·S·F·B 모두)의 S_d와 탐색에 적용하는가'**이다 -- 분류는 (i)로 둘 수 있으나(적용 범위 읽기), 이 사실을 질문 첫 줄에 넣어야 한다. D2를 고르면 기존 승인 행의 S_d 적용을 빼는 것이라 **원래 취지와 다름 후보**(DEC-88·U-69 P-7)로 표지해야 한다.
3. **오케스트레이터 의견의 선택 편향**: 의견 = 'D2 + 봉인 9 전도 여유 행을 S_d 행에 포함'. 같은 DEC-88 문장·같은 design §3.10.4가 정의한 두 행 가운데 전도 여유 행만 넣고 반전 수준 하한 행은 뺀다. 넣는 근거('탐색의 연속 부등식 행이므로 S_d 순방향 행에 든다')는 두 행에 똑같이 적용된다 -- 하나만 고르는 물리·원칙 근거가 없다. 대안표에 (D1 = 두 행 모두) / (D2 + 전도 여유 행만) / (D2 문자 그대로)를 대칭으로 두어야 한다.
4. **'O-186 목적과 정합'은 판별 근거가 아님**: O-186은 좌표(ln IDu 하나, gm/ID 비단조 구간 포함)를 정한 결정이고 정의역의 넓이를 정하지 않는다. 위 2의 실측대로 ln IDu는 D1·D2 모두에서 단일값 좌표다 -- D1도 O-186과 똑같이 정합. 의견의 근거로 쓰면 편향.
5. **'누설점 출발은 (라)와 전도 여유 행이 막음'의 물리 결함**:
   - (라)는 막지 못한다(B36-M1 3 -- nfet 최대점 VGS = 0, 7380/7380).
   - 전도 여유 행 경계는 ln(gm·tol_V/I_off) = 0, 즉 **tol_V(봉인 판정 해상도)에 따라 움직이는 점**이다(예시 tol_V 0.1·1 mV에서 nfet 첫 허용 VGS 중앙 0.225·0.150 V, gm/ID ≈ 29, ID(5 µm) 7.9e-13·8.8e-14 A; pfet ID 1e-17·9e-19 A -- tol_V 값은 예시이지 실측 셀값 아님, Q-T0 미결). 속도 행 없는 nfet은 (라)·D2에서 이 경계가 출발점이 되므로 출발이 판정 허용오차가 정한 약반전 깊은 곳에 놓인다 -- '물리적으로 의미 있는 출발'이라는 주장을 세우려면 이 사실을 대가로 적어야 한다(원칙 1·11).
   - D2의 아래 끝 VGS = 0은 물리 경계가 아니라 LUT 생성기의 VGS 훑기 시작점이다(ID > 0은 VGS < 0에서도 이어짐). 'D2 = ID > 0 전부'는 실제로 'SPICE 표본 정의역'(E-0 용어, plan:1363)이고, 행이 없으면 출발이 표본 경계에 붙는다 -- 질문에 명시.
   - D1 쪽의 물리 결함도 같이 적을 것(대칭): nfet 정점 = VGS = 0 격자점이라 D1도 속도 행 없는 nfet의 누설 출발을 막지 못한다(M-J1 §1 C·위 표); pfet 정점은 약반전 plateau에서 수치 반올림이 정한다(상대차 ≤ 1.3e-6, M-J1 §4.6) -- 기존 반전 수준 하한 행 자체가 pfet에서 잡음 위치라는 결함(행 정의 몫 -- design §3.10.4).
6. **적용 범위 누락**: 계획의 '그 L bin LUT 정의역' 세 자리(plan:303 ×3, 1891, LA-1 toy 1946)는 **이득 행 탐색 개방의 S 좌표 범위**이지 S_d의 정의가 아니다(S_d 정의 = design 41 §6 머리). D1/D2 결정은 탐색 개방 후보 범위까지 바꾸므로 그 영향(D2면 탐색 개방 후보가 누설 영역까지)을 적어야 한다. 또 '전도 여유 행을 S_d에 넣는가'는 후보 문서가 스스로 design 41 §6 몫(iii)이라 적었다 -- (i) 질문에 섞으려면 (iii)에서 (i)로 옮기는 이유를 적을 것.
- 정정 방향: 1·2를 '사실'에, 3의 대칭 대안표, 4 철회, 5의 물리 대가(양쪽), 6의 범위를 넣고 '원래 취지와 다름 후보(D2 = 기존 DEC-88 행 S_d 미적용)' 표지 뒤 상정. 권고는 대신 정하지 않는다.

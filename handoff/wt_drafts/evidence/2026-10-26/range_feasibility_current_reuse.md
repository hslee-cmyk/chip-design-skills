- 스크립트·출력: `wt/_scratch_rangefeas_cr/` (`lutlib.py`, `a1_endpoint.py`~`a7_bound.py`, `a*_out.txt`).
- 원문: Xie·Chen 2019, 로컬 `chip-design-skills/skills/analog-gmid-design/assets/library/sources/current_reuse_telescopic_ota__xie_chen_2019/source.pdf`(md `paper.md`). 웹 링크는 찾지 못했다(paper.md 5행 기록과 같음).
- 포화 판정 = spec `spice_check.saturation_rule` `vds_ge_vdsat`(VDS − VDSAT ≥ 0, 여유 0, VDSAT = BSIM `@m[vdsat]` = LUT VDSAT 열).

## 0. 판정

**성립(gm/ID ≥ X 강제)**. 확신도는 중상(포화 기준 결론) / 중(gm/ID 수치 경계, 가정 A1·A2에 의존)이다.

- 범위 끝 포화(출력 소자 VDS ≥ VDSAT)만 보면 출력 소자 gm/ID 하한은 nfet 약 2~11, pfet 약 5.6~10.8이다(L과 x = I_R/Iq에 따라, §2 표 1). 낮은 하한이다. 원문(p.4 gm/ID 17·19)이나 B81 봉인점(입력 15.5, 캐스코드 25)의 영역보다 아래이므로 다른 spec과 충돌하지 않는다.
- 실제로 더 묶는 조건은 범위 끝이 아니다. **정지점의 class-AB 부동쌍 헤드룸** `VSG15 + VGS16 ≤ 1.8 − VDSAT9`이다(§3, 표 3). sky130 pfet |VTH|가 0.8~1.0 V로 커서 생긴다. 범위 끝은 이 조건을 저항 감지 전류(I_R)만큼만 더 조인다. 증분은 x = 1에서 VSD9 −0.02~−0.05 V, x = 3에서 −0.06~−0.15 V다.
- 포화 기준 최대 Vod(CM 0.9 V 고정)는 정지점 출력 소자 gm/ID에 따라 달라진다.
  - gm/ID 10에서 약 1.42~1.49 V
  - gm/ID 15에서 약 1.55~1.59 V
  - 약반전 끝(BSIM vdsat 바닥 0.042~0.047 V)에서 **1.705~1.715 V**
  - 마지막 값은 BSIM 바닥에 기댄다(§5 표시). 이 값이 원문 3 dB 값 1.706 V(Table I p.1, Fig.10 p.10)와 거의 같은 것은 우연의 일치로 본다. 정의가 다르다.
- 원문 정의(3 dB 이득 저하)와의 차이(§4): 포화 기준으로는 ±1.2 V가 쉽게 성립한다. 그러나 VDS = VDSAT 지점에서 출력 소자 gds가 정지점의 3~300배다. 그래서 '포화'가 이득 유지를 뜻하지 않는다. 출력단 이득 추정만으로 보면 긴 L(≥ 0.5 µm)·gm/ID ≤ 15에서는 3 dB 기준 Vod가 ±1.2 V보다 작을 수 있다(추정, 확신도 낮음). 포화 기준이 원문보다 약한 기준이라는 뜻이다. 범위 끝 이득 유지는 static 오차 0.1 %(O-133, 계단 끝 Vod ±1.2 V, O-134 A3)가 따로 강제한다.

### 원래 취지와 다름(브리핑 전제)
브리핑은 "출력 노드에서 레일까지 telescopic cascode 적층"을 전제했다. 연결로 보면 출력 노드 Vop·Vom은 telescopic 1단 출력이 아니다. 2단 class-AB 공통 소스의 드레인이다.
- Vom: M15(pmos, S=vdd, G=Vg15)와 M16(nmos, S=gnd, G=Vop1)
- Vop: M25(pmos, G=Vg25)와 M26(nmos, G=Vom1)

그래서 출력 노드 적층은 레일당 소자 하나다. telescopic 적층은 1단 출력 Vop1·Vom1에 있고, 범위 끝에서 수십 mV만 움직인다(§3.2). 원문도 같은 구조다(Fig.1 p.2, Fig.3 p.3, Fig.7 p.7: 출력 M77/M86 id 20.45 µA, VSG 0.487 V, VGS 0.475 V, Vout 0.896 V).

## 1. 연결 해석과 노드 식

### 1.1 출력 노드(범위가 걸리는 곳)
- V_hi(Vom) = 1.8 − VDSAT(M15), V_lo(Vom) = VDSAT(M16). Vop도 M25·M26으로 같다.
- body effect: 출력 소자 4개는 source가 레일이다. 그래서 VSB = 0이다(**가정 A0**: topology에 bulk 핀이 없어 pmos bulk = vdd, nmos bulk = gnd로 둔다. LUT 규약 body = −VS/+VS와 같다).
- Vod = +1.2 V(Vop 1.5, Vom 0.3)에서 한계 소자는 M25(VSD 0.3)와 M16(VDS 0.3)이다. Vod = −1.2 V에서는 M15·M26이다. 대칭이라 네 소자 모두 같은 조건을 받는다. 반대쪽 소자는 VDS 1.5 V라 여유가 크다.
- DC 부하: Cf·Cs·CL·Cc는 DC 전류가 0이다. DC 전류가 흐르는 길은 R1(Vom–Voc)–R2(Voc–Vop)뿐이다. 범위 끝 전류는 I_R = Vod/(R1+R2)이다. M37a 게이트(Voc)는 DC 전류가 0이므로 I_R은 순수 차동 전류다(CM 전류 0).
  - KCL(Vom = 0.3): I16 = I15 + I_R. KCL(Vop = 1.5): I25 = I26 + I_R. 한계 소자(M16·M25)가 큰 쪽 전류를 나른다.

### 1.2 class-AB 전류 분배(k)
- KVL(연결에서 유도):
  - Vg15 = vdd − VSG11a − VSG11b + VSG9a, 그래서 VSG15 + VSG9a = VSG11a + VSG11b
  - Vop1 = VGS14a + VGS14b − VGS9b, 그래서 VGS16 + VGS9b = VGS14a + VGS14b
- KCL(Vg15): I9a + I9b = I8.
- **가정 A1**: M15/M9a, M16/M9b가 약반전 지수 법칙을 따르고, 정지점에서 둘이 대칭으로 나뉜다고 둔다. 그러면 Iq/I15 + Iq/I16 = 2(조화평균 = Iq)가 된다.
- I_R = x·Iq이면 큰 쪽 k_hi = (1 + x + √(1+x²))/2, 작은 쪽 k_lo = (1 − x + √(1+x²))/2이다.
  - x = 0: 1 / 1
  - x = 1: 1.707 / 0.707
  - x = 3: 3.58 / 0.58
- x의 범위:
  - R1·R2 θ 상자는 각각 [10 kΩ, 10 MΩ]이다(spec theta_bounds). 그래서 I_R ∈ [0.06 µA, 60 µA]다.
  - Iq는 θ다. 원문은 20.45 µA다(Fig.7(b) p.7).
  - 그래서 x는 대략 0(R 큼)~3(R 최소, Iq 원문)이다. Iq·R이 정해지기 전에는 x를 정할 수 없어서 표를 x별로 냈다.

### 1.3 1단(telescopic, current-reuse) 노드
- 연결: vdd–M6∥M7(Vx)–M1b(G=Vim)–M2b(G=Vbias2)–Vop1–M3b(G=Vbias3)–M4b(G=Vim)–Vy–M5–gnd.
- M1b·M4b는 게이트를 공유한다(입력 CM = Vcm).
- Vx = Vcm + VSG1(VSB = 1.8 − Vx), Vy = Vcm − VGS4(VSB = Vy). body 포함이다.
- Vop1 창: [Vy + VD3 + VD4, Vx − VD1 − VD2]. 꼬리 조건은 1.8 − Vx ≥ VD6, Vy ≥ VD5다.
- 핵심 KVL: **VSG1 + VGS4 ≤ 1.8 − VD5 − VD6**. 입력 CM과 상관이 없고 범위와도 상관이 없다.
- Vop1 = VGS16, Vom1 = VGS26(2단 게이트)이다. 범위 끝에서는 Vop1이 VGS16(k_lo, VDS 1.5)에서 VGS16(k_hi, VDS 0.3) 사이를 움직인다.

### 1.4 class-AB 부동쌍
VSD(M9a) = VDS(M9b) = Vg15 − Vop1 = **1.8 − VSG15 − VGS16 ≥ max(VDSAT9a, VDSAT9b)**이다. Vg25·Vom1 쪽도 같다.

- Vop1 이동(`a4_out.txt`, L16 0.5)

  - g16 20: [0.622, 0.631](x 0), [0.595, 0.703](x 3)

- 1단을 묶는 것은 정지점 KVL VSG1 + VGS4 ≤ 1.8 − VD5 − VD6이다. 예: 입력 pfet gm/ID 15(L 0.18·0.5)와 nmos 15 조합은 VSG1 + VGS4 = 1.61~1.77 V로 불성립이다. 입력 pfet은 VSG가 작은 쪽(약반전, gm/ID 약 18 이상, L 0.18에서 VSG 0.54 V)이어야 한다. B81 §3.2 관찰(입력 gm/ID 15.5 at VSG 0.64 V)과 방향이 같다. 다만 B81은 정합 확인에만 쓰고 근거로 쓰지 않았다.
- 원문 p.2 "1단 출력이 약 0.5 V라 아래쪽 NMOS 바이어스에 압박"이 이 Vop1 하한 조건이다. sky130에서는 VGS16이 0.56~0.86 V라 원문보다 여유가 있다.

- Vod_max(포화) = 2·(0.9 − max(VDS_e,n, VDS_e,p))이다. 두 소자 중 나쁜 쪽이 정한다.
- k > 1이면 표 1처럼 VDS_e가 커진다. 예: x = 3, g 15, L 0.5에서 Vod_max는 약 1.30~1.33 V다.
- 3 dB 추정식(`a3_gain3db.py`): A2 ∝ gm_e/(gds_e + gds_q,other). 다른 쪽 소자의 gds는 정지점 같은 종류 값으로 근사했다. R1+R2 부하와 1단 이득 변화는 뺐다. 그래서 **3 dB 열은 경향만 보인다**(확신도 낮음). 원문 Fig.10(p.10, 0.18 µm L 360 nm)은 ±1.2 V까지 이득이 거의 평탄하다(75.6 dB). 공정과 L이 달라 직접 비교할 수 없다.
- 결론
  - 포화 기준(우리 정의)으로 ±1.2 V는 성립한다. 포화 기준 최대 Vod는 gm/ID 최선에서 약 1.71 V다(BSIM 바닥에 기댐). 바닥에 기대지 않는 gm/ID 15 근처에서는 1.55~1.59 V다.
  - '포화 기준으로 ±1.2 V가 성립하지 않을 가능성'은 없다(L·k 전 범위에서 gm/ID ≥ 11.2이면 충분, 표 1).
  - 반대로 포화가 이득 유지를 보장하지 않는다. 범위 끝 이득 유지는 static 오차 0.1 %(β·A ≥ 66.4 dB 상당, O-133)가 계단 끝 Vod ±1.2 V에서 따로 판정해야 한다.

## 5. 약반전 BSIM vdsat 바닥에 기대는 결론 표시
- [바닥 의존] pfet VDSAT 바닥 0.0396~0.0465 V, nfet 0.0378~0.043 V(VDS 0.3, VS 0, `a1_out.txt`). 'Vod_max 1.705~1.715 V'와 표 1·4의 g ≥ 18 pfet 행은 이 바닥에 기댄다. 이 지점에서 gds는 정지점의 11~310배라 포화라는 말이 소신호 의미를 잃는다.
- [바닥 비의존] 판정 '성립'과 표 1의 하한(VDSAT = 0.3 V 근처, 중강반전)은 바닥과 무관하다.
- 표 3의 VD9 = 0.05 열은 M9를 약반전 바닥 근처로 둔 낙관값이다. 0.10 열(gm/ID 약 15)을 함께 냈다.

## 6. CMFB와 범위 끝
- 감지
  - Voc = (R2·Vom + R1·Vop)/(R1+R2) = CM + (Vod/2)·(R1 − R2)/(R1 + R2)이다.
  - R1 = R2이면 Vod와 상관없이 Voc = CM이다(선형 저항이라 감지 비선형이 없다).
  - **R1 ≠ R2이면** 범위 끝 CM 오차는 ΔCM = −0.6·(R1−R2)/(R1+R2) V다. 예: R1/R2 = 1.1이면 −29 mV다. 노드 범위가 [0.3, 1.5]에서 밀린다.
  - spec theta_bounds는 R1·R2를 따로 둔다. **사용자 확인 포인트 1**: R1 = R2 묶음이 있는지 확인이 필요하다.
- DC 동작점
  - M37a/b 게이트는 Voc = Voc_des = 0.9로 고정이고 Vod와 상관이 없다. 그래서 CMFB 증폭기 동작점은 범위 끝에서 변하지 않는다.
  - tail = 0.9 − VGS37(body)이다. L 0.5에서 g37 15이면 0.153 V, g37 20이면 0.217 V다. M38은 VDSAT38 ≤ tail이어야 한다(g38 ≈ 12 이상이면 충족).
  - Vcmfb 하한은 0.24~0.32 V이고, 실제 값은 1.8 − VSG36a ≈ 0.7~0.9 V라 여유가 있다(`a5_out.txt`).
- I_R은 순수 차동 전류다. 그래서 CMFB가 범위 끝에서 추가 CM 전류를 공급할 필요는 없다. CMFB는 class-AB 비선형으로 생기는 Vop1/Vom1 CM 이동(수십 mV, §3.2)만 흡수하면 된다.
- Voc_des = 0.9 V는 M39(vdd 다이오드)와 M40(pmos, G = D = gnd, S = Voc_des)의 비율로 정해진다.
  - **가정 A0**(M40 bulk = vdd)이면 VSB40 = 0.9 V다. 같은 L에서 W40/W39가 43(L 0.5)~70(L 1)이어야 한다.
  - CM 0.9 V의 정확도는 이 비율의 공정 민감도를 따른다. 범위 끝 노드 값(0.3/1.5)의 정확도도 같이 따라간다. 원문 p.3: "larger channel length … to reduce process variation".

## 7. 강제 gm/ID와 다른 spec의 충돌
- 정착 40 ns·0.1 %(O-134), GBW: 출력 소자 gm/ID가 높으면 같은 전류에서 gm2가 커진다. 비우성 극점에 유리하다. 충돌이 없다.
- 면적 4e-8 m²
  - 표 1 하한(≤ 11)은 충돌이 없다.
  - 표 3이 긴 L pfet에 약반전(g ≥ 18)을 강제하면 밀도가 0.01~0.2 A/m로 떨어진다. 그러면 Iq 20 µA에서 W가 0.1~2 mm가 되어 면적·Cgg2(비우성 극점)와 충돌한다.
  - 짧은 L pfet(0.15~0.25 µm, gm/ID 8~16, 밀도 약 1~3 A/m, W 약 10~20 µm)을 쓰면 피할 수 있다.
  - B81 §9.1(원문 전압 보존 점의 M25 W 0.80 m, 면적 20배)과 같은 방향이다. 정합 확인용이다.
- 이득(static 0.1 %): 짧은 L은 gds가 커서 A2가 작다. 범위 끝 이득 유지(§4)와 맞물린다. 실측하지 않았다.
- CMRR·PSRR·잡음: 이 분석 범위 밖이다(미측정).

## 8. 가정 목록
- A0: bulk = 레일(pmos vdd, nmos gnd). topology에 bulk 핀이 없다.
- A1: class-AB 분배 조화평균 관계(약반전 지수 법칙, 정지점 대칭 분배, M9 body 변화 무시). 중반전에서는 k가 달라진다. 표는 x별로 냈다.
- A2: 3 dB 추정의 A2 식(§4). 경향용이다.
- LUT는 tt 27 °C만이다. 코너(ss·ff)와 온도는 보지 않았다.

## 9. 사용자 확인 포인트
1. R1 = R2 묶음이 spec에 필요한가(§6). 묶지 않으면 범위 끝 CM이 (R1−R2)/(R1+R2)·0.6 V만큼 밀린다.
2. 브리핑 전제(출력 노드 = telescopic 적층)가 연결과 다르다(원래 취지와 다름 §0). 범위 끝 헤드룸 고리(R8)의 대상 소자는 M15·M16·M25·M26이고, 1단 6소자가 아니다.
3. '포화 = vds ≥ vdsat(여유 0)'은 원문 3 dB보다 약한 기준이다(§4). 범위 끝 이득 유지를 static 오차 판정(O-133)에 맡기는 것으로 충분한지 확인이 필요하다.
4. 실제 강제 조건(부동쌍 헤드룸, §3.1)은 범위가 아니라 정지점 KVL이다. 이 조건을 범위 성립의 일부로 볼지, 정지점 봉인 조건으로 볼지 결정이 필요하다. 엔진에서는 KVL 고리로 이미 다루는지 확인해야 한다(미확인).

## 1. topology 해석 (connectivity만)

| 소자 | 종류 | S | G | D |
|---|---|---|---|---|
| MP | p | vdd | vb1 | vb1 (다이오드) |
| M3 / M4 | p | vdd | vb1 | X / Y |
| M6 / M5 | p | X / Y | bias3 | out / Vg7 |
| M1 / M2 | n | tail | vin_n / vin_p | X / Y |
| M11 | n | gnd | vb2 | tail |
| MN | n | gnd | vb2 | vb2 (다이오드) |
| M9 | n | gnd | Vg9 | Vg9 (다이오드) |
| M10 | n | gnd | Vg9 | Vg10 |
| M7 | n | Vg9 | Vg7 | Vg7 (다이오드) |
| M8 | n | Vg10 | Vg7 | out |

- 출력 노드: `out` = M6.drain = M8.drain (+ CL 1 pF to gnd). 다른 소자 단자 없음. 단일 출력(single-ended). 확신도 높음.
- 입력 n쌍(M1/M2, 꼬리 M11)의 drain이 PMOS 전류원(M3/M4) drain 노드 X/Y에 붙고, 같은 노드에서 PMOS M6/M5 source가 이어진다
  -> 입력 전류가 X/Y에서 "접혀" 공통 게이트 PMOS(M6/M5, gate = 외부 bias3)로 간다 = folded cascode. 근거: 연결(M1.D = M3.D = M6.S = X),
  원문 p.34 그림의 M3-M6 가로선·M4-M5 가로선과 일치. 확신도 높음.
- 아래쪽 부하: M9(다이오드)·M10 미러 위에 M7(다이오드, source = Vg9)·M8(gate = Vg7) -- 다이오드를 쌓은 일반(자기 바이어스) cascode 전류 미러.
  M5 drain(Vg7)이 미러 입력, out이 미러 출력. low-voltage(wide-swing) 미러가 아님(별도 cascode bias 없음). 확신도 높음.
- 출력단 종류: 높은 임피던스 cascode 출력(공통 게이트 M6 위, cascode 미러 M8/M10 아래). follower 아님(VGS 항이 출력과 레일 사이 직렬 경로에
  "구동"으로 들어가지 않음 -- 단, 아래쪽 미러의 VGS10이 고정 바이어스 전압으로 들어감). 확신도 높음.
- 극성: vin_n 상승 -> M1 전류 증가 -> X에서 M6 전류 감소(M3 고정) -> out 하강 -> vin_n = 반전 입력. 이름과 일치.
- 되먹임·CM 제어: netlist에 되먹임 수동소자 없음, CMFB 없음(단일 출력이라 필요 없음). spec `feedback.elements = []`(PM은 β=1 루프 정의).
- 부하: CL 1 pF 뿐 -> 정상상태 DC 부하 전류 0. 출력 범위 끝 DC 계산에 부하 항 없음.

### 출력에서 레일까지 DC 직렬 경로

- 위(vdd <- out): out -> M6(S=X) -> M3(S=vdd). 포화 두 개 직렬. bias3는 외부 입력이라 X를 경계(VDD − VDsat3)까지 둘 수 있다.
  - M3 포화: VSD3 = VDD − VX >= VDsat3
  - M6 포화: VX − Vout >= VDsat6
  - -> **V_hi = VDD − VDsat3 − VDsat6** (VDsat 2개)
- 아래(out -> gnd): out -> M8(S=Vg10) -> M10(S=gnd). M10 gate = Vg9(다이오드 M9)이고 M8 gate = Vg7 = VGS9 + VGS7(다이오드 두 개 적층).
  균형에서 Vg10 ≈ Vg9 = VGS9. M8 포화: Vout − Vg10 >= VDsat8.
  - -> **V_lo = VGS10 + VDsat8** (= VTH + VDsat10쯤 + VDsat8: VGS 1개 + VDsat 1개, 일반 cascode 미러의 VTH 손해 하나)
  - M10은 VDS10 = VGS9 >= VDsat10이라 자동 포화.

### 출력 밖이지만 같은 포화 요구가 만드는 조건 (전 MOS 포화 규칙)

- M5 포화: Vg7 <= VY − VDsat5, VY 경계 = VDD − VDsat4 -> **VGS9 + VGS7 <= VDD − VDsat4 − VDsat5 (= V_hi와 같은 식)**.
  즉 다이오드 적층 미러 입력 전압 2·VGS_n이 위쪽 범위 끝 아래여야 한다. 균형(오프셋 0) 개루프 출력 = Vg7.
- 입력 ICMR(참고, spec에 icmr 제약 없음 -- `input_dc` pending SP-2): Vcm_min = VDsat11 + VGS1(VSB = Vtail), Vcm_max = VDD − VDsat3 + VTH1(> VDD -> 레일 제한).

## 2. 이론 스윙 식

- V_hi = VDD − VDsat(M3) − VDsat(M6; |VSB| = VDsat3)
- V_lo = VGS(M10; VSB = 0) + VDsat(M8; VSB = VGS10)
- 같은 단의 소자 짝(M3/M4, M5/M6, M7/M8, M9/M10)은 연결상 같은 전압을 받으므로 gm/ID를 위쪽 단(p: M3·M6) gm/ID_p, 아래쪽 미러(n: M7~M10) gm/ID_n 두 축으로 둔다.
- VDsat = LUT `VDSAT` 열(BSIM op vdsat, ngspice @m[vdsat]) -- spec `saturation_rule = vds_ge_vdsat`(여유 0)과 같은 양.
- 범위 끝은 DC 양(DEC-65·O-154). AC(이득·출력 저항)는 이 계산에 쓰지 않음.

## 4. 순환 위험과 "의미 있는 요구"의 논리

- 능력식 V_hi(θ) = VDD − VDsat3(θ) − VDsat6(θ)를 엔진이 고른 θ 그대로 요구로 쓰면 범위 끝 포화 고리는 정의상 늘 0 여유로 통과 -> 판정 무의미.
- 의미 있는 요구 = θ와 무관한 고정 숫자 [V_lo, V_hi]. 그 숫자가 (a) 실현 가능(어떤 θ에서 전 MOS 포화로 도달)하고 (b) 비자명(아무 θ나 통과하지 않음)해야 한다.
  - (a) 상한: 가장 약반전 쪽 능력 ≈ [0.62, 1.71](gm/ID 22). 다만 V_hi 쪽은 pfet vdsat 바닥 아티팩트라 물리 상한은 그보다 낮게 본다.
  - (b) 하한: 강반전 쪽에서는 범위가 없어진다(gm/ID 5에서 폭 < 0). 따라서 범위를 선언하면 R8 고리가 출력 적층(M3·M6·M8·M10)의 gm/ID를
    "선언 gm/ID 이상"으로 묶는 실질 제약이 된다 -> 비자명.
- 원문(p.34~38)은 레이아웃 예제로 폭(W)만 있고 전원·L·전류·응용·스윙 단서가 없다("Only Ws are shown", p.34). 응용과 연결할 근거 없음 -> 범위 값은
  원문 인용이 아니라 gm/ID 설계 의도에서 유도해야 한다.
- 같은 이유로 중심을 VDD/2(0.9 V)로 맞춘 대칭 범위는 부적절: 이 회로의 구조적 중심은 ≈1.2 V(위 VDsat 2개 대 아래 VGS+VDsat)이다.

## 5. 기존 spec과의 정합

- 레일: vdd 1.8, gnd 0 -> 위 식 그대로. 
- 부하: CL 1 pF(용량만) -> DC 범위 끝에 부하 전류 항 없음. 정합.
- icmr: spec에 icmr 제약 없음, `input_dc` pending SP-2. 단위 이득 버퍼로 쓰면 출력 = 입력이므로 실효 범위 = 출력 범위 ∩ ICMR이고, 같은 gm/ID에서 아래 끝이 거의 같다(3.5).
  SP-2 입력 DC를 정할 때 이 범위 안에 두는 것이 정합.
- swing_out_v: 이 spec에 없음 -> O-154 Q3 삭제 대상 없음.
- O-154 Q4: folded_cascode는 **'미선언'으로 이미 확정**됨. 아래 권고 A를 채택하면 그 결정을 바꾸는 것 -> **원래 결정과 다름(사용자 재결정 필요)**.
  미선언 유지 시 R8·R10 (i) 행 없음, 범위 끝 양 '정의 불능'(O-154 Q1).

## 6. 권고

**권고 A: 출력 절대 범위 [0.80, 1.60] V** (단일 출력이라 Vod·CM 없음)

- 유도: 출력 적층 gm/ID 15(p·n 같은 값, 중간 반전 약반전 쪽) 가정 -> L 1 µm에서 [0.797, 1.605] V. 끝을 0.05 V 격자로 안쪽 반올림(요구가 능력보다 엄격해지지 않게, 여유 3~5 mV).
  L 0.5~2 µm, VDS 0.15~0.9 V에서 [0.79~0.82, 1.60~1.61] -> gm/ID 15 설계가 통과 가능, gm/ID ≲ 14 출력 적층은 위반.
- 의미: 출력 적층 소자에 "gm/ID >= ~15" 설계 의도를 범위 끝 포화 고리로 강제. 3.4표에서 gm/ID_n = gm/ID_p = 15가 M5 조건도 만족(실현 가능).
- pfet vdsat 바닥 구간(gm/ID_p >= 18)에 기대지 않음.

## 7. 확신도

- 출력 노드·적층·출력단 종류 해석: **높음**(연결 명확, p.34 그림과 일치).
- 식(V_hi = VDD − VDsat3 − VDsat6, V_lo = VGS10 + VDsat8): **높음**(Vg10 = Vg9 균형 가정, 미러 불균형 시 Vg10이 조금 움직임).
- LUT 수치: **중상**(tt 27 °C 한 corner, VDS 조회점·L 선택 감도 ±0.03 V, 같은 단 소자 짝 같은 gm/ID 가정).
- 권고 값 A: **중간** -- gm/ID 15는 설계 의도 선택이지 회로에서 강제되는 값이 아니다.

## 8. 사용자 확인 포인트

1. O-154 Q4에서 folded_cascode는 '미선언'으로 확정됨. 이 제안(A)을 채택하면 그 결정을 바꾸는 것(원래 결정과 다름). 미선언 유지(D)도 선택지.
2. 설계 의도 gm/ID(출력 적층) 15를 받아들이는가? 12면 [0.88, 1.52], 18~20이면 [0.73, 1.70](⚠ pfet vdsat 바닥).
3. 위·아래 끝을 다른 gm/ID로 둘지(p·n 분리) -- 예: gm/ID_p 15·gm/ID_n 15가 아니라 n 쪽만 더 약반전 등. 3.4표 참조.
4. 쓰임이 단위 이득 버퍼면(SP-2 입력 DC와 함께) 실효 범위 = 출력 범위 ∩ ICMR. 아래 끝이 같은 gm/ID에서 거의 같음(3.5). ICMR을 따로 선언할지.
5. 범위 끝 포화 판정은 BSIM vdsat(여유 0, spec saturation_rule)으로 한다는 전제. 약반전 pfet vdsat 바닥(≈0.045 V)을 그대로 받을지.
6. 끝값 반올림 격자(0.05 V 안쪽)는 제안일 뿐 -- 원시값 [0.797, 1.605]를 그대로 쓸지.

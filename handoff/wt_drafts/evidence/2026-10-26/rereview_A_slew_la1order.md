**판독**
1. **R10 엔진 꼴 하한은 16/16 성립했다.** 여유는 3.3× 이상이다. 정확 꼴(max_창[I_cell − I_load] ≥ C_lower·SR)도 16/16 성립했다. 원 실측의 '대리 확인'이 직접 측정으로 바뀌었다. 표본 8점은 두 회로뿐이고 전부 front 0 점(B80)이라 spec 근처 점이 아니다(미확인 §8).
2. **'정확한 필요조건'에는 숨은 가정이 있다.**
   - 출력 노드 KCL은 C_lower·dV/dt = Σ I_cell − I_fight − I_load + I_inj(움직이는 단자 용량: Miller·되먹임 C, 신호 구동 소자의 Cgd)다.
   - R10은 I_inj를 버린다. 그래서 I_inj ≤ 0일 때만 필요조건이다.
   - ngcc에서 I_inj 최대가 **+0.18 µA**(양수, 계단 앞쪽)로 실측됐다. 이 점의 C_lower·SR의 약 9 %다.
   - 평균은 음수(부하 쪽)였고 여유가 커서 이번 표본에서는 위반이 없다.
   - 일반 물리로는 보장되지 않는다.
   - ⚠ 원칙 경고: P0 물리 정합 — R10 문언 '정확한 필요조건'은 I_inj ≤ 0 가정을 적지 않았다 — 이 실측 ngcc +0.18 µA, DEC-104 R10(GB 303행).
3. **부하 이중 계상(F-1)**
   - 원 넷리스트의 nmcnr·ngcc 출력에는 `Cp_CL`과 `Cp_LOAD_<out>`이 둘 다 있다.

     - 추종 0.71이라 O-151 T2 추종 판정 결과는 미측정이다.
   - ngcc는 M12 자기 용량이 지배해서 SR이 거의 그대로다(0.204 → 0.203).
4. **같은 이중 계상이 2026-10-23 60점 실측에도 있다**(`_scratch_srfb/ext/_scratch_audit_slew/spice/pts/*/…free.cir`에서 nmcnr·ngcc에 `Cp_LOAD_Vout` + `Cp_CL`. two_stage_ota·folded는 하나).

**그때 권고·답**: "따로 분류 (권고)". oracle 전용 제약의 FAIL은 '엔진 결함'과 따로 분류하고, U-76 (1)(5)에서 엔진 결함으로 세지 않는다.

**규칙 점검표**
- 1 대안표: 빠졌음. 결정 행·계획 S-2에 '오케스트레이터 기본안'으로만 남아 있다.
- 2: 해당.
- 3: 부분. '작성자≠검증자·기준 약화는 사용자 승인' 절차는 지켰다(사용자 답).
- 4: 지켰음(U-112 연결).
- 5: 계획 작성자 보강(S-2)을 옮겼다.
- 6: '판정 기준 완화'로 표시했다.

**다시 따진 대안표**

| 칸 | (가) 현행: oracle 전용 FAIL = 따로 분류, 엔진 결함 아님 | (나) 엔진 결함으로 셈 | (다) **(가) + R10 거짓 거부는 엔진 결함** |
|---|---|---|---|
| 물리 정합 | ○ 엔진이 재지 않는 양의 FAIL은 엔진 계산 오류가 아니다 | × 엔진이 슬루를 판정하지 않는데(O-122) 결함으로 세면 원인 귀속이 틀린다 | ○ O-143 이후 엔진은 R10 하한으로 슬루에 **관여**한다. 필요조건이 거짓 거부를 내면 그것은 엔진 계산 결함이다 |
| fail-closed(P1) | △ 회로 결과는 front에서 빠지고 기록(O-144 U-112)되므로 숨지 않는다. 그러나 엔진 쪽 위반 경로가 없다 | ○ | ○ |
| 단순성 | ○ | ○ | △ 거부 점 표본 oracle 측정 하나 |
| 실측 | -- | -- | 이번 16/16 성립(거짓 거부 0)이지만 표본이 spec 근처 점이 아니다 |
| 원칙 | ⚠ 원칙 경고: 작성자≠검증자 — O-143으로 엔진이 슬루에 관여하게 됐는데 그 관여의 오류를 세는 자리가 없다 — 계획 297행 (6)(i)·303행 R10 | 결함 귀속 오류 | ○ |

**판정: 유지 + 보완**(확신도 중).
- 이후 결정(O-143)이 이 결정의 전제('엔진이 슬루를 재지 않는다')를 일부 바꿨다.
- 새 권고 문언: "(i) 엔진이 재지 않는 oracle 전용 제약(슬루·정착)의 oracle FAIL은 엔진 결함과 따로 분류한다. 단 DEC-104 R10 하한이 거부한 점이 oracle에서 그 제약을 통과하면(거짓 거부) 엔진 결함으로 센다. 측정은 SB-1 완료 조건(거부 점 표본)이다."
- 판정 기준을 더하는 것이므로 사용자 결정이 필요하다.
- 정착(O-145 settle_s)도 같은 'oracle 전용' 분류에 든다. 엔진의 O-139 대역폭 하한은 '추정'·판정 아님이라 거짓 거부 경로가 없다. 문언에 함께 적는다.

- **해법 = LA-1: 유지**(확신도 상).

  - O-153(as-built 근거 제외) 대조: 옛 권고 근거는 '계획에 있으나 미구현'과 실측이었다. as-built 보존 논리는 쓰지 않았다. 영향 없음.
- **완료 조건 9: 유지 + 위험 문언 보충**(기본안, 사용자 결정 불요).
  - (a) 'ss 선언 library 회로마다 front ≥ 1'은 엔진 결함 판정 신호로 타당하다.
  - 그러나 이후 O-140·O-143이 folded(gain 70 dB·PM 70°·GBW 10 MHz)·common_gate spec을 LA-1 범위 안에 넣었다. 그래서 spec 자체가 sky130에서 실현 불가하면 front 0이 정답일 수 있다(O-133 current_reuse '불가면 fail-closed'와 같은 꼴).
  - 보충 문언: "(a) 미달 회로는 통과로 세지 않고, spec 실현 불가의 독립 근거(oracle·손계산 상한)가 있으면 card를 멈추고 사용자에게 보고한다(기준 약화 아님)."
  - P1 fail-closed와 작성자≠검증자에 맞는다.
- **순서 'IT-2c 바로 뒤'**: O-126으로 대체됐다(아래).
- **F-1 연결**: LA-1 범위 14의 common_gate C_L 1 pF 추가는 연결 넷에 따라 공식 어댑터의 `LOAD_<out>` 이중 계상 갈래를 탈 수 있다. data 커밋 때 확인하도록 기록을 권한다.

## 8. 미확인

- §0 표본은 2회로·8점이고 모두 front 0 출발점(B80)이다. spec 근처 점, R10 하한이 실제로 출발 전류를 올리는 점에서는 재지 않았다.
- R9 LUT 조회 대신 같은 모델 SPICE DC로 대리했다. LUT 대 BSIM 모형 차(0.3~1.5×, `slew_estimate_vs_bound.md` §1)는 이번 여유(3.3× 이상) 안이지만 직접 확인하지 않았다.
- 선언 출력 범위 계단(§1 새 권고)으로 nmcnr·ngcc SR을 다시 재지 않았다. 판정값이 바뀌는 크기는 미측정이다.
- F-1: 공식 `legacy_adapter.convert` 단독 실행으로 nmcnr 이중 부하를 재현하지 않았다(코드 판독만). 2026-10-26 U-112 되먹임 사례(nmcnr (다) M302 정체 0.27 V/µs)가 단일 부하에서 수렴하는지 미측정이다. '되먹임 없음' 결론의 P0·P2 근거(θ 둘째 생산자, 자기 부하)는 부하와 무관하게 남는다.
- nmcnr all×2 단일 부하 SR 0.364가 O-151 T2 추종 판정을 통과하는지(추종 0.71)는 V_final(DC 해)을 재지 않아 미확인이다.
- 양의 주입(+0.18 µA)의 기제(Miller Cm1·Cm2 대 신호 구동 소자 Cgd)를 나누지 않았다.

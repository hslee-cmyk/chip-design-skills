## 1. 정의 분석

### 1.1 R8 '범위 끝 헤드룸 고리'가 가리키는 상태 (계획 문언)
- GB 303 R8: "범위 끝 헤드룸 고리는 R5′와 같은 R-1′ 고리이고 평가점(**범위 끝 노드 전압과 그 상태의 소자 전류**)만 다르다(새 고리 집합 없음)".
  - 고정하는 것: 출력 노드 = 범위 끝 V.
  - '그 상태'가 어떤 구성의 어떤 입력 조건인지는 R8에 **적혀 있지 않다(모호)**.
- GB 303 R9 (같은 행): "작은 편차(**헤드룸·포화 여유·창 끝**)는 W·바이어스 고정 KCL 선형 감도 끝, 큰 편차(**방향별 피크 공급 능력**)는 같은 W에서 … LUT를 극단 단자 전압으로 조회".
  - 이 문장이 두 상태를 가른다. 헤드룸은 선형 감도 상태이고 과구동 상태가 아니다. I_cap은 극단(과구동) 상태다.
  - 따라서 R8 안의 두 반쪽은 서로 다른 상태다.
    - 헤드룸 고리 = 선형 상태
    - 전류 부등식 I_cap ≥ R_ss = DEC-65 과구동 상태
  - OP 449는 두 반쪽을 한 상태(과구동)로 합쳤다. 이것이 결함의 근원이다.
- GB 303 R2 (c) "DC 동작 범위"와 GB 637 N3.8 (2):
  - 출력 스윙(DC 동작 범위 보고 양) = "입력 공통모드를 동작점에 두고 차동 입력을 훑을 때 출력이 움직이는 범위", 소자 조건 = DC 범위 조건(O-54).
  - 요구(선언 범위) ⊆ 능력(R2 (c))이 R1·R2 틀의 판정이다. 능력의 정의 문장이 바로 (A)다.
- 엔진 손계산 상태: KCL 선형 감도는 전달 뷰 여기 입력 한 포트에 단위 전압을 주고 나머지 입력을 고정해 푼다(`_scratch_srfb/scripts/pts.py` `vx = nodal_solve(..., {non: 1})`, 엔진 `nodal_solve` 사용).
  - 출력이 범위 끝으로 가도 차동 입력은 V_out/A(µV~mV)만 움직인다. 그래서 입력 CM은 사실상 고정이다. 엔진 상태는 (A)(와 as-built servo A2)와 같은 족이다.
  - R8 블록 자체는 아직 구현되지 않았다(DE-1·SB-1 미병합). 이 판정은 계획 문언과 감도 계산 꼴에서 나온 것이다.

### 1.2 DEC-100 응용 망, β = 1 측정 구성과의 관계
- DEC-100 (2): 모든 해석은 DUT ⊕ 측정 구성별 응용 망이다. 그래서 (A)에도 응용 망의 DC 원소를 넣었다(nmcnr RL 25 kΩ → agnd).
- N3.8은 출력 조건이 다른 세 양을 나눈다(graph 규칙 3 축 = '측정 중 출력의 조건').
  - (1) ICMR(servo)
  - (2) 출력 스윙(입력 CM 고정) = (A)
  - (3) follower 사용 범위(β = 1 또는 선언 구성, 출력이 입력을 따라감) = (B)
- (B)는 N3.8 (3)과 같은 상태다. 정의는 oracle `.dc`이고, 엔진 칸은 0이다(응용 양, 소비자 = 슬루 계단).

### 1.3 B87(출력 범위 ∩ ICMR, β = 1)이 판정 정의에 들어가야 하나
- 실측(§2.2 P3): 결합 효과는 실재한다. (A) PASS, (B) FAIL인 봉인점이 있다.
- 그러나 그것은 **amp 사양(출력 스윙)이 아니라 응용 양(follower 사용 범위)**이다. 헤드룸 요구 판정(A)에 넣으면 축 둘(스윙·ICMR)이 한 판정에 섞인다(graph 규칙 3).
- 결합이 요구가 되는 곳은 원문 측정이 β = 1로 계단을 거는 회로(nmcnr·ngcc)의 과도 측정이다. 그래서 들어갈 자리는 범위 판정 정의가 아니라 **과도 측정 유효성 조건**(§5)이다. 엔진 쪽 반영(B87)은 backlog 그대로 둔다.

### 2.3 (D) 거짓 FAIL 기제 (실측)
- DEC-65 구성은 출력을 고정하고 입력을 끝까지 민다. 출력을 고정하면 되먹임이 아무것도 하지 못한다. 그래서 과구동 Δ는 그대로 입력쌍을 조향한다.
  - |Δ|가 입력쌍 조향 폭(수~수십 mV)을 넘으면 한쪽 입력 소자가 꺼진다(DEC-90 꺼짐 = FAIL).
  - 내부 고임피던스 노드(1단 출력)는 레일로 간다(포화 이탈).
- 깨지는 Δ:

| 회로 | 깨지는 Δ |
|---|---|
| ngcc | +2 mV / −10 mV |
| current_reuse | ±8 mV |
| nmcnr | −28 mV / +120 mV |

  이 값들은 범위 끝과 무관하게 같다. 그래서 (D)는 '범위 끝에서 헤드룸이 있는가'가 아니라 '과구동에서도 선형인가'를 잰다. 그것은 정의상 불가능한 요구다. 출력이 묶이지 않은 증폭기는 과구동에서 선형일 수 없다.
- P3에서는 Δ = 0에서도 FAIL이다. follower 망이 입력 CM을 V_end로 끌어 B87 결합까지 들어가기 때문이다.

## 4. I_cap ≥ R_ss의 oracle 정확값

- **정의와 같은 구성**: DEC-65(GB 264)·R2 (b) 그대로다. 출력 포트를 범위 끝 V에 고정하고, DUT ⊕ 응용 망에서 여기 입력을 허용 범위 끝까지 민다. 즉 (D)의 **구성**이다. 이 상태에서 재는 것은 **순 전류뿐**이다. 포화는 이 양의 조건이 아니다(R9 큰 편차, LUT 극단 단자 전압 조회).
- **현재 oracle 행**: 없다.
  - `grep -c "I_cap|공급 능력|R_ss"`: OP plan 0, OP design 0
  - `tools/spice_oracle/*.py`: 0
  - OP 449 행은 전류를 재지 않는다.
- **실측**(D 구성, 입력 = 레일 끝):

| pid | 끝 | 방향 | DUT가 노드로 내는 전류 I_dut | 고정 원천 순 전류(DEC-65 문언, RL 포함) | R_ss(응용 망 RL 25 kΩ → agnd 0.9 V) |
|---|---|---|---|---|---|
| P1 | 1.15 V | 공급 | **12.47 µA**(M302 바이어스 구동 class-A, Δ와 무관) | 2.47 µA | 10.0 µA |
| P2 | 1.15 | 공급 | 24.95 µA | 14.95 µA | 10.0 µA |
| P3 | 1.15 | 공급 | 2.48 mA | 2.47 mA | 10.0 µA |
| P1 | 0.65 | 흡수 | 311 µA | 301 µA | 10.0 µA |
| P4 / P5 | 0.54 / 0.14 | 공급 / 흡수 | 94 µA·257 µA / 6.4 mA·6.0 mA | 같음 | 0(용량 부하뿐) |
| P6 | Vod ±1.2 | -- | 비물리적 값(27.8 A -- 이 봉인점 M15·M25 W ≈ 0.8 m) | -- | 0(R1·R2는 DUT 원소, 응용 망 DC 부하 없음) |

- **⚠ 정의 결함(실측으로 드러남)**: DEC-65 문언 "DUT ⊕ 응용 망 DC 해에서 p를 V에 고정하는 원천이 내보내는 순 전류"는 RL이 붙은 채 잰 값이다. 그래서 그 값은 이미 I_dut − R_ss다. 여기에 다시 'I_cap ≥ R_ss'를 걸면 부하를 두 번 센다.
  - P1 공급 끝: I_dut 12.47 ≥ 10.0으로 PASS다. 그러나 문언대로 읽으면 2.47 < 10.0으로 FAIL이다.
  - 같은 물리에서 판정이 갈린다. 정정 문언은 둘 중 하나다(값 불변).
    - (i) 'I_cap = DUT 단자 전류(그 노드의 응용 망 원소 전류 제외)'
    - (ii) 판정을 '원천 순 전류 ≥ 0'으로 둔다
- **'허용 입력 범위 끝'은 정의되지 않는다**(spec `input_dc` pending SP-2, 선언 입력 범위 없음). 이번 실측은 레일을 썼다.
  - 바이어스 구동 셀(P1 공급)은 Δ와 무관하다.
  - 신호 구동 셀(P1 흡수 311 µA, P3 4.79 A)은 Δ에 크게 의존한다. 봉인점 W가 비물리적으로 크면 값도 비물리적이다.

## 5. (E)·(F)와 DC/AC 분리

### 5.1 (E) 이득 기준 (실측, `e_summary.txt`)

| pid | 동작점 이득 | 범위 끝 이득(하/상) | 3 dB 창(A 상태, 기준 = 동작점) | 포화 창(A) | 3 dB 창(B 상태, 기준 = 범위 중심) |
|---|---|---|---|---|---|
| P1 | 28.4 dB | 28.8 / **18.0** | [0.34, **1.05**] FAIL | [0.35, 1.19] PASS | [0.18, 1.00] FAIL |
| P2 | 31.3 | 31.1 / 28.6 | [0.34, 1.16] PASS(여유 12 mV) | [0.24, 1.36] | [0.17, 1.04] FAIL |
| P3 | 43.2 | 43.0 / 44.1 | [0.17, 1.72] PASS | [0.06, 1.75] | 잠금 상실(B 상태 이득 −36 dB) |

| P6 | 74.09 dB (Vod 0) | 73.26 / 73.26 (−0.83 dB) | Vod [−1.52, 1.52] PASS | [−1.71, 1.71] | = A |

- 포화보다 강하다.
  - 포화 경계에서 이득은 3 dB를 훨씬 넘게 떨어져 있다. P6 Vod 1.7 V에서 약 57 dB, 동작점보다 17 dB 낮다. P1 1.19 V 부근에서는 이득이 0 dB 아래다.
  - 3 dB 창은 포화 창보다 끝마다 0.1~0.2 V 좁다.
  - P1은 포화로 PASS, 3 dB로 FAIL이다.
- gain spec 임계(nmcnr 100, ngcc 111 dB)는 이번 봉인점이 동작점에서도 못 미친다(28~44 dB). 그래서 범위 판정을 판별할 수 없다. 봉인점은 KVL·포화 봉인점이지 spec 실현점이 아니다(미확인 항목).
- ⚠ 단일 출력의 3 dB 기준점은 정의되지 않는다. P5에서 기준이 동작점(33.5)이냐 최대(43.1)냐에 따라 판정이 바뀐다. current_reuse 원문은 차동 Vod = 0(대칭 중심)이라 정의된다.
- current_reuse static 오차 0.1 %(O-133)는 범위 끝 증분 이득을 강제하지 **않는다**(실측, `postproc.txt`).
  - β = 0.5 DC 닫힘에서 Vod −1.2: 0.078 %, +1.2: 0.003 %, +1.7(이득 −17 dB 지점): 0.023 %
  - static 오차는 할선(평균) 이득과 계통 offset이 정한다.
  - '범위 끝 이득은 static 오차가 따로 강제한다'(range_feasibility_current_reuse.md §0)는 이 봉인점에서 성립하지 않는다.
- **DC/AC 분리 판정**
  - 증분 DC 이득(`.dc` 기울기)과 1 mHz `.ac`는 같은 양이다(P1 28.4 대 28.4~28.9 dB). 각 DC 점에서의 소신호 양이다.
  - gain spec은 동작점 AC 양이다(GB N3.8 metric).
  - 범위 끝 이득 요구를 새로 두는 것은 **원래 취지와 다름**이다. 동작점 한 점의 요구가 범위 전체 요구로 바뀌기 때문이다.
  - 예외는 current_reuse다. 원문 Table I swing의 정의 자체가 3 dB 저하이므로, 원문 정의 충실성을 고르면 E(3 dB, Vod = 0 기준)가 원문 정의와 같다. 사용자 결정이다.

### 5.2 (F) 범위 미선언 안 -- 정의상 판정
- nmcnr 원문:
  - Leung 1999 Table 1 p.602 "measured at unity-feedback configuration with 0.5V step input"
  - Fig. 6 p.602
  - 출력 범위 spec 문장은 없다(output_range_candidates.md §).
- ngcc 원문: Lee 2007 Fig. 5 p.25 계단 0.14 → 0.54 V. 출력 범위 spec은 없다.
- 두 회로의 범위 값은 정착 계단(O-145)과 **같은 숫자**다. 따라서 정의상 '출력 범위 요구'가 아니라 '과도 측정 조건(계단이 선형 영역 안)'이다. ⚠ 지금 계획에서는 같은 값이 출력 범위(O-154 Q4)와 정착 계단(O-145) 두 자리에 선언된다(graph 규칙 1 -- 한쪽이 다른 쪽을 참조해야 함).
- current_reuse는 원문 Table I에 'Output swing Specs [−1.2 V, 1.2 V]'가 있다. 그래서 요구가 맞다(정의는 3 dB).
- **판정 자리**: 지금 추종 판정(GB 638, O-151 T2)은 20 %·80 % 수준과 V_final을 '같은 구성 계단 앞·뒤 입력의 DC 해'로 정한다. 그래서 follower가 계단 끝에서 DC로 잘려도 기준이 같이 잘린다. 잘림을 **잡지 못한다**(정의상).
  - 정착 오차도 '실제 최종값 = 같은 구성 DC 해'(O-134 A1) 기준이라 마찬가지다.
  - 그러므로 nmcnr·ngcc 범위를 미선언으로 두고 보고만 하면 fail-open이 된다(P3처럼 follower가 0.81 V에서 잠금을 잃는 설계가 정착 PASS를 받을 수 있다).
  - 필요한 것은 과도 측정 유효성 조건이다. '계단의 입력 구간 ⊆ 같은 측정 구성의 follower 사용 범위(N3.8 (3), 기존 정의·oracle 이름 `follower_input_range_v`)'. 이것이 (B)다.
- 사용자 질문 "출력범위를 선언하는게 맞아? gain에 맞춰서 결정되는 양 아니야?"에 대한 답:
  - 출력 스윙 **능력**은 결과 양이다. gm/ID·VDSAT와 이득-스윙 교환이 정한다. 이것은 맞다(보고 양, R2 (c)).
  - 그러나 **요구**는 응용이 거는 신호 진폭이다. 원문이 spec으로 낸 회로(current_reuse)만 요구가 정당하다.
  - nmcnr·ngcc의 값은 측정 계단 조건이고, 그 물리 요구(계단이 선형 영역 안)는 과도 측정 유효성으로 강제하는 것이 정의에 맞다.
  - 엔진 R8 헤드룸 고리는 어느 쪽이든 같은 숫자(계단 끝)를 범위 끝으로 써서 탐색을 민다. 그래서 숫자의 이름(범위 대 계단)이 바뀌어도 엔진 동작은 같다. 선언 자리 하나만 고르면 된다.

## 6. 권고

### 6.1 원칙으로 정해지는 기본안
1. **헤드룸 판정 = (A)**: OP 449 정의 칸을 다음으로 바꾼다. "출력 범위를 선언한 회로만: OP 448 swing measure(N3.8 (2) 상태 -- 입력 공통모드 고정, 여기 방향 입력, DUT ⊕ 응용 망 DC 원소 포함)의 DEC-90 영역 유지 구간(포화 + 꺼짐 없음)이 선언 범위 양 끝을 포함하는지로 판정한다. 범위 끝 노드 전압은 EO-1 입력으로 받는다." measure는 하나다.
   - 근거: R9의 작은/큰 편차 분류, R2 (c)·N3.8 (2) 정의, 실측(D 5/5 거짓 FAIL, A는 엔진 감도 상태와 같은 족).
   - 확신도 중상. R8 문언의 '그 상태'가 모호한 점은 R8에 "(헤드룸 = R9 작은 편차 상태, 전류 = DEC-65 상태)"를 덧붙여 닫는다.
2. **as-built servo(A2)는 정의가 아니다**: 창 끝 차는 ≤ 8 mV지만 입력 CM이 39 mV 움직인다. 정의대로 CM 고정 vd servo로 다시 쓴다(OP 448 '바뀌는 것' 칸 그대로). 실측 차가 작아 우선순위는 낮다.
3. **(D) 포화 판정 삭제, DEC-65 구성은 I_cap 전류 measure로만**: 새 oracle 행 'I_cap,d(V_end)'(출력 범위 선언 회로만)를 둔다. 판정은 I_cap ≥ R_ss다(R8 전류 부등식의 정확값). 포화 판정은 없다.
4. **DEC-65 문언 정정**(값 불변, 부하 이중 계산 제거): 'I_cap = 그 상태에서 DUT가 포트 p로 내는 순 전류(포트의 응용 망 원소 전류 제외)'. 또는 판정을 '고정 원천 순 전류 ≥ 0'으로 둔다. 둘 중 하나로 같은 물리다.
5. **(C)는 채택하지 않는다**(A의 부분집합이고, 안쪽 위반을 fail-open으로 놓침).
6. **B87은 범위 판정 정의에 넣지 않는다**(축이 다름). 엔진 쪽은 backlog 유지다.

  - (가) 출력 범위로 두고 정착 계단이 참조한다.
  - (나) 정착 계단으로 두고 엔진 R8 범위 끝은 계단 끝을 읽는다.
  - 지금은 두 자리 선언이다(⚠ graph 규칙 1).
- **U-c**: current_reuse swing 판정 정의를 정한다.
  - (가) 포화 기준 (A)(현 계획 축): 실측 ±1.71 V
  - (나) 원문 정의 3 dB 저하(E, Vod = 0 기준): 실측 ±1.52 V. 원문 정의 충실이고, 범위 끝 이득 요구가 새로 생긴다(원래 취지와 다름, DC/AC 축 혼합 -- AC 판정을 DC 범위 요구에 씀)
  - 권고는 (가)다. 엔진 R8은 포화 고리이고, 이득은 L bin·static 오차가 맡는 구조와 맞는다. 다만 static 오차가 범위 끝 이득을 강제하지 않는다는 실측(§5.1)을 함께 올린다.
- **U-d**: I_cap '허용 입력 범위 끝'의 정의. 선언 입력 범위가 없고(SP-2), 신호 구동 셀은 값이 Δ에 크게 의존한다.
  - 기본 후보: 레일(물리 한계, 상수 0)
  - 대안: 측정 구성의 follower 사용 범위 끝

## 7. 미확인 항목
- 봉인점 중 gain spec을 만족하는 점이 없다(28~44 dB 대 100·111 dB). 그래서 (E) spec 임계는 판별하지 못했다. spec 실현점에서 다시 재야 한다.
- 꺼짐 판정은 10⁻³ × 봉인 ID 근사이고, DEC-90 ε = (gm/ID)·tol_V 식이 아니다. current_reuse D의 꺼짐 목록은 기준 ID를 개루프 레일 점에서 잡아 신뢰할 수 없다. 그래서 포화 이탈 Δ(±8 mV)만 썼다.
- current_reuse (B)는 실제 용량 되먹임 `.tran`이 아니라 N3.8 DC 닫힘(β = 0.5, Cin 무시)이다. Cc 값이 넷리스트에 없어 과도 안정 벤치를 만들지 않았다.
- (C)의 안쪽 위반(비단조 경계)은 표본에 없어 실측하지 못했다.
- current_reuse 예산 2000 봉인점은 θ 기록이 없어 쓰지 못했다(V-B 원문 전압 보존 봉인점으로 대체).
- 엔진 R8 블록은 미구현이다. '손계산 일치'는 계획 문언과 엔진 감도 계산 꼴(`nodal_solve` 여기 입력)로 판단했다.
- §5.2 '추종 판정이 DC 잘림을 못 잡는다'는 문언 분석이다. P3 같은 점의 `.tran` 실측은 하지 않았다.
- 봉인점 W가 비물리적으로 큰 점(P3 출력 흡수 4.79 A, P6 27.8 A)은 I_cap 값의 크기만 비물리적이다. 판정 꼴에는 영향이 없다.

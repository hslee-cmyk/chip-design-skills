## 0. 판정

**성립(gm/ID ≥ X 강제)**. 확신도는 중상이다.

- 출력 끌어내림 NMOS 셋(M7·M13·M14) 각각에 하한이 걸린다.
  - 설계점(VDS 0.34~0.54 V)에서 정의한 gm/ID 기준으로 L 0.15~1.0 µm에서 **약 10.7~12.7**, L ≥ 1.5 µm에서 **약 13.1~13.9**다.
  - 아래 끝에서 M7의 CLM 전류 손실(최대 약 20 %)을 M13·M14가 떠맡는 보수 경우에는 +0.5~0.9가 더 붙는다.
  - 이 하한은 LUT 범위(gm/ID 최대 약 27) 안이다. 중간 반전이고, 약반전 VDSAT 바닥(약 0.04 V)과도 멀다.
- 위 끝 0.54 V는 여유다. M12의 VSD는 1.26 V 이상이고, LUT 전 영역(VDSAT 최대 0.72 V)에서 포화한다. 따라서 gm/ID 강제가 없다.
- β=1 결합에서 입력 창은 [0.14, 0.54]를 담을 수 있다.
  - 아래 끝(0.14 V 입력)은 PMOS 입력쌍이라 모든 조합에서 여유가 있다. Vin_min은 −0.01 ~ −0.42 V로, 0.14보다 0.15 V 이상 아래다.
  - 위 끝은 입력쌍·꼬리 소자의 gm/ID 하한을 강제한다. 이 하한은 icmr_v ≥ 0.6의 정의에 따라 달라진다(§4).

## 1. 연결로 본 출력 노드 적층 (connectivity만)

- Vout에 붙은 소자:
  - M12 pmos: S=vdd, G=VBP. 바이어스 고정 전류원이다.
  - M13 nmos: S=gnd, G=V2.
  - M14 nmos: S=gnd, G=V1.
  - M7 nmos: S=gnd, G=NX.
  - Cm1(V1–Vout), Cm2(V2–Vout), CL(Vout–gnd).
- 모두 소자 하나짜리 적층이고 source가 레일이다. 따라서 VSB = 0이고, **출력 소자에는 body effect가 없다**.
- 식 (포화 규칙 vds_ge_vdsat, 여유 0):
  - V_hi = VDD − VDSAT12(VSG12; VSB = 0)
  - V_lo = max(VDSAT7(VGS = V_NX), VDSAT13(VGS = V2), VDSAT14(VGS = V1)), 각각 VDS = Vout일 때의 값
- 정상상태 KCL: I12 = I7 + I13 + I14. CL은 DC 전류가 없다(정상상태 부하 전류 0, 저항 부하 미선언).
  - 범위 끝에서 바뀌는 것은 CLM 효과뿐이다.
  - M7은 VGS가 NX에 고정되어 있다(NX = M6A 다이오드). 그래서 VDS가 0.14 V가 되면 전류만 준다. LUT로 보면 L 0.3~2 µm에서 VDS 0.54 대비 1/1.12 ~ 1/1.28이다.
  - 되먹임 루프는 M13·M14의 게이트(V2·V1)를 올려 줄어든 전류를 메운다. 그래서 M13·M14의 VDSAT이 아래 끝에서 커진다.
- 출력 범위가 바꾸는 다른 노드는 입력쌍 게이트다. β=1에서는 Vinn = Vout이다.
  - 연결로 확인한 부호: Vinp↑ → V1↓ → M14·(M8→NP↑→M10↓→V2↓→M13) 끌어내림 감소 → Vout↑. 따라서 Vinp가 비반전 입력이다.
  - 그 밖의 내부 노드(V1 = VGS14, V2 = VGS13, NX = VGS7, ND = VGS3, NP = VSG9)는 전류로 정해지고 Vout과 무관하다.

## 3. 위 끝 0.54 V -- M12 (pfet, VSD = 1.26, VS = 0)

- 모든 L에서 VSG ≤ 1.8 전 범위의 VDSAT 최대는 0.64~0.75 V로, 1.26보다 작다. **항상 포화하고 gm/ID 강제가 없다.**
- 원문 Fig. 5의 overshoot(약 0.56 V)도 여유가 크다.
- 위 끝에서 NMOS는 VDS 0.54 V로 여유가 크다.

## 4. β=1 결합 -- 입력 창이 [0.14, 0.54]를 담는가

식(연결로 유도, M1·M2 S = TAIL, M0 S = vdd, D = TAIL):
- Vin_min = VGS3 + VDSAT1 − VSG1. M1의 드레인은 ND이고, ND는 M3 다이오드라 VGS3과 같다.
- Vin_max: Vin_max + VSG1(Vin_max) = VDD − VDSAT0. 자기일치로 풀었다. 가정 bulk = vdd이면 VSB = VDD − TAIL이다.
- V1 결합: M2 포화는 V1 = VGS14 ≤ Vin + VSG2 − VDSAT2를 요구한다.

결과:
- **Vin_min**: M1 g1 12~20, L 0.5~1.5, M3 g3 8~15, L 0.5~1.5 전 조합에서 −0.01 ~ −0.42 V다. 0.14 V 입력은 항상 가능하다. PMOS 입력쌍에 NMOS 거울 부하라 아래 쪽이 레일 아래까지 열린다.
- **V1 결합**:
  - M14 gm/ID 8~20이면 V1 = 0.60~0.84 V다.
  - Vin = 0.14에서 V1 상한은 1.00~1.19 V(M2 g 12~20)다. 여유가 있다.
- **Vin_max** (bulk = vdd, M1 VSD = 0.3 가정, M0 L = 0.5):

- 표에 쓴 M0 VDSAT: g0 = 10이면 0.173, g0 = 20이면 0.045다. g0 = 20은 pfet 약반전 바닥(약 0.044)에 기댄 값이다. **⚠ 바닥 표시.**
- bulk = source로 가정해도(L = 0.3만 계산) 결과는 +0.04 V 정도만 다르다. 위 끝에서는 VSB가 0.1~0.2 V로 작기 때문이다.

판정:
- **[0.14, 0.54]를 담는 조건은 Vin_max ≥ 0.54다.**
  - g0 = 10 기준: L 0.3이면 g1 ≥ 약 12, L 0.5이면 약 13.5, L ≥ 1이면 약 15.5가 필요하다.
  - g0 = 20(바닥 의존) 기준: 모든 L에서 g1 ≥ 10이면 된다.
- **icmr_v ≥ 0.6과의 관계는 폭의 정의에 달렸다.**
  - (a) 창을 gnd에서 자르는 정의(폭 = Vin_max − max(Vin_min, 0))라면 Vin_max ≥ 0.6이 필요하다.
    - g0 = 10이면 g1 ≥ 약 15(L 0.3) ~ 17(L ≥ 0.5)이다.
    - g0 = 20이면 g1 ≥ 약 10~12다.
  - (b) 자르지 않는 정의라면 Vin_min이 음수(−0.1 ~ −0.4)라서 폭이 0.6을 쉽게 넘는다. 이때 binding 조건은 '담기'(Vin_max ≥ 0.54)뿐이다.
  - 엔진 정의는 servo(N3.8)다. 어느 쪽인지는 이 해석 범위 밖이라 확인하지 않았다(사용자 확인 포인트 2).
- 원문 대조(참고): 원문은 입력 VDSAT을 부하의 절반으로 둔다(p.23~24). 입력쌍 gm/ID를 높게 두는 방향이라 이 하한과 같은 방향이다.

## 5. 전류·W·면적 규모와 SR

- 가정: gm3 = 2.5 mS. 원문 Table 4(p.24)의 ω3·CL, k = 4 값이다. 설계 선택이지 spec이 아니다. 본 spec(GBW 10 MHz, PM 63.4°, CL 10 pF)에서 비우세 극 ω3 = gm3/CL을 정하는 같은 계열의 값이라 규모 추정에만 썼다.

- 표의 W는 W_ref 5 µm 기준 ID/W를 선형으로 늘린 값이다. 가정이다.
- **면적**:
  - MOS 출력 소자 셋을 합쳐도 수십~수백 µm²다.
  - MIM 커패시터(2 fF/µm²)는 Cm1 + Cm2 원문값 3 pF가 1500 µm², θ 상한 20 pF가 10000 µm²다.
  - spec 25000 µm² 대비 **충돌하지 않는다**. 원문 sum(W·L)은 255 µm²다(Table 5).
- **SR 6.3 V/µs (상승)**:
  - CL만으로 필요한 전류는 I12 ≥ 63 µA다(O-146 (b) C_lower = CL만).
  - 정지 전류는 I12 = I7 + I13 + I14 ≥ I13이다. gm3 = 2.5 mS이면 I13 = 2.5 mS / (gm/ID)이고, 이것이 63 µA 이상이려면 gm/ID ≤ 39.7이다. LUT 최대 27 안에서 항상 성립한다. **충돌하지 않는다.**
  - 하강 SR은 선언되지 않았다.

## 6. 강제 gm/ID와 다른 spec의 충돌 (DC와 AC를 분리해서 본다)

DC 결론은 §2~§5다. 아래는 같은 하한이 AC spec에 주는 압력이다. 정량 판정은 하지 않았다.

- **GBW·SR**: 하한을 올리면 전류가 줄어든다(I = gm/(gm/ID)). 같은 gm에서 SR 조건은 §5대로 충돌이 없다.
- **PM**:
  - gm/ID를 높이고 L을 길게 하면 V2 노드 Cgg(M13)가 커진다. L 0.5에서 170~220 fF, L 1에서 0.6~0.8 pF, L ≥ 1.5에서 1.3 pF 이상이다.
  - Cm2(원문 1.32 pF)와 비슷한 크기가 되면 기생 극점이 PM 63.4°를 압박한다.
  - 짧은 L(0.3~0.5)이면 압력이 작다. 이 점은 추론이고 정량 PM은 계산하지 않았다.
- **이득 111 dB**:
  - 같은 VGS에서 VDS가 0.14 V가 되면 NMOS의 gds/ID가 커진다. L 0.5에서 0.14 → 2.35, L 1에서 0.09 → 2.13으로 10~17배다.
  - 범위 아래 끝에서는 출력단 Rout이 약 1/10 이하로 떨어져 출력단 이득이 약 20 dB 이상 준다.
  - 이것은 AC 양이다. gain_ss_db의 평가점이 범위 끝인지(input_dc는 SP-2 대기)에 따라 충돌 여부가 갈린다. 하한 gm/ID 자체와는 무관하고, 아래 끝 VDS = 0.14라는 사실에서 나온다.

## 7. 가정 목록

1. 입력쌍 bulk = vdd. topology에 bulk가 없다. bulk = source 대안은 L = 0.3에서만 계산했고 차이는 약 +0.04 V였다.
2. W는 W_ref 5 µm 기준 선형 스케일이다. 폭 슬라이스로 보정하지 않았다.
3. LUT 보간은 VGS·VDS 37.5 mV 격자, VS 0.2 V 격자의 선형 보간이다. 경계 gm/ID 오차는 약 ±0.2로 본다.
4. M1 VSD = 0.3, M0 L = 0.5는 표 작성용 대표점이다.
5. gm3 = 2.5 mS는 원문 설계값이고 규모 추정에만 썼다.
6. k(CLM 전류 재분배)는 1.0~1.2 범위로 감쌌다. 정확한 분배는 루프 DC 해가 정한다.

## 8. 사용자 확인 포인트

1. 강제 하한을 엔진 θ 상자 하한(출력 끌어내림 NMOS gm/ID ≥ 약 12~14, L에 따라)으로 쓸지, 아니면 범위 끝 헤드룸 고리(R8)가 자동으로 거르게 둘지 결정이 필요하다.
2. icmr_v ≥ 0.6의 폭 정의가 gnd에서 자르는 방식인가? 자른다면 입력쌍 gm/ID ≥ 약 15~17(M0 g0 = 10)이 추가로 강제된다. 자르지 않으면 '담기' 조건만 남는다.
3. gain_ss_db 111 dB를 범위 끝에서도 요구하는가? 요구한다면 아래 끝(VDS = 0.14)에서 출력단 gds가 10배 이상 커지는 것과 충돌할 수 있다(AC, 미정량).
4. 입력쌍 bulk 연결을 선언해야 한다. 현재 topology에는 없다.

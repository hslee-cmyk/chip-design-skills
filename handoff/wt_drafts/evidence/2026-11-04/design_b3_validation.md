## 결론

묶음 ③은 지금 승인하면 안 된다. **이 판으로 WB-1 card를 쓸 수 없다.**

가장 큰 이유는 V1이다. 계획은 이 card의 design·구현에 Q-W1 권고안(탐색 평가·실현 평가)을 쓰라고 정했는데(P:1225 '구현 기본안', P:1410), D40:1186은 "이 design이 정하지 않는다"로 멈춰 있고 매 평가 재풀이를 규칙으로 적는다. OP-7 선언을 읽는 자리와 HC-S가 넘긴 `dc_sat_v` writer도 design에 없다. 나머지 Major는 문언 수준으로 닫힌다.

### V3. OP-7 선언 reader가 정해지지 않았고 D40:1202가 D16과 어긋난다

**어긋남**
1. **묶임**: D40:1202 '선언이 없거나 LUT 지문과 묶이지 않으면'. D16:1393은 'LUT 파일 sha256에는 묶이지 않는다', 세트마다 meta 모델 값 ⊆ 선언 + 판 일치. 문언대로 LUT 지문 대조를 짜면 세트 일부를 다시 만들 때 틀리게 거부한다.
2. **시점**: D40 = 적재 때. D16 = '경계 위 L이 거부'. 사유 이름 없음. 결정 후보 D2.
3. **LF·raw**: D16:1386 규칙 (ii)(엔진 쪽 구현 = WB-1)가 D40에 없다. 기록 값 raw만 있으면 ⊆가 거짓이 되어 적재가 막힌다.
4. **판 값**: 세트 meta `ngspice-46` 꼴 대 선언 `{name, version}`. 엔진 쪽 대응이 없다.
5. **등록 꼴**: `lut_v2_location.json` `files`에 넣으면 등록이 안 된다. 손 대입: `_file(root, ...)`는 LUT 폴더(저장소 밖) 기준이고 `..`를 금지하므로 `lut_location_file_missing`이다.
6. **지문 fail-open**: `lut_fingerprint`·표 캐시 키에 규칙이 없다. 손 대입: 같은 LUT에서 `rule` lower → upper면 지문이 같고 `lut`·`core` 소스 해시도 같다(선언은 `assets/`). 앵커 bin이 바뀌었는데 옛 tol 표가 적중한다.
7. **서명 없음**: `bin_index(intervals, x)`에 격자·방향 인자 자리가 없고, 호출부 넷의 입력이 정해지지 않았다.

**고칠 문언**(D40:1202 마지막 두 문장 대체)

> **bin 판정 함수**: `E/lut/_helpers_bins.py` `bin_index(intervals, x, grid_m, rule)`. 각 값을 `round(값/grid_m)`으로 정수화해 닫힌 구간끼리 비교하고, 품는 구간이 없으면 None(호출부 사유 그대로), 둘이면 `rule` = `"lower"`는 앞 구간, `"upper"`는 뒤 구간(D16 `lut_bin_rule/1`).
> **선언 읽기**: 정본 = `A/lut_v2_bin_rule.json` 하나(D16). 위치 선언에 `"bin_rule": {"path": "lut_v2_bin_rule.json", "sha256": <LF 값>}`을 최상위 키로 등록한다(`files` 밖, `path`는 설정 파일 폴더 기준, 대조 = LF 값 -- N3.4 규칙 (i), 저장소 텍스트라 checkout 줄끝에 갈리지 않음). `resolve_lut_location`이 대조해 `LutLocation.bin_rule_path`로 넘기고, `load_lut_set(..., bin_rule=경로)`가 읽는다. 등록 없음 = `lut_location_config_invalid`.

#### off 소자 잔차 → R1

**작성자 주장은 맞다.** w_m = 4.5 µm, 슬라이스 {2, 5}: w_s = 5 → m = 1, r = 5/4.5 − 1 = 0.111. w_s = 2 → x = 2.25, m = 2, r = |4/4.5 − 1| = 0.111. 동률이므로 큰 폭 (1, 5 µm)다.

**판단: 수치 근사가 아니라 정의 차이다. LA-1 재점검으로 미룰 수 없다.**
- D3대로면 엔진 ΔI_off = IDu_5·4.5/L, oracle = IDu_5·5/L이다. **모델이 완벽해도 항상 11 % 차**가 난다. 두 쪽이 다른 소자를 잰다.

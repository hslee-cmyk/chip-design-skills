**근거**: DEC-109, DEC-79 (a) 개정, N3.16 R11~R13, LY13 '행 구성 함수 하나'.

**범위**: (1) 행 구성 함수 하나(DEC-109 (2) -- 행 = 같은 kind·body 넷·w_f, 닫힌 식 외곽·배선 띠·riser) (2) floorplan 추정 블록(writer 하나, 층 = DC 블록 뒤·`ss` 앞, 추정 필드 -- 면적·넷별 대지 C·소자 gate R) (3) 소비자 배선(만들면 배선): `ss` MNA 스탬프(C·gate 직렬 R), oracle 넷리스트 생산자(EO-1 범위 1~3 -- 같은 C·R 수동소자), 탐색 면적 축(DEC-79 (a) -- 옛 Σ W·L 계산 자리 같은 변경에서 삭제, spec `area_search_m2` 제약은 새 축을 읽음 -- **기준 의미 변경 표지**: 회로별 예산값은 옛 Σ W·L 정의로 선언됐고 새 축은 배선 띠·dummy·tap을 더해 같은 점에서 값이 커지므로(강화 방향, 기준 약화 아님) 제약 통과가 바뀔 수 있다 -- 회로별 영향은 완료 조건 (6), 예산값 재선언은 사용자 spec 몫) (4) MOD7의 행 그룹 유도(as-built 기둥·matching 행 그룹 블록)를 같은 함수 호출로 바꾸고 옛 유도를 지운다(정의 하나 -- graph 규칙 3; MOD7 nf 재선택 삭제는 LY-1; **원래 취지와 다름**: LA-1 경로 밖 MOD7 변경을 LA-1 앞 card에 넣음(O-229 4 범위 확장 -- 근거 = 같은 정의의 둘째 자리를 남기지 않음), LA-1 자동 결정 기록 대상) (5) PDK 선언 R11~R13 항목(역할 이름, 출처 칸 -- O-197)과 로더; 미선언 = E-0 정지 (6) gate R 분포 환산 꼴의 원문 근거(쪽 + 로컬 PDF).

### N6.22 card AP-1 -- 응용 회로 별도 topology(O-73 2단계, **미래 card**)

**선행**: IT-1·IT-2 통합 병합, SD-1. **착수 조건**: 계획 개정 -- 응용 topology의 스키마와 그것을 DUT에 붙이는 writer 하나의 정본 자리가 지금 없다(graph 규칙 6, S-7). **범위**: 원문 또는 사용자가 선언한 응용 회로(부하·되먹임·입력 망·원천 포함, DEC-100 (6) 관례 추가 금지, DEC-101 (5) 공급 대응)를 측정 구성별로 둔다. 그때 정할 것: (a) O-68·O-69 합성 측정 구성(ICMR '차동 모드만 닫음', 슬루·ICMR β = 1 follower)을 선언된 응용 회로로 대체할지 (b) 이상 전류원 13개의 위치(DUT 바이어스 대 시험 원천 -- cnr `IDC` 등, `external_network_inventory_13.md` Q2) (c) current_reuse 슬루 입력 망(O-72 (4) 공동분석 백로그)과 폐루프 잡음 450 µV 정의(`cf_external_impact.md` A6)의 자리 (d) 용량 전용 노드(용량에만 닿는 노드)가 있는 측정 구성의 대신호 전하 보존 DC 해(정착 V_start·V_final, static settling error의 기준 -- N3.8 '정착 측정 정의')의 정본 자리(writer 하나) -- v6.38.1 사용자 결정 O-157(2026-10-26, `_drafts/user_decisions.md` O-157 행) S3, graph 규칙 6(지금 자리 없음). **oracle 1b 대표 회로**(v6.26, 사용자 결정 O-78 (1)): current_reuse 응용 회로(Cs 하판의 계단 원천)를 대표 회로로 용량만 선언된 차동 출력 슬루의 t = 0 시작 동작점 경로(oracle-portability 계획 v0.6.15 N3.9 슬루 행 '시작 동작점 경로의 구현 자리', oracle design §21.6 1b)를 구현·실측한다 -- 시작점은 ICMR 공칭 점 기록 `v_in` 참조(둘째 `.op` 생산자 금지, graph 규칙 1·2·4); 그 전까지 그 경로 = 정의 불능 + 사유. 오라클 코드는 AP-1 착수 때 oracle-portability 계획에 OP card를 열어 그 계획의 card 절차로 만든다(이 card는 응용 회로·범위만 정함). (a)로 ICMR 측정 구성이 바뀌면 1b 시작점 `v_in`과 t = 0 닫힘이 같은 꼴인지 그때 다시 확인한다. **지금 범위 밖**: 엔진 코드·스키마 변경.

### N6.16 card LA-2 -- 외층 기본값 반영(DEC-73 (4)·DEC-75 v6.19)

**근거**: DEC-73 (4)·DEC-75 v6.19 개정, LA-Q3(O-36 (4))·O-37 (D), v6.19 독립 검증 지적(작성자≠판정자 -- 외층 기본값은 LA-1 구현 주체가 아니라 검증자 판정 기록이 정한다).

**입력**: 검증자 판정 기록 -- card 0 LA2-0(아래)의 외층 필요성 실험 표, n_A, 축별 '보류' 여부, 수리 발생 수, 발동 분기 목록(O-41 (1)). 작성자 보고는 입력이 아니다.

**card 0 LA2-0**(검증자, 엔진 무변경): 면적 축 두 눈금 차(DEC-80 (ii), Q-EM1)가 선언된 뒤(레이아웃 판정 축 뒤; 전력 bin = b_P -- O-178) **LA-2의 실제 base**에서 LA-1 완료 조건 3의 외층 필요성 실험을 다시 잰다(LA-1 때 판정은 면적 축 차 미측정이면 '보류'였으므로 그 기록을 그대로 쓰지 않는다). 같은 spec·인자·면적 축 차 선언으로 구성 OL-off·OL-on을 돌리고 결과·발동 분기 목록을 판정 기록으로 남긴다.

**범위**: LA2-0 판정 기록이 '끔'(측정한 층 0 활성 회로 전부에서 축마다 차 ≤ bin 분해능, 표본 n_A ≥ 1, 수리 경로 검증됨, 면적 축 두 눈금 차 선언됨)이면 DEC-75 외층 항목의 기본값을 끔으로 바꾸고(선언 읽기 1곳의 기본값), 판정 기록의 발동 분기 목록을 엔진 전역 선언값(판정 기록 id 출처, 회로 spec·S3 runs 산출물 금지, DEC-73 (4))으로 기록해 자동 켬 (iv)(목록 밖 분기 발동 시 외층 켬, O-41 (1))가 쓰게 한다. 그 밖(보류·표본 없음·수리 경로 미검증·넘은 회로 있음)이면 기본값을 바꾸지 않고 사유를 기록한다. 자동 켬 (i)~(iv) 규칙은 바꾸지 않는다.

**완료 조건**(변경 종류: 기본값만 바꾸므로 순수 리팩터링 -- 같은 계산 경로를 기본값으로 옮긴 것, 비교 대상 = LA2-0의 OL-off 결과; 결정성 비트 동일): (1) 판정 기록 id 인용 (2) 기본값을 바꾼 경우 13회로 결과가 **같은 base·같은 면적 축 차 선언으로 LA2-0이 재실행한 구성 OL-off 결과**와 필드별 같음(순수 리팩터링 기준 -- 같은 계산 경로를 기본값으로 옮긴 것이므로) (3) 자동 켬 (i)~(iv) red toy 재확인 -- (iv)는 목록에 없는 분기(예: 측정 회로가 발동하지 않은 결합 종류)를 발동하는 toy에서 외층이 돎(회로 이름이 아니라 분기로 판정) (4) 결정성 비트 동일 (5) N6.3 공통.

**순서**: LA-1 병합 뒤. 착수 조건(LA2-0 포함) = 면적 축 두 눈금 차 선언(DEC-80 (ii) -- 탐색 축 대 판정 축 실측 차, 이름·자리 N5.3 Q-EM1): 레이아웃 판정 축(N6.1 단위 9, MOD7·MOD8) 구현이 선행이다. 전력 축 bin = b_P(DEC-73 (4))라 전력 쪽 선행은 없다(사용자 결정 O-178; `power_dc_w` 대조 정의 정정 PW-1a는 oracle 판정의 정의 동일성 몫). 면적 축 차는 **회로마다 그 회로의 값**을 쓴다(LA-Q3가 '측정한 층 0 활성 회로 각각에서 성립할 때만 끔'이라 여러 회로를 묶는 집계 규칙은 필요 없고 만들지 않는다).

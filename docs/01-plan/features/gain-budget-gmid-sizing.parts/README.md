# gain-budget-gmid-sizing.plan.md 조각 폴더

`gain-budget-gmid-sizing.plan.md`(계획 정본)를 **내용 변경 없이** 파일로 나눈 조각이다. 계획서에는 절 제목·결정 행의 ID와 한 줄 요약·링크 표지만 남고, 본문은 이 폴더에 있다. 절 번호(N6.14 등)·card ID·DEC 번호는 바뀌지 않았다.

| 폴더 | 내용 | 계획서의 자리 |
|---|---|---|
| `cards/<ID>.md` | N6 card 절 본문(`### N6.n card <ID> ...`의 제목부터 다음 제목 앞까지) | 제목 줄 + `<!-- split:section=... -->` + 링크 |
| `archive/<ID>.md` | 철회·삭제된 card(`-- **철회**`·`-- **삭제**`)와 폐기된 N3.12 절 | 같음 |
| `decisions/<ID>.md` | N2.1 결정 레지스터에서 3,000바이트를 넘는 표 행(원래 한 줄 그대로) | 요약 행 + `<!-- split:row=... -->` (적용·상태 칸은 줄여 둠) |
| `status/*-status.md` | 계획서 맨 위 Status 줄 전체 | 한 줄 요약 + 표지 |

## 읽는 법
- 새 세션은 계획서에서 필요한 절만 읽고, 그 절이 링크한 조각만 따라간다.
- 요약 행의 제목은 조각에서 뽑은 색인용 문구이고 정본이 아니다. **정본은 조각 파일**이다.

## 고치는 법
- 조각 파일을 직접 고친다(계획서의 요약 행·링크 줄은 손대지 않는다). 결정 행의 적용·상태 칸을 바꿀 때는 조각의 행(정본)과 계획서의 요약 행 둘 다 맞춘다.
- 분할 전 상태로 되돌리려면 `.ai/verification/20261111-plan-split/scripts/split_plan.py rebuild <plan.md> <출력>`을 쓴다. 복원 결과는 분할 전 계획서와 바이트 단위로 같다(검사: `check_split.py`).
- 이 분할은 계획서의 구조를 바꾼 것이지 규칙·결정 문언을 바꾼 것이 아니다. 줄 번호 인용(`:1857` 같은 증거 문서의 인용)은 분할 전 기준이라 어긋난다.

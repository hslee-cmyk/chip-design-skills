# headroom-chain Planning Document

> **Summary**: 엔진 출발 규칙에 두 규칙을 넣는다. 두 규칙은 연결과 물리 관계(KVL·영역 조건)에서 유도하고, 회로·소자 이름은 쓰지 않는다.
> 1. **R-1′ 사슬 헤드룸 제약(소거식)**: 전도 MOS마다 포화 부등식 V(위쪽 넷) − V(아래쪽 넷) ≥ VDsat + tol이 있다. 이 부등식들에서 KVL로 정해지지 않는 미지수를 Fourier–Motzkin으로 소거한다. 미지수는 drain에만 닿는 넷의 전압과, F에 닿지 않는 Gs⁺ 성분(입력 DC 미선언 입력 묶음 포함)의 오프셋이다. 소거 결과는 미지수가 존재할 필요충분조건이고, 이것을 출발 구간 제약으로 쓴다. 소자 하나로 F 쪽 넷 사이를 잇는 식이 길이 1 특수형이다. 입력 공통모드 창이 비는 것은 이 규칙의 특수형이다.
> 2. **R-3 gate 공유 직렬 적층의 source 쪽 소자**: KVL로 VDS(X) = VGS(X) − VGS(Y)가 정확히 성립하는 소자 X다. 같은 gate·같은 bulk·같은 VT0이면 X 포화 ⇔ Y의 source 쪽이 강반전이 아님이다(N3.9 R3-a). 그래서 동작점에서 Y가 전도하면 X에 포화를 요구하지 않는다. 대상은 봉인 7·입력 창·스윙, SPICE `all_saturated`, 사슬 항이다. X의 영역은 LUT로 판정해 기록하고, 동작점이 LUT 정의역 안인지 보는 게이트(fail-closed)를 둔다.
>

## N0. 문서 안내

* **담는 것**: 목적·범위, 확정 결정과 상위 계획과의 관계, 규칙·정의와 물리 유도, 제한 조건 점검표(P-1), 정본 위치와 재사용, 게이트, 원래 취지와 다른 항목, 선행 측정(card 0), card 단계, 완료 조건, 위험, 원문 근거, 열린 결정.
* **담지 않는 것**: 경위, 측정값과 그 해석, 버전 이력. 이것들은 history에 둔다. 계획에는 측정의 결론과 지시만 적는다.
* **값 원칙**: 이 문서에는 수치 상수를 두지 않는다.
  * 여유 `tol`은 봉인 7 정의(상위 DEC-88)의 `tol_VDsat`(LUT `VDSAT` 열 leave-one-out 셀값)을 참조한다.
  * VDS 정의역 하한은 LUT 데이터(on_mask)에서 유도한 값이다.
* **이름 원칙**: 규칙·코드·판정에 회로·소자·넷 이름을 쓰지 않는다. 이름은 측정 대상(N6)과 history에만 사례로 나온다.
* **물리 원칙(P-1)**: 모든 제한·예외·한정 조건은 물리 유도(KVL·KCL·영역 조건 식)가 있어야 둔다.
  * 유도가 깨지는 조건은 제한으로 두지 않는다. '유도 성립 조건 + 깨지면 LUT로 확인'으로 둔다.
  * 회로의 목적(응용)은 영역 규칙의 근거로 쓰지 않는다.
  * 물리 규칙이 아닌 알고리즘 규칙은 점검표(N3.9)에 '알고리즘'으로 따로 표시한다.
* **인용 규칙**: 코드는 `파일:줄`이고 기준은 base `083b103`(worktree `wt/headroom-chain-plan`)이다. 인용한 줄은 모두 이 worktree에서 직접 읽어 확인했다. 경로 약어는 다음과 같다.
  * `E/` = `skills/analog-gmid-design/gmid_engine/`
  * `O/` = `skills/analog-gmid-design/tools/spice_oracle/`
  * `A/` = `skills/analog-gmid-design/assets/`
* **오케스트레이터 기본안**: 사용자 결정·상위 문서가 정하지 않은 것을 원칙으로 정할 때 '(기본안)'으로 표시한다. 사용자가 바꿀 수 있다.

### N0.1 용어

| 용어 | 정의 |
|---|---|
| Gs⁺ | 쓰기 계획이 노드 전압을 쓰는 그래프다. 레일·노드 목표·선언 입력 포트를 고정 노드 F로 합친다. 변은 MOS (gate, source) 변, 저항 변, 미선언 입력 포트끼리의 '같은 DC' 변이다(`E/sizing/writer_plan.py:8-11`). **이 계획은 Gs⁺를 따로 만들지 않고 쓰기 계획 출력 `node.dc_writer`를 읽는다**(사본 금지) |
| F 성분 / KVL 넷 | Gs⁺에서 F에 닿는 성분을 F 성분이라 한다. 그 성분의 넷이 **KVL 넷**이다. KVL 넷의 전압은 F 값(레일·노드 목표·선언 입력 DC)에 Gs⁺ 경로의 ±VGS·저항 강하를 더한 θ 식이다 |
| 창 뿌리 성분(부유 성분) | Gs⁺에서 F에 닿지 않는 성분이다. 쓰기 계획은 그 뿌리를 W4 `free_window`로 쓴다(`E/sizing/writer_plan.py:20-21, :234`). 뿌리가 입력 포트면 y 키는 `input_common_mode`, 아니면 뿌리 넷이다. 성분 안 넷 전압 = 뿌리 전압 + 성분 안 ±VGS 합이다. **뿌리 전압(성분 오프셋)은 미지수로 다룬다.** θ의 y는 순서 창 안 상대 위치이고 그 창은 다른 노드 값에 의존한다(`E/sizing/s2_values.py:38`, `E/sizing/block_columns.py:197-214, :772-775`). 그래서 y를 전압처럼 쓰지 않는다 |
| 고립 넷 | Gs⁺ 밖 넷이다. 쓰기 계획은 이것을 자기 y를 갖는 W4로 쓴다(`E/sizing/writer_plan.py:236-238`). drain 단자에만 닿는 넷이고, 전압은 미지수다 |
| 미지수 묶음 | 창 뿌리 성분 하나(오프셋 하나) 또는 고립 넷 하나다 |
| 위쪽 방향 | VDS 변의 전압 순서다. nmos는 source → drain, pmos는 drain → source가 위쪽이다(`E/search/iv_headroom.py:66-70`와 같은 규칙). 전도 중인 소자의 위쪽 단자 전압이 더 높다 |
| 소거식 | 미지수 묶음을 Fourier–Motzkin으로 소거해 나온 부등식이다(N3.1-1). 하나는 위쪽 방향 경로 하나에 대응한다. 경로는 KVL 넷 a에서 출발해 미지수 묶음만 지나 KVL 넷 b에 닿고, ΔV = V(b) − V(a) − (지난 창 뿌리 성분 안 VGS 차 합)이다. 이 문서에서 '사슬'은 소거식의 경로를 뜻한다 |
| 길이 1 사슬 | 미지수 묶음을 지나지 않는 사슬이다. 전도 MOS 하나의 두 단자가 모두 KVL 넷이다 |
| 적층 소자 X(R-3 후보) | gate 넷이 같고 kind가 같은 MOS X, Y가 있고, X의 drain 넷 = Y의 source 넷인 X다(S1, 연결만). 면제는 동작점에서 Y가 전도할 때만 한다(N3.2-1) |
| 지켜지는 소자 | R-3 후보 X에 대해, Z의 drain 넷과 source 넷 사이 **모든** Gs⁺ 경로에서 X의 VGS 변이 절단 변인 소자 Z(Z ≠ X)다 |
| 포화 면제 집합 | 봉인 7·입력 창·스윙 metric이 포화 판정에서 빼는 소자 집합이다. 지금은 spec 선언 triode뿐이다(`E/sizing/dc_inputs.py:8, :37-38`). 이 계획은 여기에 동작점별 R-3 면제를 합친다 |
| 전도 | 봉인 7과 같은 판정으로, `op.current > 0`이다(`E/sizing/seal_saturation.py:55-56`). 출발 단계에서는 출발 구간이 정한 전류(자리값 포함)가 양수인 것이다 |
| 출발 구간 | 단계 A8 `start_intervals`가 내는 소자별 gm/ID·L·전류 구간과 출발 사다리다(`E/search/start_intervals.py:1-31`) |

## N1. 목적·범위·요구

### N1.1 목적

파일럿 `current_reuse_telescopic_ota`는 master에서 층 0 시험점이 모두 봉인 7 `no_root_in_window`로 실패해 front가 0이다(백로그 52-55행). 사용자 해석 승인 C-1과 측정 M-1~M-9(history H2)에서 나온 결론은 셋이다.
* 실패 노드는 모두 연결에서 유도되는 VDS 부등식을 출발점이 어긴 곳이다.
* 지금 출발 규칙은 소자별 절대 하한만 쓴다(`E/search/iv_headroom.py:5-11`). 그래서 이런 결합 부등식을 잡지 못한다.
* gate 공유 직렬 적층의 source 쪽 소자에도 일괄 포화를 요구한다. 그런데 Y가 강반전이면 이 소자의 포화는 불가능하다(N3.9 R3-a).

이 기능의 목표는 셋이다.
1. 포화 부등식의 소거식을 출발 구간 제약으로 쓴다(R-1′). 상위 DEC-27·DEC-64 VDS-1을 일반화한 것이다.
2. Y가 전도하는 적층 소자 X에 포화를 요구하지 않는다. 대신 영역 기록과 LUT 정의역 게이트를 둔다(R-3).
3. 소거식이 출발을 바꾸지 않는 회로에서 결과가 비트 동일함을 보인다(사용자 C-1 "루프 없는 회로 출발점 비트 동일").

### N3.1 R-1′ 사슬 헤드룸 제약(소거식)

1. **소거식 생성**(연결과 쓰기 계획 출력만 쓰고, 이름은 쓰지 않는다)
   * **변수 분류**:
     * KVL 넷 전압은 θ 식이다.
     * 미지수는 고립 넷 전압과 창 뿌리 성분 오프셋 o_c다. 창 뿌리 성분 c 안 넷 n의 전압은 o_c + κ_n이고, κ_n은 성분 안 ±VGS·저항 강하 합(θ 식)이다.
   * **기초 부등식**: 전도 MOS마다 V(위쪽 단자) − V(아래쪽 단자) ≥ term이다(term은 N3.1-2). 단자가 미지수 묶음에 있으면 그 묶음 미지수의 하한 또는 상한이 된다. 같은 창 뿌리 성분 안 두 단자를 잇는 소자는 o_c가 상쇄되어 θ만의 식이 된다(길이 1과 같은 꼴).
   * **소거(유도)**: 미지수 묶음마다 하한 식들과 상한 식들의 쌍마다 식 하나를 낸다(Fourier–Motzkin). 묶음을 차례로 소거하면 남는 식이 위쪽 방향 경로에 대응한다. 경로는 KVL 넷 a → (미지수 묶음들) → KVL 넷 b다.
     * 남은 식: Σ term ≤ V(b) − V(a) − Σ(지난 창 뿌리 성분마다 '들어온 넷 κ − 나간 넷 κ'의 부호 합).
     * 이 식들의 집합은 미지수가 존재할 **필요충분조건**이다(선형 부등식계에서 FM 소거는 정확하다).
     * 극소성(안쪽에 KVL 넷 없음)은 정의가 아니라 이 소거의 결과다.
   * **입력 CM 빈 창**: 입력 DC 미선언 입력 묶음은 창 뿌리 성분이다. 그 오프셋(입력 공통모드 전압)의 하한 > 상한이 곧 이 소거식 하나의 위반이다. 별도 규칙을 두지 않는다(특수형).
   * **분기·kind·평행**: 미지수 묶음의 단자 수와 kind에는 제한을 두지 않는다. 방향은 소자별 위쪽 방향 규칙으로 정한다. 평행 소자(같은 두 넷 사이 VDS 변 여럿)는 각자 기초 부등식을 내므로, 같은 경로의 식은 항 = 평행 소자 term의 최댓값 하나로 묶인다(N3.9 C-7).
   * **고립 넷 위쪽 방향 순환**: 미지수 묶음만으로 된 위쪽 방향 순환이 있으면 Σ term ≤ 0이다. term > 0이므로 항상 실행 불가다. 탐지해 사유 코드로 멈춘다(fail-closed, N3.9 C-2).
   * **따름 사실**(N3.9 C-4): 고립 넷은 G_vgs 밖이라 gate·source·저항 단자가 아니다. 그래서 고립 넷 하나를 지나는 경로는 아래에서 nmos drain으로 들어와 위로 pmos drain으로 나간다. nmos·pmos drain이 만나는 넷만 지난다. 창 뿌리 성분을 지나는 경로는 그 성분의 어느 넷으로든 드나들 수 있다.
2. **항(term)**
   * **일반 전도 소자**: VDsat + tol_VDsat. VDsat는 LUT `VDSAT` 열, tol은 봉인 7과 같은 LOO 셀값이다(DEC-88).
   * **전도하지 않는 소자**(ID = 0, 전도 판정 N0.1): 기초 부등식이 없다. 그 소자를 지나는 소거식은 만들지 않는다(N3.9 C-9). 출발 단계에서는 출발 구간이 정한 전류로 판정한다.
   * **동작점별 R-3 면제 소자**(N3.2): 포화를 요구하지 않는다. term = LUT on_mask 유도 VDS 하한이다(N3.3-2, X-4, U-H8).
   * **diode 연결 소자**: drain이 gate라 G_vgs 안이다. 그래서 diode는 고립 넷에 닿지 않는다. diode의 기초 부등식 VGS ≥ VDsat + tol은 LUT로 평가한다(N3.9 C-6).
   * 출발 단계의 소자 동작점(VDS, VSB)은 출발 구간 규칙(F-2)을 따른다.
3. **출발 구간 반영**(기본안)
   * 소거식마다 조정 소자 하나를 DEC-95 (3) 순서로 고른다. 그 순서에서 **diode는 조정 소자로 고르지 않는다**(쓰기 계획에서 diode가 독립 writer로 남는 것과 같다, `E/sizing/writer_plan.py:12-14`).
   * 조정 소자의 ln IDu 경계를 LUT 역산(`vgs_for_current_density` 방향)으로 낸다. 나머지 소자는 그 칸의 선택점 값에 둔다.
   * 조정은 구조 순서로 한 번 지나간다. **모든 조정 뒤 그 칸의 소거식 전체를 다시 평가한다.** 다른 식이 깨졌으면 그 칸에 충돌 기록을 남긴다. 반복 수리는 하지 않는다(알고리즘 규칙, N3.9 A-1).
   * 경계는 출발 행 Bound(새 출처 이름)로 기록한다. 구간이 실제로 좁혀질 때만 출처를 남긴다(`E/search/start_intervals.py:321-323` 관행).
   * **사다리 칸**: 칸 0만이 아니라 모든 칸에 같은 규칙을 적용한다(F-20). 칸마다 충돌 여부를 기록한다. 층 0은 지금처럼 칸 순서로 확인한다(N3.9 A-2).
4. **충돌**: LUT 곡선 범위 안 어느 값으로도 식을 만족할 수 없으면 자르지 않고 `StartConflict`를 남긴다. 사다리·θ는 바꾸지 않는다(N4-3 '충돌만 추가'). 입력 CM 빈 창(N3.1-1 특수형)도 같은 기록에 사유 코드를 달아 멈춘다(위험 R-1, U-H3).
5. **층 0 거르기**(기본안, C-1 승인안과 다름 -- X-8, U-H9)
   * 층 0 Halton 시험점과 실패 수리 점을 커널 전에 같은 소거식 함수로 거른다. 커널 평가는 0이고 평가 예산에 넣지 않는다. 거른 점 수는 보고 칸으로 낸다.
   * 시험점 생성 규칙(F-15)은 바꾸지 않는다.
   * 거르기 판정은 저장하지 않는다(새 캐시 없음). 같은 점이 다시 오면 LUT memo 조회로 다시 판정한다. 다시 온 횟수는 HC-V에서 센다. 0이 아니면 design이 기존 평가 캐시 항목에 판정을 싣는 방안을 낸다(새 캐시가 아님, G-4).
6. **기존 VDS-1과의 관계**(완료 조건 3)
   * **비교 단위**: 소자 단위 '어떤 길이 1 사슬 묶음에 속하는가'다. base 집합 = `vds_saturation` 기록이 있는 소자다. 기록 형식 차이는 비교에서 뺀다(평행 소자는 base에서는 각자 기록, 새 정본에서는 한 식의 최댓값 항으로 묶임 -- 표현 차이, F-3).
   * **포함 관계**: base 집합 ⊆ 새 길이 1 집합이다. 차집합 소자마다 다음 원인이 **하나 이상** 붙는다.
     * (i) Gs⁺에만 있는 변(저항, 입력 포트–F, 노드 목표)으로 두 단자가 같은 F 성분에 이어짐
     * (ii) 두 단자가 서로 다른 Gs 성분이지만 둘 다 F 성분
     * (iii) diode
     * (iv) d·s가 둘 다 F 넷(레일 병합)
   * 반대로 base에 있고 새 길이 1 집합에 없는 소자는, 두 단자가 같은 창 뿌리 성분인 소자다. 이 소자는 새 정본에서 o_c가 상쇄된 식으로 남는다. 그래서 '길이 1 꼴 식'으로 함께 센다(N3.1-1 기초 부등식).
   * R-3 소자 자신의 식(VDS(X) = VGS(X) − VGS(Y))은 기록에 남는다. 소비 때 면제 여부에 따라 항이 바뀐다.
7. **헤드룸 예산과의 관계**: 기존 소자별 헤드룸 하한(F-1)은 그대로 둔다. 소거식은 결합식이고 헤드룸 예산은 최소 비용 완화식이다. design은 출처 이름 분리와 포함 관계를 보인다(G-3). 상위 DEC-64의 W4 처리(쓰기 계획 y, 층 0 창)도 그대로 둔다. R-1′은 그 미지수를 소거한 출발 제약을 더할 뿐이다(X-1).

### N3.2 R-3 gate 공유 직렬 적층의 source 쪽 소자

1. **후보와 면제**(연결 + 동작점, 이름 없음, 유도는 N3.9 R3-a)
   * **후보**(S1, 연결만): MOS X, Y의 kind가 같고, gate 넷이 같고, Y의 source 넷 = X의 drain 넷이다. 중간 넷 단자 수와 gate 넷 종류(레일 포함)에는 제한을 두지 않는다(N3.9 R3-b·R3-c).
   * **면제 전제**(동작점, 기본안, U-H12): 그 동작점에서 Y가 전도한다. 판정은 봉인 7과 같은 ID > 0이다.
     * 유도는 'Y source 쪽 강반전 ⇒ X 비포화'다. Y가 꺼져 있으면 X가 포화할 수 있으므로 면제하지 않는다. 이 경우 X는 일반 포화 판정을 받는다.
     * 중간 넷이 직렬(DC 전류 단자 둘)이면 KCL로 I(Y) = I(X)다. 그래서 X가 전도하면 전제가 저절로 성립한다. 직렬 조건은 이 전제의 특수형이다.
   * 기존 정본(복합 diode `dc_role` rule 1c, `gs_groups`)과 후보 집합이 같은지는 card 0 M-H3에서 잰다.
2. **포화 면제 집합** = spec 선언 triode ∪ {동작점에서 Y가 전도하는 R-3 후보 X}.
   * 합집합은 한 함수가 한 곳에서 만든다. 동작점에 의존하므로 봉인 계산 안(그 동작점의 `dc_op`)에서 판정한다. 위치는 G-6이다.
   * 읽는 곳: 봉인 7(`E/sizing/seal_saturation.py:55-56`), 입력 창(`E/sizing/block_columns.py:148, :225-231`), 스윙 metric(`E/metrics/metrics_aux.py:214`), 소거식 항(N3.1-2, 출발 단계 전류로 판정), 오라클 입력 칸(HC-O).
   * 선언과 유도가 같은 소자를 가리키면 정보로만 기록한다.
3. **영역 기록**: 면제된 X는 포화 판정을 받지 않는다. 대신 봉인 보고에 LUT 영역(VDS 대 VDsat)을 기록한다. 약반전이면 X가 포화일 수 있고(N3.9 R3-a), 그것도 그대로 기록한다.
4. **지켜지는 소자 Z**: Z의 포화 판정은 일반 규칙으로 남는다. Z가 없거나 Z가 면제면 거부하지 않는다. 그 경우 '그 X의 VGS에 의존하는 포화 판정 없음'을 기록한다(기본안, U-H7). Z의 존재는 X의 동작 조건이 아니기 때문이다(N3.9 R3-d).

### N3.3 R-3 게이트(fail-closed)

1. **판정 대체**: 면제된 X의 포화 판정 자리는 (i) 영역 기록(N3.2-3)과 (ii) 정의역 게이트가 맡는다.
2. **LUT 정의역 게이트**
   * 조건: 면제된 X의 동작점 VDS가 [LUT on_mask 유도 VDS 하한(F-10과 같은 함수), VDS 축 끝] 안이고, 그 VDS에서 VGS 역산이 정의된다.
   * 조건을 어기면 소자 이름을 단 사유 코드로 거부한다.
   * 이것은 **모델 정의역 조건**(데이터)이고 물리 제한이 아니다. 보고도 그렇게 하고, 봉인 7 포화 위반으로 분류하지 않는다.
   * 같은 하한을 소거식 항으로도 쓴다(N3.1-2, X-4, U-H8). 근거는 history H2: 하한이 없으면 출발점이 이 게이트에 걸린다.
3. **게이트가 실제로 거부함**: 정의역 밖 동작점 픽스처로 거부를 먼저 보이고, 그다음 통과를 본다(완료 조건 5).

### N3.5 계산 재사용과 XRUN-F1 규칙

* 소거식·R-3 후보는 θ 무관이다. 실행마다 처음 한 번 계산하고 그 실행 안에서 재사용한다. 실행 사이 재사용은 없다(상위 U-89). 같은 입력 재계산은 0이어야 한다(G-10 계수, 완료 조건 6).

* 소거식 필드는 `start_intervals` READS(F-19)와 그 입력 판에 들어간다. R-3 후보 필드는 봉인·입력 창·스윙 블록 READS에 들어간다.
* 색인 키는 XRUN-F1 X-20·X-21을 따른다. 키 = (블록, 분할, 입력 판)만이고, 실행 바깥 지문은 금지하며, 디스크 저장도 금지한다. 새 키 칸은 없다.

* **파일 겹침**: HC-1은 `E/search/start_intervals.py`·`layer0_center.py`·`iv_*`를 고친다. XRUN-F1 card C도 search 층을 고치므로 HC-1은 card C 뒤에 병합한다.

### N3.6 SPICE 오라클 반영(HC-O)

* 오라클은 엔진을 import하지 않는다(상위 N3.8). 엔진이 오라클 입력에 다음 칸을 넘긴다: 소자별 면제 여부와 근거(선언 / R-3, Y), 지켜지는 소자.

* 합격 판정 코드(`O/oracle_compare.py:389-420`)는 OP-3에서 코어로 옮겨진다.
  * 이 계획은 옛 파일을 고치지 않고, OP-3 뒤 새 코어에 배선한다(기본안, U-H10).
  * 그 전까지 R-3 소자가 있는 회로의 SPICE 판정은 그 소자를 '포화 아님'으로 보고한다. 결과에는 '알려진 차이(HC-O 전)'로 적는다.
* spec 어휘 `free_spec_and_all_saturated`의 뜻을 바꾸는 방법은 U-H1이다(X-3).

## N4. 13회로 적용 판정

판정은 규칙으로 하고, '해당 없음'은 사유로 남긴다.

1. **무동작 A**: 소거식이 0개이고 동작점별 R-3 면제가 없으면 무동작이다(완료 조건 1).
2. **무동작 B**: 다음을 모두 만족하면 무동작이다(완료 조건 1).
   * base 출발 사다리의 **모든 칸**이 모든 소거식을 만족한다(구간을 좁히지 않음).
   * 층 0에서 거른 시험점 수가 실측 0이다.
   * 면제가 0이다.
3. **변화 있음**: 소거식이 구간을 좁히거나 시험점을 거르면 결과가 바뀐다. 바뀐 칸마다 출처 기록이 있어야 한다(완료 조건 2). **충돌만 추가**되는 경우(사다리·θ 무변)에는 바뀐 칸이 `conflicts` 하나뿐이어야 한다.
4. **면제 있음**: 면제가 있으면 봉인 7 행 집합이 바뀐다. 바뀐 행은 면제 소자 행뿐이어야 하고, 영역 기록 칸이 더해진다.

**창 뿌리 성분(부유 성분)이 있는 회로**
* 오프셋 소거로 새 식이 생긴다. 생긴 식은 그 성분에 닿는 위·아래 소자 쌍마다 하나다.
* 이런 회로는 v0.2의 '길이 1만' 회로보다 N4-3에 들 가능성이 크다. 검증자의 대략 계수로는 비포트 부유 성분이 13회로 중 7개에 있다. 확정 수는 card 0 M-H2에서 잰다.
* 무동작 조건은 같다(N4-2). 다만 이 회로들에서는 '모든 칸 만족'과 '거른 점 0'을 실측으로 확인한 뒤에만 무동작으로 센다. 이 회로들을 예측만으로 무동작 목록에 넣지 않는다.

**새 보고 칸의 base 비교 규칙**
* 대상 칸: 거른 점 수, 소거식 출처, 칸별 충돌, 영역 기록, 면제 근거.
* 비트 비교에서는 이 칸들을 뺀다. 대신 N4-1·N4-2 회로에서 0이거나 비어 있음을 따로 단언한다.
* 제외 목록은 검증자가 소유한다.

1. **무동작**: N4-1·N4-2 회로에서 아래가 base와 비트 동일하다.

   * 그 밖의 제외 칸은 검증자가 소유하고, 판정 기준 변경으로 보고한다.
   * base = XRUN-F1 card C 병합 뒤 master
2. **변화의 출처**: N4-3·N4-4 회로에서 아래를 확인한다.
   * 바뀐 출발 칸은 모두 소거식 출처나 정의역 하한 기록이 있다.
   * '충돌만 추가'인 경우에는 `conflicts`만 바뀐다.
   * 바뀐 봉인 7 행은 면제 소자 행뿐이다.
3. **VDS-1 포함 관계**(N3.1-6): 13회로에서 소자 단위로 판정한다.
   * HC-1 전 `vds_saturation` 소자 집합 ⊆ 새 '길이 1 꼴 식' 소자 집합(창 뿌리 성분 안 상쇄 식 포함)
   * 차집합 소자마다 원인 (i)~(iv)가 하나 이상 있고, 원인이 없는 차이는 0이다.
   * 평행 소자 기록 형식 차이는 비교에서 뺀다.
4. **이름 금지**: 새로 쓰거나 고친 규칙 코드에 회로·소자·넷 이름 리터럴이 0이다(AST 문자열 리터럴 검사, 주석·docstring 제외).
5. **실제로 거부함**: 각각 거부를 먼저 보이고, 그다음 통과를 본다.
   * (i) 소거식 만족 불가 → 충돌 + 사유 코드
   * (ii) 입력 CM 빈 창 → 사유 코드
   * (iii) 고립 넷 위쪽 순환 → 사유 코드
   * (iv) 면제 소자가 정의역 밖 → 게이트 거부
   * (v) Y가 꺼진 동작점 → X는 면제되지 않고 포화 판정을 받는다
6. **graph 단일 정본·재계산**:
   * 소거식·R-3 후보·면제 함수의 writer는 하나씩이다.
   * 같은 입력 재계산 0(G-10)
   * `composite_diodes`·쓰기 계획 계산 수가 base와 같다.
   * `vds_saturation` 참조 grep 0
7. **배선**: 새 필드·함수가 실제 경로에서 호출된다. 엔진 소비자(출발 구간·층 0·봉인 7·입력 창·스윙·소거식 항)가 HC-1 안에서 그것을 읽는다.
8. **파일럿 목표**:
   * 파일럿 출발 사다리 칸 0의 θ가 모든 소거식을 만족한다.
   * 층 0 실패가 남으면, 그 사유가 소거식을 어긴 θ의 `no_root_in_window`가 아님을 보인다.
   * 입력 CM 빈 창이면 그 사유 코드로 멈춘다(U-H3).
   * front ≥ 1은 보고 항목이다.
9. **SPICE**(HC-O): 면제 소자(SPICE 동작점에서 Y 전도)가 포화 판정에서 빠지고 영역이 기록된다.
10. **gap·bkit**: 상위 N6.3 확인과 design 대 구현 gap 분석을 통과한다.

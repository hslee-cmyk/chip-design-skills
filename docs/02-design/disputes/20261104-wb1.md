## 문제의 test

1. `test_slice_param_tables_column_unavailable_propagates[upper-min, lower-max]` -- GMBS 열 없는 합성 LUT(`write_slice_lut(gmbs=False)`)에서 `ParamTables.lookup` 이 `lut_column_unavailable` 을 던질 것을 기대한다.
   실측: `lut.gmb` 는 GMBS 열이 없으면 VS 할선으로 계산한다(lut/CONTRACT.md 4.4 '(4) gmb 정본 = GMBS 열(있을 때), 없으면 r5 VS 할선'). 그래서 `param_row` 는 열 없음 없이 19 마디 행을 낸다
   (`derived(memo, "param_row", "nmos", 100, 1e-6, 0.0, -0.45)` 를 직접 불러 확인). 이 구현은 `_param_row` 의 광범위 except 를 조회 불능 사유 다섯과 `lut_curve_undefined` 로만 좁혔다(s4).
   그래도 던질 열 없음 사유가 이 LUT 에는 없다 -- 기대 사유의 출처(어느 열)가 card 에 없다.
2. `test_dc_solve_rdep_*` 의 전제 1 -- `circuit_r_dep` 에서 `dc_scc_order` 의 순환 SCC 가 정확히 하나일 것(`{vin, vout}`). 실측: 둘이다 -- `SccEntry(nb1, cyclic=True, devices=(M0, M1))`(diode M0 의 1변수 순환)과 `{vin, vout}`.
   card §3 D-2 는 '미측정, 전제가 깨지면 멈추고 보고'. 전제 단언만 풀고(순환 SCC 중 노드 2개짜리만 센다) 돌렸을 때: 사이클 test 는 통과(`slice_cycle`, M1 호출 2회), 수렴 두 건은 봉인 7 실패(M1 slack −47 mV)로 끝난다.
3. `test_window_w4_gate_only_root_is_rail_range_without_constraints` -- `circuit_cs_pmos_load` 의 입력 `in` 이 `node.dc_window` 키에 들 것을 기대한다(IT-2b 문언). 실측: `in` 은 W4 뿌리가 아니다(θ 스키마에 `("y","in")` 없음, IT-2c 'W4 뿌리 항목만'). 뒤의 `len(w.constraints) == 0` 도 `constraints` 가 int 라 TypeError.

## 근거(oracle 또는 사용자 원문)

- 1: lut/CONTRACT.md 4.4, spec card '거부해야 할 입력' 표 (`lut_column_unavailable` = CDD 없는 표, `w_of` 쪽) -- GMBS 없는 슬라이스는 거부 대상이 아니다.
- 2: spec card §3 D-2 '이 회로의 통과는 미측정이다 ... 전제 단언이 깨지면 그 사실 자체가 결정 입력이다'.
- 3: design 40 §3.11-1 '필드 = node.dc_window, W4 뿌리마다', IT-2c 후 입력 포트 창은 `node.dc_window_cfg`.

## 요청

각 test 의 기대(또는 회로 전제)를 card 계약에 맞게 고치거나, 1 은 어느 열이 없어야 하는지 card 에 적어 달라. 2 는 D-2 회로를 diode 순환이 SCC 하나로 묶이지 않는 꼴로 다시 정하고
봉인 7 을 지키는 손 값으로 다시 구성해 달라(회로·기대값은 이 역할이 고치지 않는다). 3 은 게이트에만 닿는 W4 뿌리를 가진 회로로 바꾸고 `w.constraints == 0` 으로 단언해 달라.

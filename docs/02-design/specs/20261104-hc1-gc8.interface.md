## 3. 판정 함수 (`gmid_engine.sizing`)


### 3.1 `f_exist` 닫힌 식

- `weights` = {변 이름 → (term, K_lo, K_hi)}. MOS 변: term = 항, K = V_known(lo_net), V_known(hi_net). **`weights`에 없는 MOS 변은 그 평가에서 뺀 변이다**(비전도, 구조적 0). 저항: `weights[저항] = (None, K(near_net), K(far_net))`.
- `vr_bounds` = {저항 → (lo, hi) 또는 None}, V_R = V(far) − V(near) 부호 그대로. None·키 없음 = 변 쌍 없음. **`I_R` 인자 없음.** `VrEdge`가 있으면 `weights`에 그 저항 키가 있어야 한다. 없으면 호출 계약 위반 `ValueError`.
- 변 u → v의 무게 w는 제약 x_v − x_u ≥ w를 뜻한다.
  - MOS: `lo_node → hi_node`, w = term + K_lo − K_hi.
  - 저항: `near_node → far_node`, w = lo + K(near) − K(far). `far_node → near_node`, w = −hi + K(far) − K(near).
- `feasible` = 양의 순환 없음(자기 고리 w > 0 포함). 가상 시작점 Bellman–Ford, 변 순서 = 필드 순서.
- `cycle`(불능일 때): 마디 수만큼 완화한 뒤 선행 그래프의 순환 가운데 무게 합(`violation` > 0)이 가장 큰 것, 동률이면 정준 순서 첫 순환. `edges`는 필드 순서가 가장 앞인 변에서 시작한다. `path_kind` = `F_STAR`가 순환에 있으면 `"via_f"`, 없으면 `"same_root"`. `theta_free` = 순환 모든 변의 `ends_theta`가 False. 저항 변 쌍이 순환에 있으면 `theta_free` False.
- 가능할 때: `node_lo`, `node_hi` = ((마디, 값 또는 None), ...) `F_STAR` 제외, `nodes` 순. `node_lo[n]` = `F_STAR` → n 최장 경로, `node_hi[n]` = −(n → `F_STAR` 최장 경로), 경로 없으면 None. `vr_lo[R]` = K(far) − K(near) + (near → far 최장 경로), `vr_hi[R]` = K(far) − K(near) − (far → near 최장 경로). 불능이면 네 칸 `()`. `vr_lo`·`vr_hi` = ((저항, 값 또는 None), ...) `vr_edges` 순, 경로 없으면 None. `vr_bounds`가 None이어도 식 그대로(K는 `weights[저항]`).

### 3.2 `j_point` 표

`view.ops` = {소자: `.current`, `.vds`를 가진 값(`DeviceOp`)}, `view.sat` = {소자: `SatBound`}, `view.floors` = {선언 triode 소자: `vds_floor`}, 풀이 실패면 `ops` 비고 `failure_*` 칸.

| # | 조건 | 결과 |
|---|---|---|
| 1 | `failure_reason == "no_root_in_window"` | `violated`, 행 (`"writer_root"`, `failure_node` 또는 `failure_device`와 맞는 `RootRow.net`, None), `reason` = `"chain_violation"` |
| 2 | 다른 `failure_reason` | `undefined`, `reason` = 그 사유, 행 없음 |
| 3 | 변 `term_kind == "off"` 또는 `op.current ≤ 0` | 행 없음. 이 소자에서 `view.sat`·`view.floors`를 읽지 않는다 |
| 4 | `"sat"`, `sat.reason == "reverse_vds"` | 행 (`"sat"`, 소자, None) |
| 5 | `"sat"`, `sat.vdsat_v` None(그 밖 사유) | 정의 불능 표지, `reason` = 그 사유 |
| 6 | `"sat"`, VDS < `vdsat_v` | 행 (`"sat"`, 소자, VDS − `vdsat_v`) |
| 7 | `"lut_floor"`, VDS < `floors[소자]` | 행 (`"lut_floor"`, 소자, VDS − floor) |

`state`: 행 ≥ 1 = `violated`(`reason` `"chain_violation"`), 아니고 정의 불능 ≥ 1 = `undefined`(변 순서 첫 사유), 아니면 `ok`(`reason` None). VDS = `vdsat_v` 정확히 = 위반 아님(문턱 없음). `tol_v`를 읽지 않는다.

**퇴화 등가**(H8): 모든 넷이 정해진 점에서 K = 그 점 전압, term = 표 값이면 `f_exist(...).feasible` ⇔ `j_point(...).state == "ok"`.

## 4. 칸 판정과 거르기 (`gmid_engine.search`)

```text
dc_prefix(sctx, theta) -> (snapshot | None, failure | None)    # θ = expand_ties를 거친 값, failure = FailureRecord
judge_rungs(sctx) -> None                                                      # build_search_context 끝에서 1회
loop_dependents(snapshot, conflicts, notes, *, donors, counters) -> GraphSnapshot   # writer "loop_dependents"
```

- **`dc_prefix`**: `evaluate`가 쓰는 DC 블록 열(`dc_columns`, `dc_widths`까지)을 같은 `donors`·`counters`로 돈다. 후보 실패 예외는 `failure`로 돌려준다. `sctx.counters["kernel_calls"]`·`["requests"]`·평가 예산 불변. `evaluate`와 **같은 블록 열 함수**를 지난다: `gmid_engine.sizing`의 커널 앞부분을 `run_kernel`과 `dc_prefix`가 함께 부른다(같은 `donors`·`counters`, `parent = None`, `w_request` 없음). `evaluate` 자체는 `dc_prefix`를 부르지 않는다. `memo.bound_state == "counting"`이면 여기서 창을 연다(`"window_open"`). 닫기는 첫 `evaluate` 끝 그대로다.
- `evaluate`와 입력이 같아야 graft가 성립한다(H11).
- **`judge_rungs`**: `sctx.rungs`의 칸마다 `layer0_start`와 같은 θ 조립(`centre_start`), 원뿔 밖 칸 = 판정 없음(기록 없음), `dc_prefix` → `j_point`. **`violated`이고 동작점이 있을 때만** `f_exist`를 한 번 부르고 그 반환을 `LoopConflict.exist`에 담는다(풀이 실패·`undefined` 칸 = None). `ok` 칸에서 `f_exist` 호출 0. 뒤 `loop_dependents`로 B1을 만들고 `sctx.dc.base`를 B1로 한 번 바꾼다. `rungs`가 None이면 빈 두 필드를 쓴다. `sctx.context_fp` 불변.
- **`f_exist` 입력**(그 칸 스냅샷 읽기, 호출 안에서 만들고 버린다).
  - V(net) = 레일이면 `node.dc_rail_v`, 아니면 `node.dc_v`. K(net) = V(net) − (넷의 마디가 `F_STAR`면 0, 아니면 V(마디 넷)).
  - MOS 변: `on_structural`이고 `op.current > 0`이면 `weights[소자]` = (term, K(lo_net), K(hi_net)). term = `sat`이면 `sat.vdsat_v`, `lut_floor`이면 `vds_floor`.
  - **`vdsat_v`가 None인 변은 `weights`에 넣지 않는다**(대체값 없음. `reverse_vds`는 `rows` 행, 그 밖 사유는 정의 불능 표지).
  - 저항: `weights[저항]` = (None, K(near_net), K(far_net)). `vr_bounds[저항]` = (min, max) of I·R, R ∈ θ 저항 상자(묶음 구성원은 대표의 상자, `domain.ties`), I = 그 칸 `far → near` 방향 전류. `device.dc_current`의 저항 양의 방향 = t0 → t1(첫 단자 → 둘째 단자)이므로 far → near로 환산한다(부호는 착수 때 base에서 확인, 미측정). 값이 θ로 고정된 칸이어도 구간은 상자로 준다(HC:220).
- **필드**(`graph/start`, `START_KEY`): `graph.loop_conflicts` = `LoopConflict` tuple(위반·정의 불능 칸만), `graph.loop_stack_notes` = ((칸, X, Y, `lhs_max`, `gap_v`), ...), 값 = `StackJudge` 칸 그대로. `off` 선언 Y는 판정하지 않는다. `graph.rungs` 비트 동일.
- **`SearchContext.loop_conflicts`**: `self.dc.base.field("graph", START_KEY, "loop_conflicts")` 꼴로 읽는 속성(`rungs`와 같음). 새 슬롯 아님.
- **`layer0_start`**: `loop_conflicts`에 있는 칸은 `evaluate`를 부르지 않는다. `start_status = "chain_filtered"`, `Layer0Result.chain_filtered` = 그 칸 번호. 전 칸이 걸리면 기록하고 순회 뒤 단계로 간다. 재판정 0. 관찰 지점 = 모듈 전역 이름 `gmid_engine.search.layer0_center.evaluate`.
- **결과 JSON**(`find_front`의 `notes`): 언제나 한 줄 `{"verdict": "chain_start", "rule": "R-1'", "chain_filtered": [...], "loop_conflicts": [...], "stack_notes": [...], "chain_cuts": [...]}`. 무동작 회로 = 넷 다 빈 목록. `loop_conflicts` 항목 = `{"rung", "state", "rows", "reason", "feasible", "cycle", "node_lo", "node_hi", "vr_lo", "vr_hi"}`, `cycle` = `{"edges": [...], "path_kind", "theta_free", "violation"}` 또는 null, 나머지는 `exist` 칸 값 그대로(tuple은 목록), `exist` None이면 뒤 여섯 null. `chain_cuts` 항목 = `{"component", "side", "value", "device", "reason"}`. front 점 기록에 칸 `"triode_region"` = 선언 triode마다 `{"device", "region", "protected_none", "vds_v", "vdsat_v"}`, 뒤 둘 = `device.dc_op.vds`, `device.dc_sat_v.vdsat_v` 읽기(없으면 빈 목록).
- **출력 함수**(규칙 L 표기): `search/find_front.py:_chain_start_note`, `search/find_front.py:_triode_rows`.

### 4.1 단좌표 자르기

```text
chain_cut(edge, component, cells, anchors, margin_of, tol) -> (cells′, records)     # gmid_engine.sizing, records = ChainCut tuple
```

`cells` = ((lo, hi), ...), `anchors` = 그 좌표의 꺾임점(L이면 LUT L 앵커, 그 밖 `()`), `margin_of(c)` = g(c) = V(hi) − V(lo) − term 또는 None, `tol` = 호출자가 주는 선언 값. **표본 = 칸마다 칸 끝 ∪ 칸 안 앵커**, 오름차순. 칸 안 g는 앵커 사이에서 L 선형이므로 표본 부호로 만족 집합이 정해진다. `bracket_root`에 `None`을 넘기지 않는다: 근 찾기 중 `margin_of`가 `None`이면 행 1과 같이 칸 불변 + `cut_undefined`. 위에서 아래로 첫 맞는 행:

| # | 조건 | `cells′` | `records` |
|---|---|---|---|
| 1 | 표본에 None | 그대로 | (`reason = "cut_undefined"`) |
| 2 | 모든 표본 g ≥ 0 | 그대로 | `()` |
| 3 | 모든 표본 g < 0 | 그대로 | (`reason = "cut_empty"`) |
| 4 | 만족 집합이 연속한 한 구간 아님 | 그대로 | (`reason = "cut_not_interval"`) |
| 5 | 나머지 | 전부 위반인 칸 삭제, 부호가 바뀌는 앵커 구간마다 근을 내어 그 칸 끝으로 한다(한 칸 안에서 양쪽 다 좁아질 수 있다) | 줄어든 쪽마다 (`component`, `"lo"`/`"hi"`, 근, `edge.device`, None). 칸을 통째로 지우면 기록 값 = 남은 끝 |

`search_domain`: `route == "cut"`이고 **`on_structural`인 변**마다 부른다. 좌표가 `("L", m)`이면 대상 = `SearchDomain.l_cells`의 m 칸, `tol` = `SearchDomain.grid_m`. `margin_of(c)` = V(hi) − V(lo) − term. V = 그 넷의 F 값(`steps` 없는 뿌리 값, θ 무관). term = `sat`이면 `sat_threshold(memo, kind, w_key, c, vgs, vds, vsb).vdsat_v`(`None`이면 g = `None`), `lut_floor`이면 `vds_floor`. 줄면 `chain_cuts`에 적는다. 좌표가 그 밖이거나 `m`이 `l_cells`에 없으면(묶음 구성원) `chain_cuts`에 `reason = "coordinate_not_in_box"`.

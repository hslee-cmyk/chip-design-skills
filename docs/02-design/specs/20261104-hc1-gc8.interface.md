- `lo_net`·`hi_net` = 표 2.1. `lo_node`·`hi_node` = 그 넷의 마디: `root_kind == "F"`이면 `F_STAR`, `"W4"`이면 `root_net`. 단 뿌리 → 넷 경로에 값 미선언 저항이 있으면 넷에 가장 가까운 그 저항의 `far_net`이다(HC:220 차분 변 쌍의 마디).

- `on_structural` = `off` 선언 아님 그리고 `("current", device)`가 `dc_current_symmetry.zeros`에 없음. 변을 지우지 않는다.
- `coords` = 정렬 tuple. θ 성분 `(kind, key)`: 양 끝 넷 `steps`에 든 MOS의 `("ln_idu", m)`(그 MOS가 writer일 때)·`("L", m)`, θ 저항 `("resistance", r)`, 양 끝 넷 뿌리의 W4 `("y", y 키)`, 소자 자신의 `("L", 소자)`와 writer면 `("ln_idu", 소자)`, 소자 source 넷 경로의 같은 좌표. L 동치류는 주인 성분으로 센다.
- `route` = 좌표 1개 `"cut"`, 2개 이상 `"filter"`, 0개 `"none"`.
- `ends_theta`([E-2]) = 양 끝 넷의 `steps`에서 공통 앞부분을 뺀 나머지가 하나라도 있으면 True.
- `vr_edges` = 값 미선언 DC 경로 저항(`I_R` 구조적 0 제외)마다 `VrEdge(저항, 뿌리에서 먼 넷, 가까운 넷, 먼 넷 마디, 가까운 넷 마디)`. `root_rows` = `dc_self_referential` 소자마다 `RootRow(소자, 그 소자가 쓰는 넷)`.
- `nodes` = `F_STAR` + 변에 나오는 나머지 마디, `dc_colour` 순.

**손 값**(`circuit_cs_pmos_load()`): 변 M1 = (`gnd`,`out`,`F_STAR`,`"out"`,`"sat"`,True, (`("L","M1")`,`("ln_idu","M1")`,`("y","out")`),`"filter"`,False), M2 = (`out`,`vdd`,`"out"`,`F_STAR`,`"sat"`,True, (`("L","M2")`,`("ln_idu","M2")`,`("y","out")`),`"filter"`,False). `vr_edges = ()`, `root_rows = ()`.

**손 값**(`circuit_cs_res()`, R1 값 미선언, `engine_elements=("R1",)`): `vr_edges = (VrEdge("R1","out","vdd","out",F_STAR),)`, M1 `hi_node == "out"`. R1 값 선언(`element_values=(("R1",v),)`): `vr_edges = ()`, M1 `hi_node == F_STAR`.

### 2.4 `graph: triode_protected`, `graph: stack_candidates`

- `triode_protected` = ((X, (Z, ...)), ...): X = 선언 triode. Gs⁺ = `dc_vgs_edge` 변 + 저항 변. Z = 지우기 전 Z.drain과 Z.source가 이어지고 X 변을 지우면 끊어지는 MOS(Z ≠ X). 지우기 전에 안 이어진 Z는 넣지 않는다.
- `stack_candidates`(S1, `build_s1`이 쓴다) = ((X, Y), ...): kind 같음, gate 넷 같음, Y.source 넷 = X.drain 넷. 이름 정렬.

## 3. 판정 함수 (`gmid_engine.sizing`)

```text
f_exist(chain, weights, vr_bounds) -> ChainExist
j_point(chain, view) -> ChainVerdict
```

### 3.1 `f_exist` 닫힌 식

- `weights` = {변 이름 → (term, K_lo, K_hi)}. MOS 변: term = 항, K = V_known(lo_net), V_known(hi_net). **`weights`에 없는 MOS 변은 그 평가에서 뺀 변이다**(비전도, 구조적 0). [E-3] 저항: `weights[저항] = (None, K(near_net), K(far_net))`.
- `vr_bounds` = {저항 → (lo, hi) 또는 None}, V_R = V(far) − V(near) 부호 그대로. None·키 없음 = 변 쌍 없음. **`I_R` 인자 없음.**
- 변 u → v의 무게 w는 제약 x_v − x_u ≥ w를 뜻한다.
  - MOS: `lo_node → hi_node`, w = term + K_lo − K_hi.
  - 저항: `near_node → far_node`, w = lo + K(near) − K(far). `far_node → near_node`, w = −hi + K(far) − K(near).
- `feasible` = 양의 순환 없음(자기 고리 w > 0 포함). 가상 시작점 Bellman–Ford, 변 순서 = 필드 순서.
- `cycle`(불능일 때): 마디 수만큼 완화한 뒤 선행 그래프의 순환 가운데 무게 합(`violation` > 0)이 가장 큰 것, 동률이면 정준 순서 첫 순환. `edges`는 필드 순서가 가장 앞인 변에서 시작한다. `path_kind` = `F_STAR`가 순환에 있으면 `"via_f"`, 없으면 `"same_root"`. `theta_free`([E-2]) = 순환 모든 변의 `ends_theta`가 False. 저항 변 쌍이 순환에 있으면 `theta_free` False.
- 가능할 때: `node_lo`, `node_hi` = ((마디, 값 또는 None), ...) `F_STAR` 제외, `nodes` 순. `node_lo[n]` = `F_STAR` → n 최장 경로, `node_hi[n]` = −(n → `F_STAR` 최장 경로), 경로 없으면 None. `vr_lo[R]` = K(far) − K(near) + (near → far 최장 경로), `vr_hi[R]` = K(far) − K(near) − (far → near 최장 경로). 불능이면 네 칸 `()`.

### 3.2 `j_point` 표

`view.ops` = {소자: `.current`, `.vds`를 가진 값(`DeviceOp`)}, `view.sat` = {소자: `SatBound`}, `view.floors` = {선언 triode 소자: `vds_floor`}, 풀이 실패면 `ops` 비고 `failure_*` 칸.

| # | 조건 | 결과 |
|---|---|---|
| 1 | `failure_reason == "no_root_in_window"` | `violated`, 행 (`"writer_root"`, `failure_node` 또는 `failure_device`와 맞는 `RootRow.net`, None), `reason` = `"chain_violation"` |
| 2 | 다른 `failure_reason` | `undefined`, `reason` = 그 사유, 행 없음 |
| 3 | 변 `term_kind == "off"` 또는 `op.current ≤ 0` | 행 없음. 이 소자에서 `view.sat`·`view.floors`를 읽지 않는다 |
| 4 | `"sat"`, `sat.reason == "reverse_vds"` | 행 (`"sat"`, 소자, None) |
| 5 | `"sat"`, `sat.vdsat_v` None(그 밖 사유) | 정의 불능 표지, `reason` = 그 사유 |
| 6 | `"sat"`, VDS < `vdsat_v` | 행 (`"sat"`, 소자, VDS − `vdsat_v`) |
| 7 | `"lut_floor"`, VDS < `floors[소자]` | 행 (`"lut_floor"`, 소자, VDS − floor) |

`state`: 행 ≥ 1 = `violated`(`reason` `"chain_violation"`), 아니고 정의 불능 ≥ 1 = `undefined`(변 순서 첫 사유), 아니면 `ok`(`reason` None). VDS = `vdsat_v` 정확히 = 위반 아님(문턱 없음). `tol_v`를 읽지 않는다.

**퇴화 등가**(H8): 모든 넷이 정해진 점에서 K = 그 점 전압, term = 표 값이면 `f_exist(...).feasible` ⇔ `j_point(...).state == "ok"`.

## 4. 칸 판정과 거르기 (`gmid_engine.search`)

```text
dc_prefix(sctx, theta, cells, origin) -> (snapshot | None, failure | None)    # failure = FailureRecord
judge_rungs(sctx) -> None                                                      # build_search_context 끝에서 1회
loop_dependents(snapshot, conflicts, notes, *, donors, counters) -> GraphSnapshot   # writer "loop_dependents"
```

- **`dc_prefix`**: `evaluate`가 쓰는 DC 블록 열(`dc_columns`, `dc_widths`까지)을 같은 `donors`·`counters`로 돈다. 후보 실패 예외는 `failure`로 돌려준다. `sctx.counters["kernel_calls"]`·`["requests"]`·평가 예산 불변. `evaluate`도 같은 길을 지난다.
- **`judge_rungs`**: `sctx.rungs`의 칸마다 `layer0_start`와 같은 θ 조립(`centre_start`), 원뿔 밖 칸 = 판정 없음(기록 없음), `dc_prefix` → `j_point`. **`violated`이고 동작점이 있을 때만** `f_exist`를 한 번 부른다. `ok` 칸에서 `f_exist` 호출 0. 뒤 `loop_dependents`로 B1을 만들고 `sctx.dc.base`를 B1로 한 번 바꾼다. `rungs`가 None이면 빈 두 필드를 쓴다. `sctx.context_fp` 불변.
- **필드**(`graph/start`, `START_KEY`): `graph.loop_conflicts` = `LoopConflict` tuple(위반·정의 불능 칸만), `graph.loop_stack_notes` = ((칸, X, Y, lhs_max, rhs), ...). `graph.rungs` 비트 동일.
- **`SearchContext.loop_conflicts`**: 그 필드를 읽는 속성. 새 슬롯 아님.
- **`layer0_start`**: `loop_conflicts`에 있는 칸은 `evaluate`를 부르지 않는다. `start_status = "chain_filtered"`, `Layer0Result.chain_filtered` = 그 칸 번호. 전 칸이 걸리면 기록하고 순회 뒤 단계로 간다. 재판정 0. 관찰 지점 = 모듈 전역 이름 `gmid_engine.search.layer0_center.evaluate`.
- **결과 JSON**(`find_front`의 `notes`): 언제나 한 줄 `{"verdict": "chain_start", "rule": "R-1'", "chain_filtered": [...], "loop_conflicts": [...], "stack_notes": [...], "chain_cuts": [...]}`. 무동작 회로 = 넷 다 빈 목록. front 점 기록에 칸 `"triode_region"`(선언 triode 없으면 빈 목록).

### 4.1 단좌표 자르기 [E-4 채택 전제]

```text
chain_cut(edge, component, cells, margin_of, tol) -> (cells′, records)     # gmid_engine.sizing, records = ChainCut tuple
```

`cells` = ((lo, hi), ...), `margin_of(c)` = g(c) = V(hi) − V(lo) − term 또는 None, `tol` = 호출자가 주는 선언 값. 칸 끝 표본으로 판정한다. 위에서 아래로 첫 맞는 행:

| # | 조건 | `cells′` | `records` |
|---|---|---|---|
| 1 | 표본에 None | 그대로 | (`reason = "cut_undefined"`) |
| 2 | 모든 끝 g ≥ 0 | 그대로 | `()` |
| 3 | 모든 끝 g < 0 | 그대로 | (`reason = "cut_empty"`) |
| 4 | 만족 집합이 연속한 한 구간 아님 | 그대로 | (`reason = "cut_not_interval"`) |
| 5 | 나머지 | 전부 위반 칸 삭제, 교차 칸 끝 = 근 | 줄어든 쪽마다 (`component`, `"lo"`/`"hi"`, 근, `edge.device`, None) |

`search_domain`: `route == "cut"`인 변마다 부른다. 좌표가 `("L", m)`이면 대상 = `SearchDomain.l_cells`의 m 칸, `tol` = `SearchDomain.grid_m`. 줄면 `chain_cuts`에 적는다. 좌표가 그 밖이면 `chain_cuts`에 `reason = "coordinate_not_in_box"`.

## 5. 봉인 (`gmid_engine.sizing`, `gmid_engine.lut`)

```text
stack_unsat(memo, kind, w_key, vgs_y, vsb_x) -> StackJudge
dc_seal_triode(snapshot, lut, *, donors, counters) -> GraphSnapshot    # writer "dc_seal_triode"
```

**`stack_unsat` 닫힌 식**: lhs(L, VGS) = VGS − VDsat(L, VGS, VDS = VGS − vgs_y, vsb_x), L·VGS = LUT 축 격자점, VDS < 0인 점 제외. VDS·VS 축은 선형 보간. `lhs_max` = 최댓값, `rhs` = `vgs_y`, `holds` = `lhs_max < rhs`. 모든 점이 제외면 `holds` True, `lhs_max` None. VDSAT 열 없음 = `holds` False, `lhs_max` None. 범위 = LUT 정의역 전체(상자를 읽지 않는다).

`R4_VDSAT["nmos"]` (c0, c1, c2, cs, cl) = (0.0625, 0.25, 0.25, 0.125, 0.0625), VDSAT = c0 + c1·VGS + c2·VGS² + cs·VS + cl·iL에서 손 값:

|---|---|---|---|---|---|---|
| R-1 | 0.75 | 0 | 0.5 | `R4_L[0]` | 1.5 | True |
| R-2 | 0.5 | 0 | 0.5 | `R4_L[0]` | 1.5 | False(`rhs` = `lhs_max`, 부등호 엄격) |

| R-4 | 0.75 | 0.25 | 0.46875 | `R4_L[0]` | 1.5 | True |

## 6. `iv_headroom`과 GC-8

### 6.1 HC-1 커밋: `iv_headroom`

- VDS 방향 = `chain.edges`, VGS 방향 = `dc_vgs_edge`. 구조적 전도 = `on_structural`. `on_structural` False인 소자는 예산 행 없음.
- `headroom_bounds(ctx, lengths, budgets=None).inactive`: 창이 미상이라 뺀 예산 행의 경계 식마다 (`SRC_HEADROOM_VDSAT` 또는 `SRC_HEADROOM_VGS`, `WHY_WINDOW_UNKNOWN`), 정렬·중복 없음. 대체값 없음.
- 모든 MOS에 `off`·구조적 0이 없으면 결과 불변.

### 6.2 GC-8 커밋

```text
order_terms(chain) -> {net: ((is_lower, other_net), ...)}        # gmid_engine.sizing, 순수 함수
headroom_bound(local, rail_v, costs, chain, vgs_edges, windows, constraints, input_dc_v, differential_out) -> HeadroomResult
EdgeCost.vds_edge_floor_v                                        # 옛 vds_min_v, 값 정의는 HC-S 그대로
```

**`order_terms`**: `on_structural`인 변마다 필드 순서로 `hi_net`에 `(True, lo_net)`, `lo_net`에 `(False, hi_net)`. `term_kind`를 읽지 않는다.

손 값: 변 A(lo `a`, hi `b`, sat), T(lo `b`, hi `c`, lut_floor), O(lo `c`, hi `d`, off, `on_structural` False). → `{a: ((False,"b"),), b: ((True,"a"),(False,"c")), c: ((True,"b"),)}`, `d` 없음.

**`headroom_bound`**: 변 = `chain.edges` 순서로 `device ∈ local`이고 `on_structural`인 소자. VDS 변 비용 = `sat`이면 `costs[kind].vds_edge_floor_v`, `lut_floor`이면 0. VGS 변 = `vgs_edges[소자]`, 비용 = `costs[kind].vgs_min_v`. `kind` = `local.kind[소자]`. **LUT 정의역 하한 값을 읽지 않는다.** 창 식은 그대로: [max(레일 최저, L(n)), min(레일 최고, U(n))], `L` = 레일 + 비용 합 최장, `U` = 레일 − 비용 합 최단.

**창 미상 [E-7 채택 전제]**: `on_structural` False 변의 끝 넷인데 위쪽 또는 아래쪽 경로가 없으면 그 행 `status = STATUS_UNKNOWN`. 다른 넷의 경로 없음은 지금처럼 `STATUS_CERTIFIED`(레일 끝이 상한).

| id | 입력(레일 gnd 0, vdd 1.8, 비용 nmos vds 0.2·vgs 0.5, pmos vds 0.3·vgs 0.6) | 기대(창 `n`) |
|---|---|---|
| G-a | M1 nmos `gnd → n` sat, M2 pmos `n → vdd` sat, VGS 변 M1 `gnd → g1`, M2 `g2 → vdd` | `lo_edge_v` 0.2, `hi_edge_v` 1.5, 폭 1.3 |
| G-b | G-a에서 M1 `lut_floor`(floor를 어떤 값으로 줘도 같음) | `lo_edge_v` 0, `hi_edge_v` 1.5, 폭 1.5. base = 1.3이라 red |
| G-c | G-a에서 M1 `off`, `on_structural` False | M1 변 없음. `status == STATUS_UNKNOWN` [E-7], `hi_edge_v` 1.5 |
| G-d | G-a를 이름 전단사 | 같은 창 |

**`vds_edge_floor_v` 손 값**: HC-S card S7 표 그대로, 칸 이름만 바뀐다. `vds_min_v` 이름 grep 0.

3. **출발**: `wf_start` = 칸마다 `WfCell(members, w_key | None)`, 선택 규칙 (i) W_c 이하 가장 넓은 정의 후보 (ii) 없으면 가장 좁은 정의 후보 (iii) 없으면 None + 기록 `wf_start_undefined`{members, why ∈ {`reference_slice_undefined`, `no_member_density`, `no_defined_candidate`, `reference_start_undefined`}}, margin null. 짝 없는 비쓰기 단일 멤버 칸(I_i 있음) = 그 kind 기준 폭 슬라이스 키(후보 집합 안 + 출발 L의 L 위치 판정 -- VGS·VDS·VSB 안 읽음; 아니면 `reference_start_undefined`) + 기록 `wf_start_reference`{members, w_key}(출력 전용), 다멤버 칸의 짝 없음 = `no_member_density`(v6.39.5). 한 번만(8단계 전류 되먹임 0). 출발 블록은 뷰 유무와 무관하게 늘 실행(v6.39.5).
4. **평가 입력**: `WfInput(cells_ref, keys)` 필수, 평가 키 = (context_fp, schema_fp, L 칸, `wf` 지문, w_fixed_fp, θ) -- 같은 θ·다른 키 = 다른 키.
5. **탐색 평가**: 정수 m 0(`dc_finger.m` = W/w_f, residual 0.0), 노드 풀이 평가당 1회, 슬라이스 = 칸 키(소자별 선택 0). 칸 멤버 하나라도 그 슬라이스에서 조회 불능이면 그 평가 실패(`lut_axis_out_of_range` 등 기존 사유 -- 다른 슬라이스 0).
6. **실현 평가**: m = `realize_fingers`(칸 단위), W′ = m·w_f, `dc_finger` = (정수 m, m·w_f/W_θ − 1), 키 = (평가 입력 지문, 실현 표지).
7. **실현 정수화**: 키 K = (E1, E2, E3, E4, E5) 사전식 최소 -- 계산 꼴·부동소수 꼴은 interface §1(card 고정).
8. **이웃 시험**: front 점에만, L 칸 다음 w_f 칸, 칸마다 후보 목록 바로 아래·위, 수락·종료 = (L-b) 하나.
9. **graph**: 새 필드 = `wf_start` 하나(writer `start_intervals`), `dc_finger` writer = `dc_solve` 하나, 폐포 계산 자리 하나, 새 cache·sctx 슬롯 0.
10. **삭제**: `finger_slice`·`FingerSlice`·`reachable_slices`·`slice_cycle`·`REASON_SLICE_CYCLE`·`slice_rounds`·`RealizedFinger`·`polish_l_cells`·`FingerGeom.w_f_m` 정의·호출 0.

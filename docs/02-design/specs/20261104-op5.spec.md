### 꼬리 정의(A-24, D §18.3)

정의는 PSD S [V²/Hz]의 적분 I(f0) = ∫ S df와 꼬리 상계 T.

1. n̂ = 마지막 격자 구간의 −Δln S/Δln f, n̂_앞 = 바로 앞 구간.
2. **검사**: n̂ ≥ n̂_앞 − δ `[C-4]`, n̂ > 1. δ = 8u/Δ, u = 그 파일 자릿수 반 단위(`Resolution.data_rel`), Δ = 마지막 구간 Δln f. 어기면 `noise_tail_bound_undefined`, 값 없음.
3. T(f0) = S(f0)·f0/(n̂ − 1). 유도: S(f) ≤ S(f0)(f0/f)^n̂의 f0~∞ 적분.
4. ε = r², r = `noise.rel_resolution`, 없으면 reltol. **T(f0) ≤ ε·I(f0)**이면 f_hi = f0, 격자 불변.
5. 넘으면 f_hi = f0·(S(f0)·f0/((n̂ − 1)·ε·I(f0)))^(1/(n̂ − 1)), 한 번만 다시 잰다. 다시 잰 값에서 부등식이 틀리면 같은 사유로 거부, 반복 없음.
6. 격자: |I_k − I_(k−1)| ≤ reltol·I_k까지 2배. 상한 = ⌈log_2(최대 점 수/시작 점 수)⌉ `[C-7]`. 못 맞추면 `noise_grid_unresolved`.

**비교 분류**(A-24): `top_extensions = 0`이고 T ≤ ε·I인 입력 = 비트 동일 대상. 옛 상한 안 확장 입력과 n̂ ≠ 2로 판정이 갈리는 입력 = '정의를 바꾼 칸', 변화표에 입력마다 원인을 적는다. 첫 f_top 평탄 구간 거부는 fail-closed.

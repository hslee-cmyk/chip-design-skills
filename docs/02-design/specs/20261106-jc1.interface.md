## 1. `junction_at_vgs_min(memo, device, kind, L, vds, vsb, geometry, reference) -> (cdb, csb)` (`gmid_engine.metrics` 공개)

입력: `memo` = lut `LutMemo`(그 `.lut` = `LutSet`), `device` = 소자 이름(정지 기록용), `kind`, (L, vds, vsb) = 그 소자 봉인점 값(LUT 부호 규약 크기 -- 켜진 점 `caps` 조회와 같은 인자), `geometry`·`reference` = `metrics.DiffusionGeometry`(그 평가 기하 / 그 kind LUT 생성 기하 손가락 하나). 순수 함수(memo 밖 상태 0).

**계산(이 순서 그대로 -- 기대값도 이 연산 순서로 float 계산해 `==` 비교, 허용오차 상수 0)**:
1. `table = memo.lut.cap_map[kind]`, `g0 = min(table.grids[1])`(기준 폭 표 VGS 축 첫 값).
2. 열 판별(열 단위, 이 순서): 표에 CDD 열 없음 → `SealViolationError` detail `{reason: "lut_column_unavailable", column: "CDD", kind}`(`devices` 빈 값); CSS 열 없음 → `column: "CSS"`; CGS 열 없음 → `column: "CGS"`(CGB 결손과 섞지 않음 -- CGS 대신 CGG − CGD를 쓰지 않는다).
3. `c = caps(memo, kind, L, g0, vds, vsb, reference.finger_w_m)`(`reference.finger_w_m` = 그 kind `w_ref_m`이라 배율 1). L·축 실패는 `caps`의 기존 사유 그대로.
4. `r_d = (geometry.ad_m2 * geometry.m) / (reference.ad_m2 * reference.m)`, `r_s = (geometry.as_m2 * geometry.m) / (reference.as_m2 * reference.m)`; `cdb = (c.cdd - c.cgd) * r_d`, `csb = (c.css - c.cgs) * r_s`.
5. **음수 관문**: `not (cdb >= 0)`(음수·NaN)이면 `SealViolationError(devices=(device,), detail={reason: "junction_cap_negative", terminal: "d", value: cdb})`; 이어 csb 같은 꼴(`terminal: "s"`). d 먼저. 통과하면 `(cdb, csb)`.

분기·문턱·클램프는 5의 부호 관문 하나뿐이다(VDS 첫 마디·긴 L·좁은 폭도 같은 식).

**toy C(기준 폭 표 손 열)**: `tests/lut/conftest.py` `ToyBuild`에 슬라이스(기존 `toy_slice_arrays` 꼴)와 기준 폭 표 dict를 직접 준다. **VGS 축은 0에서 시작하지 않는다**: 슬라이스·기준 폭 표 모두 VGS = (0.25, 0.5, 1.0)(적재 관문 = 슬라이스와 기준 표 L·VGS·VDS 축이 같아야 함; 슬라이스 열은 기존 r5 toy 닫힌 식을 이 격자에서 계산). L = `TOY_L`, VDS = `TOY_VDS`(0.5, 1.0), VS = `TOY_VS`(0, 0.5), `w_ref_m` = 1e-6. 기준 표 열(접미사 `_n`, 모양 [3, 3, 2, 2], 인덱스 (l, g, d, s)) = 아래 손 식(F):
- `CGG = (16 + l + 2g + d + s)·1e-16`, `CGD = (2 + g + d)·1e-16`, `CGS = (3 + g + s)·1e-16`, `CGB = (1 + l)·1e-16`
- `CDD = (9 + l + 3g + 2d + s)·1e-16`, `CSS = (11 + 2l + g + d + 3s)·1e-16`
그러면 g = 0(VGS 0.25) 마디에서 CDD − CGD = (7 + l + d + s)·1e-16 > 0, CSS − CGS = (8 + 2l + d + 2s)·1e-16 > 0. 조회점은 **격자 마디**(L ∈ `TOY_L`, vds ∈ `TOY_VDS`, vsb ∈ `TOY_VS`)로 둔다 -- 마디 조회는 표 값 그대로다(전제 C-0: `caps(memo, "nmos", L, 0.25, vds, vsb, 1e-6).cdd` == 표 CDD 마디 값; 안 서면 멈추고 보고). LUT 생성 규칙 선언 toy = `lut_diffusion_ad_per_w_m` = `a`, `as_per_w_m` = `b`, `pd_extra_m`·`ps_extra_m` 임의(> 0)(기존 `tests/metrics/test_junction_source.py`·`test_junction_field.py`의 toy 선언 꼴); 기준 기하 손 값 = `DiffusionGeometry(1e-6, a*1e-6, b*1e-6, 1e-6 + pd_extra, 1e-6 + ps_extra, 1.0)`(생성자 직접 -- `from_lut_rule`로 만들지 않음).

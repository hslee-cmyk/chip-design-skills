## 2. 형식

선언 = `lut_bin_rule/1`, 칸 뜻 D §16. 기술자 칸(선택, 닫힌 키에 더함):

```json
"bin_rule_decl": {"path": "<기술자 폴더 기준 또는 절대>", "sha256": "<LF>"}
```

어댑터 능력:

```python

```

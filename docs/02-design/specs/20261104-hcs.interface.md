# HC-S 포화 기준 단일화 interface card (card id `20261104-hcs`)

- 작성 2026-11-04, 독립 판정 전. **card base = GL-1·IT-1 + IT-2·EO-1 범위 4·card C를 포함한 master**(오케스트레이터가 sha를 적는다).
- **test 작성 주체는 엔진 소스를 보지 않고 이 문서만 쓴다.** 기존 test·conftest는 읽어도 된다. 피검 함수로 기대값을 만들지 않는다.
- `E/` = `skills/analog-gmid-design/gmid_engine/`. import는 패키지 공개 이름으로만 한다.
- 근거 판: HC-D v0.1.2, 계획 v6.38.10, design v1.16.6(위임 A-46·A-49).

## 1. 정본 함수 (`gmid_engine.lut`)

```text
SatBound(vdsat_v, tol_v, reason)                                       # frozen dataclass
REASON_REVERSE_VDS = "reverse_vds"
REASON_VDSAT_COLUMN_UNAVAILABLE = "vdsat_column_unavailable"
REASON_LUT_DOMAIN = "lut_domain"
REASON_OFF_DECLARED = "off_declared"                                   # 필드 쪽에서만
sat_threshold(memo, kind, w_key, L, vgs, vds, vsb) -> SatBound
sat_threshold_grid(memo, kind, w_key) -> ndarray | None                # 축 (L, VGS, VDS, VS), 열 없으면 None
derived(memo, "vds_floor", kind, w_key) -> float                       # 옛 sizing 안 함수
```

위에서 아래로 첫 맞는 행:

| # | 조건 | `vdsat_v` | `tol_v` | `reason` |
|---|---|---|---|---|
| 1 | vds < 0 | None | None | `reverse_vds`, **LUT 조회 0** |
| 2 | VDSAT 열 없음 | None | None | `vdsat_column_unavailable` |
| 3 | L 위치·축 밖(`SealViolationError`) | None | None | `lut_domain` |
| 4 | 값 있음, tol 셀 None | `vdsat(...)` | None | None |
| 5 | 값 있음 | `vdsat(...)` | `tol_vdsat_table(memo, kind, w_key).at(L, vds)` | None |

- `vdsat`·`tol_vdsat_table`은 lut 공개 함수이고 test가 기대값 출처로 쓸 수 있다(별도 test 대상). 합성 LUT 닫힌 식 = conftest `r4_vdsat_at`, `r4_tol_vdsat`.
- 슬라이스 없음(`KeyError`)과 모르는 실패 사유는 다시 던진다. 0으로 바꾸지 않는다.
- `DERIVED_TABLES`에 `"vds_floor"`가 든다(기존 항목 뒤).
- `vds_floor` = `on_mask`가 그 VDS 열부터 끝 열까지 모든 (L, VGS, VS)에서 참인 첫 VDS 격자값, 없으면 VDS 격자 최소. 닫힌 식 = conftest `r4_vds_floor`.

ΔX = 0이면 `sat_threshold` 호출 0. s′ 식은 `20261104-eo1r4-sf1l` interface §4 그대로. `vdsat_v` None(사유 `reverse_vds`, `triode`만 도달) = EO-1 §4 그대로 `OUT_OF_DOMAIN`, `sat_threshold` 호출 0 |

## 3. 곡선과 `edge_costs` (`gmid_engine.search`, `gmid_engine.lut`)

**`derived(memo, "edge_costs", kind, w_key).vds_min_v`**: 포화 가능 격자점 = 전도·분지 마스크(분지 = on_mask ∧ VGS ≥ 같은 (L, VDS, VS)에서 gm/ID 최대인 VGS 마디)가 참이고 그 격자 VDS 축 값 ≥ 같은 점 `sat_threshold_grid`인 점. `vds_min_v` = 그 점들의 VDSAT 최솟값. tol 합 없음. 열 없음 → `vds_min_v` = 0.0, 포화 거르기 없음. VGS 비용 포화 술어도 VDS ≥ VDSAT(tol 없음), 전도·`id_equivalent` 조건은 그대로.

**`headroom_bounds(ctx, lengths, budgets=None)`**: VDS 엣지 하한 gm/ID = `hull(curve.gm_id, curve.values, budget, below=True)`, `level` = budget 그대로. 열 없음 → 그 VDS 경계 없음, 결과 `inactive`에 (`gmid_engine.search.start_values.SRC_HEADROOM_VDSAT`, `"vdsat_column_unavailable"`). 대체값 없음.

**`domain_bounds(ctx, lengths, vds_budget)`**: 그 gm/ID 마디의 VDS 탐침 = VDSAT 값을 VDS 격자 위로 올린 값(tol 없음). 열 없음 → 그 소자 곡선 경계 비활성(기존 `curve_bundle_of` None 경로), 정의 불능을 0으로 바꾸지 않음.

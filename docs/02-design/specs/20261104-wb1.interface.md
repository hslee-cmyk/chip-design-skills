## 1. bin 판정과 선언 (`gmid_engine.lut`, `gmid_engine.core`, 커밋 1)

```text
file_sha256(path) -> str                 # gmid_engine.core. sha256(바이트의 CRLF → LF). 파일 없음 = FileNotFoundError
bin_index(intervals, x, grid_m, rule)    # gmid_engine.lut._helpers_bins. -> int | None
l_position(l_grid, l_bins, L, grid_m, rule, context=())   # gmid_engine.lut._helpers_anchor. 반환 그대로 (lo, hi, l_value)
widths(lut, kind)                        # 서명 불변, w_key >= round(w_min / grid) 정수 비교
resolve_lut_location(config_path, env)   # LutLocation.bin_rule_path 칸 추가(끝, 기본 None)
```

**`bin_index`.** 각 값을 `round(값 / grid_m)`로 정수화해 닫힌 구간끼리 비교한다. 품는 구간이 없으면 None, 하나면 그 index, 둘이면 `rule` = `"lower"` 앞 구간, `"upper"` 뒤 구간. `intervals`는 lo 오름차순.

| g | intervals | x | rule | 결과 | base |
|---|---|---|---|---|---|
| 5e-9 | ((3e-6, 5e-6), (5e-6, 7e-6)) | 4.9999999999999996e-06 | lower | 0 | |
| 5e-9 | 같음 | 4.9999999999999996e-06 | upper | 1 | red |
| 5e-9 | 같음 | 7.5e-6 | lower | None | |
| 1e-8 | ((1e-6, 2e-6),) | 1e-6·(1 − 32·eps) (eps = 2⁻⁵²) | lower | 0 | red(1 ulp 밖 None) |
| 1e-8 | ((1e-6, 2e-6),) | 2e-6·(1 + 32·eps) | lower | 0 | red |

**`l_position`.** 앵커 비교 = 격자 정수. 나머지 사유 어휘 불변. `round(L/g)`가 앵커 정수와 같으면 그 앵커 `(i, i, l_grid[i])`. 앵커가 아닌 같은 bin = `(k−1, k, L)`.

**위치 선언.** `A/lut_v2_location.json` 최상위 키 `"bin_rule": {"path": "lut_v2_bin_rule.json", "sha256": <LF 값>}`, `files` 밖. `path`는 설정 파일 폴더 기준.

| 입력 | 결과 |
|---|---|
| 키 없음, dict 아님, 절대 경로, `..`, sha256 없음 | `lut_location_config_invalid`, detail `item = "bin_rule"` |
| 파일 없음 | `lut_location_file_missing` |
| 파일 LF 값 ≠ 설정(CRLF로 바꾼 같은 파일은 통과) | `lut_location_sha256_mismatch` |
| 정상 | `LutLocation.bin_rule_path` = 절대 경로 |

**적재 적용.** 실패는 모두 `SchemaRejectedError`, `dict(exc.record.detail)["reason"]` = `bin_tie_undeclared`, detail `set`, `why`. 세트 이름 = 슬라이스는 파일 이름, 나머지 `"cap"`, `"noise"`, `"mismatch"`(주어진 파일만). meta `model_files_sha256`는 평탄(`{상대 경로: 값}`) 또는 kind 아래 중첩(`{kind: {상대 경로: 값}}`)이고 펴서 모은다. 판 문자열 = meta `ngspice`, 마지막 `-`로 나눠 선언 `simulator.name`·`.version`과 대조. 선언 스키마 = `lut_bin_rule/1`(op7a interface §2). 엔진이 판정에 읽는 칸 = `rule`, `model_files_sha256`, `simulator`(`compat` 안 읽음).

| 입력 | why |
|---|---|
| `bin_rule=None`, 파일 없음 | `decl_missing` |
| JSON 오류, `schema` 다름, `rule` ∉ {lower, upper}, 묶음 빈 목록, `simulator` 칸 없음 | `decl_invalid` |
| 세트 meta 값 0개 | `model_unrecorded` |
| 세트 `ngspice` 없음 | `simulator_unrecorded` |
| 판 문자열에 `-` 없음, 한쪽 빈 값 | `simulator_unparsed` |
| 이름·판 다름 | `simulator_differs` |
| X ∉ 선언, 파일 b를 읽어 X = sha256(b)이고 LF(b) ∈ 선언 | **통과**, (세트, 상대 경로)를 `bin_rule_machine_dependent`에 |
| X ∉ 선언, 루트 없음(인자·meta 둘 다) | `model_root_missing` |
| X ∉ 선언, 파일 없음 | `model_file_missing` |
| X ∉ 선언, 위 규칙 불성립(X = LF(b)인데 선언에 없음 포함) | `model_undeclared` |

슬라이스 세트의 기존 `_model_paths` 사유(`lut_model_root_missing`, `lut_model_file_missing`, `lut_model_file_sha256_mismatch`)는 그대로이고 그 뒤에 대조한다. **단언은 cap·noise·mismatch로 하고 슬라이스는 `model_unrecorded`·`simulator_*`만 쓴다.**

**지문.** `lut_fingerprint` 항목에 `("bin_rule_sha256", 값)` 필수. 규칙만 다른 두 선언 → 두 `LutSet.fp`가 다르다. 같은 선언 → 같다. 파일 경로는 지문에 없다. `bin_rule_machine_dependent`도 없다.

`LBinMap.anchor_bin`·`w_bin`은 `rule`로 정해진다: 경계 위 앵커가 `"lower"`면 앞 bin, `"upper"`면 뒤 bin(§4 toy로 손 대입).

## 2. 선택 함수 (`gmid_engine.lut`, 커밋 4)

```text
FingerSlice(m: int, w_f_m: float, w_key: int)                # frozen
reachable_slices(lut, kind, L) -> tuple[int, ...]
finger_slice(lut, kind, L, w_of) -> FingerSlice
slice_of_finger(lut, kind, L, w_f_m) -> int
is_slice_gap(exc) -> bool
SLICE_GAP_REASONS                                            # 문자열 tuple
```

`lut` = `LutSet`(J-1). 읽는 칸은 이것뿐이라 **손 stub로 test한다**(`types.SimpleNamespace`): `lut.spec.manufacturing_grid_m`, `lut.spec.min_finger_w_m`(((kind, m), ...)), `lut.slice_map`(`{(kind, w_key): 슬라이스}`, 슬라이스는 `.l_bins`만), `lut.cap_map[kind].w_key`, `lut.bin_rule`. `LBinMap(model_files, w_bin, bins, anchor_bin)`, `LBin(model, lmin, lmax)`는 `gmid_engine.lut`.

실패 = `SealViolationError`, `dict(exc.record.detail)["reason"]` = `"slice_missing"`. `finger_slice` detail: `kind`, `L`, `why` ∈ {`no_w_hi`, `no_candidate`}, `excluded`(뺀 키 오름차순). `slice_of_finger` detail: `kind`, `L`, `w_f_m`. `devices`는 호출부가 채운다.

**`reachable_slices`.** w_hi = `slice_map[(kind, cap_map[kind].w_key)].l_bins.w_bin[1]`. `cap_map[kind].w_key` None, 그 슬라이스 없음, `l_bins.bins` 빈 값, `bin_index`로 L을 품는 bin 없음 → `()`. 아니면 슬라이스 키 중 `round(W_min/g) ≤ key ≤ round(w_hi/g)` 오름차순.

공용 stub: g = 1e-8, kind `nmos`, 슬라이스 키 {200, 500, 700}, 기준 키 500, `w_bin` = (1e-6, 5e-6), `bins` = (LBin("b", 5e-7, 3e-6),), W_min = 1e-6.

| 입력 | 결과 |
|---|---|
| L = 1e-6 | (200, 500) (700 > w_hi) |
| W_min = 3e-6 | (500,) |
| L = 4e-6 | () |
| 기준 키 None | () |
| `bins` = () | () |

**`finger_slice`.** `()`이면 `w_of`를 부르지 않고 `slice_missing`, `why = "no_w_hi"`. 키마다 `w_of(key)`. **None, 비유한, ≤ 0은 그 키를 뺀다.** x = W/(key·g), k = ⌊x⌋. k = 0이면 m = 1. 아니면 x − k ≤ k + 1 − x일 때 m = k, 아니면 k + 1. 잔차 = |m·key·g/W − 1|(정수 곱 m·key 먼저). 최소 잔차, 같으면 큰 키. `w_f_m` = key·g. 남는 키 0 = `slice_missing`, `why = "no_candidate"`. `w_of`가 던지면 그대로 올린다. 저장 0, graph 안 읽음.

슬라이스 키 {200, 500}, `w_of` = 상수:

| W | 결과 (m, w_f_m, w_key) | 손 |
|---|---|---|
| 4e-6 | (2, 2e-6, 200) | 200: x = 2, 잔차 0. 500: x = 0.8 → m = 1, 잔차 0.25 |
| 12e-6 | (6, 2e-6, 200) | 500: x = 2.4 → m = 2, 잔차 1/6 |
| 0.5e-6 | (1, 2e-6, 200) | W < w_s. 200: 잔차 3, 500: 잔차 9 |

그 밖:

| 입력 | 결과 |
|---|---|
| 키 {200, 400}, w_hi 키 400, W = 12e-6 | (3, 4e-6, 400). (6, 200)과 (3, 400)의 곱이 같아 동률, 큰 키 |
| g = 2⁻²⁶, 키 {200}(w_hi·W_min도 그 키), W = x·200·g: x = 2.5 / 2.6 / 0.4 | m = 2 / 3 / 1 |
| 키 {200, 500}, W = 12e-6, `w_of(200)` = None | (2, 5e-6, 500) |
| 모든 키에 W = 0, 음수, NaN, inf, None(각각 한 번) | `slice_missing`, `no_candidate`, `excluded` = (200, 500) |
| `w_of(200)`이 `SealViolationError(lut_column_unavailable)` | 그대로 전파, 사유 같음 |
| 기준 키 None | `slice_missing`, `no_w_hi`, **`w_of` 호출 0** |

**`slice_of_finger`.** `width_key(w_f_m, g)`가 격자 밖이거나 키가 `widths(lut, kind)`에 없으면 `slice_missing`. w_hi를 쓰지 않고 `w_of`가 없다.

공용 stub에서: 5e-6 → 500, 7e-6 → 700(w_hi 위), 4e-6 → `slice_missing`, 5.000000001e-6 → `slice_missing`. 키 50 추가, 5e-7 → `slice_missing`(W_min 밖).

**`is_slice_gap(exc)`.** `SealViolationError`의 `reason` ∈ `SLICE_GAP_REASONS` = (`lut_axis_out_of_range`, `lut_l_not_anchor`, `lut_l_outside_model_bins`, `lut_l_bin_unbracketed`, `lut_l_cross_bin`). `lut_column_unavailable`, `lut_curve_undefined`, `lut_query_failed`, 빈 detail → False. `w_of`를 만드는 쪽은 `with_device`로 감싸기 전에 판정한다.

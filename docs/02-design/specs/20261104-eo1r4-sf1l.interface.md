## 1. 공용 판정 (`gmid_engine.sizing`)

```text

RegionJudgment(device, declared, actual)            # frozen dataclass
judge_region(device, declared, current, vds, vdsat) -> RegionJudgment
```

`declared` ∈ {`None`, `"triode"`, `"off"`}. `vdsat` = 수, `OUT_OF_DOMAIN`, `None`(VDSAT 열 없음). `actual` 문자열 ∈ {`saturation`, `triode`, `cutoff`, `out_of_domain`, `not_judged`, `unresolved`}. 위에서 아래로 첫 맞는 행:

| # | declared | current | VDS 대 vdsat | actual | mismatch |
|---|---|---|---|---|---|
| 1 | `off` | 무관 | 무관 | `not_judged` | False |
| 2 | None·`triode` | ≤ 0 | 무관 | `cutoff` | True |
| 3 | None | > 0 | VDS < 0(vdsat 값 안 봄) | `triode` | True |
| 4 | `triode` | > 0 | VDS < 0 | `triode` | False |
| 5 | None·`triode` | > 0 | `OUT_OF_DOMAIN` | `out_of_domain` | True |
| 6 | None·`triode` | > 0 | `None` | `unresolved` | False |

## 2. 봉인 7·9

```text
dc_seal_region(snapshot, lut, *, donors, counters) -> GraphSnapshot     # writer "dc_seal_region"
    READS device.dc_op, device.region_decl   WRITES graph.dc_seal_7, graph.dc_seal_9
seal_dc(...)                                 # IT 병합본 서명에서 linear_devices 인자만 없어짐
```

항목 값은 기존 `SealItem(item, status, magnitude, tol, margin, devices, nodes, detail)`, status ∈ {pass, fail, undefined}, 키는 기존과 같다(conftest `seal_item`).

`device.dc_op`의 MOS마다 `judge_region`을 한 번 부른다. vdsat 입력: VDS < 0이면 **LUT 조회 없이** `None`, 아니면 그 점 LUT VDSAT(열 없음 = `None`, 축·L 위치 밖 = `OUT_OF_DOMAIN`).

| 항목 | status | `devices` | `detail` 키 |
|---|---|---|---|
| 9 | `cutoff` ≥ 1 → fail; 아니고 `out_of_domain` ≥ 1 → undefined; 아니면 pass | fail이면 `cutoff` 소자, undefined이면 `out_of_domain` 소자(이름순) | `domain_edge`(아래); undefined면 `reason` = `"out_of_domain"` |
| 7 | 행 3·8·10 ≥ 1 → fail; 아니고 행 6 ≥ 1 → undefined; 아니면 pass | fail이면 그 소자, undefined이면 행 6 소자 | `slack_v`, `reverse_vds`, `indistinct`, `indistinct_undefined`; undefined면 `reason` = `"lut_vdsat_column_missing"`(`seal_status` = 봉인 7 대기 그대로) |

- `slack_v` = vdsat이 수인 소자 중 최소 VDS − vdsat(그런 소자가 없으면 키 없음). `reverse_vds` = 행 3 소자 tuple(없으면 키 없음).
- `indistinct` = |VDS − vdsat| < tol인 ((소자, VDS − vdsat), ...) 이름순(양쪽 띠). tol = `tol_vdsat_table(memo, kind, w_key).at(L, vds)`. 판정을 바꾸지 않는다. `indistinct_undefined` = tol None 또는 조회 실패 소자. 항목을 미정으로 만들지 않는다.
- 축 끝 읽기: `lut_axis_bounds(memo, kind, w_key) -> ((축, 첫 값, 끝 값), ...)`(`gmid_engine.lut`, 축 = `AXES` 순서, 값 사본 필드 없음, 없는 슬라이스 `KeyError`).
- `domain_edge` = LUT 표본 끝에 닿은 ((소자, 축), ...), 축 ∈ `"L"`, `"VGS"`, `"VDS"`, `"VS"`(lut `AXES`). 닿음 = 값 ≤ 축 첫 값 또는 ≥ 축 끝 값.
- `magnitude`·`tol`·`margin` 값은 단언하지 않는다(`tol`·`margin`은 None).
- 통과한 봉인점의 선언 없는 MOS는 모두 ID > 0, VDS ≥ VDSAT.

**봉인 6** `dc_seal_bulk_reverse(snapshot)` READS `device.dc_op`, `device.dc_tol_v`. `junction_forward(vds, vsb) = max(0, −vsb, −(vds + vsb))`(`gmid_engine.sizing`). 값 > 0 소자 ≥ 1 → fail, devices = 그 소자, 아니면 pass. detail `indistinct` = 순방향 0이고 min(vsb, vds + vsb) < tol_V인 ((소자, 그 값), ...), `band_undefined` = tol_V None 소자. `tol`·`margin` 단언 금지.

**없어지는 것**: `dc_seal_saturation`, `dc_seal_conduction`, 필드 `dc_off_current`·`dc_conduction_floor`, `DcInputs.linear_devices`. `E/`(tests 포함) 단어 grep 0.

## 4. ss 층 (`gmid_engine.metrics`)

```text
OffOp(vgs, vds, vsb, w_key)          # frozen, kind·W·L 칸 없음
OffDelta(node_dv, sources)           # node_dv = ((넷, ΔV), ...), sources = ((소자, ΔI_off), ...)
ss_off_op(snapshot, lut, *, donors, counters)      # writer "ss_off_op",    device.off_op
ss_off_delta(snapshot, lut, *, donors, counters)   # writer "ss_off_delta", graph.ss_off_delta
off_region_gate(snapshot, lut) -> None             # 필드 쓰기 0, 거부 = 예외
```

순서(`ss_evaluate`): `ss_off_op` → `passive_values`·`ss_dev`·`ss_circuit`·`ss_nodal` → `ss_off_delta` → `off_region_gate` → 나머지. off 선언 없으면 앞 둘과 관문 호출 0, 필드 없음.

**식.** p = +1(nmos), −1(pmos).
- `vgs = p(Vg − Vs)`, `vds = p(Vd − Vs)`, `vsb = p(Vs − Vb)`. d·s는 topology 표기. `vdb = vds + vsb`(= p(Vd − Vb)).
- `ΔI_off = op_point(memo, kind, w_key, L, vgs, vds, vsb).IDu · w_m / l_m`, L = `l_m`(> 0).
- 주입(노드로 들어가는 전류): nmos = drain −ΔI, source +ΔI. pmos = drain +ΔI, source −ΔI. 고정 넷 주입은 없어진다.
- `G·ΔV = 주입`, G = `graph.ss_nodal.g`의 미지수 부분. off 소자 스탬프 포함.
- **스탬프**: off 소자 `gm`, `gmb`, `gds`, C 열은 `device.off_op` 점 LUT 값 × (`w_m`/`l_m` 환산, 다른 MOS와 같은 열 규칙). DC 전류는 0 모형.

**관문.** 대상 = `device.dc_op`의 MOS(선언 없음 + `triode`).
- ΔVDS = p(ΔV_d − ΔV_s), ΔVGS = p(ΔV_g − ΔV_s), ΔVSB = p(ΔV_s − ΔV_b).
- VDS′ = VDS + ΔVDS. VDSAT′ = VDSAT + Σ_X [vdsat(X + ΔX, 나머지 그대로) − vdsat(X)], ΔX = 0이면 그 항 조회 0.
- VDS < 0 소자(`triode`만 봉인을 통과해 온다): 기준 VDSAT 조회 0, vdsat 입력 = `OUT_OF_DOMAIN`, 보정 조회 0. VDS′ < 0이면 표 행 4 통과, VDS′ ≥ 0이면 행 5 거부. 수치 문턱 없음.
- `region_mismatch(judge_region(소자, 선언, op.current, VDS′, VDSAT′))`이면 거부. 보정 조회 축 밖 = `OUT_OF_DOMAIN`. tol 미사용.
- **닫힌 식**(VDSAT = a0 + a1·VGS + a2·VDS + a3·VSB인 합성 LUT, 격자 안): s = VDS − VDSAT일 때 **s′ = s + (1 − a2)·ΔVDS − a1·ΔVGS − a3·ΔVSB.**

**정지.** 표 순서대로 첫 맞는 행(`off_vgs_negative` → `off_bulk_forward` → `off_outside_lut`이 `ss_off_op`). 모두 `SealViolationError`(`CANDIDATE_FAILURE_CLASSES`, `dict(exc.record.detail)["reason"]`, `exc.record.devices`), 부분 스냅샷 있음.

| reason | 조건 |
|---|---|
| `off_vgs_negative` | vgs < 0인 off 소자 하나 이상. 소자 전부 기록 |
| `off_bulk_forward` | `junction_forward(vds, vsb)` > 0(봉인 표 6행과 같은 식, 경계 0 V, tol 입력 없음). 소자 전부 기록. LUT 조회 전 |
| `off_outside_lut` | 그 밖 LUT 축 밖(vds < 0 ∧ vdb ≥ 0 포함). 클램프 없음 |
| `off_delta_undefined` | `ss_nodal`이 `Undefined`, 또는 인수 `lu`가 None, 또는 주입 넷이 floating |
| `off_gate` | 관문 거부. detail `s_prime` = ((소자, s′), ...) |

## 5. O-h (`gmid_engine.search`)

```text
check_off_judged_by(region_decl, constraint_classes, declared) -> None     # declared = spec.judged_constraints
```

`SchemaRejectedError`(`dict(exc.record.detail)["reason"]`, stop 부류 -- 후보 실패 기록 아님, 작성자 판단). off 소자마다. `verified_by(metric).kind`, 레지스트리 밖 metric은 `verified_by`가 실패한다.

| 입력 | reason |
|---|---|
| `judged_by` 빈 값 | `off_judged_by_undeclared` |
| metric이 판정 제약 칸에 없음 | `off_judged_by_not_judged` |
| kind ≠ `spice_oracle`(`spice_unverifiable`, `engine_only`), 레지스트리 밖 | `off_judged_by_unverified` |
| 모두 통과 | 반환 None |

`build_search_context` 경로에서 `constraint_classes` 뒤 탐색 전 한 번. 평가 호출 0.

**판정 제약 칸**: `.judged`의 ((metric, op, 값), ...) metric ∪ `declared[i].metric`(i ∈ `.ss`, `declared[i]`는 `.metric` 속성을 가진 선언). `.notes`는 아님. `ConstraintClasses(judged, ss, notes)`를 직접 만들어 넣는다.

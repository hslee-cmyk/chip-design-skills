## 5. 기준 폭 대조 `compare_base_width.py` (ngspice 0)

```text
python -P <AU>/compare_base_width.py --location A/lut_v2_location.json --pdk-decl A/sky130_pdk_decl.json --plan <V>/plan.json --data <D> --cache <T>/table_cache --out <V>/compare.json
```

`GMID_LUT_TABLE_CACHE_DIR`를 `--cache`(빈 임시 폴더)로 두고 돌린다(공용 표 캐시에 쓰지 않음 -- `tol_v_table`은 `lookup_persistent`). 끝나면 그 폴더를 지운다.

1. **옛 값(LutSet A)**: §2 S1-1과 같은 적재(옛 중점 파일 = 위치 선언 `verify_midpoints`). memo A = `LutMemo`(적재 꼴은 `E/tests/lut/conftest.py`와 같게). kind마다 기준 폭 키 b = `lut.cap_map[kind].w_key`(옛 중점 `w_ref_m`의 키와 같아야 함, 아니면 멈춤). `rows_old` = `midpoint_l_bin_checks(memoA, kind, b).rows`. 승인 중점 넷이 모두 앵커 2개 bin 안이므로 rows 넷·`skipped` 0이어야 한다(아니면 멈춤). B도 같다.
2. **새 값(LutSet B)**: 그 kind의 기준 폭 새 파일(`<D>`, w_key = b)을 옛 중점 파일 꼴로 **다시 담은 임시 npz** `<T>/repack_base.npz`(kind 둘을 한 파일에): 배열 `L`·`VGS`·`VDS`·`VS`·`w_ref_m`(= 새 파일 `W`)·`corner`·`temp_c`, 열 = 새 파일 ID·GM·VDSAT을 `LutSpec.cap_column_suffix` 선언의 접미사를 붙인 이름으로(옛 중점 파일 꼴), `meta_json` = 적재가 읽는 키만 새 파일·stub 사실로(`L_source` = stub `L_source`, 조건 = 새 meta `corner`·`temp_c_from_log`). 값을 지어내는 키가 필요하면 멈춤. 이 파일로 `load_lut_set(..., verify_midpoints=<repack>)`(나머지 인자 A와 같음) → 새 memo B. `rows_new` = `midpoint_l_bin_checks(memoB, kind, b).rows`. 다시 담기는 열 이름만 바꾼다(값 변환 0). 임시 npz는 판정 뒤 지우고 sha256만 기록.
3. **새 tol_V**: `tol_v_table(memoB, kind, b)`(기본 `l_bin_checks=None` = B의 새 중점 값). 셀 (앵커 i, VDS k)의 값 = `.cells[i][k]`의 `id_equivalent_v`. 앵커 i = 앵커 2개 bin(넷)의 앵커(여덟).
4. **셀 표**: bin마다 model 이름으로 `rows_old`·`rows_new` 짝짓기(넷 다 양쪽에 있어야 함, 아니면 멈춤). 셀 (kind, b, 앵커 i, k)마다 `old` = 그 bin `rows_old.id_equivalent_v[k]`, `new` = `rows_new` 같은 칸, `diff` = |new − old|, `tol_new` = 3의 값, `ratio` = diff / tol_new.
5. **판정**(spec 완료 조건 3): `diff > tol_new`인 셀이 하나라도 있으면 `stop` = "diff_exceeds_tol". old·new 중 한쪽만 None = `stop` = "one_side_undefined". diff 정의, tol_new None = `stop` = "tol_undefined". 둘 다 None = `both_undefined` 수로 셈.

```text
compare.json = {"base_commit", "kinds": {kind: {"base_w_key": b, "old_midpoints_sha256", "repack_sha256",
                 "cells": [{"anchor_L_m", "vds_k", "vds_v", "model", "old_v", "new_v", "diff_v", "tol_new_v", "ratio"}],
                 "n_cells", "n_both_undefined", "max_diff_v", "max_ratio"}},
                "stop": null | {"reason", "cells": [...]}}
```

기대 셀 수 = kind 2 × 앵커 8 × VDS 49 = 784(`n_cells` 합 + 둘 다 None 포함). 다르면 멈춤. 값 기대는 **미측정**(옛 값 참고: 권고 agent 검산 `qa_ngspice_mid.txt` `CHECK_REF` -- nmos 1.5956e-2, pmos 8.4318e-3 V가 기준 폭 bin (1.0, 2.0] 최댓값; 이 card의 판정 근거 아님).

**graph 규칙 점검**: 대조값·tol_V는 엔진 정의 함수 출력 그대로다(대조 스크립트 안 식 0). A·B는 서로 다른 LutSet·memo라 derived 키가 섞이지 않는다(`tol_v_table` 키에 외부 값 tuple이 들지만 `midpoint_l_bin_checks` 키는 (kind, w_key)뿐이라 한 memo로는 둘을 못 낸다 -- 그래서 둘로 나눔). 결과는 기록 파일뿐이고 엔진 자리(필드·cache)에 남지 않는다.

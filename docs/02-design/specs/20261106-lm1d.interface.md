   - 열 = 새 파일 ID·GM·VDSAT을 `LutSpec.cap_column_suffix` 선언의 접미사를 붙인 이름으로(옛 중점 파일 꼴);

   그 밖 키가 필요하면(적재 거부) 값을 지어내지 않고 멈춤. 이 파일로 `load_lut_set(..., verify_midpoints=<repack>)`(나머지 인자 A와 같음) → 새 memo B. `rows_new` = `midpoint_l_bin_checks(memoB, kind, b).rows`. 다시 담기는 열 이름만 바꾼다(값 변환 0). 임시 npz는 끝나면 지우고 sha256만 기록(`np.savez` zip 시각 때문에 실행마다 다를 수 있음).
3. **새 tol_V**: `tol_v_table(memoB, kind, b)`(기본 `l_bin_checks=None` = B의 새 중점 값). 셀 (앵커 i, VDS k)의 값 = `.cells[i][k]`의 `id_equivalent_v`. 앵커 i = 앵커 2개 bin의 앵커.
4. **셀 표**: bin마다 model 이름으로 `rows_old`·`rows_new` 짝짓기(넷 다 양쪽에 있어야 함, 아니면 멈춤). 셀 (kind, b, 앵커 i, k)마다 `old` = 그 bin `rows_old.id_equivalent_v[k]`, `new` = `rows_new` 같은 칸, `diff` = |new − old|, `tol_new` = 3의 값, `ratio` = diff / tol_new.
5. **판정**(spec 완료 조건 3): `diff > tol_new`인 셀이 하나라도 있으면 `stop` = "diff_exceeds_tol". old·new 중 한쪽만 None = `stop` = "one_side_undefined". diff 정의, tol_new None = `stop` = "tol_undefined". 둘 다 None = `both_undefined` 수로 셈. **부호별 수**(관찰 o1): 둘 다 정의된 셀에서 `n_new_gt_old`(new > old), `n_new_lt_old`(new < old), `n_equal`(new = old)을 센다(판정 기준 아님, 기록).

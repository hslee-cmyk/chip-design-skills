# EO-1 범위 1~3 interface card (card id `20261105-eo1r13`)

- 작성 2026-11-05, 독립 판정 전. **card base = EO-1 범위 4·card C·TB-1·HC-S·WB-1을 포함한 master**(오케스트레이터가 sha를 적는다).
- **test 작성 주체는 엔진 소스를 보지 않고 이 문서만 쓴다.** 기존 test·conftest는 읽어도 된다. 피검 함수로 기대값을 만들지 않는다. ngspice 실행 0, 실제 oracle 실행 0(stub만).
- `E/` = `skills/analog-gmid-design/gmid_engine/`. import는 패키지 공개 이름으로만 한다(`gmid_engine.search`).
- 칸 정의 정본 = oracle-portability design §11.1(`spice_oracle_input/2`). 이 문서는 값의 출처만 정한다.

## 1. 생산자

```text
oracle_input_of(snapshot, spec, topology_ref, run_decl, lut_files) -> dict     # 부수 효과 0, 스냅샷 안 바꿈
OracleInputUndefined(reason, pointer)                                          # 예외. reason ∈ {oracle_input_undefined, reference_width_undeclared}
```

- `snapshot` = 봉인 통과 점의 스냅샷(ss 필드 포함). `spec` = 회로 spec 객체. `topology_ref` = `(path, sha256)`.
- `run_decl` = `{"descriptor": {"path", "sha256"}, "simulator": {...}, "testbench": {...}}`(사전 인자, 파일 읽기는 이 card 밖).
- `lut_files` = 항목 `(path, sha256, kind, w_key, nested)`의 tuple. `nested` = 파일 안 LUT 소자 키 또는 None.

| 칸 | 값의 출처 | 없을 때 |
|---|---|---|
| `schema` | 상수 `"spice_oracle_input/2"` | |
| `circuit` | topology 이름 | 패턴 위반 = `oracle_input_undefined`, pointer `/circuit` |
| `process.descriptor`, `simulator`, `testbench` | `run_decl` 그대로 | 키 없음 = `oracle_input_undefined` |
| `process.lut_files[]` | `lut_files` 중 그 점 `dc_op`가 쓴 (kind, w_key)만. `{path, sha256, kinds: {kind: nested}}` | 어떤 소자 kind를 못 덮음 = `oracle_input_undefined`, pointer `/process/lut_files` |
| `process.corner`, `process.temp_c` | 내지 않음 | |
| `rails[]` | `spec.supplies_v` ∩ topology `supply_nets`, `voltage` = 선언 값. `reference: true` = 값이 0 V인 레일 전부 | 0 V 레일이 0개·2개 이상이어도 그대로 낸다(oracle이 막는다) |
| `devices[]` | 이름·kind·핀 = 그 소자 `device.kind`·`device.pins`, `bulk` = `device.bulk`(선언 없으면 kind별 레일 기본). `L` = `device.dc_L`. `finger_w` = `device.dc_finger.w_f_m`, `n_fingers` = `.m` | |
| `devices[]`(`off` 선언) | `finger_w` = 선언 `w_m`, `n_fingers` = 1, `L` = 선언 `l_m` | |
| `devices[].diffusion` | ad·as = 규칙 값 × `finger_w`, pd·ps = `finger_w` + 규칙 값(LUT 규칙 선언, 손계산 가능). `basis` = 규칙 이름 | 선언 없음 = `reference_width_undeclared`, 대체값 0 |
| `sources[]` | topology·응용 망 선언 원소. `value` = `device.dc_current` 또는 선언 값 | |
| `passives[]` | topology·응용 망 선언 원소. `value` = `device.passive_value` | 값 없는 수동소자 = `oracle_input_undefined`, pointer `/passives` |
| `bias_voltages[]` | 게이트 전용 넷의 `node.dc_v` | |
| `ports`, `feedback_passives`, `cm_output_loop` | spec·topology 선언 | 뷰가 없으면 칸 없음 |
| `predictions.nodes` | `node.dc_v` ∪ `node.dc_rail_v` | |
| `predictions.devices.<n>` | ID·VGS·VDS·VSB·gm_id = `dc_op`, gm·gds = `ss_dev`(크기 규칙: PMOS 부호 반전), `region` = `device.region_decl` 사상(없음 → `"sat"`, `triode`, `off`). `off` 소자 VGS·VDS·VSB = `device.off_op` | `off_current_A`·`tol` 키 없음 |
| `predictions.metrics[]` | `graph/metrics` 값, `measure` = `verified_by(metric).measure` | `measure`가 None이거나 값 없음 = 그 행 없음 |
| `acceptance.constraints[]` | 판정 제약 칸(`.judged` ∪ `.ss`의 선언) 중 `verified_by(metric).kind == "spice_oracle"`: `{measure, op, limit}` | |
| `acceptance.not_measurable[]` | 같은 칸 중 `spice_unverifiable` metric 이름 | 조용히 빼지 않음 |
| `judge` | `{"sat_margin_V": 0}`만(OP-3 판) | `off_current_A`·`tolerances` 없음 |
| `noise`, `offset_mc`, `swing_icmr` | 내지 않는다(OP-5 전 판은 oracle이 거부, O§11.4 K-4) | |
| `topology` | `{path, sha256}` = `topology_ref` | |
| `provenance` | `{"producer": "oracle_input_of", "snapshot_fp": <fp>}` | 출력 전용 |

닫힌 키: 위 표 밖 키 0. 부하 원소를 추가로 만드는 코드 없음(원소 수 = 선언 수).

## 2. 판정 호출과 참조

```text
OracleRef(record_id, compare_ref, input_sha256)     # frozen
OracleReject(reject_ref, code, stage)               # frozen
OracleCall(run_decl, topology_ref, lut_files, runner)  # frozen. runner(input_path, out_dir) -> int 반환 코드
```

`runner`는 외부 진입점 호출 자리다. test는 stub을 넣는다. 반환 코드는 oracle §11.7: 0·1 = 결과 있음, 2 = 거부 또는 막힘.

## 3. `judge_point`

```text
judge_point(snapshot, spec, call, record_root) -> OracleRef | OracleReject
```

순서: `oracle_input_of` → `<record_root>` 아래 입력 JSON 쓰기 → `call.runner` → 결과 읽기.

| 조건 | 결과 |
|---|---|
| 생산자가 `OracleInputUndefined` | 입력 파일 0, runner 호출 0, 예외 그대로 위로(§5가 기록) |
| 반환 2, `<circuit>.reject.json` 있음 | `OracleReject(path, code, stage)` |
| 반환 0·1, free `compare.json` 있음 | `OracleRef(record_id, path, input_sha256)` |
| 그 밖 | `RuntimeError`(조용히 통과 금지) |

## 4. `bridge_status`

```text
bridge_status(ref) -> str     # ∈ {"valid", "pending", "undetermined", "record_mismatch"}
```

`ref.compare_ref` 파일을 읽어 `record_id`를 다시 계산해 대조한다. 식 = compare JSON에서 `record_id`·`netlist` 칸을 뺀 본문의 정규 JSON sha256(oracle §11.7). 정규 JSON = 키 정렬, 구분자 `,`·`:`(공백 없음), 비 ASCII 그대로, UTF-8(oracle `core/results.py` `canonical_sha256`과 같은 규칙. 엔진은 그 모듈을 import하지 않는다).

| `record_id` | `summary.conduction_definition` | 결과 |
|---|---|---|
| 다름 | 무관 | `record_mismatch` |
| 같음 | `channel_sign` | `valid` |
| 같음 | `threshold_eps1` | `pending` |
| 같음 | 그 밖·없음 | `undetermined` |

읽는 칸은 oracle §11.7 'EO-1이 읽는 칸' 밖으로 나가지 않는다.

## 5. `find_front` 배선

```text
find_front(sctx, given_starts, *, oracle=None)        # oracle = OracleCall 또는 None
```

| 조건 | 실행 기록 / notes | 호출 |
|---|---|---|
| `oracle is None` | notes `{"verdict": "oracle_undeclared", "rule": "EO-1"}` | 생산자·runner 0 |
| `oracle` 있음, `sctx.archive is None` | notes `{"verdict": "oracle_no_record_root", "rule": "EO-1"}` | 0 |
| 봉인 통과 시작점 0 | notes `{"verdict": "no_sealed_start", "rule": "EO-1"}` | 0 |
| 봉인 통과 시작점 | `starts[]` 그 행에 `"oracle": {record_id, compare_ref, input_sha256}` 또는 `"oracle_reject": {reject_ref, code, stage}` | 점마다 1회 |
| 생산자 거부 | 그 행 `"oracle_undefined": {reason, pointer}` | runner 0 |

- 대상 판별 = 그 시작점 평가의 봉인 상태. 평가 재호출 0: `sctx.counters` 전체(`kernel_calls`, `hits` 포함)가 판정 호출 전후 같다.
- `SearchFront`·`EvalResult` 필드 불변. `run_id` 불변.
- 호출 자리 = `sweep_front`·감도 게이트 뒤, `append_run` 앞.

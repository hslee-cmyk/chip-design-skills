## 관찰 가능한 계약

test용 정확한 시그니처·toy는 `20261104-ub1-nl1.interface.md`. 번호 C-n은 그 문서와 같다.

- **C-1 미지수 집합 U_b**: 고정 집합 F = 그 뷰 교류접지 ∪ 여기(입력·`drive`) 넷 ∪ 남의 블록 넷. U_b = (블록 노드 ∪ 블록 소자의 d·s·저항 단자 ∪ 저항 폐포 ∪ 용량 전용 넷) − F. 비멤버 MOS의 채널은 U_b를 넓히지 않는다. 두 모드가 같은 규칙이다.
- **C-2 비멤버 스탬프**: d 또는 s가 U_b에 닿는 비멤버 MOS는 봉인 모드에서 단자 스탬프 그대로 넣는다(다른 단자는 고정 전압). 분기 없음. source 단자면 (gm + gmb + gds), drain 단자면 gds가 된다. 행 모드는 값이 없어 0으로 두고 소자 목록을 기록한다(`load_note`).
- **C-3 저항 폐포·`decomposed_only`**: 저항으로만 이어지는 넷을 F 전까지 넣는다. 저항 하나가 U_b와 입력·남의 블록 넷을 이으면 `decomposed_only`. 행 모드 상한은 그때 미상이다.
- **C-4 막다른 가지**: 저항 단자 하나 말고 U_b 안 소자가 안 닿고, 출력이 아니고, 스탬프 소자의 gate·bulk가 읽지 않는 넷은 뺀다. 되풀이한다. 두 모드 같은 해.
- **C-5 FF**: S1 (가)(A-35). 주경로 사슬은 FF 셀을 탭 0으로 스탬프해 gds 부하만 남고, 경로 기여는 탭 구동 해의 차다. `exclude`·`extra` 의미 유지.
- **C-6 복합 블록**: 경로 기여 = 다른 입력 넷에 gate가 있는 소자의 gm·gmb를 0으로 둔 같은 모델의 해.
- **C-7 조립 하나**: `block_stamp_matrix` 하나. `row_gains`, `block_local_gain`, `ff_gm_ratio`(FF 전류)가 부른다.
- **C-8 NL-1**: `_helpers_dc.limit_matrix(g, c, charge)` 한 자리. `dc_limit_parts`와 `nodal_factor`가 부른다. 전하 주입 열·영 C 처리는 `solve_dc_limit`과 같은 뜻이다.
- **C-9 행 모드 용량 전용 노드**: G4(A-36). 스탬프 소자 gate가 전회로 DC 전도 단자 0인 넷(F 밖)을 읽으면 `block_gain_model_of` -> `(None, "charge_node_row_mode")`.
- **C-10 E-01**, **C-11 E-16**: interface 표대로.
- **C-12 구조 입력**: `metric_structure`가 `BlockStruct.members`, `ViewStruct.ac_ground`, `achievability._block_spec`이 `BlockSpec.others`를 채운다.
- **C-13 결정성**: 같은 입력 비트 동일. 넷·소자 이름 전단사에 값 불변(부호는 이름순 단위 구동 규칙을 따른다, as-built와 같음).

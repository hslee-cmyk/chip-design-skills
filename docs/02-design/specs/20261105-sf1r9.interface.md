## 1. θ 상자 (`gmid_engine.search`, `gmid_engine.sizing`)

```text
zero_cancel_box(lut, S, kinds, current_boxes) -> (lo, hi)      # 순수 함수, 값 저장 0
```

적용 상자 = `graph/kernel: search_domain`의 `Variable`, writer `search_domain` 하나. 소자마다 첫 맞는 행:

| # | 소자 | 상자 | 없을 때 |
|---|---|---|---|
| a | `engine` 커패시터 | lo = C_u = ρ_A·w² + 4·ρ_P·w(합성 PDK 선언). hi = C_max(A_B) = C_u·((√A_B − 2e + s)/(w + s))²(A_B = `area_search_m2` 예산, s = MIM 배열 간격, e = MIM 감싸기 폭) | 면적 제약 없음 = `theta_capacitance_bounds_undeclared`(detail `missing` = `area_search_m2`). MIM 양 미선언 = 같은 사유(`missing` = `pdk_mim`). C_max ≤ C_u = INFEASIBLE_TARGET `area_budget_below_lower_bound`. 상자 선언 있음 = `theta_bound_element`(`why` = `capacitance_box_second_source`) |
| b | `engine` 저항, DC 전류 0, S ≠ ∅ | `(ss_resistance, R)` θ 성분. 상자 = `zero_cancel_box` = [1/max Σ_{c∈S} gm_c, 1/min Σ_{c∈S} gm_c], gm_c 범위 = (LUT gm/ID 정의역 최소·최대) × `current_box`(그 kind). 호출자 = `search_domain` | 상자 선언 있음 = `theta_bound_element`(`why` = `resistance_box_not_dc_path`) |
| c | DC 경로 `engine` 저항 | 회로별 선언 상자 | 선언 없음 = `theta_resistance_bounds_undeclared` |
| d | 그 밖(S가 비는 보상 저항 포함) | 없음 | `theta_resistance_bounds_undeclared`, 탐색 전. 상자 선언 있음 = `theta_bound_element`(`why` = `resistance_box_not_dc_path`) |

**S 셀**: R의 끝 넷 E에 R과 보상 C만 닿으면 그 C마다 경로 하나. 경로의 두 끝 (A, B)에 gate = A, drain = B인 CS 셀(source 교류접지)의 합집합. 어느 쪽 단자가 끝인지 무관. 합집합이 비면 S 미정.

**없어지는 것**: `SearchSettings.resistance_bounds_ohm`, `capacitance_bounds_f`, `StartView.theta_bounds`, `passive_values`의 구조 규칙 값(R = 1/Σ`dc_gm`). `E/`(tests 포함) 단어 grep 0. 문자열 `"theta_bounds"`·상수 `THETA_BOUNDS`·`_FIELD_BOUNDS` 엔진 소비 = 선언 상자 블록 하나.

**선언 상자**: `@compute_block` `spec_search_decl`(`gmid_engine.search`), writes `graph/kernel: declared_theta_box` = `ThetaBound` tuple, READS `device.element_class`·`device.kind`, extras = spec. 거부 `theta_bound_element`(원소가 저항·커패시터 밖이거나 값 mode가 engine 아님, gate `spec_search_decl`). 로더는 구문 검사만. `theta_bound_declaration`(`authoring`)은 없어진다.

**출발값**: θ 저항 `ss_resistance`는 `graph/start: rungs` 칸 θ에 값 1/Σ_{c∈S} gm_c(그 칸 매크로 gm)로 실린다. 매크로가 전류를 못 정한 칸은 성분 없음.

## 2. 면적 (`gmid_engine.metrics`, `gmid_engine.layout`)

| 입력 | 결과 |
|---|---|
| 값 미정 수동소자(측정 부하 아님) | `area_search_m2` = 정의 불능, 사유 `area_undefined`, `elements` = 그 소자 tuple |
| MIM 양 미선언 커패시터, 선언 값 C < C_u 커패시터, head 면적 미선언 | 같음. 0 대체 없음 |

## 3. 저항 종류와 기생 (`gmid_engine.metrics`, `gmid_engine.core`)

```text
device.passive_parasitic = {수동소자: PassiveRealization(area_m2, r_kind, l_m, c_par_f)}
    # writer passive_values(device.passive_value 와 같은 블록). 행 = 값이 정해지고 측정 부하가 아닌 소자.
    # 커패시터 행: r_kind·l_m·c_par_f = None. 면적 불능 소자 = 행 없음.
```

- 후보 = 선언 종류 중 R ≥ `r_min_ohm`(칸 없는 종류 = 0). 그중 Ω당 면적 W_min²/R□ 최소, 동률은 이름순. 값 R마다 `passive_values`가 한 번 고른다.
- 후보 0(선언 종류 0 포함) = 그 점 E-0, 후보 실패 사유 `resistor_kind_unrealizable`, `{소자, R}`.
- l = R / r_l, r_l = R□ / w(유도, 선언 칸 없음). C_par = 면적 계수 × l × w + 둘레 계수 × 2(l + w)(합성 선언, 머리 무시 -- 머리 저항과 머리 길이 항을 둘 다 뺀다).
- 양 끝에 C_par/2, 반대 끝 = 최저 전위 레일. 소신호 MNA에만. DC 결과 불변. 측정 부하 저항은 없음.
- 적용 = θ R과 값 선언 R.

## 4. 오라클 칸과 PDK 로더

- `/passives[].parasitic_c_F`: number ≥ 0, 저항만. 커패시터에 있으면 거부(O§11.6). 값 = `device.passive_parasitic` 직렬화(생산자 `oracle_input_of`, 재계산 0).
- 소자 줄: 이상 R + 양 끝 C_par/2. 칸 없으면 이상 R. 측정 부하 = 칸 없음.
- `read_pdk_decl` 원본 형식 추가 `magic_drc_tech`: 역슬래시 이어짐을 합친 DRC 문장에서 규칙 번호 = 메시지 끝 괄호의 첫 토큰, 값 = 문장의 정수, 단위 = 선언 `units_m`. 두 번 나온 규칙은 쓰일 때만 `pdk_rule_ambiguous`.
- 선택 최상위 키 `derived_quantities` = {이름: {`expression`, `basis`}}: 식의 이름 = 기존 양 이름(한 단계), 없으면 `pdk_quantity_undeclared`, `rules` = 그 양들의 규칙 합집합.
- 역할 이름: `mim_min_w_m`, `mim_array_spacing_m`, `mim_enclosure_m`, `mim_perimeter_cap_f_per_m`, `mim_min_cap_f`.
- `resistor_types` = {`candidates`: {이름: {`sheet_ohm_per_sq`, `min_w_m`, `head_area_m2`, `c_area_f_per_m2`, `c_perimeter_f_per_m`, 선택 `r_min_ohm`}}}, 값 = 선언 양 이름. `selected_as`·`poly_res_*` 없음. `PdkDecl.resistor_kinds` = 후보표.
- `r_min_ohm`의 양 = 선언 폴더 기록 파일(`sources`, 기존 형식)의 `.param r_min_ohm = 값` 줄.
- 기존 선언 양 전부의 `value_m`·출처 sha는 형식 추가(c1) 전후 같다. `poly_res_*`는 c6에서 없어지는 선택 양이라 c6 비교 대상이 아니다.

## 1. θ 상자 (`gmid_engine.search`, `gmid_engine.sizing`)

```text
zero_cancel_box(lut, S, kinds, current_boxes) -> (lo, hi)      # 순수 함수, 값 저장 0
```

적용 상자 = `graph/kernel: search_domain`의 `Variable`, writer `search_domain` 하나. 소자마다 첫 맞는 행:

| # | 소자 | 상자 | 없을 때 |
|---|---|---|---|
| a | `engine` 커패시터 | lo = ρ_A·w² + 4·ρ_P·w(합성 PDK 선언). hi = 면적 제약의 역(**SG-2 대기**) | 면적 제약 없음 = 상한 정의 불능 정지(사유 **SG-8 대기**). PDK 양 미선언 = 정지 |
| b | `engine` 저항, DC 전류 0, S ≠ ∅ | `(ss_resistance, R)` θ 성분. 상자 = `zero_cancel_box` = [1/max Σ_{c∈S} gm_c, 1/min Σ_{c∈S} gm_c], gm_c 범위 = (LUT gm/ID 정의역 최소·최대) × `current_box`(그 kind) | |
| c | DC 경로 `engine` 저항 | 회로별 선언 상자 | 선언 없음 = `theta_resistance_bounds_undeclared` |
| d | 그 밖(S가 비는 보상 저항 포함) | 없음 | `theta_resistance_bounds_undeclared`, `theta_capacitance_bounds_undeclared`, 탐색 전 |

**S 셀**: R의 끝 넷 E에 R과 보상 C만 닿으면 그 C마다 경로 하나. 경로의 두 끝 (A, B)에 gate = A, drain = B인 CS 셀(source 교류접지)의 합집합. 어느 쪽 단자가 끝인지 무관. 합집합이 비면 S 미정.

**없어지는 것**: `SearchSettings.resistance_bounds_ohm`, `capacitance_bounds_f`, `StartView.theta_bounds`, `passive_values`의 구조 규칙 값(R = 1/Σ`dc_gm`). `E/`(tests 포함) 단어 grep 0. 문자열 `"theta_bounds"`·상수 `THETA_BOUNDS`·`_FIELD_BOUNDS` 엔진 소비 = 선언 상자 블록 하나(**SG-3 대기**).

**선언 상자**: 이름·필드·입력 = **SG-3 대기**. 출발값 = **SG-4 대기**.

## 3. 저항 종류와 기생 (`gmid_engine.metrics`, `gmid_engine.core`)

```text
device.passive_parasitic    # writer passive_values, DUT 저항만. 칸 = SG-5 대기(최소한 l_m, c_par_f)
```

- 후보 = 선언 종류 중 R ≥ `r_min_ohm`(접촉 항 없는 종류 = 0). 그중 Ω당 면적 W_min²/R□ 최소, 동률은 이름순.
- 후보 0 = 그 점 E-0, 사유 `resistor_kind_unrealizable`, `{소자, R}`.
- l = R / r_l(선언 값). C_par = 면적 계수 × l × w + 둘레 계수 × 2(l + w)(합성 선언, 머리 무시). 식 구성의 정본 = 선언 셀 파일 식의 머리 뺀 꼴(D40:914, 항 구성은 **SG-5 대기**로 확정).
- 양 끝에 C_par/2, 반대 끝 = 최저 전위 레일. 소신호 MNA에만. DC 결과 불변. 측정 부하 저항은 없음.
- 적용 = θ R과 값 선언 R.

## 4. 오라클 칸과 PDK 로더

- `/passives[].parasitic_c_F`: number ≥ 0, 저항만. 커패시터에 있으면 거부(O§11.6). 값 = `device.passive_parasitic` 직렬화(생산자 `oracle_input_of`, 재계산 0).
- 소자 줄: 이상 R + 양 끝 C_par/2. 칸 없으면 이상 R. 측정 부하 = 칸 없음.
- `read_pdk_decl`: 형식 추가·항목 이름 = **SG-2 대기**. 기존 선언 양 전부의 `value_m`·출처 sha는 전후 같다.
- 선언 키 `r_min_ohm` 형식·기록 칸 = **SG-5 대기**.

## 1. θ 상자 (`gmid_engine.search`, `gmid_engine.sizing`)

```text
zero_cancel_box(lut, S, kinds, current_boxes) -> (lo, hi)      # 순수 함수, 값 저장 0
```

적용 상자 = `graph/kernel: search_domain`의 `Variable`, writer `search_domain` 하나. 소자마다 첫 맞는 행:

| # | 소자 | 상자 | 없을 때 |
|---|---|---|---|
| a | `engine` 커패시터 | lo = C_u. hi = C_max(A_B) = C_u·(1 + (√A_B − a)/p)²(C_u, p, a = `CapArrayDecl`, A_B = `area_search_m2` 예산) | 면적 제약 없음 = `theta_capacitance_bounds_undeclared`(detail `missing` = `area_search_m2`). 세 양 미선언 = 같은 사유(`missing` = `pdk_cap_array`). √A_B ≤ a = `InfeasibleTargetError`, reason `area_budget_below_lower_bound` |
| b | `engine` 저항, DC 전류 0, S ≠ ∅ | `(ss_resistance, R)` θ 성분. 상자 = `zero_cancel_box` = [1/max Σ_{c∈S} gm_c, 1/min Σ_{c∈S} gm_c], gm_c 범위 = (LUT gm/ID 정의역 최소·최대) × `current_box`(그 kind). 호출자 = `search_domain` | |
| c | DC 경로 `engine` 저항 | 회로별 선언 상자 | 선언 없음 = `theta_resistance_bounds_undeclared` |
| d | 그 밖(S가 비는 보상 저항 포함) | 없음 | `theta_resistance_bounds_undeclared`, 탐색 전 |

**선언 상자 거부 한 규칙**: a·b·d 행 소자에 상자 선언이 있으면 `theta_bound_element`(gate `search_domain`).

**S 셀**: R의 끝 넷 E에 R과 보상 C만 닿으면 그 C마다 경로 하나. 경로의 두 끝 (A, B)에 gate = A, drain = B인 CS 셀(source 교류접지)의 합집합. 어느 쪽 단자가 끝인지 무관. 합집합이 비면 S 미정.

**없어지는 것**: `SearchSettings.resistance_bounds_ohm`, `capacitance_bounds_f`, `StartView.theta_bounds`, `passive_values`의 구조 규칙 값(R = 1/Σ`dc_gm`). `E/`(tests 포함) 단어 grep 0. 문자열 `"theta_bounds"`·상수 `THETA_BOUNDS`·`_FIELD_BOUNDS` 엔진 소비 = 선언 상자 블록 하나.

**선언 상자**: `@compute_block` `spec_search_decl`(`gmid_engine.search`), writes `graph/kernel: declared_theta_box` = `ThetaBound` tuple, READS `device.element_class`·`device.kind`, extras = spec. 거부 `theta_bound_element`(원소가 저항·커패시터 밖이거나 값 mode가 engine 아님, gate `spec_search_decl`). 로더는 구문 검사만. `theta_bound_declaration`(`authoring`)은 없어진다.

**출발값**: θ 저항 `ss_resistance`는 `graph/start: rungs` 칸 θ에 값 1/Σ_{c∈S} gm_c(그 칸 매크로 gm)로 실린다. 매크로가 전류를 못 정한 칸은 성분 없음.

## 3. 수동소자 실현과 저항 기생 (`gmid_engine.metrics`)

```text
device.passive_realization = {수동소자: PassiveRealization(area_m2, c_par_f)}
    # writer passive_values(device.passive_value 와 같은 블록). 행 = 측정 부하(None, None), 또는 값이 정해지고 면적이 정의되는 소자.
    # 커패시터 행: c_par_f = None. 저항 행: c_par_f = c_par_per_ohm × R. 행 없음 = 정의 불능.
```

소비자: `metrics_dc`·레이아웃 입력(`area_m2`), `ss_circuit`·`oracle_input_of`(`c_par_f`).

- 양 끝에 C_par/2, 반대 끝 = 최저 전위 레일. 소신호 MNA에만. DC 결과 불변. 측정 부하 저항은 없음.
- 적용 = θ R과 값 선언 R. 값 R에 따라 종류를 고르지 않는다.
- 행 없는 저항(값 있음, 저항 양 미선언): 소신호 계 = 정의 불능 `pdk_quantity_undeclared`(`elements` = 그 저항). 이상 R로 풀지 않는다. `oracle_input_of` = `oracle_input_undefined`, pointer `/passives`.

## 4. 오라클 칸과 PDK 선언

- `/passives[].parasitic_c_F`: number ≥ 0, 저항만. 커패시터에 있으면 거부(O§11.6). 값 = `device.passive_realization.c_par_f` 직렬화(생산자 `oracle_input_of`, 재계산 0).
- 소자 줄: 이상 R + 양 끝 C_par/2. 칸 없으면 이상 R. 측정 부하 = 칸 없음.
- `read_pdk_decl` 원본 형식 추가 0. 기록 파일 = 기존 형식 `spice_instance_line`(`line_pattern`이 `.param` 줄을 고름, `base` = 선언 폴더, 주석은 값이 아님).
- 선택 최상위 키 `derived_quantities` = {이름: {`expression`, `basis`}}: 식의 이름 = 기존 양 이름(한 단계), 없으면 `pdk_quantity_undeclared`, `rules` = 그 양들의 규칙 합집합, 값 < 0 거부는 기존 양과 같다.
- 엔진이 읽는 이름: `cap_unit_f`, `cap_array_pitch_m`, `cap_unit_side_m`, `resistor_area_per_ohm_m2`, `resistor_head_area_m2`, `resistor_c_par_per_ohm`. 배열 세 수 또는 Ω당 면적이 0이면 `pdk_quantity_invalid`.
- `resistor_types.candidates.<이름>` 칸 = `area_per_ohm_m2`, `head_area_m2`, `c_par_per_ohm`(값 = 선언 양 이름, 셋 다 필수). `selected_as` 키 없음. 선택 = 선언 시점에 `area_per_ohm_m2` 최소, 동률은 이름순, `resistor_<칸>`으로 낸다.
- 기존 선언 양 전부의 `value_m`·출처 sha는 로더 변경 전후 같다. 후보표 변경(c5)으로 값이 바뀌는 선택 양은 비교 대상이 아니다.

## 2. 기술자 `oracle_pdk_descriptor/1`

모든 층의 키 집합이 닫혀 있다. 칸 뜻 = D §10.2. 그 표와 다른 곳은 `[D-2]` 표시한 곳이다.

 "engine_decl": {"path": "<기술자 폴더 기준 또는 절대>", "sha256": "<LF>"},

 "kinds": {"<kind>": {"call_form": "subckt_wrapper", "name": {"value": "..."},
                      "inner_device": {"expr": {}},
                      "geometry_unit": {"source": "<엔진 quantity 키>"},
                      "parallel_multiplier": {"to": [{"target": "instance_multiplier"},
                                                     {"target": "model_param", "name": {"value": "..."}}],
                                              "source": {}},
                      "includes": [{"source": "<키>"}], "polarity": "n"}},

 "temperature": {"tnom": {"<kind>": {"source": "<키>"}}, "range_source": "spec"},

- `extra_engine_decls`, `temperature.tnom`의 kind 층, `diffusion.decl` = `[D-2]`.

- `name`·`inner_device`의 `expr` = 엔진 선언 `sources` 식 형식(`E/core/CONTRACT.md` §9). 실제 파일은 원본에서 읽는 식을 쓰고, toy는 `value`를 쓴다.

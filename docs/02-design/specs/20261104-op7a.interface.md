## 2. 선언 스키마 `lut_bin_rule/1`

키 집합은 닫혀 있다. 단위는 SI(m).

```json
{"schema": "lut_bin_rule/1",
 "model_files_sha256": ["<LF sha256 오름차순, 중복 없음, 1개 이상>"],
 "simulator": {"name": "ngspice", "version": "46"},
 "compat": {"mode": "default", "spiceinit_text": "", "spiceinit_sha256": "<sha256(spiceinit_text의 UTF-8)>"},
 "rule": "lower",
 "evidence": {"points": [{"L": 1.8e-07, "W": 4e-06, "chosen_bin": "<모델 이름>"}],
              "mode": "default", "source_basis": "generator_record", "measured_by": "verifier", "date": "2026-11-04"}}
```

- `rule`: `"lower"` = 경계 정수값에서 그 값을 `lmax`(`wmax`)로 갖는 bin. `"upper"` = 그 값을 `lmin`(`wmin`)으로 갖는 bin.
- `evidence.mode` = 측정에 쓴 모드(§16 '측정에 쓴 모드를 evidence에 씀'). `compat.mode`와 같아야 한다.
- `evidence.source_basis` = 값 `"generator_record"` 하나. 뜻 = '출처 = 생성기 자기 기록, 값으로 독립 판별 불가'.
- 빈 문자열의 sha256 = `e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`.

## 3. 시그니처

`bin` = `{"model": str, "lmin": float, "lmax": float, "wmin": float, "wmax": float}`.

| 심볼 | 시그니처 | 계약 |
|---|---|---|
| `grid_index` | `grid_index(x_m, grid_m) -> int` | `round(x_m / grid_m)`. 소속 비교는 이 정수끼리만 한다(상위 DEC-105 (2)) |
| `anchor_set` | `anchor_set(axes, grid_m) -> tuple[float, ...]` | `axes` = 파일별 L 축(m) 목록의 목록. 격자 정수로 합집합, 오름차순, 값은 처음 나온 float |
| `tie_axes` | `tie_axes(l_m, w_m, bins, grid_m) -> tuple[str, ...]` | `"L"`: W를 품는 두 bin a, b가 있어 a.lmax = b.lmin = l. `"W"`: L을 품는 두 bin a, b가 있어 a.wmax = b.wmin = w. 품음 = 정수 양끝 닫힘. 결과 정렬 |
| `point_direction` | `point_direction(l_m, w_m, chosen, bins, grid_m) -> dict[str, str]` | `tie_axes`의 축마다 `"lower"` 또는 `"upper"`(§2 뜻). 점이 `chosen`의 정수 닫힌 구간 밖이면 `BinRuleStop("bin_outside")`. 동률 축에서 `chosen`의 그 축 끝이 어느 쪽도 경계와 같지 않으면 `BinRuleStop("tie_interior")`. 동률 아니면 `{}` |
| `derive_rule` | `derive_rule(directions) -> (rule \| None, reason \| None)` | 모든 dict의 값을 모은다. 비면 `(None, "no_tie_point")`, 하나면 `(값, None)`, 둘이면 `(None, "mixed_direction")` |
| `union_model_sha` | `union_model_sha(records, read_bytes) -> (list[str], list[str])` | `records` = `(경로, 기록 sha256)` 나열. `read_bytes(경로)`가 `FileNotFoundError`면 `BinRuleStop("record_file_missing", 경로)`. LF = `sha256(b.replace(b"\r\n", b"\n"))`, raw = `sha256(b)`. 기록 = LF면 일치, 기록 = raw(LF와 다름)면 기계 의존, 둘 다 아니면 `BinRuleStop("record_sha_mismatch", 경로)`. 반환 = (LF 값 오름차순·중복 제거, 기계 의존 경로 오름차순) |
| `split_version` | `split_version(text) -> (name, version)` | 마지막 `-`로 나눈다. `-` 없거나 양쪽 중 빈 쪽이 있으면 `BinRuleStop("simulator_version_unparsed", text)` |
| `set_versions` | `set_versions(by_set) -> ((name, version), tuple[str, ...])` | `by_set` = {세트 이름: 판 문자열 또는 None}. None인 세트 이름 정렬 = 둘째 반환(선언이 적용되지 않는 세트). 값이 0종이면 `BinRuleStop("simulator_version_unrecorded")`, 2종 이상이면 `BinRuleStop("simulator_version_mixed")` |
| `spiceinit_sha` | `spiceinit_sha(text) -> str` | `sha256(text.encode("utf-8"))` |
| `build_decl` | `build_decl(model_files_sha256, simulator, mode, spiceinit_text, rule, points, date) -> dict` | §2 모양, `measured_by = "verifier"`, `evidence.mode = mode`, `evidence.source_basis = "generator_record"`. `points` = `(L, W, chosen_bin)` 나열 |
| `validate_decl` | `validate_decl(d) -> list[str]` | 위반 JSON 포인터 정렬 목록(중복 제거), 없으면 `[]`. 아래 T-7 |
| `isolated_env` | `isolated_env(env, home_dir) -> dict` | 사본. `HOME`·`USERPROFILE` = `home_dir`, `HOMEDRIVE`·`HOMEPATH`·`SPICE_USERINIT_DIR` 삭제, 나머지 그대로 |
| `judge_controls` | `judge_controls(default_rule, cwd_rule, home_rule) -> (verdict, reason)` | 아래 T-8 |
| `judge_empty_init` | `judge_empty_init(default_bins, empty_bins) -> (verdict, reason)` | 두 dict(점 → 모델 이름)가 같으면 `("ok", None)`, 다르면 `("stop", "control_undetermined")` |
| `w_boundary_points` | `w_boundary_points(bins, grid_m) -> tuple[tuple[float, float], ...]` | 같은 L 구간(정수)의 두 bin a, b에서 a.wmax = b.wmin인 경계마다 `(L, W)`. L = `round((lmin + lmax) / (2 * grid_m)) * grid_m`, W = 그 경계. 중복 제거, (W, L) 격자 정수 오름차순. L의 격자 정수가 lmin·lmax 정수와 같으면 `BinRuleStop("w_boundary_no_interior")`. a.wmax = b.wmin이고 L 구간이 겹치지만 같지 않으면 `BinRuleStop("w_boundary_not_product")`. 겹침 = 정수 구간 공통 길이 > 0(끝만 닿으면 겹침 아님) |
| `slice_tie_cells` | `slice_tie_cells(l_axis_m, w_m, per_l, measured, bins, grid_m) -> list[dict]` | `per_l` = meta `model_bin_per_L`(키 = µm 문자열, 값 = bin 이름) 또는 `None`. `measured` = `{(L 격자 정수, W 격자 정수): (기본 모드 bin, 대조 모드 bin)}`. `l_axis_m` 순서로 `tie_axes(L, w_m, bins, grid_m)`가 비지 않은 칸마다 `{"l_m", "w_m", "recorded", "default", "hsa"}`. 키 대응 = `grid_index(float(키) * 1e-6, grid_m)`. 그 L의 키가 없으면 `recorded = None`, 측정이 없으면 `default = hsa = None`. `per_l`이 dict 아님, 키가 숫자 아님, 두 키가 같은 격자 정수, 값이 문자열 아님이면 `BinRuleStop("source_record_missing")` |
| `record_source_mode` | `record_source_mode(cells, declared) -> str` | `cells` = `slice_tie_cells` 결과를 모은 것. 이름 비교, 문턱 없음. 비면 `source_no_tie_cell`. 칸을 순서대로 본다: `recorded`가 None이면 `source_record_missing`, `default`나 `hsa`가 None이면 `source_cell_unmeasured`, 셋이 같으면 `source_record_both_modes`, 둘 다와 다르면 `source_record_no_mode`. 칸마다 `recorded == default`면 `"default"`, `recorded == hsa`면 `"hsa"`. 모은 값이 2종이면 `source_record_mixed`, `declared`와 다르면 `source_mode_differs`. 아니면 그 모드 이름을 돌려준다. 실패는 모두 `BinRuleStop`, `detail` = 그 칸 |
| `combined_bin_check` | `combined_bin_check(recorded, measured) -> None` | `recorded` = `{점 키: 기록 칸}` 또는 `None`, `measured` = `{점 키: 본 측정 bin 이름}`. `None`·빈 dict면 `combined_bin_missing`. 칸이 dict가 아니거나 `model`이 문자열이 아니면 `combined_bin_unparsed`, 키가 `measured`에 없으면 `combined_bin_unmeasured`, 이름이 다르면 `combined_bin_differs`. 실패는 모두 `BinRuleStop` |
| `cap_bind_check` | `cap_bind_check(recorded, pinned) -> None` | 둘 중 하나가 `None`이면 `BinRuleStop("cap_bind_missing")`, 다르면 `BinRuleStop("cap_bind_differs")` |
| `record_only_files` | `record_only_files(reached, recorded) -> tuple[str, ...]` | `reached` = `{닿는 파일 경로: (LF sha256, raw sha256)}`, `recorded` = `{기록 경로: 기록 sha256}` 또는 `None`. `reached`가 비거나 `recorded`가 `None`·빈 dict이면 `BinRuleStop("include_not_recorded")`. 닿는 파일의 두 값이 모두 기록 값에 없으면 `BinRuleStop("include_not_recorded", 경로)`. 반환 = 값이 닿는 파일의 어느 값과도 같지 않은 기록 경로, 오름차순 |
| `netlist_lines` | `netlist_lines(subckt, includes, points) -> list[str]` | 아래 T-10. 안쪽 이름 꼴 `m.<inst>.m<subckt>` = 옛 입력 `op_probe`·`A/sky130_lut_sweep.py:168-171` 사실. 틀리면 `showmod_incomplete`로 멈춘다. 다른 PDK는 OP-8 경로 |
| `parse_probe_log` | `parse_probe_log(text, bins, grid_m) -> dict[str, str]` | 아래 T-11. `SHOWMOD`·네 경계 키가 아닌 줄은 무시한다 |

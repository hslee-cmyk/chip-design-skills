2. **(a) 보상 C.** 엔진은 `CapArrayDecl(c_unit_f, pitch_m, unit_side_m)` 세 수(C_u, p, a, 모두 양수)만 안다. 하한 = C_u, 상한 C_max(A_B) = C_u·(1 + (√A_B − a)/p)²(A_B = 면적 예산). 면적 제약 없음·세 양 미선언 = `theta_capacitance_bounds_undeclared`(detail `missing`). √A_B ≤ a = `InfeasibleTargetError`, reason `area_budget_below_lower_bound`(단계 B `stage_b.py:160`이 잡아 정지 사유로 보고).

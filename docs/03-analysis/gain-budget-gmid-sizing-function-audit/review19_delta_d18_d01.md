* **drain 쪽이 신호 소자인 혼재 노드는 현 library에 0이다.** 따라서 '충돌' 갈래는 **발동 0**이고 DEC-76 표기
  ("미구현(발동 0)", 만나면 `unsupported_rule_branch` 안전망)가 필요하다. 동시에 이것은 **"진짜 신호 충돌을 전압 구동으로 덮는"
  경우가 현 library에서 구조적으로 생길 수 없다**는 뜻이기도 하다 — 전압 구동으로 바뀐 14건은 전부 drain 쪽이 DC 바이어스다.
* **넓어진 탈출구로 새로 전압 구동이 된 것은 2건뿐**이고 둘 다 drain 쪽 소자의 gate에 그 뷰의 신호가 실린다:
  파일럿 `Vx`/`M7`(CMFB가 tail 게이트를 구동 — 문장이 든 예 그대로), folded `Vg10`/`M10`(캐스코드 미러의 출력 소자).
  **folded 쪽은 '주입'이라는 문장의 설명보다 비중이 크다**: `M10`은 미러가 옮겨 온 차동 반쪽 신호 전류 **전부**를 싣는다.
  판정(전압 구동)은 `Vg10`이 `M8` source인 저임피던스 노드라 구조적으로 무리가 없고 정지·stage 결과도 바뀌지 않지만,
  근거 문장 "기존 블록으로의 주입이다"는 이 경우를 과소 서술한다. 회로별 귀속은 J2·J5(미러) ratify에서 확인할 자리다 → **S3 메모**.
* 14건 중 12건은 drain 쪽이 **셀이 아닌 off_path 전류원**이다. 문장은 "**다른 셀의** drain"이라 적었으므로 문면대로면 이들은
  혼재 노드가 아니고 기본 갈래(CS/CD source = 전압 구동)로 간다. **어느 읽기든 답은 전압 구동으로 같다**(측정). 단어만
  "다른 소자의 drain"으로 바꾸면 모호성이 사라진다 → S3.
* **sf "적층 source 6넷"**: 이전 `review_needed`(K8 아님) → 지금 `review_needed`(DC 역할 못 가름, J 대기). **사유만 바뀌고 정지는 유지**.
  여기에 `N17`/`N20` 2넷이 **새로 `review_needed`에 들어온다**(이전에는 K8 연결성 조건으로 통과시켰다). 문장이 "예: `N17`·`N20`
  (J12-b ratify 대상)"이라 적은 것과 일치한다. sf 혼재 `review_needed` 합계 **6 → 8**.

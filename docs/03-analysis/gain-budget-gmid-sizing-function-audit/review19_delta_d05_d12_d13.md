## 3. D-13 ((a) 분기·합류를 다입력 블록 판정보다 먼저)

### 3.1 두 읽기

N3.7 문장 순서: ① 입력 기준 규칙("…닿는 넷이면 한 블록") → ② 다입력 블록 → **③ 새 문장 "(a)를 이 판정보다 먼저 한다 …
합류 노드 조건을 만족하는 병렬 셀은 복합 블록이고 다입력 블록으로 떨어지지 않는다"** → ④ 예시 → ⑤ 캐스코드 합류도 같다 →
⑥ **미러 합류도 같다**.

* **읽기 R1**: "이 판정" = ②(다입력 판정)뿐. 순서 = **①⑤⑥(한 블록 판정, 미러 포함) → (a) → ②**.
* **읽기 R2**: ③의 둘째 구절 "합류 노드 조건을 만족하는 병렬 셀은 복합 블록이고"를 **전칭**으로 읽음. 순서 = **(a) → ①⑤⑥ → ②**.
  (a)의 합류 노드 조건("두 경로가 신호 셀 사슬로 이어져 합류하고, 합류 노드가 전류 구동이거나 블록 출력노드")은
  미러 부하 합류(`vin_n→M1→D3→M4→O1` + `vin_p→M2→O1`)도 문면 그대로 만족한다. 게다가 ⑥ 미러 갈래가
  **③보다 뒤에** 적혀 있어 위에서 아래로 읽으면 R2가 자연스럽다.

### 3.3 미러 갈래와 ngcc `M7` — 순서가 묶음 경계를 가른다

* R1(미러 → (a) → 다입력)에서 `M7`의 입력 `NX`는 diode `M6A`의 drain이라 ⑥으로 "앞 블록 내부 노드"가 되고
  `Vout` 합류 경로는 **`M13`·`M14` 둘**이다. R2에서는 (a)가 먼저라 **셋**(J12 기본안 문장 "M7·M13·M14 세 경로")이다.
* **여기에 D-08이 겹친다**: 새 DC 역할 절차 (2)로 `{M6A(diode), M7}`은 gate `NX`·source `gnd`를 공유하고 diode 멤버가
  있으므로 **`M7` = DC 바이어스 전류원**이다 → 규칙 5 예외로 **stage를 시작하지 않는다**. 즉 R1에서는 `M7`이
  미러 갈래와 규칙 5 예외 **양쪽으로** 경로에서 빠지고, 남는 `M7`의 `Vout` 주입은 K8도 아니다(`Vout`에 CD source가 없다)
  → **어느 분기에도 속하지 않는 주입**으로 남는다. J12의 "gmf1 가지(M5·M6A·M6B·M7)" ratify 항목에 이
  두 파급(경로 수 2 대 3, `M7` 주입의 분류 부재)을 적어야 한다 → **신규 D-20(S2)**.

**이전 보고서의 누락 정정**: 파일럿·folded의 이 **혼재 `review_needed`**는 이전 보고서 §2 정지 사유 표에는 있었지만

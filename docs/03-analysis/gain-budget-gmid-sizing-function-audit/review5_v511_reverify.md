- 대상: 작업본 plan(1107줄, 커밋 전). 결정표 §7의 7개 지적 항목을 주장 줄에서 직접 읽어 대조했다.
- 측정: 새 정의(가지 = 레일·분기 노드(DC 엣지 차수 ≥ 3) 사이 극대 직렬 사슬, 기둥 = 하단→상단 레일 단순 경로)를 library topology json 7개에 그대로 적용했다(스크립트 `review5/col.py`. DC 엣지 = MOS 채널 + 잎 가지치기 후 남은 저항 + 이상원, 게이트·커패시터 제외).

## 2. 열거 폭발 (검사 2)

- 최대가 파일럿 244개(가지 32, 분기 노드 9)로, 깊이 40 제한과 상한 30만에 걸리지 않았다. 열거는 실행 가능하다.
- 축소 규칙(255(3), 447): "경로 열거 수가 DEC-34 예산을 넘으면 가지 단위 국소 문제로 축소하고 사유 기록"은 판정 가능한 기준(열거 수 대 예산 값)이고, `unsupported_rule_branch` 정지가 아니라 축소라 DEC-59 정지와 충돌하지 않는다.

## 3. 국소 자유도 (검사 3)

- (7) 확정 금지 목록은 K1·K2·K3·K8·폴딩 합류·class-AB 루프·CMFB tail·블록 가로지르는 L 동치류로, K1~K8과 y 정의에 맞다(K5·K6는 `ss` 제약이라 애초에 국소 확정 대상이 아니다).
- 층 0에 남는 자유도: 블록 안에서 닫히는 소자의 gm_id, 블록 안에서 닫히는 L 동치류의 L, 기둥 내부 VDS 배분, 블록 전류. 파일럿처럼 미러 동치류가 블록 5개를 가로지르는 회로는 L이 조립으로 넘어가 층 0의 결정이 gm_id·VDS로 좁아지지만 비지 않는다. DEC-04(소자별 독립)와도 충돌하지 않는다.

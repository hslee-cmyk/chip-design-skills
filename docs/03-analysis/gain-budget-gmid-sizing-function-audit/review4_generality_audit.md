# gain-budget-gmid-sizing plan v5.8 일반성 감사 (독립 검토)

- 대상: `docs/01-plan/features/gain-budget-gmid-sizing.plan.md` (997줄, 전수 열람)
- 보조 확인(실제 열람한 것만): `library/*.topology.json`의 `kind` 값 전수 grep, `nmcnr_amplifier.topology.json:59-60`, `two_stage_ota.topology.json:290-296`, `current_reuse_telescopic_ota.topology.json:1938-1943`, `stick_diagram.py:2856-2868`(`find_structural_symmetry_candidates` docstring)
- 표기: 모든 근거는 `plan.md:줄`. 반례 회로 번호는 과제의 1~10을 따른다.
- 반례 회로의 연결 가정(교과서 표준형):
  1. 5T OTA: NMOS 입력쌍 + NMOS tail + PMOS diode 미러 부하, 단일출력, 출력 CL.
  2. CS 증폭기: NMOS CS 1개, PMOS 전류원(또는 저항) 부하, 입력 포트 1개.
  3. 3단 NMC: 1단 차동→단일출력, 2·3단 CS, Cc1(출력→1단 출력), Cc2(출력→2단 출력), 선택적 Rz.
  4. 2단 Miller OTA + NMOS 소스 팔로워 출력(drain=VDD, source=출력, 전류 싱크).
  5. gain-boosted telescopic: 캐스코드 gate를 보조증폭기가 구동, 보조증폭기 입력은 캐스코드 source.
  6. CG 입력 TIA: 전류 입력 포트가 NMOS source, gate 바이어스, drain 저항 부하(+선택적 shunt Rf).
  7. FD folded cascode + 저항 평균 CT-CMFB.
  8. LDO: 오차증폭기(비대칭, 한 입력은 분압점), PMOS pass(CS), 저항 분압, CL+ESR, 레일 VIN/GND(+별도 bias 공급 시 3개).
  9. current-starved 인버터 증폭기(PMOS·NMOS CS 병렬 + 직렬 기아 소자) / 전류 미러 전류증폭기.
  10. native·고전압 소자 kind가 섞인 회로.

### 1.3 전체 판정

**부분 종속.** 원시 규칙(교류접지 3분류, 셀 우선순위, 단자 스탬프 블록 모델, 노드전압 정본·봉인·상태 계약)은 connectivity·LUT만으로 정의되지만, 그 위의 stage 구성(tail·input·load), L 동치류 주인, gain metric(DM), 보상 형식(Cc·Rz), 루프 뷰 생성 조건, 슬루·출력 전류 규칙은 "차동 입력 + 직렬 사슬 + Miller 보상 OTA"를 전제한다. 계획 스스로 범위를 "차동 입력 전압증폭기 계열"로 좁히고(137), 4개 회로 측정은 그 부류 안에서만 이뤄지므로 일반성 주장(244)을 뒷받침하지 못한다.

## 4. 일반성 측정 계획 점검

### 4.1 계획이 정한 측정

- DEC-47(221) "모든 동작 변경 Phase는 4개 회로 전부에서 측정", WP-05(244) "필요 없는 회로의 무동작 증명", IC7(634) "4개 회로 실행 + 필요 없는 기능 발동 계수 0", N6.3(806), N9.3(918).
- 무동작 증명의 정의(102): "발동 계수가 0이고 산출물이 전후 동일".

### 4.2 충분하지 않은 이유

1. **무동작 증명은 해가 없음을 보일 뿐 규칙이 맞음을 보이지 않는다.** 발동 0인 분기는 정답 여부에 대한 증거가 0이다. 계획 자체가 발동 0인 분기를 인정한다: follower 없음(231, 311), 전압 구동 CG 없음(308), 루프 탐지 결과 미측정(311 iii).
2. **4개 회로가 한 부류다.** 범위가 "차동 입력 전압증폭기"(137)이고, kind는 4개 회로 전부 `nmos`/`pmos`(수동은 resistor/capacitor/current_source)뿐이다(library grep). 파일럿은 차동 출력(`sense_p Vop`/`sense_n Vom`, current_reuse_telescopic_ota.topology.json:1941-1942), two_stage는 단일출력(`sense_p OUT`/`sense_n gnd`, two_stage_ota.topology.json:293-294). 레일 3개 이상은 nmcnr(`vdd`/`vss`)뿐인데 W0(341)는 이미 이를 반영하지 않는다.
3. **여러 검증이 4개보다 적은 회로로 되어 있다.** 3층 할당 대조 "파일럿과 한 개 회로"(422), 그룹 좌표강하·wall-clock 파일럿만(800-801), 결합 잔차 데이터 파일럿만(408), 레이아웃 비교 파일럿만(859), DEC-04 근거 파일럿만(179).
4. **U-22 기본안(858)이 측정 확대를 스스로 막는다.** 근거로 "WP-07상 픽스처 손타이핑 금지"를 드는데, WP-07(246)은 test 픽스처를 손으로 치는 것을 금할 뿐이고 library에 토폴로지를 추가하는 절차는 N9.3(918)에 따로 있다. 근거가 기본안을 뒷받침하지 않는다.
5. **oracle이 declared stage다**(311, 796). 신규 회로에는 declared가 없어서 부류를 넓히면 판정 기준이 사라진다(H-18).

### 4.4 제안

- **규칙 분기 커버리지 표를 regression 산출물로 둔다.** SP1·루프·보상·슬루·LR의 각 분기(위 표의 행)마다 library 회로별 발동 계수를 매 실행 기록하고, 발동 회로가 0인 분기는 `unverified_rule_branch`로 표시해 그 분기를 타는 신규 회로에서 STRUCTURE_UNRESOLVED로 정지한다.
- **"4개 회로"를 "각 분기 발동 회로 ≥1 + 기존 4개 무동작"으로 바꾼다.** DEC-47(221)·IC7(634)·N6.3(806) 문구를 함께 고친다. 추가 회로는 topology.json connectivity이므로 WP-07·WP-08·U-16 절차(사용자 확인)로 넣는다.
- **U-22 기본안을 "추가"로 바꾸고 근거를 N9.3으로 고친다**(858).
- **정답 기준을 ratified 대조표 + 독립 SPICE AC**(443)로 둔다. declared stage는 불일치 보고 입력으로만 쓴다.
- **발동 0인 분기가 있는 동안에는 일반성 주장을 보고서에 쓰지 않는다**("4개 회로에서 측정됨, 분기 X·Y는 미검증"으로만).

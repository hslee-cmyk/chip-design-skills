### 왜 조건이 물지 않는가 (구조 사실)

파일럿 CMFB 루프 `['N1a2a','Vom1','N_cc_rz2','Vop','Voc','Vcmfb','Vx']`에서
수동 구간은 `Rz2,Cc2,R2`(끝점 `Vom1`..`Voc`)이고 **나머지 호**는

```
Voc --M37a--> Vcmfb --M7--> Vx --M1a--> N1a2a --M2a--> Vom1
```

이다. 이 호의 **모든 노드가 순방향 경로 위**에 있다 — `Voc`·`Vcmfb`·`Vx`·`N1a2a`·`Vom1` 전부
"여기에서 도달 ∧ 출력 포트로 역도달"을 만족한다(파일럿 순방향 19넷에 다 들어 있다).
CMFB 감지·오차증폭 경로가 입력쌍을 거쳐 출력으로 이어지기 때문이다.

가장 엄격한 V3도 막지 못했다: 되먹임 커패시터 `Cf1[Vom,Vip]` 덕에
`Vip → Vom → Voc → Vcmfb → Vx → N1a2a → Vom1 → Vop`가 **실제로 단순 경로**다.

> **핵심**: 보상 루프와 되먹임 루프를 가르려면 **"나머지가 신호 흐름 방향으로 간다"**는
> **순서**가 필요한데, 같은 문단이 **"이 판정은 복귀 경로 계산(거리)에 의존하지 않는다"**고 못박는다.
> 순방향 경로는 **노드 집합**이라 방향을 담지 못한다. 조건이 물지 않는 근본 이유가 이것이다.

## 7. 판정: **커밋 보류 권고** (기각 아님 — "무효")

이 문장은 **library 9회로에서 분류를 하나도 바꾸지 않는다.** 근거로 적은 실측
("이 조건 없이는 (2) 11건 중 10건이 (3-b) 조건도 동시에 만족")은 **조건을 넣은 뒤에도 그대로 10건**이다.
계획서에 "이 조건으로 (2)와 (3-b)는 배타가 되고 판정 순서 의존이 사라진다"라고 적으면 **측정과 어긋나는 주장**이 된다.

### 선택지 (고르는 것은 규칙 설계 소관)

| 안 | 내용 | 대가 |
|---|---|---|
| **㉠ 이대로 커밋하되 문구를 사실에 맞춘다** | 조건은 남기되 "**현 library 발동 0**"을 명시하고(DEC-76 형식), "(2)와 (3-b)가 배타가 된다"는 주장을 **뺀다**. R8-01은 열린 항목으로 J11에 올린다 | R8-01 미해결이 계속 남는다. 다만 **커버리지 손실은 없다**(CMFB 루프 뷰 4개가 남으므로) |
| **㉡ (2)∧(3-b)면 루프 뷰도 만든다** | 새 판별식을 만들지 않고 "(2)로 분류해도 (3-b) 조건을 함께 만족하면 루프 뷰를 만든다"로 둔다 | 파일럿 루프 뷰 4 → **6**, ngcc 0 → **4**(끊는 점 후보는 측정상 전부 존재하므로 정지 위험 0 유지). J11 대조 규모가 는다 |
| **㉢ 순서를 쓰는 조건으로 바꾼다** | "나머지 호가 **블록 순서를 거스르지 않는다**"처럼 **구조적 순서**(BFS 거리가 아니라 블록 순서)를 쓴다 | "거리에 의존하지 않는다"는 문장을 "**BFS 거리**에 의존하지 않는다(블록 순서는 쓴다)"로 고쳐야 하고, 블록 순서를 입력으로 쓰면 **블록→루프 순환** 여부를 따로 확인해야 한다 |

**내가 재 본 범위에서 ㉡이 가장 싸다**: 새 판별식이 필요 없고, 이미 측정된 값으로
"루프 뷰 파일럿 6 · ngcc 4 · sf 3, 끊는 점 후보 0인 루프 0건, 정지 위험 0"이 곧바로 나온다.
**단 이것은 제안이고, 어느 안이 회로적으로 옳은지는 J11·J7 소관이다.**

## 8. 확인 못 함

1. **새 조건이 발동하는 회로가 존재하는지** — 9회로에서 발동 0인 것만 확인했다. 원리상 "나머지가 순방향 밖으로
   우회하는" 루프가 있으면 발동하지만, 그런 회로가 library에 없다.
2. **㉡을 택했을 때 파일럿 루프 뷰 6개·ngcc 4개의 끊는 점**은 이번에 (2)로 분류된 루프에 대해서는 재지 않았다
   (앞 라운드에서 같은 루프들에 후보가 있었음은 확인했다 — ngcc 4건 전부 후보 있음, 파일럿 6건 전부 후보 있음).
3. **㉢의 순환 여부** — 블록 순서를 루프 분류의 입력으로 쓰면 순환이 생기는지 확인하지 않았다.
4. **대칭(기모드) 축약 뷰** — 여전히 비축약 뷰만 측정했다. 축약하면 `Voc`가 가상접지가 되어 파일럿 CMFB
   사이클이 사라지므로 R8-01 자체가 축약 뷰에서는 나타나지 않을 수 있다(미측정).

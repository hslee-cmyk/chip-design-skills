# 최적화 축 감사 -- "전력·면적 2목적, 성능 스펙은 제약"이 계획서에 반영됐는가

- 사용자 지시(2026-09-16): "최적화 축은 전력과 면적이야. gm-id-methodology.md에 있는 것과 같이 등전력과 등면적 LUT에서 최적해를 찾는 것이 성능스펙이 만족하는 최적화의 목적이야."
- 방법론 근거(실제 확인): `gm-id-methodology.md` §6.4 "스펙(반드시 만족) = GBW·PM / **attribute(최적화 대상) = 전력, 면적**", "2D sizing space (gm/ID1, gm/ID2)에서 **등전력(타원)·등면적(쌍곡선)·등이득(점선) contour를 겹쳐 절충점 선택**", "등전류 contour ∩ 등면적 contour → 동일 전력·면적 두 구현. 면적 contour를 밀어 접점 → 주어진 전류의 최소 면적. 여러 전류 반복 → **전력-최소면적 관계**". §10.2는 면적 비용함수 `H = W1/L1 + W2/L2`를 제약(Cm1+Cm2 = α·CL) 아래 최소화하는 닫힌 해(등H 타원 ∩ 제약 직선의 접점).
- 대상: plan v5.12 작업본(1115줄, 커밋 전). 저장소는 수정하지 않았다.
- **결론: 반영돼 있지 않다.** 계획서 전체가 **단일 목적(전력) + 면적은 상한 제약**이다. 면적을 목적 축으로 다루는 곳은 한 곳도 없다(아래 표에서 '둘 다 목적' 0건).

## 3. 방법론 → 현 구조 정합안(문장 초안)

**(1) 축 선언(신설 DEC-77 초안)**
> **DEC-77 최적화 축은 전력과 면적 둘이다.** 성능 스펙(gain·GBW·PM·슬루·Rout 등)은 전부 **제약**이고, 최적화 대상(attribute)은 (전력, 면적) 2목적이다(`gm-id-methodology.md` §6.4). 엔진의 산출물은 스칼라 최적해 하나가 아니라 **제약을 만족하는 (전력, 면적) Pareto front**이며, 사용자가 예산·가중치를 선언하면 front 위의 한 점을 고르고 선언이 없으면 front를 제시하고 정지한다(DEC-07 개정). 면적은 U-13에서 확정한 정의 하나(`area_um2`)만 쓰고, 전력은 U-10에서 확정한 정의 하나만 쓴다 -- 두 축의 정의가 확정되기 전에는 front를 '추정'으로 표시하고 판정에 쓰지 않는다(DEC-72와 같은 규칙).

**(2) 블록 국소(층 0): 등이득 축을 bin으로, 나머지 두 축을 비지배로**
> DEC-71 (3) 목적을 교체: "목적 = (전력, 면적) 2목적. 블록 이득은 **등이득 contour**에 해당하는 bin으로 고정한다 -- gain bin마다 (전력, 면적) 비지배 점 집합을 남긴다(방법론 §6.4의 '등전력 타원·등면적 쌍곡선·등이득 점선 겹치기'의 이산 대응). 동률이면 포화 여유 최솟값이 큰 점."
> DEC-71 (6) 축을 교체: "(전력, 블록 이득) 평면" → "**gain bin별 (전력, 면적) 비지배 점 집합**". 점 수 상한은 축마다 분해능을 둔다 -- 전력·이득은 모델 오차(DEC-72), 면적은 U-13이 정하는 면적 추정 오차(레이아웃 추정과 Σ W·L의 차, LR8 실측에서 잰다).

**(3) 조립: front 생성**
> DEC-73 조합 선택을 교체: "조립 단계는 총 gain 제약과 조립 등식을 만족하는 조합 중 **(전력, 면적) 비지배 조합 전부**를 만든다(블록 순서 × 누적 gain bin DP, bin = 모델 오차·면적 오차). 단일 해로 좁히지 않는다. 사용자 선언이 있으면(면적 예산 또는 가중치) 그 점을, 없으면 front 전체를 산출한다. 동률·비교 불가 시 타이 브레이크는 (i) 활성 제약 여유 합이 큰 조합 (ii) 이름 정렬 첫 조합(NFR-4 결정론)."

**(4) 외층: ε-제약 스칼라화(방법론의 '면적 contour 밀기'와 동형)**
> 455 외층 행에 추가: "외층 SLSQP는 front 점마다 **ε-제약**으로 돈다 -- 그 점의 면적을 상한으로 고정하고 전력을 최소화한 뒤, 상한을 U-13 면적 격자만큼 밀어 다시 푼다(방법론 §6.4 '면적 contour를 밀어 접점, 여러 전류 반복 → 전력-최소면적 관계'). 가중합은 쓰지 않는다(볼록성 가정이 없다)."

**(5) 보고**
> N6.3·7b DoD에 추가: "산출물은 (전력, 면적) Pareto front 표(점마다 θ*, 활성 제약과 여유, gain 예산, 선택 여부)와 선택 점 하나다. front 점 수와 축 분해능(전력·면적)을 함께 적는다."

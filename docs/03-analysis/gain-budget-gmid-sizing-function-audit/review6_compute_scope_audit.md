## 0. 판정 기준과 실측 기반

### 0.1 "SPICE 미세조정 대전제"를 수치로 환산한 분해능 바닥

| 출처 | 수치 |
|---|---|
| `gm-id-methodology.md:464-469`(§6.5) | gm 4mS(hand) vs 4.05mS(sim), fp1 200→215MHz(**7%**), fp2 5.8→4.8GHz(**20%**). 저자 결론 "typical discrepancies are no more than **10-20%**" |
| `gm-id-methodology.md:481`(§6.6, 1996 원조 논문) | 전 절차를 지킨 gm/ID 합성은 HSPICE·실측 대비 **<5%**(gain/fT/PM/slew/swing 전부) |
| `gm-id-methodology.md:323`(§4.5) | "최종은 **고급 시뮬레이터로 미세조정** — gm/ID는 최적 근방으로 안내하는 도구" |

→ **모델 분해능 바닥 ≈ 이득 0.4~1.7 dB(5~20%), 극점 7~20%.**

* **A(필수)** = 빼면 결과가 이 바닥보다 **크게** 틀리거나, 틀렸다는 사실이 SPICE로 드러나도 **원인 규명이 불가**하다.
* **B(정밀도 과잉)** = 겨냥한 해상도·빈도가 이 바닥보다 가늘다. SPICE 미세조정이 흡수한다.
* **C(조건부)** = 특정 회로 부류·Phase에서만 발동한다.

### 0.2 이 대전제의 전제 결손 — 먼저 읽을 것

`RD:79`(사례 39, 유형 10 검증 부재):

> ngspice 대조는 세션21 **이상화 VCCS+R 넷리스트**(같은 gm/gds 입력)로 **MNA 솔버 정확성만** 확인(Adm 99.0154 vs 99.0154dB). 트랜지스터 레벨(BSIM) AC gain과 LUT 사이징 결과를 대조한 기록은 **미확인**. `cross_check_with_spice` def **0건**. … **LUT 1차 계산 오차 10~20%가 gain 제약 54dB 판정에 미치는 영향 미정량**. 근본원인: "검증이 **솔버 == 솔버**에 머묾, 사이징 모델 == 실소자 대조 없음"

**따라서 현재 계획의 정밀도 논쟁은 근거가 비어 있다.** 모델-실소자 오차가 몇 dB인지 모르는 채로 계획은 여러 곳에 **격자 분해능급(0.01~0.1 dB) 목표**를 박아 두었다 — NFR-5 "활성 제약 여유 ≤ 격자 분해능"(PLAN:174), 내층 DP "gain bin 해상도 = 인접 격자점 gain 차의 최솟값"(PLAN:447), bisection "종료 = metric 격자 분해능"(PLAN:621). 이 감사의 B 판정 대부분이 이 한 뿌리에서 나온다.

### 0.4 실측이 즉시 뒤집는 계획의 전제 4가지

1. **선형대수는 공짜다.** 전회로 MNA 135.6 µs + `parasitic_pm` 339 µs = 평가의 **1% 미만**(R6 M2).
   → PLAN:984의 위험 항목 "전체회로 MNA 반복으로 wall-clock 예산 초과"와 RD:62(사례 22, 세션21이 B21 수정을 "blast radius"를 이유로 제외해 **1개월 방치**)의 비용 전제가 **실측과 맞지 않는다**. DEC-05·DEC-66·잔차 기록을 비용을 이유로 줄일 근거는 없다.
2. **비싼 것은 LUT 곡선 생성과 사이징 루프다.** 곡선캐시 warm이면 `_solve_vgs` 6.74 µs × 51소자 = 0.34 ms로 평가 1회(≈80 ms)의 0.4%뿐이다. → **평가 1회 비용의 함수 단위 귀속이 아직 없다**(cProfile 기록을 저장소에서 찾지 못했다. 사례 33의 계측은 274.5 ms 시대의 것). **어느 층을 줄일지 정하기 전에 cProfile이 선행돼야 한다**(WP-10이 이미 요구).
3. **기둥 열거는 싸고, DEC-71 재정의는 실측으로 정당화된다.** R5V511:19(H1)가 옛 정의로 `two_stage_ota` 기둥 **1개**, `folded_cascode` 신호 경로 **0개**임을 실측해 층 0 무동작을 경고했고, 재정의(가지 + 단순 경로) 뒤 이번 실측이 각각 **3·7**로 회복됨을 확인했다(R6 M4). 동시에 기둥 수는 파일럿 62가 최대라 **PLAN:255 (3)의 "예산 초과 시 가지 단위 축소" 폴백은 현 library 7개에서 무동작**이다.
4. **library 7개 회로 전부 `supply_nets` 미선언**(R6 M4). U-26(b)는 6a의 실질 차단 조건이다.

**핵심 비대칭**: 잃어도 되는 것은 전부 **탐색·정밀도 계층**이고, 대체 불가한 것은 전부 **구조 유도와 물리 정합성 계층**이다. 그런데 계획의 구현 부담(7b)과 미확정 결정(U-13·U-14·U-23·U-32·U-33)은 대부분 전자에 몰려 있다.

## 3. 끝까지 남겨야 하는 최소 게이트 집합

경량 경로를 택해도 아래 8개는 전부 남긴다. 실측 기준 합계 런타임 = **평가 1회당 1 ms 미만**(MNA 136 µs + 봉인 µs급 + 카운터), 즉 평가의 **1% 미만**.

| # | 게이트 | 최소 형태 | 막는 실측 사고 |
|---|---|---|---|
| G1 | **DC 봉인**(N3.6 항목 1·2·3·5·7; 4·6은 W 티어·음전위 레일이 생길 때) | 평가마다 O(N_소자) | 사례 4: **76.48 → 52.17 dB(−23.5 dB)** 허구 기준값이 10세션 존속. 사고21 KVL 수정만으로 **+5.24 dB** |
| G2 | **노드전압 단일 writer**(W0~W4, 원시 대입 grep 금지) | 수치 비용 **0** | 사고 13·14·19·21·22·23·24(별표 최다 클래스). 버전 혼재 **7/51소자**, conflicts **4건 × 222.7 mV** |

| G4 | **LUT 축 범위 + 단조성 게이트**(LR3·DEC-11, DF-10 잔여 2곳 포함) | O(1) | 사례 32: **W 2.36배** 조용히 틀림, 1,895건, 최적점 L이 정확히 최악 구간 |
| G5 | **단위·이름 레지스트리 + 옛 키 거부 로드 게이트** | 런타임 **0** | 사례 31: `area_um2` 10⁶·10¹²배 → 면적 제약 **항상 만족** |

| G7 | **구조 유도 대조표 + `review_needed` 잔존 시 탐색 전 정지**(DEC-43·44·59) | 실행 1회 O(V+E) | RD:65(4회로 중 1개만 동작), RA:85(한 회로 3곳 불일치), 사고9(10건), §13.3(신호 5개 필요) |

## 4. 권고

### 4.1 전체 방향: **(ii) 경량 기본 경로 + 정밀 경로 선택**

(i) 그대로를 권고하지 않는 이유 두 가지.
1. 정밀 목표(격자 분해능)가 모델 오차(미측정, 문헌상 10~20%)보다 **2자릿수 가늘다**. 근거 선언값 없는 해상도를 목표로 삼는 것은 상수를 지어내는 것과 같다(WP-03의 정신).
2. 평가 1회 ≈80 ms 중 **선형대수가 1% 미만임만 확정**됐고 나머지는 **함수 단위로 귀속되지 않았다**. 어느 층을 만들지/줄일지의 근거가 아직 없다. 게다가 계획 자신이 §0.5의 계산비용 충돌 5건을 미해결로 적어 두었다.

(iii) 대폭 축소도 권고하지 않는다 — 구조 유도·봉인을 줄이면 41건 중 RC1·RC2 클래스(14건)가 그대로 재발한다.

## 5. 확인 못 한 것

* **평가 1회 ≈80 ms의 함수 단위 내역.** 선형대수가 1% 미만임만 확정(R6 M2). cProfile 기록을 저장소에서 찾지 못했다(사례 33의 계측은 274.5 ms 시대).
* **모델(LUT+MNA) 대 트랜지스터 레벨 SPICE의 실제 오차.** 저장소에 대조 기록 **0건**(RD:79). 이 감사가 쓴 1 dB 바닥은 문헌값이다.
* **층 0·3층 할당의 실제 평가 수.** 전부 미구현이라 DEC-34 식·실측 단가로 계산한 추정이다(U-33 미측정).
* **결합 잔차(블록 gain 합 대 전회로 gain)의 실제 크기.** HIST:5006 "**아직 측정하지 않았다**", RB:119 "이 검토는 그 측정을 하지 않았다".
* **내층 DP의 gain bin 수 실값.** bin 해상도가 격자에 의존하는데 블록 국소 모델이 미구현이라 계산할 수 없다.
* **`parasitic_pm_ss_deg` 제약이 어느 L에서 활성인지**(I-A10, folded는 `omega_c` 미노출로 측정 불가).
* **봉인 항목 6(벌크 역바이어스)·K7(뷰 공유)의 수치 오차 실측** — 둘 다 예방적·잠정 판독이며 실측 사례 미확인.
* **MT1~MT3 자동 분류의 타당성** — RB:216-221이 스스로 "이 검토의 **추론이며 실측이 아니다**"라고 명시.
* **RD 표의 사례 1·2 행 본문**이 파일에서 잘려 있다(`review_D…:43`이 사례 3 중간부터 시작). 내용은 RD:8·21·24 요약과 HIST:3375로 복원 가능.

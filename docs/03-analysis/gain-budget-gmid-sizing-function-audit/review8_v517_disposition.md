## 6. 유지한 것

* **절 번호 체계 N0~N9 유지**. 코드 주석·`.ai/context.md`·메모리·레지스트리가 N번호로 인용 중이므로 번호를 바꾸지 않았다. 추가는 `N9.4`(끝에 붙여 기존 번호 불변)와 N6.1·N6.2의 `0(문서)` 행뿐이다.
* 부록 A·B만 삭제했고 본문 절은 하나도 지우지 않았다.
* N3.16 "흡수되는 옛 이름" 열, N4.3 과거 사례 재생 표(커밋 해시)는 이력이 아니라 **실행 입력**이라 유지.
* MT1~MT3 ID 행은 DEC-74·N3.8이 그 이름을 인용하고 있어 정의 행을 지우지 않고 "(v5.12 폐기)" 버전 표기만 뺐다(감사는 행 삭제를 제안했으나 참조 무결성 때문에 압축으로 처리).
* DEC-15·DEC-19 행도 DEC-64·DEC-71이 사례로 인용하고 A.2 대응(A23→DEC-15, A31→DEC-19)이 있어 행을 지우지 않고 경위 문장만 뺐다.

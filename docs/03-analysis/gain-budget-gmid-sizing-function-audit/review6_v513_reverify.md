## 2. 작성자가 다르게 둔 1건 판정

- 쟁점: 탐색 축 대 판정 축 차의 `review_needed` 임계를 **PDK 격자값(내 제안)**이 아니라 **면적 축 모델 오차 선언값**으로 두었다.
- 판정: **작성자 판단이 옳다.** 격자값은 0.0021 µm² 규모인데 Σ W·L과 레이아웃 면적의 실제 차는 finger 간격·dummy·배선으로 그보다 몇 자릿수 크다(그래서 DEC-79가 두 축을 분리한 것이다). 그 값을 임계로 두면 게이트가 **모든 실행에서 항상 발동**해 `review_needed`가 상시화되고, 실제로 이상한 경우를 가려내지 못한다(WP-02의 "게이트는 실제로 거부한다"의 반대 극단). 선언된 모델 오차를 임계로 두면 "이번 회로의 차가 이전에 측정·선언한 차를 넘었는가"라는 판별력 있는 검사가 된다. 격자값을 보고 눈금과 bin 폭 하한으로만 남긴 것도 DEC-72의 "측정된 오차보다 가늘게 쪼개지 않는다"와 일관된다.

## 3. 새 모순 점검

- **bin 폭 확대 대 NFR-5**: 확대는 (ii) = max(격자, 모델 오차)에서 출발해 2배씩 커지므로, 확대가 일어나면 front 해상도가 NFR-5 여유 바닥보다 굵어질 수 있다. 확대 배수·사유는 기록하게 돼 있어 추적은 되지만, "굵어졌다"는 사실을 보고에 표시하라는 문장은 없다(아래 N1).
- **예산·LRU 정합**: 층 0 점 수 상한(459)·조립/DP 상태 수·S2 LRU 상한(402, 층 0 평가 수를 포함)이 모두 같은 bin 폭에서 나오고, 예산 게이트가 DEC-34 식 상한으로 잘라 준다. 전역 샘플이 기본 비활성이어도 식은 상한 계산용으로 남는다(408)라 계산 경로가 끊기지 않는다.
- **판정 축 재평가 대 MOD8·LR9·7b DoD**: 순서는 탐색(탐색 축) → 최종 front 재필터(판정 축) → 뒤집힌 점만 MOD8 재실행이고, 7b DoD(902)에 front 표·선택 점·"front 점이 서로 지배하지 않음" 픽스처가 있어 검증 경로가 닫힌다. 다만 재필터 ↔ MOD8 재실행의 **반복 상한**이 없다(아래 N2).

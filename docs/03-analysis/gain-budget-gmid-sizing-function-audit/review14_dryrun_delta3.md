## 5. 새 회귀 — 다섯 변경이 서로 충돌하는가

### (가) diode 제외 × 9 (c) diode 미러 갈래 — **모순 아님** ✓

두 규칙은 **같은 소자의 다른 속성**을 본다(`r7_checks.txt` (5)):

| 소자 | 셀 분류(규칙 3) | 9 (c) 갈래(그 **노드**의 성격) |
|---|---|---|
| 파일럿 `M36a@Vcmfb` | `load(diode)` | 미러 입력 → `M7` |
| folded `M7@Vg7` / `M9@Vg9` | `load(diode)` | 미러 입력 → `M8` / `M10` |
| ngcc `M3@ND`,`M6A@NX`,`M9@NP` | `load(diode)` | 미러 입력 → `M4`/`M7`/`M10` |
| nmcnr `M108@NodeM1`,`M203@NodeC` | `load(diode)` | 미러 입력 → `M109`/`M204` |
| two_stage(_sf) `M3@D3` | `load(diode)` | 미러 입력 → `M4` |
| 파일럿 `M36b@N36b` | `load(diode)` | **진짜 diode 부하** |

"셀이 아니다"(신호를 옮기는 주체가 아니다)와 "그 노드가 미러 입력이다"(노드 속성)는 양립한다.
9 (c)의 미러 갈래는 **노드**를 보고, 셀 제외는 **소자**를 본다.

> **단, `M36b@N36b`는 '진짜 diode 부하'로 판정되지만 `N36b`가 순방향 밖이라 (c)가 아예 평가되지 않는다.**
> → **(c)의 '진짜 diode 부하' 갈래는 현재 library 발동 0**이다. DEC-76("발동 0 분기는 구현하지 않는다")
> 대상으로 상태를 적어 둘 것(S3).

### (나) [**R7-01, S2**] 최소 고정점 (a)와 규칙 4 BFS가 '소자'인지 '셀'인지 명시가 없다

* 규칙 3의 도달성 (a)는 "**신호 넷을 gate로 받는 소자**의 drain·source 넷"이라 적는다 — **소자**다.
  그대로 읽으면 diode도 여전히 신호를 전파하고 신호 넷 집합이 불변이다(내 구현). **"셀이 아니면 전파도 안 한다"**로
  읽으면 folded `Vg9`가 신호 넷에서 빠지고 `M10`·`Vg10`·순방향 경로·CG 판정이 연쇄로 흔들린다.
* 규칙 4의 BFS 엣지도 "…인 **소자**의 gate->drain"이라 적는다. 내 첫 구현에서 diode를 셀 기준으로 빼 보니
  **BFS 거리가 바뀌어 복귀 경로 판정이 달라졌다**(파일럿 (3-a) 2·(3-b) 10 / folded (3-a) 2·(3-b) 0).
  소자 기준으로 되돌리니 위 절 2 ③의 값이 나온다.
* → **"셀이 아니다"라는 문장이 도달성·BFS에는 적용되지 않는다**는 한 줄이 필요하다. 지금은 읽는 사람마다 값이 갈린다.

### (다) 나머지 — 충돌 없음

* DEC-59 순방향 제한(셀 단위 분기) × 셀 수 집계 순방향 제한 × 9 (c) 순방향 제한 × CS/CD 타이브레이크 순방향 제한:
  **네 곳 모두 규칙 3 정본 정의의 같은 집합**을 쓴다(구현상 같은 객체). 순환 없음 ✓
* 9 (a)가 용어집 값을 "그대로 읽는다"로 바뀐 것: 재서술 제거만이므로 값 변화 없음 ✓ (tap 0 유지)
* 용어집 '셀'의 '방향 신호 그래프' → 최소 고정점 그래프 정정: 내 구현이 이미 그 그래프를 쓰고 있어 값 변화 없음 ✓

## 8. 확인 못 함

1. **루프 (3-b) 12건 각각의 끊는 점 후보 존재 여부** — 4라운드째 미측정. 규칙 2는 끊는 점이 없으면
   `review_needed`라 적으므로, 이것이 사이징 4회로에 남은 **유일한 미측정 정지 위험**이다.
2. **대칭(기모드) 축약 뷰** — 비축약 뷰만 돌렸다. 규칙 8 (ii)의 "축약 = 비축약" 검증 미수행.
3. **DEC-64 G_vgs 사이클 분류 수치** — 재측정하지 않았다.
4. **"diode는 셀이 아니다"의 좁은 읽기**(이중 출력 판정에서만 제외)로 돌렸을 때의 값 — 그 읽기는
   '둘 다 교류접지가 아닌' diode에 적용할 규칙이 남지 않아 구현할 수 없었다.
5. **규칙 3 도달성에 diode를 빼는 읽기**의 전체 파급 — folded 신호 넷이 줄어드는 것까지만 확인했고
   9회로 전수로 돌리지 않았다.
6. **어느 읽기가 옳은가** — R7-01은 "규칙이 두 답을 낸다"까지만 보고했다.

## 3. 검사 항목별 결론

- (a) "최소 전력 해" 전제 규칙은 전부 2목적으로 고쳐졌다: LR5 격자 확장(491 "두 축 비지배 개선 + 축별 max(분해능, 모델 오차)"), LR7(493 "(전력, 면적) 비지배 비교"), U-23(972 "목적 축 값(두 축)"), DEC-70 상위 k(259 "두 목적 축의 비지배 순위"), 중층 종료(461 "ε-제약으로 고정한 한 축 아래의 다른 축"), 7c DoD(902 "두 목적 축에서 지배당하지 않음"), 시작점(407). 실패 캐시(406)는 목적값과 무관해 영향이 없다. 잔존 모순은 M1뿐이다.
- (b) H1 참조. 상한이 DEC-34·S2 LRU·`wall_clock_budget_s`와 정합하지 않는다(S2 LRU 상한은 "층 0 평가 수 = 블록별 비지배 점 상한의 합"을 쓰므로 같은 인수로 커진다).
- (c) M2 참조. MOD8 수렴 루프·LR8과의 연결(차 > 분해능이면 재실행)은 DEC-79에 있다.
- (d) M3 참조. 그 밖에는 정합한다 -- U-10 확정(958)·DF-16(812)·U-23·U-33 지표가 모두 '목적 축 값(두 축)'으로 통일됐고, `_metric_supply_current`의 레일 인자 정리는 MG1(Phase 4) → 교체 7a 순서라 앞뒤가 맞는다.
- (e) 순환 없음. 7a가 모델 오차·전력 정의·면적 두 축·분해능 식을 **산출**하고 7a DoD가 그 산출물의 존재를 확인한다. DEC-80의 입력(PDK 선언값)은 Phase 4라 앞선다. front는 눈금 확정 전 '추정'으로만 쓰이고 층 0 실행은 7b다.
- (f) 참조 무결성: DEC-77~80 정의(262~265), 용어집 2행(97·98 다음 '목적 축 / 제약'·'(전력, 면적) front'), N1.1 (f), I-A2 닫힘(N5.3 머리 + A.2), U-10·U-13 갱신, 부록 A.2 v5.13 신설 목록까지 이어진다. N0 위반은 L3 한 건(경계), 승인·지시 범위 밖 과잉 변경은 없다.

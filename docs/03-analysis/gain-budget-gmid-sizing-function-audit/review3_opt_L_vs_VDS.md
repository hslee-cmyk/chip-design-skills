### 1.2 L과 VDS가 각각 바꾸는 것

| 항목 | L 증가 | VDS 증가 | 근거 |
|---|---|---|---|
| intrinsic gain gm/gds | 크게 오르지만 수확체감이 있다. nmos VDS=0.6V: 0.15→0.35µm에서 3.94배, 0.35→4µm에서 추가 4.0배 | 저VDS에서 급하게 오르고 이후 완만하다. nmos L=0.35µm: 0.2→0.4V에서 22.9→53.0, 0.6→1.2V에서 70→93.5 | S1, S2 |
| L·VDS 상호작용 | 긴 L일수록 VDS 효과가 커진다. pmos L=1µm: VDS 0.2→1.2V에서 64.6→636 (9.8배). L=0.15µm에서는 7.3→8.9 | 짧은 L에서는 VDS를 올려도 gain이 거의 안 오른다(pmos 0.15µm) | S2 |
| fT / 기생 pole | 급락한다. 0.15→0.35µm에서 0.287배, 1µm에서 0.041배 | 거의 불변이다. L=0.35µm, 0.2→1.2V에서 3839→4634MHz(+21%) | S1 |
| W, 면적 W·L | 커진다. L 0.15→4µm에서 면적 498.8배 | 약간 줄어든다. W −15% | S1 |
| 매칭 σ ∝ 1/√(WL) | 좋아진다. 0.35µm에서 2.07배 | 거의 영향이 없다(W −15%면 √WL −8%) | S1, Pelgrom |
| 헤드룸 | VGS가 약간 줄어든다. nmos 0.779→0.650V (0.15→4µm) | VDD 제로섬이다. 스택 KVL로 묶인다 | S1 |
| 미러 전류비 정확도 | **L이 같아야 비가 W비로 축약된다.** 아래 1.3 참고 | 같은 L이라도 ΔVDS가 CLM 오차를 만든다 | S5 |

### 1.3 미러: 같은 L이 주는 이점 (S5)
조건: 기준 L=0.35µm, W/L을 같게 맞춘 이상비 1, VDS=0.6V.
- **nmos**
  - 출력 L=0.5µm면 비오차가 +20.7%(g=15), +35.5%(g=22)다.
  - VGS가 공통으로 +20mV 이동하면 비오차가 −2.25pp 변한다. 즉 오차가 바이어스점을 따라 움직인다.
  - 출력 L=1.0µm, g=15에서는 +82.6%이고, +20mV 이동에 −9.6pp 변한다.
- **같은 L**: 비오차는 정의상 0이다. 남는 것은 ΔVDS=0.1V에 의한 CLM 오차뿐이고, 크기는 L=0.35µm에서 2.07%, L=1.0µm에서 0.84%다.
- **결론**: 서로 다른 L의 미러는 수십 % 계통 오차가 나고, 그 오차가 바이어스 이동에 따라 움직인다. 이 LUT는 tt 한 코너뿐이라 PVT 코너 자체는 재지 못했다. VGS 이동은 PVT에 대한 대리 지표로만 봤다. 이 결과는 LR1·DEC-17(`true_current_mirror_groups` docstring, `sizing_recipe.py:2363-2368`)을 정량으로 뒷받침한다.
- **주의**: pmos L=0.15µm, g=22에서는 +8913%라는 비정상 값이 나왔다. `gin_cap_check.txt`에서도 pmos 0.15/0.2µm의 gm_id≥16 구간은 W가 수천 µm로 나온다. pmos 짧은 L의 약반전 끝 구간은 LUT 신뢰도가 낮다.

### 1.4 VDS만으로 gain을 올릴 수 있는 범위 (S3: iso-gain 최소 면적, gm_id=15, ID=5µA)

| nmos gm/gds 목표 | VDS≤0.3V | VDS≤0.6V | VDS≤1.2V |
|---|---|---|---|
| 80 | L=1.0µm, WL 3.36µm² | L=0.425µm, 0.61 | L=0.35µm, 0.39 |
| 120 | L=2.5µm, 18.2 | L=0.7µm, 1.65 | L=0.5µm, 0.84 |
| 200 | 불가 | L=2.5µm, 17.9 | L=0.7µm, 1.63 |

- 이 표에서 모든 목표에 대해 VDS=1.2V일 때 최소 면적 해의 L은 knee(0.25~0.35µm) 이상이다. **VDS만으로 L을 대체하는 영역은 없다.** VDS는 필요한 L을 줄여줄 뿐이다.
- 파일럿 stage1은 VDD 1.8V에 6소자 스택(M6-M1a-M2a-M3a-M4a-M5)이라 VDS가 평균 0.3V다.
- VDS 상한이 0.3V면 같은 gain 80에 드는 면적이 VDS 1.2V 대비 8.6배다(3.36 vs 0.39).
- 즉 **"VDS 먼저"는 헤드룸이 넉넉한 스택에서만 싸다.**

### 2.4 해석
- **Q1/Q2/Q3는 L 조합 수가 압도적으로 작다.**
- 그러나 파일럿에서 거대 동치류가 이미 L 변수의 대부분(51소자 → 21)을 흡수했다. 남은 P의 L 변수는 신호경로 매칭쌍(M1·M2·M3·M4·M15/25·M16/26·M9/18a·M9/18b 등)이다.
- 이 소자들은 블록 DP로 **블록 단위로 분해해 풀면**, 21차원 곱이 아니라 블록별 곱의 합으로 계산량이 준다(2.5 참고).

## 3. 스펙 딱 맞춤(NFR-5) 관점: S6 결과

### 3.1 S6 모델 정의
- **소자**: 반회로 M1a(pmos 입력)-M2a-M3a-M4a(nmos 입력).
- **입력쌍**: gm_id 공유(`compensation.shared_gm_id_groups`), gm_in 합은 고정.
- **gain**: `2·Xu·Xd/(Xu+Xd)`, `X = A_in + A_cas·g_in/g_cas + A_in·A_cas`.
- **KVL**: `ΣVDS ≤ VSG1 + VGS4`.
  - 두 입력 게이트가 같은 Vip에 붙어 있으므로 `Vx − Vy = VSG1 + VGS4`다.
  - 즉 stage1 내부 3노드의 창 폭은 **입력 소자의 gm_id·L이 정한다**(W2 성격). 이것은 스택 전체 VDD를 자유롭게 나누는 문제가 아니다.
- **목적**: 전력 최소(g_in 최대)를 먼저, 그다음 면적 최소.
- **넣지 않은 것**: gmb, 기생 pole(LR6), tail 포화, 블록 간 결합.

### 3.2 결과 (T: stage1 gain 목표, 셀 = 오버 dB / 반회로 면적 µm²; g_in은 표에 적지 않은 한 17)

| 방법 | 50 dB | 60 dB | 70 dB | 80 dB | 최대 gain |
|---|---|---|---|---|---|
| P | **0.10 / 14.69** | **0.06 / 15.02** | **0.07 / 15.81** | **0.04 / 19.71** | 89.2 |
| B = U-23 강제 (블록 안에서 Q2와 같다) | 0.47 / 15.10 | 0.38 / 15.34 | 0.07 / 16.04 | 0.06 / 20.87 (+5.9%) | 89.2 |
| Q3 = 블록 단일 L | 0.90 / 16.51 | 0.15 / 16.60 | 0.13 / 16.83 | 0.09 / **33.25 (+69%)** | 89.2 |
| Q4 = 단일 L ∈ {0.25, 0.3, 0.35}µm | 2.77 / **45.63** | 0.55 / 45.66 | g_in=16(전력 +6%), 0.02 / 8.63 | **불가** | 70.4 |
| H = 소자별 L ∈ kind knee 후보 3 | 0.96 / 45.01 | 0.12 / 45.12 | **불가** | 불가 | 69.2 |
| P-Veq = L 독립, VDS 균등 고정 | 1.70 / 15.29 | 0.54 / 15.54 | 0.16 / 16.04 | 0.15 / 20.06 | 88.6 |

### 3.3 판독
1. **L을 knee 근방으로 묶어두면 전력 최소점에서 면적이 3배로 강제된다.**
   - 원인(`gin_cap_check.txt`): pmos 입력은 gm_id=18에서 모든 L에서 W>200µm(W_bounds)라 g_in 상한이 17이다.
   - g_in=17에서 L별 W는 0.35µm 127µm, 0.425µm 38µm, **0.5µm 29.6µm(최소)**, 1.0µm 58µm다.
   - 그래서 P/B/Q3는 L1=0.5µm를 골랐다. knee 이하로 묶인 Q4·H는 W=127µm(L=0.35µm)를 강제로 쓰게 되어 면적이 45µm²다.
   - **이 제약은 gain이 아니라 전류밀도(IDu)와 W 한계가 L을 요구하는 경우다.** VDS로는 해결되지 않는다(IDu의 VDS 의존은 약하다, S1 W −15%).
2. **gain 상한**: knee 근방 이산 L만 쓰면(Q4, H) 69~70dB에서 막힌다. 80dB에는 L 0.7µm가 필요했다(P·B·Q3 모두 L2~L4=0.7µm). 이산 후보는 **확장 규칙이 있어야** 쓸 수 있다.
3. **VDS 자유 배분의 가치는 면적보다 맞춤 정밀도에 있다.**
   - P-Veq 대비 P의 면적 차: 60dB에서 −3.4%, 70dB에서 −1.4%, 80dB에서 −1.8%.
   - 오버 dB: 50dB에서 1.70→0.10, 60dB에서 0.54→0.06.
   - VDS는 연속 미세조정 노브로 NFR-5의 "여유 ≤ 격자 분해능"을 싸게 달성한다.
   - 반대로 L 없이 VDS만으로는 80dB의 면적을 못 맞춘다(Q3 +69%).
4. **U-23 (B vs A=P)**: 이 블록에서 B는 평가 옵션이 1/9, 시간이 1/5이다. 대신 면적이 50dB +2.8%, 80dB +5.9%이고, 오버가 0.47dB로 P의 0.10보다 크다.
   - 계획의 판정 규칙(`plan.md:847`: "B가 평가 수를 줄이면서 목적값·제약 여유·면적이 A와 격자 분해능 안에서 같거나 나으면 B")을 적용하면 **이 모델에서는 A 유지**다. 면적 차가 격자 분해능보다 크다.
   - 전력 목적값은 둘 다 g_in=17로 같았다.
5. **T=30/40dB 오버(5~22dB)**: 모든 방법에서 생긴다. gain 제약이 비활성이고 전력·W 한계가 L1=0.5µm를 강제하기 때문이다. NFR-5는 **활성 제약**의 여유만 규정하므로 위반은 아니다. 다만 "스펙 오버"로 보고할 때 활성/비활성 구분을 명시해야 한다.

### 3.4 모델 한계 (결론을 과신하지 말 것)
- **tail 헤드룸**: VDD−VSG1−VGS4가 0.11~0.29V뿐인데 tail 두 개의 포화를 강제하지 않았다. 실제로는 입력 gm_id·L 선택을 더 조일 것이다.
- **미반영 항목**: gmb, 기생 pole 상한(LR6), CMFB·미러 결합이 없다.
- **LUT**: tt 한 코너이고, pmos 짧은 L 약반전 끝은 신뢰도가 낮다.
- **S6의 성격**: 전체회로 MNA가 아니라 블록 국소 근사다. 계획 N3.8 기준으로 MT1 수준이다.

## 5. 권고: 하이브리드 (P 구조 유지 + L 후보 좁히기와 확장 + VDS는 연속 미세조정)

### 5.1 원칙
1. **L의 단위는 P의 동치류로 둔다.** 등식 관계 외의 L 공유 강제는 넣지 않는다. Q1/Q3는 파일럿에서 cross-kind 결합으로 분리성을 깨고, 면적 오버를 강제한다.
2. **각 동치류의 L 격자는 좁혀서 시작한다.** 전 격자 대신 {knee 앵커와 그 이웃}과 {`feasible_L_window` 하한}의 합집합에서 시작한다.
   - `feasible_L_window` 하한은 W_bounds·전류가 요구하는 최소 L이다. 파일럿 pmos 입력의 0.5µm가 이 경우다.
   - 실측상 knee 후보만 쓰면(H) 면적 3배·70dB 상한이 생기므로, **실현가능 창을 반드시 합쳐야** 한다.
3. **확장 규칙**: 블록 gain 상한 `A_i,max`(N3.7)가 목표에 못 미치거나 W 한계로 실현 불가하면, 그 동치류만 LUT 앵커를 한 칸씩 위로 넓힌다. 상한은 LR6(parasitic_pm_deg)이다.
4. **VDS(W4)의 역할**: DP 결정변수를 줄이는 1차 노브가 아니라, L 격자점 사이의 **연속 미세조정 노브**로 둔다. 실측으로 오버 1.7→0.1dB의 정밀도를 주고, 면적 이득은 1~3%다.
   - LR7의 "L보다 VDS 먼저"는 스택 헤드룸이 넉넉할 때만 싸다(S3: VDS≤0.3V면 면적 8.6배).
   - stage1 같은 current-reuse 스택에서는 창 폭 자체가 입력 gm_id·L에 종속된다(`Vx−Vy = VSG1 + VGS4`).

### 5.2 계획서 수정 문안 제안
- **N3.9 LR7 교체**:
  > "gain이 부족하면 (1) W4 자유 노드전압 창이 남아 있으면 먼저 재배분한다. (2) 창이 `Σ VDS_min` 근처로 소진됐거나, 창 폭이 그 블록 소자의 VGS에 종속되는 경우(예: 입력 게이트가 공유된 current-reuse 스택)에는 VDS 재배분을 L 확장과 같은 격자 단계에서 함께 평가한다. 어느 노브를 쓸지는 순서 규칙이 아니라 블록 DP의 목적값(전력, 다음 면적)으로 정한다. 근거: review3 S3(VDS≤0.3V에서 iso-gain 면적 8.6배), S6(P vs P-Veq 면적 차 ≤3.4%)."
- **N3.9 LR5에 추가**:
  > "L 동치류의 초기 탐색 격자 = {kind knee 앵커와 인접 앵커} ∪ {`feasible_L_window` 하한 앵커}. 블록 gain 상한이나 W 한계로 실현 불가하면 그 동치류만 인접 앵커로 한 칸씩 확장하고, 상한은 LR6이다. 전 격자는 확장이 LR6에 닿은 뒤에만 쓴다. 근거: review3 S6 H(knee 후보만 쓰면 70dB 상한, 면적 3배)."
- **N3.7 내층 블록 DP에 문장 추가**:
  > "DP 결정 벡터는 kind가 다른 소자의 L을 같은 변수로 묶지 않는다(반회로 분리성 유지). 등식 관계가 cross-kind로 걸린 경우만 결합 좌표로 스캔한다. 근거: review3 S6 Q3(L 조합 1/729인데 벽시계 시간이 P보다 김)."
- **DEC-04 보완**: "소자별 독립"을 유지하되 다음 문장을 붙인다.
  > "L을 kind·블록 단위로 통일하는 방식(Q1~Q3)은 파일럿에서 L 동치류가 5블록을 모두 병합(실효 1)해 Q1과 같아지고, 80dB 블록에서 면적 +69%를 강제하므로 채택하지 않는다(review3)."
- **NFR-5 해석 주석**:
  > "스펙 오버는 활성 제약에 대해서만 판정한다. 비활성 제약(예: 전력·W 한계가 L을 강제해 gain이 남는 경우)의 여유는 오버로 세지 않고 보고에 '비활성'으로 표시한다."

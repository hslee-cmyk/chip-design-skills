## 2. 검사 항목별 결론

- **(a) DEC-81 ↔ DEC-59·DEC-76·N1.2**: 한 문장으로 정합한다 -- 속성 `계산 규칙 있음` / 상태 "미구현(발동 0, U-34)" / 동작 "그 분기를 타는 회로는 DEC-59가 탐색 전 정지". N1.2 행도 "계산 규칙은 DEC-81로 정의돼 있고 남은 것은 발동 회로 추가(U-34)"로 바뀌어 out-of-scope 판정 규칙과 어긋나지 않는다. DoD도 "발동 0"을 판정 대상으로 적어(6c: "분기·합류가 없으면 묶음 0과 발동 0을 명시") 조용한 무동작이 막힌다.
- **(b) Q1 ↔ 착수 조건·U-26·MG1·IC11**: 순환 없다. 기존 4개 회로는 레일이 정확히 둘(vdd/gnd 또는 vdd/vss)이라 MG1(Phase 4)까지 전환기 해석으로 Phase 4까지 갈 수 있고, U-26 (a)가 Phase 4라 MG1과 같은 시점에 닫힌다. 신규 3회로는 `agnd` 3레일이라 선언 전에는 GB0에서 거부되며 U-26 (b)가 6a 착수 조건이다. 따라서 "선언 전에 갈 수 있는 곳" = 기존 4개는 Phase 4, 신규 3개는 6a 착수 전까지로 문서에서 읽힌다. 거부 증명이 공격 13 + IC11 선행 조건으로 배선됐다.
- **(c) Q2 ↔ 62 실측·DEC-76 상한·층 0**: 폭발하지 않는다. 현 library 최대 레일 수는 3(sf·pushpull)이라 쌍은 최대 3개이고, `agnd`에는 DC 엣지가 없어 (vss,vdd) 쌍만 경로를 낸다(실측 재확인: sf 기둥 8, 미포함 MOS 0). 파일럿 62가 (최저, 최고) 쌍의 값이라는 서술도 그대로 유지됐고 DEC-76의 "예산 상한 이하" 근거가 그대로 성립한다.
- **(d) DEC-81 ↔ 층 0·조립 DP·K8·병렬 셀**: 겹치지 않는다. 병렬 셀 한 블록 규칙은 **블록 내부**(같은 출력노드로 합류하는 셀), DEC-81은 **블록 사이**(같은 합류 노드를 공유하는 병렬 경로 블록)다. K8과의 우선순위는 N3.7 (a)/(b)와 "두 조건에 모두 해당하면 (a)"가 그대로 남아 있다. 층 0 기둥 집합과의 범위 산정은 결정표 Q6이 밝힌 대로 미기재이며, 발동 0 상태에서 규칙을 더 쓰지 않은 판단은 WP-17·DEC-76과 맞는다.
- **(e) U-34**: 7b 착수 조건에 "U-34(복합 블록 검증 회로를 **추가할지** -- 추가하지 않으면 그 분기는 발동 0인 채 DEC-59가 정지시킨다)"로 적혀, 결정이 "추가 안 함"이어도 7b가 막히지 않는다(U-13 면적 예산과 같은 형식).
- **(3) 사실 확인**: `ngcc_3stage_topology`는 `sizing_recipe.py`의 `_COMPENSATION_REGISTRY` import(1464~1471행)에 실재하고 DF-31이 가리키는 함수와 같다 ✓. `gm-id-methodology.md` §10.1~§10.2(NGCC, feedforward 조건 gmf,i = gm,i, 면적 비용함수 닫힌 해)도 실재한다 ✓. CG 8 / 축약 6 / pass 묶음 2와 역병렬 쌍 오발동 0은 v5.14 재검증에서 잰 값 그대로다 ✓.

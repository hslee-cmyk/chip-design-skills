## 4. 감사자 유보 사항

* 토큰 수(83,000)는 **추정**이다. 문자·바이트·줄 수는 실측이다.
* 절감 자릿수는 항목별 문자 수 실측에 기반하되, "압축"으로 분류한 E 항목의 절감은 압축 후 문장을 아직 쓰지 않았으므로 **예상치**다(표에 그렇게 표기했다).
* `00-common`이 N6.1에 없다는 것은 문자열 검색(`grep -n "00-common"` → 1026행 단 1건)으로 확인한 사실이다.
* history 문서의 신설 절 구조는 제안이며, 실제 이관은 사용자 승인 후에 한다(저장소 무수정 원칙).

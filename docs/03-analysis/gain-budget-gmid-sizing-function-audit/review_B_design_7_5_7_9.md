## Q1. gain 할당의 정식화 -- 분리형 DP는 성립하는가, 결합 항은 무엇이고 어떤 해법이 맞나

### Q1.1 DP가 요구한 분리성

H:1613-1615: "각 stage의 (전력, 면적, gain)은 자기 gm_id_i에만 의존 [L_i, VDS_i 고정 시], 결합은 오직 합으로만".
프로토타입의 stage 표는 PR:36-45에서 `LUT.gm_gds_ratio(g, L, vds, VS)` 즉 **구동소자 하나의 intrinsic gain**이고 `VS=0` 고정(PR:32)이다.
PR로 확인한 것은 "intrinsic 표가 주어졌을 때 DP가 전수와 일치한다"(H:1636)까지다. **회로 gain이 그 표의 합이라는 것은 검증한 적이 없다**.

### Q1.3 graph로 결합 항을 정의하는 방법

1. **블록**: S1v 차동 뷰의 SCC 응축 DAG에서 stage 블록 B_i(§Q2의 분할 규칙).
2. **블록 국소 변수 x_i**: B_i 안의 gm_id 동치류, L 동치류(블록 안에 닫힌 것), 블록 내부 노드전압(D1).
3. **결합 변수 y**(S1 엣지에서 기계적으로 추출):
   - K1: B_i 출력노드에 drain이 있으나 B_i에 속하지 않는 소자의 (gm_id, L, vds, vsb) -- 출력노드의 **terminal 목록**(H:2918)에서 나온다.
   - K2: `equal_vgs` 동치류 중 소속 소자가 2개 이상 블록에 걸친 것.
   - K3/K4: `stacked_vsb` 엣지와 vertical_stack 노드 사슬 중 2개 이상 블록에 걸친 것.
   - K5/K6: 신호경로 노드(`signal_path_nodes` SR:4043)에 게이트가 물린 다음 블록 소자의 Cgg, 보상 수동소자(Cc).
4. **정확한 분해식**: DC 차동 뷰에 블록을 가로지르는 피드백 SCC가 없으면
   `gain_total(x, y) = Σ_i 20log10( gm_i(x_i) · R_out,i(x_i, y) )`
   이고, 조건부로(y 고정) **완전 분리**된다. R_out,i에 외부 부하 gds를 넣는 것이 `gain_stages_sum`(SR:3028-3037, 선언 소자만)과의 차이다.
5. **분리성 판정은 측정으로**: 위 식과 `gain_full_circuit_db`(SR:5615)의 차이를 θ마다 계산해 "결합 잔차"로 둔다. 기존 `tests/probe_mirror_gain_ranking.py`의 6480조합(P:735)이 그대로 검증 데이터다 -- **이 검토는 그 측정을 하지 않았다**(읽기 전용). 잔차가 0에 가깝지 않으면 DC 뷰에도 블록 간 피드백(예: class-AB M9a/M9b 2-사이클, P:939)이 있다는 뜻이고 그 부분은 T3로 남는다.

### Q1.4 DP / 좌표강하 / SLSQP 중 무엇이 맞나 -- 권고: **3층 조합, 역할을 나눈다**

| 층 | 방법 | 맡는 것 | 왜 이 방법인가(근거) |
|---|---|---|---|
| 내층 | **조건부 블록 DP**(y 고정) | 블록 국소 변수 x_i의 전역 최적 배분 -- 전력 최소, gain ≥ target, 면적 ≤ budget | 비단조(A11)라 기울기 방법은 부적합, 탐욕은 37.5% 오답(H:1635). y 고정이면 K1~K4가 사라져 H:1613의 분리성이 **정확히** 성립. N=4 0.294s(H:1636) |
| 중층 | **결합변수 y에 대한 블록 좌표강하** | y(공유 VGS 동치류, 경계 부하 소자, 공유 스택 노드전압)를 1차원 격자 스캔으로 갱신 → 내층 DP 재실행 | y 차원이 작다(파일럿 미러군 3개, P:735). 각 단계가 정확 최소화면 목적값 비증가. 내층 표는 x_i만의 함수라 **y가 안 바뀐 블록의 표는 S2 memo 적중**(P:982) |
| 외층 | **SLSQP 연속 polish + T3 전역 게이트** | 격자 해상도 오차, K5/K6(PM·보상), DC SCC 블록이 남긴 T3 제약 | SLSQP 단독은 98% infeasible·페널티 경사 0(P:932), 국소해(P:940) -- **시작점**을 DP 해로 주면 그 약점이 줄어든다. 판정권은 전역 게이트(H:680-682) |

- **DP 단독이 안 되는 이유**: B21(K1)과 B19'(K2)가 파일럿에서 실측으로 존재한다.
- **좌표강하 단독이 안 되는 이유**: 블록 내부가 비볼록·비단조(A11)라 x_i 방향 1-D 갱신은 탐욕과 같은 실패를 할 수 있다. 내층 DP가 그 방향을 전수로 대신한다.
- **SLSQP 단독이 안 되는 이유**: 현행이 이미 그렇고(SR:9651-9654, `_optimize_theta_slsqp` SR:11342) §12.3-2/-10의 결과다.
- **gain metric이 T3인 회로**(folded/nmcnr/two_stage, H:1511-1516): 내층 표의 gain은 대리(proxy)이고, "DP 예측 vs 전역 게이트 실측"을 나란히 보고(H:682). Q1.3-5의 잔차가 곧 그 괴리다.
- **B21 결정 권고**(P:738 선택지 ①②③ 중): ③의 변형 -- **제약 판정은 `gain_full_circuit_db`**(전체 MNA), **할당은 K1을 포함한 블록 gain**(②의 "누가 부하인가"를 선언 대신 출력노드 terminal로 유도), **괴리는 블록별 귀속 metric으로 감시**. 판정권을 전체회로 쪽에 둬야 목적함수가 눈먼 제약을 이용하는 B21 현상이 구조적으로 막힌다. ★ 회로 해석이 걸린 결정이라 D8 공동분석 대상.
- **S2/S3의 역할**: 블록 표 (gm_id 격자 × L 동치류 × 경계상태 y × LUT 해시) → S2 memo, 평가 간 재사용. 좌표강하의 각 (y, 배분, 제약여유, 실패분류) → S3 아카이브, Pareto front(§7.9-12)와 실현가능 조각이 부산물로 누적.

## Q2. `A_i,max` 실측과 stage 분할(G6)의 선후 -- 분할이 먼저다

### 선후 근거

- `A_i,max = max over (gm_id,L,VDS) of [gm/gds]`(H:1364)는 **"stage i에 어떤 소자가 속하고 그 출력노드 R_out을 누가 이루는가"가 정해진 뒤에만** 정의된다. K1(부하 소유권)이 미정이면 같은 소자 집합에서도 A_i,max가 26dB 달라진다(B21, P:738).
- §7.9 Phase 2의 feasibility 검사 `Σ A_i,max < gain_target → Phase 1 피드백`(H:1396)은 합의 **항 구분**이 틀리면 거짓 feasible/infeasible을 낸다.
- 현재 분할은 손 선언(`gain_stages_sum.stages` TJ:1883-1897, `compensation.stage_devices`)이고 규칙이 없다(G6, P:756; H:2986-2988). §8.3의 5신호 전용은 입력쌍을 cascode로 오분류(P:756).
- 따라서 순서: **S1(θ-무관) → S1v 분할(θ-무관, topology당 1회, P:962) → 블록별 A_i,max 표(θ-의존, LUT만, S2 memo) → Σ 검사 → 할당(Q1)**.

### 분할 규칙이 받아야 할 입력

| 입력 | 이유 | 출처 |
|---|---|---|
| connectivity + 단자 타입(gate/drain/source) + **수동소자** | 신호 방향 `gate→drain`, `source→drain`(SR:4047, SR:4056-4065). Miller Cc·CMFB 저항은 루프를 닫는다(P:939) | S1(P:961) |
| `ports` input/output | DAG의 시작·끝. two_stage_ota는 출력 미선언(two_stage_ota.topology.json:322) | D5(P:1021) |
| **여기 모드**(DM / CM / supply) | 방향과 루프가 모드마다 다르다(P:939). stage 분할은 DM 뷰 기준, tail 판정은 CM 뷰 대조 | S1v(P:962) |
| AC 접지 집합(레일, 이상 소스, excite=0 단자) | bias 노드를 신호경로에서 뺀다(SR:4048-4051 실측: bias 노드가 각 ~90° 먹음) | S1 + spec |
| diode/미러/L 동치류 정본 | bias 가지를 한 단위로 축약, 경계 결합(K2) 식별 | S1 "개념당 정의 하나"(P:961) |
| 피드백 엣지 + 극성(SCC 응축) | 피드백을 stage 순서에서 빼고 안정성 해석에만 | S1v(P:962), H:2942-2944 |
| **받지 말아야 할 것**: role 라벨, LUT 값, θ | C4(P:302). 분할은 θ-무관이어야 S1 키(topology+유도규칙 해시)로 캐시된다(P:961) | -- |

### 분할 규칙 후보(가설 -- 4회로 대조 전 미검증)

- DM 뷰 SCC 응축 DAG 위에서 **고임피던스 노드**(드레인만 물린 노드)를 stage 출력 경계로 본다. 이 구분은 §7.11 구현이 이미 쓰는 것이다: 소스가 붙은 노드는 `1/(gm+gds)` 저임피던스, 드레인만 붙은 노드는 고임피던스(P:656-660).
- 입력 경계~출력 경계 사이 신호경로 소자 = stage 구동/캐스코드(캐스코드는 저임피던스 source 노드를 거치므로 같은 stage에 남는다), 출력노드에 drain이 있고 신호경로 밖인 소자 = 그 stage의 **부하**(K1), 공통 source 노드를 drain으로 잡는 CM 경로 소자 = tail(§7.6-1).
- current-reuse(M1a∥M4a)는 한 stage 안의 gm 서브그룹 2개(H:1472-1473).
- 유도 결과는 손 선언과 **대조만** 하고 불일치는 `review_needed`로 정지(P:1177 Phase 6, §12.7-5). 규칙 확정은 D8 공동분석(P:1198) -- 회로위상 해석을 단독 판단하지 않는다는 원칙.

## Q3. §7.8 DOF 진단을 S1 방정식 그래프로 세면

### 무엇을 변수·방정식으로 세나 (D1 노드전압 정본 전제)

| 종류 | 항목 | S1 표현 |
|---|---|---|
| 변수 | 내부 노드전압 V_n | S1 노드 |
| 변수 | 소자 gm_id, L(동치류 단위), 가지 전류 | S1 엣지 속성 |
| 항등식(자유도 소비 없음) | vds=V(d)−V(s), vsb=V(s)−V(rail) | D1이면 정의. `stacked_vsb`(B25)도 여기로 흡수 |
| **등식** | diode `vds_eq_vgs`: `vgs_for_gm_id(gm_id,L,vds,vsb)=vds` → gm_id 종속(B16, P:731) | `vds_eq_vgs` 엣지 |
| **등식** | 미러 `equal_vgs`: 그룹 전원 VGS 동일 | `equal_vgs` 엣지 |
| **등식** | 직렬 KCL(같은 가지 전류), 노드 KCL | KCL 그룹 |
| **등식** | `matching{offset}` 동일값, `same_as`, `budget_ref` | 관계 엣지 |
| **등식** | 선언 전류 `value_amp`(B14), 배터리 루프 KVL(G4) | 이상소스 엣지 / KVL branch |
| **등식** | 보상 방정식(gm_1=2π·GBW·Cc 등), 종속 `Rz=1/gm2` | 보상 레지스트리가 엣지로 선언(G2: 계수기 본문 상수 금지, P:752) |
| **부등식** | gain ≥, cmrr/psrr ≥, area ≤, slack ≥ 0, PM ≥, 포화 | 자유도 소비로 세지 않음(B6) |

### B5 해소

사고19 픽스처 "한 vertical_stack의 vds 미지수 2 / KVL 방정식 1"(P:304). D1에서 레일 사이 k소자 스택은 내부 노드 k−1개가 변수이고 합=vdd는 항등식이 된다 -- 그러면 **스택별 자유도 = (k−1) − (그 스택 내부의 diode 등식 + offset 등식 + budget_ref 등식)**이 기계적으로 나온다. 이것이 B5가 요구한 "stack별 (vds 미지수 vs KVL+참조 등식, 랭크)" 축(P:720)이다.

### B6 해소

구조 rank는 **등식 엣지만**으로 계산한다. 부등식은 "잠재 활성"으로 목록만 내고, 실제 활성 여부는 해를 찾은 뒤 S3 아카이브의 제약여유(P:965)로 보고한다. hard stop은 **등식 over-determined 블록**에만(원 설계 H:1344-1348의 반복 금지 범위를 좁힘).

### 계산 방법과 출력

- 변수-등식 이분그래프의 최대 매칭 → Dulmage–Mendelsohn 분해로 **over / square / under 블록**을 증거 net과 함께 지목(원 설계의 "어느 목표끼리 같은 자유도를 다투는지"(H:1324-1327)가 블록 단위로 나온다).
- status는 전역 하나가 아니라 블록별: under = 최적화 여지(실패 아님, H:1328), over = 충돌 방정식 목록 + `review_needed`.
- C-c의 SCC 블록과 같은 그래프라 "반복이 필요한 곳"과 "자유도가 부족한 곳"이 같은 좌표계로 보고된다.

### 정직한 한계

- **구조 rank ≥ 수치 rank**. 사고19는 두 식을 대입하면 항등식 `b=b`만 나오는 **수치(대수) 종속**이었다(H:1347-1348). 변수 패턴만 보는 구조 매칭은 이런 종속을 독립으로 셀 수 있다 -- square 판정 블록에는 **여러 θ에서 Jacobian 수치 rank 확인**을 추가해야 한다. 단 한 점 수치 분류를 무효화 근거로 쓰지 말라는 규칙(P:990)에 따라 이것은 진단 보고용이지 캐시 키가 아니다.
- 부등식이 활성화되는 조합은 사전 진단으로 알 수 없다 -- 사후 보고만 가능.

## Q4. §7.6 T1/T2/T3를 S1v로 자동 분류할 수 있나 -- **조건부로 예**

### 규칙

metric m의 support set S(m)(실제로 읽는 소자·노드)과 S1v 블록 분할 {B_i}로:

- **T1**: S(m) ⊆ 한 블록(+그 블록 bias) 이고 MNA를 안 쓴다.
- **T2**: m이 Σ_k f_k로 선언되고 S(f_k) ⊆ B_k 이며, **f_k가 B_k 출력노드의 terminal 전부를 포함**한다. 선언은 합인데 출력노드 terminal이 빠졌으면 "위장 T2"로 표시 -- 파일럿 `gain_stages_sum`이 정확히 이것(B21, TJ:1883-1897 vs M10/M19).
- **T3**: S(m)이 블록을 가로지르는 SCC를 포함하거나 전체 MNA(`_full_circuit_response`는 gnd/excite만 고정하고 나머지 전부 자유노드, SR:5564-5574 → support = 회로 전체).

### S1v가 T3를 줄이는 방법(가설 -- 측정 필요)

- 모드별 뷰에서는 루프가 달라진다(P:939). Miller Cc는 DC에서 개방이라 **DC 차동 뷰**에서 루프가 아니고, 이상적 대칭 차동 여기에서는 CM 노드가 여기되지 않아 CMFB 루프가 **DM 뷰 경로에 안 들어올 수 있다**. 그러면 `gain_full_circuit_db`는 DM 뷰에서 블록 사슬(경계 노드 포함 two-port 연쇄)로 계산 가능해져 **블록 memo 가능한 T3**가 된다.
- 반대로 `cmrr_estimate_db`/`psrr_estimate_db`는 CM/supply 뷰에서 CMFB 루프와 bias-gen 체인을 통과한다(SR:5547-5550 docstring이 그 결합을 "하나의 선형계 안에 자동으로"라고 명시) → 기약 T3로 남는다.
- DC 뷰에도 class-AB M9a/M9b 2-사이클(P:939)이 있으므로 그 블록은 어느 뷰에서도 SCC다.
- 위 두 문장의 "빠진다/남는다"는 이 검토의 **추론**이며 실측이 아니다. 검증: DM 뷰 블록 사슬 gain vs 전체 MNA gain을 4개 회로에서 비교.

### 자동 분류가 안 되는 곳

- support가 **선언에 없고 코드 안에 있는** metric: `circuit_family` 폐형식(`_metric_cmrr_estimate` SR:5632-5641, `_folded_cascode_rout` SR:3040-3058). support를 선언에서 읽으면 B18(`devices` 없는 metric을 "무관"으로 분류, P:733)이 재발한다 → **C-a reader 기록**(평가 중 실제로 읽은 필드 계측, P:974)이 선행돼야 자동화된다.
- 회귀 기준: H:669-673의 파일럿 수동 분류(T1 4 / T2 1 / T3 8)를 재현하되, `gain_stages_sum`은 "위장 T2"로 **다르게** 나와야 정답이다(B21).

## graph 기반 재설계 핵심

1. **분할이 모든 것의 선행**: S1v DM 뷰 SCC 응축 DAG로 stage 블록·부하·tail을 θ-무관 1회 유도, 손 선언과 대조 후 `review_needed`(D8 공동분석).
2. **할당 = 조건부 블록 DP + 결합변수 좌표강하 + SLSQP polish**: 결합변수(K1 경계 부하, K2 공유 VGS, K3/K4 공유 스택)를 S1 엣지에서 기계 추출. 블록 표는 S2 memo, 좌표강하 이력·실패·Pareto는 S3.
3. **판정권은 전체회로 metric**(B21 ③ 변형), 할당은 부하 포함 블록 gain, 괴리는 블록별 귀속 metric.
4. **§7.5는 검사기가 아니라 D1 불변식 + 봉인 게이트**: 노드전압 정본이면 다중도달 불일치·스택 합·vsb 버전 혼재가 표현 불가, Vgs 검사는 `equal_vgs` 엣지 잔차. SPICE 교차검증만은 graph가 대체 못 함(독립 oracle, §14).
5. **§7.8은 등식 엣지 이분그래프의 DM 분해 + 수치 rank 보강**: B5(스택별 노드 자유도)·B6(부등식 제외)를 구조로 해소, 사고19형 수치 종속은 다중 θ Jacobian rank로 보강.
6. **T1/T2/T3는 support set × 블록 투영으로 자동 분류**, 단 C-a reader 기록이 선행 조건. 모드별 뷰로 DM gain의 T3를 블록 memo 가능 형태로 낮출 수 있는지는 4회로 측정으로 확인할 가설.

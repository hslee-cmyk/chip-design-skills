## 4. 판정

H1(높음) 때문에 커밋할 수 없다. H1을 fix1 형태의 물리(전류는 θ 기저, 루프 등식은 gm_id 하나를 종속)로 되돌리면서, 기저를 "KCL·이상원·미러로 정해지지 않는 가지 전류, y 분할·이상원 포함, 중복 계수 금지"로 정의하면 커밋할 수 있다. M1은 같은 변경에 넣기를 권한다.

## 2. 역병렬 pass 묶음 조건 (검사 2)

- 조건(규칙 3, 334): "두 소자가 같은 두 노드 사이에 서로 **반대 방향**으로 놓이고 **둘 다 gate가 그 뷰의 신호 경로 밖**이면 도달 순서로 CG/pass를 가르지 않고 N3.2-2의 pass 묶음 하나로 본다".
- 오발동 측정(7회로 전수, 같은 채널 노드쌍을 공유하는 소자쌍):
  - 파일럿: M9a/M9b(Vg15, Vop1) **반대 방향** ✓, M18a/M18b(Vg25, Vom1) **반대 방향** ✓, M6/M7(Vx, vdd)은 **같은 방향**이라 조건 밖(게다가 M7 gate `Vcmfb`는 CMFB 뷰에서 신호라 gate 조건도 불만족) ✓.
  - folded·nmcnr·two_stage·two_stage_ota_sf·sf_pushpull·pushpull: 같은 노드쌍을 공유하는 소자쌍 **0** → 발동 0. sf의 M18/M19는 노드쌍이 다르고 gate가 신호(Y)라 CD로 남는다. sf 복합 diode(M5/M6, M7/M8, M13/M14)도 채널 노드쌍이 달라 걸리지 않는다 ✓.
- 다른 규칙과의 정합: 셀 우선순위는 gate가 신호를 받는 경우(CS·CD)를 먼저 가르므로 묶음 조건은 그 뒤에만 적용된다 ✓. DEC-63 묶음은 **CD 셀만** 모으고 pass는 J10 예외로 빠지므로 두 묶음이 겹치지 않는다 ✓. 루프 분류 (0)~(4)는 이미 "pass 묶음 하나로 합쳐 2단자로 두고 묶음 내부 왕복은 폐경로에서 뺀다"(332)라 같은 묶음을 전제한다 ✓. DEC-64(G_vgs)는 gate–source 무향 엣지 기반이라 채널 방향과 무관하다 ✓.

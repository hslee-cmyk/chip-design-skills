### 검사 (a)~(d) 답

- **(a) 419·J10 수정이 J10 기본안·DEC-57·극점 노드 목록과 충돌하는가**
  - 극점 노드 목록은 "교류접지 아닌 모든 노드 + 속성"(91)이라, Vg15가 버퍼 출력에서 블록 내부 노드로 바뀌어도 목록은 그대로다. 충돌 없음.
  - DEC-57(234)의 "보상은 버퍼 출력 포함 극점 노드 목록"도 유지된다.
  - J10 기본안(독립 버퍼)에 "병렬 셀 입력을 잇는 pass 구간은 뒤 블록 흡수" 예외를 붙인 것 자체는 모순이 아니다.
  - 그러나 J3의 선택지 "stage 출력노드 = Vg15"와는 충돌한다(B4).
  - 419 문구가 "게이트" 기준이라, 기존 사이징 대상 회로 3개가 문자 그대로 `기록만`에 걸린다(B1).
- **(b) follower 사슬 묶음 규칙이 버퍼에 적용되는가**
  - `pushpull_follower_buffer`: 입력 넷 vin 하나에서 M3→M1, M4→M2로 갈라져 vout에서 합류한다. M5·M6은 gate가 교류접지인 load다. 90에 맞으므로 `계산 규칙 있음`이다.
  - `sf_pushpull_output_opamp` 경계 조건 (i)(N5·N13 고정)에서도 같다.
  - **전체 회로에서는 아니다.** N5·N13이 교류접지가 아니라서 M17·M20이 CS 셀이 되어 버퍼에 두 번째 입력이 생긴다(B3).
- **(c) 노드 구동 종류 source->drain 엣지가 셀 우선순위·엣지 비용과 모순되는가**
  - 루프 뷰 항목 안의 루프 탐지 그래프 정의라, stage 번호 BFS(310 비용)와 셀 분류(306)는 바뀌지 않는다. 모순 없음.
  - 다만 같은 루프 분류 문장에 (ii)/(iii) 중첩과 diode 자기 루프 문제가 있다(B2). 이 문제는 v59c의 (iii) 재정의 때 생겼고, 3차 검증에서 놓쳤다.
- **(d) IC11 Phase 4 대상이 DEC-60·DF-24·DF-26과 맞는가**
  - `two_stage_ota` 레일 vdd·gnd는 전환기 이름 집합에 들어 있고, DF-19·DF-26 교체(Phase 4)와 U-26 (a)(Phase 4, 790 착수 조건)도 맞다.
  - DF-24 red 픽스처("음전위 레일을 `supplies`에 둔 픽스처")가 IC11 (vdd 0.9, gnd −0.9)과 같은 입력이다.
  - I-C11 해소도 Phase 4에 있다. 모순 없음.
